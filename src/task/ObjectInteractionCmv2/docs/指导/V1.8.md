# ObjectInteractionCmv2 V1.8 指导：扩大正式训练 batch

用户确认停止未完成的 V1.7.1 batch=16 随机初始化 run，并保留其已生成的独立产物；以相同 V1.5 articulated 模型、数据、GRAB stride=1、ARCTIC stable stride=5..10、两域 1:1、GPU1、seed=42、16 epoch 和随机初始化，改用 `batch_size=64` 重新训练。

在新正式 run 前执行一次 B64 的真实 mixed-domain forward/backward/optimizer smoke。不得恢复 V1.7.1 的 checkpoint，不能修改 cache、GT、split、FK metadata、validation stride 或其他 GPU 的任务。若 smoke OOM 或出现 non-finite，停止而不启动正式 run。
