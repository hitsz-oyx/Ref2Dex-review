# ObjectInteractionCmv2 V1.7 指导：V1.5 从零正式二域训练

用户确认 V1.5 articulated model 从随机初始化进行 16 epoch 双域训练：GRAB 固定 stride `1`；ARCTIC 每个 transition 仅在 stride `5..10` 中确定性选择；两域按 `1:1` 采样。保持 V1.6 GPU1 calibration 的 batch=16、MANO 4096、seed=42、无 V1.4 checkpoint。

验证固定 stride=2，并按 GRAB/ARCTIC validation structured loss 的等权均值选择 `best.pt`。不改 cache、GT、split、FK metadata 或 queue。
