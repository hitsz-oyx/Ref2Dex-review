# ObjectInteractionCmv2 V1.4 指导：三域刚体交互训练

## 用户确认范围

用户在 2026-09-17 明确确认：本轮目标属于 `ObjectInteractionCmv2`，在 V1.3 刚体接口上加入
GRAB、ARCTIC、OakInk2 三域训练，并先补齐 OakInk2 导出失败帧再做 smoke。旧
`ObjectInteractionCm` 的三域改动已回退，不属于本指导范围。随后用户再次明确手点合同：MANO 每只手
固定 2048 点，Inspire 每只手固定 10135 点；双手合并后分别为 4096 和 20270 点。

## 研究目标

在保持 V1.3 刚体模型输出合同的前提下，验证同一套 swept interaction 接口能否读取三种数据域的
双手几何 cache，并以等概率进行训练采样。每个数据域的采样概率固定为 `1/3`，不按原始帧数或
序列数加权。

## 固定不变量

- 数据域：`grab`、`arctic`、`oakink2`；不加入 DexYCB。
- 交互定义：最终模型交互半径保持 `0.02 m`，局部 swept KNN 保持 `K=32`。
- 模型：继续使用 V1.3 `v1_3_rigid_only`；不加入 residual 分支、`p_effect` 预测或 effect loss。
- 坐标与监督：cache 的逐帧物体刚体位姿和直接 SE(3) 监督保持不变；不使用未来帧物体状态反推输入。
- decoder 兼容流：`hand_points_world.npy`/normals 保留左右各 1538、双手 3076 点，只用于兼容读取。
- 高分辨率训练流：`knn_hand_points_world.npy`/normals 是唯一训练手点输入，按显式 `hand_variant` 解释：
  `mano` 为每侧 2048、双手 4096；`inspire_f1` 为每侧 10135、双手 20270。3076 不能作为 V1.4
  高分辨率训练输入。
- 变长 batch：同一 batch 可以同时出现 MANO 与 Inspire；loader 只在 batch 内按最大 H 补零，并提供
  `hand_valid_mask`，模型和 swept KNN 必须屏蔽 padding。
- cache：三域必须有可审计的 schema/index/manifest；OakInk2 失败帧从原始 annotation 和静态物体
  几何补齐，不通过删除选择帧或插值掩盖失败。
- split：沿用现有各域 split/index；本轮不重划已有 GRAB/ARCTIC split。OakInk2 仅纳入其已有
  selection index 标记为 train 的 segment。
- stride：三域均为 30 Hz 几何 cache，训练允许 `1..10` 帧 stride；验证固定 stride `2`。实际
  transition 使用 cache 的 `source_frame_id`/`frame_time`，不能用连续数组位置替代有效帧。

## 当前 smoke 的 variant 选择

三域概率按 `grab/arctic/oakink2` 计算，和手型 variant 解耦。当前可用 cache 的 smoke 入口显式使用
GRAB MANO、ARCTIC MANO、OakInk2 Inspire；loader 仍支持 OakInk2/其他域的 MANO 4096 流，待对应
高分辨率 cache 完成后可只改 source 配置，不改模型或点数语义。

## 阶段边界

1. 先完成 OakInk2 193 个失败 segment 的原始帧回填，并生成 MANO/Inspire variant 明确的完整 cache
   manifest/index；旧的 3076 点试回填不得接入训练。
2. 再实现 Cmv2 三域 loader、variant 校验、stride 采样、严格等概率 sampler 和最小 smoke。
3. smoke 只证明接口、shape、finite、GT 重建和 sampler wiring；通过后再另行批准并启动大规模训练。

本指导不预先宣称跨域泛化或训练效果成立；效果结论需要独立的验证运行和 held-out 指标。
