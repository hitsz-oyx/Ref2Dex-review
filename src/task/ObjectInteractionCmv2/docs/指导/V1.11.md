# ObjectInteractionCmv2 V1.11 指导：OakInk2 MANO 全量导出与短 stride 二域训练

## 用户确认范围

用户于 2026-09-19 要求现在启动 OakInk2 MANO 全量导出，并并行从随机初始化训练 GRAB+ARCTIC 二域模型；两个域的训练 stride 均在 `1..3` 间采样。

## 固定边界

- OakInk2 导出使用已完成 selection 的全部 1849 段，生成每手 2048 / 双手 4096 的 MANO KNN32 cache；新建独立 output root，不覆盖 smoke、Inspire cache 或旧 queue。
- 二域训练使用现有 `two_domain_mano_split_seed42`，随机初始化、seed=42、batch=64、16 epoch、物体随机 1024/4096 点、二域 1:1 batch 平衡；不加载旧 checkpoint。
- GRAB 与 ARCTIC 训练 stride 都固定为离散集合 `{1,2,3}`；validation 保持 stride=2。
- GPU1 仅运行训练，GPU2 仅运行数据导出；任一 run 不停止、覆盖或等待无关用户进程。

## 禁止事项

- 不改变坐标系、单位、GT、split、cache schema、KNN32、MANO correspondence、模型架构、loss 或已完成数据。
- OakInk2 MANO cache 完成不自动加入当前二域训练；三域训练另行确认。
