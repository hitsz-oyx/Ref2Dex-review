# ObjectInteractionCmv2 V1.10 指导：数据与 cache 软链接导航层

## 用户确认范围

用户于 2026-09-19 确认在 `data/processed_data/` 下单独整理 Cmv2 所用数据，以规范命名的软链接区分输入数据与派生 cache。

## 目标与边界

- 新建 `data/processed_data/oicmv2/` 作为仅导航用途的入口；其中全部叶子均为软链接。
- 纳入 GRAB、ARCTIC 的 MANO 和 Inspire F1 输入，以及 OakInk2 已完成的 selection 输入；纳入已完成的 GRAB+ARCTIC MANO / Inspire cache。
- 不移动、重命名、删除或改写 NAS 上任何既有实体；不修改训练配置、index 内路径、split、schema、模型、checkpoint 或运行。
- OakInk2 当前没有完成态的 Inspire hand cache；不得把失败的 partial 输出作为正式 cache 入口。

## 命名不变量

- 数据域目录固定小写：`grab`、`arctic`、`oakink2`；手表示固定为 `mano`、`inspire_f1`。
- `data/` 仅容纳原始或中间输入，`cache/` 仅容纳可由训练/评估读取的派生 geometry/cache 根。
- 每个链接必须使用绝对 NAS target；链接 target 已存在且不经由新入口循环解析。
