# ObjectInteractionCmv2 V1.5 指导：ARCTIC 铰接对象首阶段

## 用户确认范围

用户于 2026-09-18 确认直接开始铰接架构实现。首阶段固定为当前 Cmv2 cache 已核验的
ARCTIC two-link / single-joint 合同：`L=2`、`J=1`；GRAB 保持 `L=1`、`J=0` 的刚体 fallback。

## 研究目标

将单 root 刚体路径扩展为结构化 root SE(3) 与 revolute joint motion，并以解析 FK 重建逐点物体 flow。
手-物交互证据仍只来自当前时刻几何与 hand future flow；future object state、future q 与 GT flow 仅用于
监督和 FK replay。

## 固定不变量

- 仅修改 `ObjectInteractionCmv2` 的新 V1.5 实现，不改变 V1.4 刚体 loader、模型、配置、训练、cache 或 checkpoint。
- ARCTIC 必须读取已有的 `obj_part_id`、`obj_articulation`、`obj_root_pose_world`；不得用兼容的 identity
  `obj_pose_world` 作为 root GT。
- GRAB sample 必须严格退化为 one link、zero joint，且解析 FK flow 与 root SE(3) reference 一致。
- 运行时必须保留 `link_valid_mask`、`joint_valid_mask` 与既有 `hand_valid_mask`；不能把 padding 或 link ID
  当作可学习的语义。
- 首阶段无 flow residual、无旧 `v1_3_rigid_only` checkpoint 自动加载、无 cache 重写、无正式训练。

## 阶段与闸门

本轮实现 loader/collate、解析 FK、link/joint graph、结构化 head 及 synthetic/Task-local smoke tests。
真实 cache 的 FK replay 与任何训练/benchmark 需在 V1.5 后续运行计划中另行确认；FK replay、坐标、单位、
point correspondence 任一失败均阻断训练。
