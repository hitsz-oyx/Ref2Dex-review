## 1. 目标与当前诊断

把 Cm 的监督单位从任意多帧 endpoint displacement 改为固定物理时域的一步局部转移：

```text
(O_t, H_t, ΔH[t→t+1]) -> Cm_t -> ΔO[t→t+1]
```

新生成的 GRAB geometric / DExplore RL 配对轨迹均为 30 Hz，且同名序列逐帧对齐。因此 V1.1
主任务固定 `delta_frames=1`、`delta_time_s=1/30` 秒；不把 future hand geometry、future contact、
phase label 或 `obj_flow_gt` 输入模型。长时域 endpoint 不进入主 Cm 训练，可在后续独立版本作为显式
horizon-conditioned auxiliary head 讨论。

当前 V1.0 实现与该目标有以下差距：

- `OakInk2RigidDataset` 只支持小型相邻帧 smoke，没有 GRAB / DExplore RL 全量 index、离线 KNN、
  sequence split 或 phase-balanced sampler；
- `LocalInteractionEncoder` 在运行时对完整 hand stream 执行 `torch.cdist`，不适合 batch 32 的
  1024×高分辨率 Inspire hand 搜索；
- 当前只有 2 cm fine-contact 路径，没有 2–5 cm approach context；
- trainer 只支持短 pilot，没有 YAML 配置、DDP、定期验证、best checkpoint、恢复和标准运行 manifest；
- 历史 V1.3 的训练时域为多 stride，其历史最佳数值不能直接当作 V1.1 一步指标。

## 2. 固定数据语义

### 2.1 输入与配对来源

使用已完成的只读导出：

- canonical GRAB：恢复当前右手表面、物体几何和参考物体 pose；
- geometric：提供同一 canonical 参考下的 Inspire 几何 retarget；
- RL：提供 teacher-policy 的 Inspire 实际 qpos 和动态物体 pose；
- geometric 与 RL 只允许在 `[373:391]` hand DOF 和 `[198:205]` object pose 上不同，其余列继续
  逐元素一致。

每个源分别生成局部样本，外层 source sampler 固定 `grab=0.5`、`inspire_f1=0.5`。同名序列的
source/split assignment 必须一致，防止一侧训练序列出现在另一侧验证或测试中。

### 2.2 一步 target

对每个可用帧 `t∈[0,T-2]`：

- 当前 object / hand geometry 均变换到 `object_pose_t` 坐标；
- `hand_flow = H_(t+1) - H_t`，以当前 object frame 表示；
- `obj_flow_gt` 由 `object_pose_t^-1 * object_pose_(t+1)` 作用到当前 object 点得到；
- `delta_time_s` 从源 `frame_time` 的相邻差得到并校验为 `1/30 s`，不只根据声明推算；
- rigid object 同时保存 `delta_xi_root_gt`，但 point-flow EPE 仍为公共主指标；
- object pool 固定 4096、运行时确定性采样 1024，单位为米，法向与点逐行对应。

### 2.3 局部邻域与 phase 标签

离线对当前帧和下一帧分别计算手物最小距离，保存 4096 object pool 到高分辨率 hand surface 的
`K=32` 邻居索引。模型使用两个同源但分开的区域：

- `0–2 cm`：fine interaction edge，保留完整相对位置、法向和 hand-flow 分量；
- `2–5 cm`：coarse approach context，只编码距离、接近速度和聚合 hand motion，不宣称为接触；
- `>5 cm`：不产生局部交互 edge。

离线 phase label 仅用于采样和分层评估，不作为模型输入：

```text
contact_establish: d_t > 2 cm and d_(t+1) <= 2 cm
release:           d_t <= 2 cm and d_(t+1) > 2 cm
approach:          d_t > 2 cm, 2 cm < d_(t+1) <= 5 cm, and d_(t+1) < d_t
manipulation:      d_t <= 2 cm and d_(t+1) <= 2 cm and object-flow RMS >= 1 mm
contact_static:    d_t <= 2 cm and d_(t+1) <= 2 cm and object-flow RMS < 1 mm
free:              remaining local transitions
```

`1 mm / step` 是待确认的 effect/no-effect 工程阈值；在任何全量 cache 或训练前，先用 train split
报告其分布和各 phase 数量。若需修改阈值，必须回到本计划协商，不根据 val/test 指标后验选择。

训练采样先以 source 0.5/0.5 平衡，再在每个 source 内对
`no_effect(contact_static+free)`、`establish(approach+contact_establish)`、`manipulation`、`release`
四组按 0.25/0.25/0.25/0.25 采样。任何组为空时停止，不静默回退或重复其他组。

## 3. Split 与防泄漏合同

优先恢复 V1.3 已冻结的 GRAB sequence-level seed-42 assignment，并将同名 geometric/RL pair 绑定到
同一 split。先生成包含原始 split fingerprint、与本次 656 条 selection 的交集/差集、每 split/source
序列数和帧数的只读报告。

当前工作机未发现历史 V1.3 `index.json` 与冻结 best checkpoint；因此在 split fingerprint 和 baseline

与 V1.3 完成直接对比。不得用当前 V1.4 工作树或其运行静默替代 V1.3 基线。

## 4. Cache 与 manifest

新增独立 `object_interaction_cmv2/local_transition_v1_1/` cache，不修改或覆盖 V1.0.3 导出。每条
sequence/source 至少保存：

```text
geometry/
  obj_points_pool_world.npy        [T,4096,3] float32
  obj_normals_pool_world.npy       [T,4096,3] float32
  obj_pose_world.npy               [T,4,4] float32
  hand_points_world.npy            [T,H,3] float32
  hand_normals_world.npy           [T,H,3] float32
  obj_knn_indices.npy              [T,4096,32] uint16
  obj_knn_distances_m.npy          [T,4096,32] float16/float32（pilot 后冻结 dtype）
  hand_min_object_distance_m.npy   [T] float32
  frame_time.npy                   [T] float32
  phase_label.npy                  [T-1] uint8
  manifest.json
```

根 index 记录 schema、source、split、pair id、frame count、fps、KNN/半径、phase 定义、输入 run manifest
hash、工具 commit、worker assignment 和验证摘要。worker 只写自己的 sequence 目录；finalize 检查完整、
无重复、可恢复且不含临时文件后再原子写 index。

## 5. 模型与 trainer 修改

### 5.1 Dataset / sampler

- 新增 V1.1 dataset，不静默改变 V1.0/OI-Cm loader；固定相邻帧，拒绝 `stride != 1`；
- 从缓存 4096 pool 确定性采样 1024 点，并同步 gather 2 cm/5 cm KNN edge；
- 有效 hand ID 去重后动态 padding，padding 不参与 feature 或 loss；
- phase-balanced sampler 的 epoch/seed/state 进入 checkpoint，恢复训练后样本流一致；
- batch 输出 `source`、sequence/frame ID、`delta_time_s`、phase 和 sample validity，便于逐样本审计。

### 5.2 Model

- 保留 V1.0 完整 object geometry、grounded tokens、structured `SE(3)` effect 和 FK flow 路径；
- fine-contact encoder 继续使用 2 cm edge；新增轻量 coarse approach encoder 读取 2–5 cm edge；
- `delta_time_s` 可用于把 hand displacement 转成 velocity/twist scale，但不替代 phase-local sample；
- 禁止在 forward 中对 1024×完整高分辨率 hand stream 执行 `torch.cdist`；
- token-only、structured-only 与 hybrid 对照使用相同 dataset、sampler、初始化 seed 和训练预算；
- residual flow 默认开启并保持 V1.0 正则；若 residual 长期承担主要预测量，按停止条件记录。

### 5.3 Trainer / config

新增 Task-local YAML 配置与 runner，冻结公共预算：

```text
seed: 42
batch_size: 32
max_steps: 202300
lr: 3e-4
weight_decay: 1e-4
source_probabilities: {grab: 0.5, inspire_f1: 0.5}
delta_frames: 1
eval_delta_frames: 1
metric_for_best: val/obj/flow_epe_mm
lower_is_better: true
```

正式运行写 `run_manifest.json`、`metrics.jsonl`、`train.log`、`checkpoints/latest.pt` 和
`checkpoints/best.pt`。checkpoint 内嵌完整 config、schema fingerprint、split fingerprint、模型 variant、
optimizer/scheduler/scaler、sampler、step/epoch 和 RNG state。只使用当时空闲且经检查的 GPU，不停止或
抢占其他任务。

## 6. 对照与指标

主比较必须在同一一步 local-transition validation/test 集上执行：

1. 冻结 OI-Cm V1.3 checkpoint，在 `stride=1` 下重新评估；
2. Cmv2 structured-only；
3. Cmv2 token-only；
4. Cmv2 hybrid。

所有模型报告相同的 point-flow EPE/RMSE（mm）、root translation error（mm）、rotation geodesic error
（degree）、相对 zero-flow 改善，并按 source、phase、sequence macro 和 frame micro 分层。sequence
cluster bootstrap 的 95% CI 固定 seed 42。历史 V1.3 `6.516671 mm` 只作为旧 multi-stride/eval-stride-2
背景，不与一步指标直接排优劣。

## 7. 执行顺序与审批闸门

1. 只读恢复/核对 V1.3 split、checkpoint 与本次 656 pair 的覆盖报告。
2. 实现 cache schema、phase 计算和定向测试；先构建每源 2 条 sequence pilot。
3. 检查相邻时间、坐标、KNN、phase 分布、GT 刚性和无 future 泄漏。
4. 实现 dataset/sampler、fine/coarse encoder 和 trainer；跑 CPU/GPU forward/backward/checkpoint smoke。
5. 用户确认 pilot 与 phase 分布后，执行全量 cache（L3）。
6. baseline checkpoint 在同一 local test 上冻结评估；再启动三个 Cmv2 variant 的同预算训练（L3）。
7. 生成最终 experiment/activity 记录，工程 smoke 与科研比较分别下结论。

本草案获用户确认并改为 `final` 前，不执行第 2 步以后的代码、cache 或训练动作。

## 8. 验证与停止条件

必须验证：

- pair 两侧 sequence/frame 一一对应，split 以 pair 为单位且 fingerprint 可复现；
- 所有相邻 `delta_time_s` 为 `1/30 s`（容差写入 manifest），无跳帧或跨序列样本；
- object/hand frame、米单位、法向、四元数顺序与刚体 flow 解析一致；
- KNN index 范围、exact 距离抽查、2 cm/5 cm mask 与 offline cache 一致；
- phase label 只进入 sampler/metrics，不进入 model batch 的可学习输入；
- 无效/空接触样本 finite，padding 不进入 attention/loss，forward 无完整高分辨率 `cdist`；
- checkpoint round-trip 与断点恢复后的采样顺序一致；
- Task-local pytest、tiny overfit、单 GPU smoke、`git diff --check` 和 activity link audit 通过。

出现 GT/future 泄漏、split 污染、坐标/单位不一致、相邻时间不成立、phase 空组、非 finite、OOM、
resume 不一致或 baseline 无法恢复时立即停止。cache/smoke 通过只属于工程 `SUPPORTED`；模型效果按主指标
与置信区间判为 `SUPPORTED`、`REFUTED` 或 `INCONCLUSIVE`。
