## 已确认范围

- 不等待 ARCTIC Inspire：训练源固定为 GRAB/MANO、ARCTIC/MANO、OakInk2/MANO、GRAB/Inspire、OakInk2/Inspire 五组；运行中不加入新 cache。
- 全局 MANO:Inspire=1:1；MANO 内 GRAB:ARCTIC:OakInk2=1:1:1；Inspire 内 GRAB:OakInk2=1:1。
  每卡64中固定32 MANO、32 Inspire；MANO整数余数按step轮换，三个step内精确均衡；两rank同组数量一致、独立随机抽样。
- GRAB/ARCTIC MANO 保持 seed42 既有 train/val/test；GRAB Inspire 按 sequence ID 核对同一划分。
- OakInk2 原始录制序列按 seed42 固定抽取10%（向上取整）作为 val，同录制的全部 segment 和两种 variant 同组，避免片段/手表示跨 split 泄漏。
  不重写物理 cache 的 split，只生成独立 index/manifest；OakInk2 test 保持空。
- 训练stride稳定选择于{1,2,3}，validation 对五组各自完整遍历stride1/2/3；OakInk2 严格保留1e-4秒连续性门槛。
- 初始化固定为 `cmv2_v111_articulated_random_init_stride1to3_formal_20260919T075300Z/best.pt`，核对架构并strict加载model权重；不恢复optimizer、epoch、step或旧best metric。
- 模型仍为 `v1_5_articulated_fk`；GRAB/OakInk2 刚体 L=1/J=0，ARCTIC L=2/J=1。保留原loss、1024/4096物体采样、KNN32、2cm邻域、GT、坐标/单位和checkpoint解释。
- GPU1+3 DDP，每卡64、全局128，16 epochs，seed42、Adam lr=0.001、FP32，不线性放大学习率。
  epoch采样预算为全部有效train transition数/global batch向上取整，按已确认组比例有放回抽样。
- validation 输出每个domain×variant×stride的loss、EPE mm、预测/GT模长、有效点角度和计数；best按stride等权、组按训练概率加权的validation loss选取，不与旧best数值混比。
