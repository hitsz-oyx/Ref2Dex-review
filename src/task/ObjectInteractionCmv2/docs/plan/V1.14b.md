## 1. 改变与保护项

改变：补齐 OakInk2 raw bundle 到既有 selection、Stage3 几何和 part-adapter 合同的可移植入口；修复
GRAB/ARCTIC/OakInk2 左右手 Inspire retarget 的本机路径；新增使用 V1.14a 模型/checkpoint 的训练 runner，允许从
`grab|arctic|oakink2 × mano|inspire_f1` 六组中显式配置 active groups，本地 pilot 可只启用 GRAB 两组。

保持：每手固定 2048、`left_then_right`、1024 物体点、KNN32、2 cm、30 Hz、GT、坐标、米制单位、loss、
stride 和随机初始化不变；旧 cache、checkpoint、runner 与运行产物只读。active groups、权重和路径必须进入配置与
manifest，不把局部 smoke 当作正式五/六组训练结论。

## 2. 实施与验证

1. 将便携 raw subset 校验 SHA 后迁入 `data/raw_data/ObjectInteractionCmv2/`，不提交数据。
2. 为 OakInk2 物化可审计的静态部件点/法向、帧位姿、距离与 selection，使现有双手 MANO/Inspire producer 和
   part-adapter 可复用；不另定义 selection 或 part 语义。
3. 让 bilateral Inspire retarget 通过显式配置定位 dex-retargeting 与 URDF，不依赖机器硬编码路径。
4. 新增 V1.14a runner/config 校验、动态 active groups、归一化权重、可配置 GPU，并保留旧 V1.12 runner。
5. 增加 Task/process 定向测试；对三域逐手形状、左右顺序、身份摘要、KNN 范围、坐标/单位和 runner
   checkpoint 拒绝门禁做验证；执行 `python tools/verify.py --changed` 与 `git diff --check`。

本计划授权实现和有界 fixture/smoke；不授权 full cache build、长时数据处理或正式训练。

既有正式指标，以及跨机器绝对路径泄漏。任一合同或 parity 失败即停止扩大运行。
