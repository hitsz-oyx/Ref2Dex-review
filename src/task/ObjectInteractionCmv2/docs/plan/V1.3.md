## 2. 已核对的直接 GT 合同

GRAB cache 提供每帧 `obj_pose_world.npy`、逐点物体几何和固定 `obj_point_id`。对相邻帧的 world
刚体位姿 `T_t=[R_t,p_t]`、`T_{t+1}=[R_{t+1},p_{t+1}]`，当前物体坐标系中的监督为：

```text
R_gt = R_t^T R_(t+1)
t_gt = R_t^T (p_(t+1) - p_t)          # m；非 COM 位移
P_(t+1)^current = R_gt P_t^current + t_gt
```

新增 Task-local 样本字段 `delta_translation_gt [3]` 和 `delta_rotation_gt [3,3]`，保留原
`obj_flow_gt [1024,3]` 不变。只有姿态矩阵正交、行列式、finite、点对应和重建误差均通过，样本才
参与直接监督；不从未来物体点反推 GT 再输入模型。只读抽查 train/val/test 各两条、每条首/中/末
相邻帧：该公式重建下一帧物体点的最大误差约 `1.3e-7 m`；全量验证仍须在实施阶段执行。

直接损失拟按物理尺度归一：平移误差除以 `0.02 m`；旋转 geodesic 乘当前物体 RMS 半径后除以
`0.02 m`，使角误差对应表面位移；点流 SmoothL1 仍报告原始米值，训练项按相同 2 cm 尺度归一。
初始权重拟为 `lambda_t=lambda_R=lambda_flow=1`。这些是待定稿的研究变量，必须冻结在 V1.3 配置与
运行快照中；不按 val 结果临时改权重。接近零角度和接近 pi 时用稳定的 SO(3) geodesic 实现，
测试有限梯度与数值边界。

## 3. 模型结构

1. 全量物体几何特征 `g_i` 用带 mask 的 attention pooling 得到 `G`；有效局部接触 `c_i` 单独
   attention pooling 得到 `I`。无接触时 `I=0`，全量物体几何仍保留。
2. token 分配改为逐物体点对 token 的竞争 `softmax_k(f(c_i,p_i,n_i))`，只让 active 点参与；按
   赋值总量得到 `token_mass`，加权得到 token feature、物体坐标 anchor 与 normal。没有 active
   点时 token、anchor、mass 和 mask 均为零。`token_mask = token_mass > eps` 只表示非空；普通
   softmax 不保证不会复制 token，需另报告 mass 分布和 anchor 分离度，不预先宣称已消除 collapse。
3. 将内部 `[z_k, anchor_k, normal_k, log(mass_k+eps)]` 编码成空间 token，以 `MLP([G,I])` 为
   query 作带 token mask 的 cross-attention，融合后的结果只预测 `delta_xi_root`。
   空接触时 cross-attention 有定义且只保留 direct/global 路径。
4. V1.3 刚体路径强制 `use_residual=false`；`obj_flow_pred=obj_flow_structured`。为保持诊断接口，
   `obj_flow_residual` 可以显式输出全零，但不得有可训练的常量 residual head。新 checkpoint
   schema/architecture 标识必须阻止误加载 V1.2 及含 `p_effect` 的早期 V1.3 checkpoint。
5. 内部 token 宽度保持 128；新增独立只读投影 `cm_tokens [B,16,32]`，连同 anchor/normal/mass/mask
   作为未来控制接口。V1.3 不接入 PPO，也不宣称 token 跨手型迁移性能。融合层只为刚体预测
   服务；无接触 token 输出为零。

## 4. 特征尺度与输出合同

拟对接触相对位置、当前/末端/swept 距离、手点位移及其法向/切向分量按固定 `0.02 m` 尺度归一；
`delta_time_s` 按 `1/30 s` 归一，并同时提供按 `delta_time_s` 计算的手点速度的无量纲形式。
物体全局坐标按当前 1024 点相对质心的 RMS 半径 `s_o` 缩放，`log(s_o/0.02)` 另传给全局分支，
不丢失真实物理大小。`s_o` 只从当前物体点计算，空/退化几何 fail-fast；所有缩放常量写入配置。
本轮保持硬 2 cm 边资格不变，只改变有效边的数值输入。

用户明确要求本版不预测 `p_effect`。V1.3.2 不包含 `effect_logit`、effect 概率输出、
effect BCE 项或 effect 标签阈值；总损失仅为平移、旋转和点流三项。用于融合的 MLP 命名为
`fusion_head`，不具有 effect 分类含义。先前只读扫描的 `0.28 mm` 估计仅保留在诊断活动
记录中，不写入配置、不用于标签或训练闸门。若以后重新引入 effect 预测，需另行协商。
GT 位移只用于监督，不进入模型输入。

## 6. 回滚与暂停条件

撤销 V1.3 Task-local 增量和本 Task 指针即可回到已提交的 V1.2 实现；V1.3 新运行使用独立 NAS
目录，不覆盖 V1.2 smoke、checkpoint、输入 cache 或其他 Task 运行。

若全量 pose/point correspondence 失配、GT 定义需变更、训练数值非 finite、token 空掩码异常、
V1.2 或早期 V1.3 checkpoint 被误加载或资源超预算，则停止相应阶段并回到计划协商；不得
临时重新加入 `p_effect`、改物理半径或扩大到 DexYCB。

## 7. GRAB 正式训练（用户在 2026-09-17 明确批准）

本节是原 §5“正式训练单独获批”的定稿增补，批准依据为用户在完整范围、设备、停止与评估方案后回复“可以”。
按 `V1.3.3` 记录独立配置和运行。先定向提交 V1.3 实现及本计划，使运行 `base_commit` 指向真实代码；
已存在的其他 Task 改动、用户指导文件、历史运行、输入 cache 不进入该提交。

1. 资源校准：从随机初始化、GRAB train 前 3 条序列，batch 16、最多 8 optimizer steps、GPU1、
   seed 42，沿用 V1.3.2 的 Adam 学习率 `1e-3`。仅检查 OOM、finite、每步时间与显存，不据此
   选择权重或调整研究超参数；校准 checkpoint 不作为正式训练初值。
2. 校准通过后另开全新运行，从随机初始化训练 **全部 GRAB train**：1068 条序列、326722
   个有效相邻帧配对；batch 16、`ceil(326722/16)=20421` optimizer steps，随机顺序、
   seed 42、Adam 学习率 `1e-3`、单 GPU1、每 1000 步及终态保存 checkpoint。
   `max_duration_s=14400`，到时保存当时最新 checkpoint、标记 `STOPPED` 并保留进度；
   OOM、nonfinite 或数据合同失配时标记 `FAILED` 并停止，不自动改 batch/半径/loss。
3. 训练达到 20421 步且状态为 `COMPLETED` 后，以终态 `latest.pt` 评估全部 GRAB val
   134 条、40762 对。val 不进入训练、不调参；本轮不运行 test。若因时间或失败停止，
   先交接状态与证据，再决定是否恢复或评估已有 checkpoint。
4. 训练和评估各用独立 `outputs/ObjectInteractionCmv2/<run_id>/`，保存解析配置、
   `run_manifest.json`、逐步 metrics、训练日志和 checkpoint；activity 记录终态、
   `last_step`、`last_epoch`、best/latest checkpoint 与证据。训练仅保留 latest，
   不宣称已选出 best。科研结论待完整 val 证据后再判断，资源校准与训练曲线均不替代 held-out 评估。
