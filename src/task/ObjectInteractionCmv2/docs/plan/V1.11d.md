## 范围

- 在 `ThreeDomainTransitions` 构建 OakInk2 transition row 时，沿用既有稳定 seed 先选择该样本的实际 stride；仅接受 `frame_time[t + stride] - frame_time[t]` 与 `stride / effective_fps` 相差不超过 `1e-4 s` 的 row。
- 记录被过滤的 OakInk2 timeline-gap transition 数，并增加 stride 1/2/3 定向测试。

## 保持不变

- 不修改 selection、原始数据、MANO/Inspire cache、sequence ID、split、坐标、单位、GT、KNN、模型、loss 或 checkpoint。
- 不改变 GRAB/ARCTIC 的 row 构造、stride 选择或有效 transition 集合。
- 不重导 OakInk2 数据；当前二域训练不读取 OakInk2，保持不受影响。

## 风险、验证与回滚

- 风险：OakInk2 的可用 transition 数会减少，且仅在实际选定 stride 跨越时间断点时发生；这正是阻止长时距被误作短 stride 的目标。
- 验证：合成 cache 在单一 gap 下，stride 1/2/3 分别过滤 1/2/3 个跨 gap transition；连续样本与现有 GRAB/ARCTIC 测试保持通过。
- 回滚：反转本计划关联的 loader、测试、文档提交即可恢复原 row 集合；不删除或变更任何 cache。
