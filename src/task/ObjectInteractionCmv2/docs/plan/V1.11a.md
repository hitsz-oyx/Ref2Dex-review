## 验证与停止条件

- 启动前确认 input index、source root、MANO/dex-retargeting asset、GPU2 及目标根状态；已有完整段必须通过 producer 的 `--resume` 验证。
- 每个完成 cache 验证 index/count、双侧高分辨率手点数、KNN32、KNN index 上界、有限值、递增帧 ID 与无 failures。
- 任一 producer 报 non-finite、schema、KNN、坐标或写入错误时，保持已有原子段并以 `FAILED` 终止对应 run；不启动后续依赖步骤。
