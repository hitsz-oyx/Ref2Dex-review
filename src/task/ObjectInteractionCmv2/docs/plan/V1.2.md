## 1. 目标与优先级

首轮只使用 GRAB 训练 action-conditioned ObjectInteractionCmv2。当前帧物体点到**候选手点运动
线段**的最短距离决定局部交互资格；不使用指导中建议的 2–3 cm 软过渡权重。GRAB 训练对固定
`stride=1`。ARCTIC、OakInk2、多数据源混合和铰接物体均不属于 V1.2 首轮实现/训练范围，后续另行
协商计划；此前提出的 ARCTIC `5..10` 与 OakInk2 `15..30` stride 只保留为未来方向，不在本版实现。

本计划只读取 GRAB 输入 manifest/index 及配置提供的路径；代码中不写死 NAS、数据集产物版本或
运行目录。不得回退到 Inspire 手点；训练输入只采用固定 correspondence 的 MANO2048 点流。

V1.1 plan 仍为未定稿草案，未在该计划下执行实现；V1.2 不继承其二源 0.5/0.5 和
2–5 cm coarse halo 设定。GRAB 相邻帧合同以本计划为准。V1.0 架构快照保持原样，不在本任务中覆盖。

## 2. 数据与时间合同

| 数据集 | 主训练 stride（30 Hz 帧数） | 目标时间跨度 |
| --- | --- | --- |
| GRAB | 固定 `1` | 约 33 ms |

只在同一连续 GRAB 序列内选择 `(t,t+1)`；缺帧或序列末尾无合法配对时显式计数并排除，断点恢复
应产生同一配对顺序。`delta_time_s` 必须来自输入的权威时间轴并进入模型条件与输出记录，不得仅用
`1/30` 代替时间轴校验。

训练样本为当前物体几何/法向、当前双手高分辨率几何/法向、候选手点流
`H_(t+1)-H_t`、`delta_time_s` 和监督 `O_(t+1)-O_t`。离线训练可从同序列未来手状态构造
候选动作流，但模型输入**不得**包含未来物体点/pose、GT object flow、phase 标签或由未来物体
决定的接触 mask。推理时 `hand_flow` 由提出的手部动作生成，保持相同输入语义。

GRAB 数据源由 Task-local 配置声明 `{name, index, manifest, stride_policy}`；loader 根据 manifest 验证
schema、坐标系、单位、左右手顺序、手点数、object point correspondence、split 和时间轴。路径可以
是任意有效挂载位置，resolved 路径及 manifest/hash 写入运行快照。输入合同固定为 MANO KNN 流每侧
2048、双手 4096 点；不得读取 Inspire 手流。decoder 流每侧 1538、双手 3076 点，也不能与训练用
MANO2048 KNN 流混用。

现有顶层 index 同时包含 GRAB/ARCTIC，adapter 先按显式配置 `dataset=grab`、`source=mano`
筛选，再验证所选条目的 `object_representation=rigid_se3`；不重写共享 index，不因其包含已排除的
ARCTIC 条目而读取这些条目的几何。保留 GRAB 原 train/val/test 成员，禁止通过重新随机划分达到
GRAB-only。`frame_time` 的 float32 舍入误差用数值容差校验，同时核对原始帧号步长与 120→30 Hz
采样合同；缺帧不能被容差吞掉。world 数组中两帧的几何统一变换到当前帧 `object_pose_t` 后构造流。

## 3. Swept 距离与模型输入

对当前物体点 `o_i`、当前手点 `h_j` 和候选流 `v_j`：

```text
alpha = clamp(-dot(h_j - o_i, v_j) / max(dot(v_j, v_j), eps), 0, 1)
d_sweep(i,j) = ||h_j + alpha * v_j - o_i||
```

零流时退化为当前点距。参与局部交互的硬条件为 `d_sweep < 0.02 m`，沿用当前 V2 模型的 2 cm
物理半径和严格小于语义；不额外叠加 2–3 cm soft halo。现有 cache 的静态候选 mask 使用 `<=`，
因此也不能复用它替代本版 swept 判定。对每个运行时物体点，按 swept 距离从
**完整有效 4096 手点流**选最近 `K=32` 候选，随后应用硬条件。只用当前帧 KNN32 会漏掉从远处
掠过物体的手点，因此现有离线 `obj_knn_indices` 只能用于读取合同/对照，不能代替 swept 选边。
手点流跨帧 correspondence 必须由固定 MANO2048 采样保证；任何点顺序不一致时拒绝样本。

物体的 1024 个运行时点始终进入全局几何分支；`has_interaction` 只控制局部边及 contact token，
不从全局物体点集中删除点。边特征至少包含当前相对位置/距离、末端距离、swept 距离、法向、
手点流的法向/切向分量和 `delta_time_s`。不使用未来物体位置判断边资格。空接触样本的局部特征为
零且 forward/backward finite。

全量 `1024×4096` swept 距离在训练时按 object/hand 维分块计算 top-32，限制峰值显存；
先在小样本上用不分块 brute force 校验结果和 tie 规则，再以目标 batch 测量吞吐/显存。
若无法满足预算，暂停并回到计划协商，不静默退化为当前帧 KNN 或软近似。

## 4. 首轮刚体 effect 边界

V1.2 首轮只使用 GRAB 刚体样本，沿用当前 `root SE(3)` effect head，不新增 part/link 或关节 effect
合同，也不声称支持铰接对象。`obj_flow_gt` 的米单位、当前 object frame、点 correspondence、左右手
语义和 train/val/test 边界保持不变。若 GRAB manifest 中出现不满足单刚体合同的样本，显式拒绝并
计数，不用 residual head 吸收结构不匹配。

出现 split 污染、时间轴不连续、MANO2048 点对应失败、Inspire 输入混入、GT 泄漏、非刚体样本、
