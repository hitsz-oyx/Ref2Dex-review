## 2. 首版模型合同（用户已确认并冻结）

### 2.1 Cm window

首版取 `K=4`，每个窗口只在一个序列内、按连续 30 Hz source frame 构造：

```text
C_t ... C_{t+3},       C_tau      : [16, 32]
A_t ... A_{t+3},       anchor_pos : [16, 3]
                        anchor_n  : [16, 3]
```

建议把 OICM 产生每帧 Cm 时的 source hand-flow 固定为 `t -> t+1`（stride=1），避免把 OICM 训练中的
`1..10` 可变 horizon 混成一个没有明确时间单位的 window。窗口边界只保留完整的 `K` 帧，不跨序列拼接，
不在开头做零填充。

每帧 token 使用：

```text
x_{tau,k} = MLP([C_{tau,k}, anchor_pos_{tau,k}, anchor_normal_{tau,k}]) + E_time(tau-t)
```

不加入 slot-ID embedding，也不做跨时间 slot 对齐/slot tracking；时间窗是带时间标记的 interaction
token set，以避免 SlotAttention permutation ambiguity。

### 2.2 首版 readout：Temporal-D2

按用户确认，首版直接采用指导中的 Temporal-D2，不做逐帧 pooling，也不做跨时间 slot tracking：

```text
Cm/anchor/time -> K*16 spatio-temporal tokens (Key/Value)
当前 Inspire state s_t -> 当前 link/state queries
future-step embedding E_future(h) 与当前 queries 融合
每个 future-step query 对全部 K*16 tokens 做 cross-attention
每个 h 的 link/query features -> q_finger + wrist output head
```

具体实现保持以下不变量：

- Cm token 只加相对时间 embedding，不加 slot-ID embedding；
- 当前 Inspire state 通过固定 Inspire URDF FK 生成 link-local query 特征，query 只表达当前
  target-hand state，不包含未来 target GT；
- `h=1..K` 使用独立 future-step embedding，输出未来 K 步 reference；
- 不在线追踪 `c_{t,k}` 的 slot identity；attention 自行完成空间/时间匹配；
- 只执行 `h=1`，下一时刻使用新的当前 state 和新的 Cm window 重新预测。

这样首版同时验证“Cm window + state-aware cross-attention”的完整指导假设；若需要 D1 作为消融，另建
独立配置/实验，不改变本 Task 的主实现合同。

### 2.3 q / wrist 输出拆分（已冻结）

为了与 Dexplore 的真实 action 语义一致，首版不把 18 个 native 数值全部当作独立 q，也不重复回归
wrist：

```text
q_finger_real : 6 维 native Inspire 独立手指 DOF
                native indices [6, 8, 10, 12, 14, 15]
wrist_state   : 6 维 [x, y, z, rotvec_x, rotvec_y, rotvec_z]
                native indices [0:6]
```

native mimic indices `[7, 9, 11, 13, 16, 17]` 在 target view 和可视化时按 Dexplore 固定耦合规则由
独立 q 重建；同时保留完整 18 维 native q 作为审计/指标字段。这样模型输出与当前 CmDecoder 的
“独立 finger q + wrist 运动”结构相近，但能够覆盖 Dexplore RL 的 18-DOF 目标。

腕部 GT 不从物体 pose 冒充。由 RL native q 经 Dexplore Inspire right URDF FK 得到 `T_wrist_world`，
再按冻结的目标坐标合同得到当前/未来 wrist state。必须在 sidecar manifest 中记录 URDF 路径和 SHA256、
native→URDF 映射及 `base_link`/wrist link 选择；若 FK 不能唯一恢复 wrist pose，则在数据闸门停止，
不得写入常数 wrist GT。

### 2.4 horizon 目标和执行

建议每个窗口预测未来 `K` 个状态：

```text
D(s_t, C_{t:t+K-1}) -> [q_{t+1:t+K}, DeltaT_{t->t+1:t+K}]
```

其中 `DeltaT` 为当前 wrist 到未来 wrist 的 SE(3) 相对量，平移单位 m、旋转用 rotvec 单位 rad；
q 可以采用 `q_{t+h}-q_t` residual，最终通过当前 state 恢复绝对 q。loss 对近端 horizon 权重更高，
默认 `w_h = 0.8^(h-1)`。推理/可视化只执行 `h=1`，然后用真实或上一轮预测后的当前 Inspire state
重新构造下一窗口，符合指导定义的 receding-horizon 执行。

原始首版合同不输出点流；该约束已由第 11 节用户追加批准的 point-flow supervision 修正覆盖。当前
训练仍不做 point-flow→q fitting，而是保留 q/wrist 输出并通过可微 FK 生成点流。

## 4. 训练和损失计划

训练时冻结完整 OICM（包括 slot encoder、anchors 和 flow heads），只更新 CmDecoderv2 时空 token
embedding、state/link query encoder、cross-attention 和 output heads。每个 RL-Inspire train sample 同时提供：

```text
当前 target state s_t                 # 仅 RL train/val 有 GT
Cm window C_{t:t+K-1}                 # 由同一 source 序列 hand-flow 在线/可审计生成
target q/wrist states for t+1..t+K   # 由 RL q + URDF FK 得到
target Inspire surface points for t+1..t+K # 与 geometry cache 相同固定 1538 点
```

当前批准的点流损失（替代历史 q/wrist 直接损失）：

```text
F_hat_h = FK(q_hat_h, wrist_hat_h) - P_current
F_gt_h  = P_gt_h - P_current
L = sum_h w_h * SmoothL1(F_hat_h, F_gt_h; beta=0.005 m)
```

点流 loss 在 `object_pose_t` 中计算，q/wrist 误差只作诊断指标；`w_h=0.8^(h-1)`，active-only
supervision mask 后重新归一化。q residual、wrist translation 和 rotation 的旧直接 loss 仅作为历史
baseline 合同，不再参与当前版本反向传播。

smoke 关闭 state perturbation；正式训练打开零均值 Gaussian perturbation：wrist translation 标准差
`0.005 m`、裁剪 `±0.015 m`，wrist rotation 标准差 `5°`、裁剪 `±15°`，每个独立 finger q 标准差
`0.05 rad`、裁剪 `±0.15 rad`。所有幅度作为配置和 manifest 字段保存，不硬编码在 Dataset 中。

## 5. MANO test 可视化协议

测试输入使用 index 的 MANO-only test sequence：

1. 从连续 MANO source frames 计算 `hand_flow`，在线调用冻结 OICM 得到每帧 Cm，构造 `K=4` future
   window；允许使用 demo 已知的未来 MANO flow。
2. 由一个明确记录的 Inspire 初始状态启动 decoder；之后每步只执行第一个预测状态，再用当前实际/预测

3. 将预测 q（恢复 mimic）和 wrist pose 通过 Dexplore Inspire URDF 渲染，与 object mesh、MANO source

4. 不把 MANO test 的 source hand 或 object pose 当作 Inspire GT；不输出 q MAE、wrist EPE 等 test 定量
   结论。RL-Inspire val 只用于训练选择和定量 wiring/学习曲线。

## 10. 用户追加批准的 5 cm active-only decoder 训练修正

用户于 2026-09-06 明确要求停止旧 decoder 训练，并在重新训练前启用 `active_only`：只有当前 Cm
source frame 对应的完整 object pool 存在 5 cm candidate 时才允许该 horizon 进入 q/wrist supervision。
执行合同如下：

- `CmDecoderV2Dataset` 的 `data.active_only=true`，窗口级保留至少包含一个 5 cm active source frame 的
  完整 `K=4` window；不修改正式 train/val/test split 或已有 view/cache。
- Dataset 返回 `[K] active_mask`，与 `C_t ... C_{t+K-1}` 一一对应；runner 用它与冻结 OICM 的
  `cm_sample_valid` 相交，得到真正的 per-horizon `supervision_mask`。
- q residual、wrist translation 和 wrist rotation loss/metrics 只在该 mask 为真时计算，并在剩余
  horizon 上按原 `w_h=0.8^(h-1)` 重新归一化；全无效 batch 返回有限的零 loss，不产生 NaN。
- 旧无 active-only 的 decoder checkpoint 仅作为历史基线保留，不续训、不覆盖；本修正后的训练需要
  独立 run 目录和新的 checkpoint/manifest。
