## 1. 已确认的研究边界

1. 新建独立 Task `src/task/CmDecoderv2/`，从当前 CmDecoder 的 q+wrist 路径抽取必要逻辑；不在
   `src/task/CmDecoder/` 内继续堆兼容分支，也不覆盖其已有代码、checkpoint、cache 或运行目录。
2. 冻结前一步 ObjectInteractionCm 的 Dexplore RL/MANO 混合训练 checkpoint。不得回退到 HRDexDB、旧
   GRAB+Inspire-F1 或几何重定向（`inspire_geometric`）checkpoint。当前 Dexplore OICM run 的最终
   checkpoint 尚需等续训终态后锁定，计划不能把中途 checkpoint 默认为正式输入。
3. Decoder 训练只使用 Dexplore `inspire_rl` variant；使用 `index.json` 的 RL-Inspire train/val
   entry，不能把同一 parent sequence 的 MANO entry 同时送入 decoder 监督。MANO test 只作为最终
   source-Cm 可视化输入。
4. 保持右手、单手、30 Hz、object-disjoint/parent-disjoint split 和 Dexplore RL 来源。最终测试不
   生成或使用 paired Inspire GT；因此 MANO test 只作肉眼可视化，不能报告 q/wrist 的定量 test 指标。
5. 允许使用 source demo 的未来 hand-flow 计算 Cm window；但不得把未来 Inspire GT、未来 target q 或
   未来 target wrist state 偷渡给测试 decoder。

当前数据事实（只读核对结果）：

- `data/processed_data/object_interaction_cm_dexplore_rl_v1/index.json` 的 train 为 1004 条序列（MANO
  501 / RL-Inspire 503），val 为 126 条（64 / 62），test 为 125 条 MANO；同一 `parent_seq_id`

## 2. 首版模型合同（用户已确认并冻结）

### 2.1 Cm window

首版取 `K=4`，每个窗口只在一个序列内、按连续 30 Hz source frame 构造：

```text
C_t ... C_{t+3},       C_tau      : [16, 32]
A_t ... A_{t+3},       anchor_pos : [16, 3]
                        anchor_n  : [16, 3]
```

建议把 OICM 产生每帧 Cm 时的 source hand-flow 固定为 `t -> t+1`（stride=1），避免把 OICM 训练中的
`1..10` 可变 horizon 混成一个没有明确时间单位的 window。窗口边界只保留完整的 `K` 帧，不跨序列拼接，
不在开头做零填充。

每帧 token 使用：

```text
x_{tau,k} = MLP([C_{tau,k}, anchor_pos_{tau,k}, anchor_normal_{tau,k}]) + E_time(tau-t)
```

不加入 slot-ID embedding，也不做跨时间 slot 对齐/slot tracking；时间窗是带时间标记的 interaction
token set，以避免 SlotAttention permutation ambiguity。

### 2.2 首版 readout：Temporal-D2

按用户确认，首版直接采用指导中的 Temporal-D2，不做逐帧 pooling，也不做跨时间 slot tracking：

```text
Cm/anchor/time -> K*16 spatio-temporal tokens (Key/Value)
当前 Inspire state s_t -> 当前 link/state queries
future-step embedding E_future(h) 与当前 queries 融合
每个 future-step query 对全部 K*16 tokens 做 cross-attention
每个 h 的 link/query features -> q_finger + wrist output head
```

具体实现保持以下不变量：

- Cm token 只加相对时间 embedding，不加 slot-ID embedding；
- 当前 Inspire state 通过固定 Inspire URDF FK 生成 link-local query 特征，query 只表达当前
  target-hand state，不包含未来 target GT；
- `h=1..K` 使用独立 future-step embedding，输出未来 K 步 reference；
- 不在线追踪 `c_{t,k}` 的 slot identity；attention 自行完成空间/时间匹配；
- 只执行 `h=1`，下一时刻使用新的当前 state 和新的 Cm window 重新预测。

这样首版同时验证“Cm window + state-aware cross-attention”的完整指导假设；若需要 D1 作为消融，另建
独立配置/实验，不改变本 Task 的主实现合同。

### 2.3 q / wrist 输出拆分（已冻结）

为了与 Dexplore 的真实 action 语义一致，首版不把 18 个 native 数值全部当作独立 q，也不重复回归
wrist：

```text
q_finger_real : 6 维 native Inspire 独立手指 DOF
                native indices [6, 8, 10, 12, 14, 15]
wrist_state   : 6 维 [x, y, z, rotvec_x, rotvec_y, rotvec_z]
                native indices [0:6]
```

native mimic indices `[7, 9, 11, 13, 16, 17]` 在 target view 和可视化时按 Dexplore 固定耦合规则由
独立 q 重建；同时保留完整 18 维 native q 作为审计/指标字段。这样模型输出与当前 CmDecoder 的
“独立 finger q + wrist 运动”结构相近，但能够覆盖 Dexplore RL 的 18-DOF 目标。

腕部 GT 不从物体 pose 冒充。由 RL native q 经 Dexplore Inspire right URDF FK 得到 `T_wrist_world`，
再按冻结的目标坐标合同得到当前/未来 wrist state。必须在 sidecar manifest 中记录 URDF 路径和 SHA256、
native→URDF 映射及 `base_link`/wrist link 选择；若 FK 不能唯一恢复 wrist pose，则在数据闸门停止，
不得写入常数 wrist GT。

### 2.4 horizon 目标和执行

建议每个窗口预测未来 `K` 个状态：

```text
D(s_t, C_{t:t+K-1}) -> [q_{t+1:t+K}, DeltaT_{t->t+1:t+K}]
```

其中 `DeltaT` 为当前 wrist 到未来 wrist 的 SE(3) 相对量，平移单位 m、旋转用 rotvec 单位 rad；
q 可以采用 `q_{t+h}-q_t` residual，最终通过当前 state 恢复绝对 q。loss 对近端 horizon 权重更高，
默认 `w_h = 0.8^(h-1)`。推理/可视化只执行 `h=1`，然后用真实或上一轮预测后的当前 Inspire state
重新构造下一窗口，符合指导定义的 receding-horizon 执行。

本合同明确不输出点流、不做 point-flow loss、不做 point-flow→q fitting；FK 只用于构造/审计 wrist
GT、恢复 mimic 和可视化 mesh，不参与首版训练 loss。

不修改 `data/processed_data/object_interaction_cm_dexplore_rl_v1/` 的原始 geometry 数组；新增
Task-local decoder view（建议路径 `data/processed_data/cm_decoder_v2/dexplore_rl_v1_1/`，最终路径
按目录规范和定稿 plan 冻结），包含：

- 只引用 OICM geometry 的 sequence、frame、`source_frame_id`、object pose 和 hand geometry；
- 从 `interaction_hand_inspire.pt` 严格提取 `q_native[:,373:391]`，按源 frame 与 geometry 一一校验；
- 保存/派生 `q_finger_real`、`wrist_pose_world`、`wrist_pose_object_t` 及完整 q provenance；
- 为每个合法窗口保存 `(sequence_id, start_frame, frame_ids, K, source_stride=1)`，窗口不得跨序列、跨

- `run_manifest.json` 记录 builder 命令、数量、丢弃窗口原因（末尾不足 K、source frame 不连续、q/FK

Decoder train/val loader 只选择 `variant=inspire_rl`；MANO test loader 只提供 source geometry/flow

## 4. 训练和损失计划

训练时冻结完整 OICM（包括 slot encoder、anchors 和 flow heads），只更新 CmDecoderv2 时空 token
embedding、state/link query encoder、cross-attention 和 output heads。每个 RL-Inspire train sample 同时提供：

```text
当前 target state s_t                 # 仅 RL train/val 有 GT
Cm window C_{t:t+K-1}                 # 由同一 source 序列 hand-flow 在线/可审计生成
target q/wrist states for t+1..t+K   # 由 RL q + URDF FK 得到
```

建议首版损失：

```text
L = sum_h w_h * (lambda_q * SmoothL1(q_hat_h, q_gt_h)
                 + lambda_p * SmoothL1(Delta p_hat_h, Delta p_gt_h)
                 + lambda_r * L_geodesic(R_hat_h, R_gt_h))
```

首版冻结以下 loss/scale：`lambda_q=lambda_p=lambda_r=1`；q residual 使用弧度制 Smooth-L1，
`beta=0.02 rad`；wrist translation 乘 `100` 后使用 Smooth-L1，原始尺度 `beta=0.01 m`；rotation
使用 SO(3) geodesic loss（rad）；horizon loss 除以 `sum_h w_h`。这些值不能从旧 HRDexDB 配置隐式覆盖。

smoke 关闭 state perturbation；正式训练打开零均值 Gaussian perturbation：wrist translation 标准差
`0.005 m`、裁剪 `±0.015 m`，wrist rotation 标准差 `5°`、裁剪 `±15°`，每个独立 finger q 标准差
`0.05 rad`、裁剪 `±0.15 rad`。所有幅度作为配置和 manifest 字段保存，不硬编码在 Dataset 中。

## 5. MANO test 可视化协议

测试输入使用 index 的 MANO-only test sequence：

1. 从连续 MANO source frames 计算 `hand_flow`，在线调用冻结 OICM 得到每帧 Cm，构造 `K=4` future
   window；允许使用 demo 已知的未来 MANO flow。
2. 由一个明确记录的 Inspire 初始状态启动 decoder；之后每步只执行第一个预测状态，再用当前实际/预测
   state 和后续 MANO Cm window 重新解码。
3. 将预测 q（恢复 mimic）和 wrist pose 通过 Dexplore Inspire URDF 渲染，与 object mesh、MANO source
   hand 和 object trajectory 同屏保存 PNG/MP4/NPZ，供人工检查抓取、接触、腕部漂移和 recursive drift。
4. 不把 MANO test 的 source hand 或 object pose 当作 Inspire GT；不输出 q MAE、wrist EPE 等 test 定量
   结论。RL-Inspire val 只用于训练选择和定量 wiring/学习曲线。

## 6. 分阶段闸门

### Gate A：静态合同

- guidance/plan 同后缀、配置导入、独立 Task 入口和 OICM strict checkpoint load；
- RL q slice shape/finite、native→URDF 和 mimic mapping 与 Dexplore 脚本一致；
- FK 生成的 wrist pose 与 hand geometry/source frame 对齐；window 不跨 sequence、split、variant；
- `Cm window [B,K,16,32]`、anchor/time token、输出 horizon shape 和所有 loss finite；
- 旧 `CmDecoder`、OICM cache/checkpoint 和 MANO test split 未被修改。

### Gate B：单卡 smoke

使用少量 RL-Inspire train/val sequence，完成 forward/backward 和若干 optimizer step；确认只有新
decoder 参数有梯度，OICM 恒为 eval/no-grad，window 顺序/边界和 per-horizon metrics 正常。smoke 只证明
wiring，不代表跨 embodiment 效果成立。

### Gate C：RL-Inspire decoder 训练

先用 RL train、RL val（不使用 MANO entry）训练和选模，保存 config、decoder-view manifest、OICM
checkpoint fingerprint、`run_manifest.json`、`metrics.jsonl`、`train.log` 和 best/latest checkpoint。
RL test 不在现有 index 中提供，因此不把 MANO test 冒充 RL quantitative test；如需要 RL held-out，另行
批准一个不改变 MANO test 口径的 split。

### Gate D：MANO test 可视化

仅在 Gate A-C 通过后运行短窗口/短 rollout 可视化；输出目录独立，不覆盖历史 CmDecoder 或 OICM
产物。最终判断只写为人工观察记录，不能将 smoke 或可视化误报为 q 解码科学结论。

## 8. 用户已确认的定稿项

前述 q 输出拆分、wrist 相对 SE(3)、固定初始 Inspire state、`K=4 + stride=1`、state query 以及
Temporal-D2 均已按用户回复确认。state perturbation 固定为：

- smoke 阶段关闭 perturbation；
- 正式 RL decoder 训练打开 perturbation；
- translation `5 mm`（裁剪 `±15 mm`）；
- wrist rotation `5°`（裁剪 `±15°`）；

- 均为零均值 Gaussian，并作为配置/manifest 字段。

以上合同已经定稿；若实现需要改变 q/wrist 定义、window 时间语义、split、checkpoint 解释、Temporal-D2
结构或 perturbation 数值，必须暂停并重新协商，不能静默偏离。
