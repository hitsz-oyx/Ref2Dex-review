## Hypothesis and evidence

假设 candidate-axis 共享 object encode 的 V1.14a adapter 能降低 V1.18 planner 的实际 rollout 开销。两个 run
固定 GPU6、seed42、1 env、64 steps、K=8、同一 reference/PPO/action/PhysX 合同，只替换 frozen Cmv2 adapter。
V1.14a 相对 V1.3 的 step/total FPS 分别从 `5.383/5.038` 提高到 `7.243/6.640`，即 `1.345x/1.318x`；
play time 从 `11.889 s` 降至 `8.836 s`。两侧均完成 epoch、finite checkpoint 和 64-sample transition buffer。
