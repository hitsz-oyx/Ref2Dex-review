## Goal / Change

在不重训 Cmv2 的前提下压缩 V1.18a 定位的 local-interaction 延迟。按累计顺序独立测量：

1. squared segment distance + merge-topk，并共享 candidate-independent object feature/query；
2. 使用 `SurfaceGeometry.hand_link` 的 swept-link expanded AABB broad phase，只对候选 link 做 exact narrow phase；
3. 只对 `<=2 cm` 的有效 edge 执行 edge MLP，再 scatter 回原固定形状。

fast path 只由 CmResidual planner 显式传入 link IDs；其他 Cmv2 调用保留 dense fallback。有效半径内 top-32
edge、米制距离及 lower-index tie-break 必须等价；半径外 masked padding 不再要求相同。

## Protected / Verification

保持 checkpoint/state_dict、权重、K=8 teacher、candidate、2 cm radius、坐标单位、observation/action/reward、
PhysX、V1.19 microbatch/chunk 与旧 outputs 不变。复用 V1.18a 的 Phase-B 首个 active state、state/candidate SHA、
GPU6、20 warm-up + 100 CUDA Event measurements；每阶段分别记录 parity、mean/median/p90、分项时间、有效
edge/link 统计和峰值显存。定向测试覆盖随机、mask、零 flow、tie、半径边界和 dense/fast model outputs；运行
`py_compile`、`python3 tools/verify.py --changed` 与 `git diff --check`。

任一阶段若有效 edge 或 rollout 行为 parity 超 `1e-6`，标为 `INVALID_IMPLEMENTATION` 并停止。若测量未形成
可重复延迟收益，保留证据但不采用该阶段；K-scaling、训练效果和其它 state 分布不从单状态 benchmark 外推。

## Rollback

逐阶段独立提交，可单独 revert；不删除输入、checkpoint、V1.18a/V1.18b 运行或历史证据。voxel hash、endpoint
近似、降 K、降精度和网络结构变更不在本计划内。
