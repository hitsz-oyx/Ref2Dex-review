## 目标

实现冻结 Cmv2 的 nominal-base effect-conditioned residual actor：它从当前实际状态和 `q_ref[t+1]` 的
controller/FK hand sweep 得到 16×40 Cmv2 token 与 predicted object-local one-step effect；reference 同一时刻
提供 desired local effect。PPO actor 由 token interaction structure、predicted/desired/error effect 学 18-D
residual；critic 不读取任何 Cmv2 token/effect，只保留现有 68-D base observation。

## 冻结合同与不变量

- actor raw transport observation 为 `[base68, token16x40, predicted6, reference6, error6]`，共 `726-D`；网络内
  token encoder/attention pooling 产生 128-D `z_Cm`，送入 PPO MLP 的有效 actor representation 为
  `[base68, z_Cm128, predicted6, reference6, error6]`，共 `214-D`。critic 只取 raw prefix `68-D`。
- Cmv2 checkpoint 固定为 V1.14.5 的 `latest.pt`、相同 SHA/schema/model config，始终 `eval`、
  `requires_grad=False`、inference mode；其输出不进入 reward、critic、optimizer 或 CmBuffer 的在线更新。
- token 的 40-D layout 严格为 `token32 + object-relative anchor3 + normalized normal3 + log mass1 + valid1`；
  valid mask 进入 self-attention 和 pooling key mask。全部无效时 `z_Cm=0`，不产生 NaN。
- actor 内模块固定为 token `40->128` MLP、单层 4-head masked self-attention 和 effect-conditioned attention
  pooling；query 来自 `base68 + normalized predicted/reference/error18`。除 token encoder/attention/actor MLP
  外不训练 Cmv2。
- predicted/reference effect 均是 current object local frame 的 `T_t^-1 T_{t+1}` 6-D `[translation, rotvec]`；
  translation 除 `0.02 m`、rotation 除 `0.05 rad`、逐元素 clamp `[-5,5]`，error 为归一化后 `reference-predicted`。
- Cmv2 actor observation 在 action 前仅使用当前 simulator state、`q_ref[t+1]` 和 reference `t,t+1`；不使用
  post-step state、future simulator state 或 executed residual prediction。V1.14.5 CmBuffer 保留对实际执行
  residual 的独立预测/PhysX label 记录，不把两者混为 actor 输入。
- 保留 GRAB reference/SHA、世界坐标/米/弧度、68-D base prefix、18-D action、V1.14.4 feasible authority、
  reward、joint/mimic limit、assets、PhysX、Cmv2 buffer schema 与共享 `src/base`；不重写历史 config/outputs。

## 实现范围

1. Cmv2 adapter 提供保留 token 维度的规范化 token encoding，并保留旧 flattened context 兼容行为。
2. transition Task 新增 opt-in V1.15 actor context：在 `compute_observations()` 生成 nominal zero-residual
   Cmv2 result、reference local effect 和 normalized error；PPO transport observation 固定 726-D。buffer task
   继续只在 pre/post physics 收集 executed-action labels。
3. 新建专用 V1.15 task/train config、registry、runner contract；旧 V1.14 no-Cm/CmBuffer config 不改。
4. 新的 PPO builder 实现上述 attention actor，并以 `actor_input_dim=726`、`critic_input_dim=68`、`separate=true`
   明确非对称切片。网络构造、actor/critic forward、mask/all-invalid、维度和 Cmv2 无梯度均有 CPU 定向测试。
5. 先做 GPU5/1-env zero/nonzero smoke：finite、726/68 network contract、Cmv2 frozen、zero-residual parity、
   target saturation、CmBuffer shard/manifest。仅通过后才进行容量探测；GPU0/1/2 分布式训练需要 GPU2 空闲、
   每卡容量结果、明确 rank output 和有限总 env-step 或人工停止状态记录，不能因本计划自动启动无限训练。

## 验证、证据与回滚

- 运行 Cmv2 adapter/evaluator、network builder、reference contract 和 CmBuffer 的定向 tests，`py_compile`、
  Hydra resolved-config contract、`git diff --check`；GPU smoke 生成独立 manifest/config/metrics/log/buffer links。
- smoke 只支持接口接线，Cmv2 accuracy、attention utility、PPO effect 和微调资格均标记 `INCONCLUSIVE`。
- 回滚只撤销 V1.15 task/config/builder/runner/tests/docs；保留生成 outputs/buffer、V1.14 checkpoint/reference 和
  用户已有改动。若 actor/critic prefix、object-local effect、Cmv2 SHA 或 mask contract 无法满足，停止，不启动训练。
