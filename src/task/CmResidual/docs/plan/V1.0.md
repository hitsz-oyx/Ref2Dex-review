## 1. 已恢复的任务目标

将当前 [CmResidual 环境](../../../../../third_party/IsaacGymEnvs/isaacgymenvs/tasks/cm_residual.py)
从“CmDecoder base 加小残差的单任务 pilot”拆成一个
可独立管理、复现和冻结 checkpoint 的控制 Task，并按以下顺序研究：

1. 用耦合几何重定向轨迹作为 reference，而不是当作可直接执行的可靠策略；
2. 参考 DexTrack 的 kinematic-bias tracking，训练接收实际物理状态和短期未来 reference 的反馈策略；
3. 通过 frame-0、联合 hand/object RSI 和小扰动评估，确认 tracker 具备跟踪与恢复能力；
4. 将通过验收的 tracker、观测归一化统计和控制合同一起冻结，作为新的 base policy；
5. 之后再训练较小、非累计的 interaction residual；OI-Cm 只在这一阶段接入。

核心分解为：

```text
coupled geometric reference
        |
        v
physics-aware reference tracker (PPO, cumulative target residual)
        |
        v
frozen base checkpoint
        |
        v
optional OI-Cm-conditioned interaction residual (bounded per-step correction)
```

## 2. 已确认事实与不能直接照搬的部分

- 当前 `CmResidual` 的 action 是 `q6 + wrist translation3 + rotvec3` 共 12 维，观测为 71 维，奖励主要是
  抬升、指尖到物体距离和 action penalty；它不是完整的 reference tracker。
- 当前正式入口
  [CmResidualOnline.yaml](../../../../../third_party/IsaacGymEnvs/isaacgymenvs/cfg/task/CmResidualOnline.yaml)
  强制使用冻结在线
  CmDecoder；历史 `reference_frozen` 已被实现 fail-closed，不能直接改个配置就当成新 tracker。
- DexTrack 公开实现的原始 action 是
  `reference(t+1) + cumulative residual target`，并把下一 reference 与累计 residual 放入观测；本计划只移植
  这个控制思想、future reference 和训练/评估分解，不复制其大文件环境、硬编码路径或未发布训练流程。
- DexTrack 的公开 `randomize_reset_frame` 不能视为本 Task 的可用 RSI：其代码会随机相位和部分手状态，
  但未证明同时恢复同相位的 object pose/velocity、手腕速度和一致接触状态。本 Task 必须实现自己的联合 RSI。
- 当前 GPU pipeline 下不能稳定取得结构化 hand-object pairwise contacts；不能把空 pairwise 输出、总 net contact
  force 或简单距离冒充真实接触标签。V1.0 的 reward/metric 默认使用几何相对量，接触只作可选诊断。
- 当前耦合几何 sidecar 已有 432 帧 `q_native[18]`、`q_finger_real[6]`、`wrist_pose_world[4,4]` 和
  `wrist_pose_object_t[4,4]`；object reference 必须从与该 sidecar 同源、同帧的 `obj_pose_world` 读取，不能
  用 policy rollout 的未来实际状态替换。
- 对这 432 帧做的只读连续性统计显示：独立 finger q6 的单元素步差 p95 `0.0184 rad`、max `0.1844 rad`；
  wrist translation
  p95 `53.7 mm`、max `100.1 mm`，wrist rotation p95 `0.1138 rad`、max `0.2958 rad`；object translation
  p95 `15.2 mm`、max `20.5 mm`。明显 wrist 跳变集中在 reference index `5..8` 和 `416..424`。这些值在
  30 Hz 控制合同下不能直接视为正常可跟踪速度，也不能静默平滑，必须先审计源帧、坐标与阶段边界。
- 初次 `inspire_geometric` retarget 根没有 converter run manifest；现有筛选和 coupled-fit manifest 不能反推出
  初次转换的精确命令、参数与 producer commit。公开在本机的 producer 会联合优化 6 个 virtual wrist 与
  12 个 finger/mimic DOF，而后续 coupled fit 明确保留 wrist 不变，因此 wrist source provenance 与连续性都
  不能靠后续拟合补救。
- DExplore tensor 同时保存右腕 position/exp-map（columns `51:57`）和 global joint quaternion block；右腕
  global quaternion 是 columns `309:313`、顺序 `xyzw`。对当前 432 帧，exp-map `54:57` 与该 quaternion 的
  SO(3) geodesic 差异 min/median/p95/max 为 `24.88/49.99/113.81/174.09 deg`，432 帧全部不等价。producer
  的 `quat_to_exp_map` 对负 `w` 使用 `abs(w)` 计算角度却没有同步翻转 vector part；本序列右腕 quaternion
  的 `w` 全为负，因此 `54:57` 不可作为新 reference 的旋转真值。
- 用 columns `309:313` 的 quaternion 与同 tensor 的 wrist/MCP landmarks 构造 human palm frame 后，二者
  的相对旋转在 432 帧内保持数值常量；这为 `xyzw` 解释提供了独立几何一致性证据。新 producer 必须读取
  quaternion，不得再从异常 exp-map 回推或拟合一个依赖旧 robot wrist 轨迹的逐帧修正。

## 4. V1.0 保持不变的边界

以下 invariant 在本计划内不得静默改变：

- Inspire native q 为 18 维、单位 rad；独立手指控制仍是 native indices `(6,8,10,12,14,15)`，其余六个
  mimic 关节继续按当前固定比例展开。
- 手腕仍由 URDF 六个腕关节和 PD target 控制，不逐步改 actor root 来伪造跟踪。
- reference fps 固定为数据 manifest 声明的 30 Hz；仿真保持 60 Hz、`controlFrequencyInv=2`，一条 reference
  transition 对应一个控制步。任何重采样必须生成新数据版本和 manifest。
- 世界长度单位为 m；旋转矩阵和 quaternion 顺序必须显式记录；不可在 loader 中隐式转置或单位换算。
- q/wrist/object reference 来自同一 sequence、同一 raw/cache frame 映射和同一 object pose source。
- 几何 reference 是已知 demonstration，可以读取短期未来 reference；不得读取未来 simulator actual state、
  future reward、未来 contact 或任何 policy rollout GT。
- base tracker 训练期间不加载 Cm、OICM 或 CmDecoder；第二阶段 residual 训练时 base checkpoint、网络参数、
  normalizer 和控制尺度全部冻结并校验 SHA256。
- 原 `CmResidualOnline`、旧配置、checkpoint、cache、output 和用户现有 dirty diff 全部保留；新运行使用新目录。
- 不修改共享 `src/base/`，不更新用户指导，不创建架构快照，除非用户另行明确批准。

### 6.1 已批准的新 reference 坐标与重定向合同

用户已批准重导出新版本 reference，旧 sidecar 只作历史对照、不得覆盖。新 producer 的权威输入和求解变量固定为：

1. `T_WH(t)`（human right wrist 在 world 中的 pose，将 H-frame 映到 W-frame）的 translation 读取 DExplore
   tensor columns `51:54`；rotation
   读取 columns `309:313`，显式解释为 `xyzw` 并先单位化。columns `54:57` 的旧 exp-map 必须 fail closed，
   只允许在诊断报告中出现；
2. robot wrist/base 轨迹由整条序列共享的唯一常量映射 `X_HB ∈ SE(3)` 得到：
   `T_WB(t) = T_WH(t) X_HB`。`X_HB` 与 q6 可联合标定，但一旦 producer 完成便写入 manifest，逐帧不再优化
   wrist，也不允许 loader 添加 frame-dependent offset；
3. 每帧只优化独立关节 `q6(t)`；native indices 固定为 `(6,8,10,12,14,15)`，其余 finger joint 只按锁定
   mimic 合同展开。virtual wrist 的 6 个 DOF 不进入逐帧 retarget variable；
4. 五个 human fingertip target 沿用 producer 的明确 index 合同 `[4,8,12,16,20]`，但必须由同一次 raw
   SMPL-X/GRAB 解算生成；object pose 使用同一 `source_frame_id` 的同源 geometry cache；
5. 优化时加入 q6 速度/加速度约束项，写出前再执行硬门：30 Hz 下各独立 DOF `|dq| <= 1.0 rad/s`、
   `|ddq| <= 20.0 rad/s^2`，数值容差均为 `1e-6`；任何帧不满足便不生成 training-eligible manifest。
   `1.0 rad/s` 来自 source URDF，`20.0 rad/s^2` 是本计划预注册的工程上限，不冒充 URDF 或硬件规格；
6. q6 逐元素满足 source URDF position limit；mimic 展开误差绝对值不超过 `1e-6 rad`。优化器、seed、dtype、
   迭代/停止条件、loss 分项、初值以及 `X_HB`/q6 最终值全部写入 manifest，失败不得回退到旧 wrist。

实现前发现既有“固定 mimic”存在两个互斥值：legacy coupled/CmResidual 代码使用 pinky
`q11=1.05*q10`，而当前数据、FK 和 Isaac Gym 配置共同指向、SHA256 为
`7d0023168a22191de2126d71f8d2a810f82e8cba56b74c82be6db04812b80f58` 的 URDF 明确声明
`pinky_intermediate=1.18*pinky_proximal`；其余四组比例一致。该差异会改变 q/native schema、FK、速度约束和
未来 checkpoint 解释。用户继续执行本会话即确认采用 URDF-authoritative `1.18`；legacy `1.05` 仅作历史兼容，
不进入本版本新 reference。

V1.0 主 reference 固定使用原 reference indices `[44,410]`（闭区间，共 367 帧），对应 raw
`source_frame_id=[176,1640]`。理由是该区间为连续 `hand_min_object_distance <= 2 cm` 的 interaction 段；在
正确 quaternion 下，该段 human wrist linear/angular speed 最大值为 `1.104 m/s` / `2.248 rad/s`，低于 source
URDF virtual wrist 的 `2.0 m/s` / `3.14 rad/s`。完整 432 帧仍可随新产物保存为 diagnostic-only source view，
但不得进入 V1.0 训练/RSI/eval，也不得把 Task-local frame 0 错当 raw frame 0。该帧区间已获用户批准。

- 产物 manifest 可在另一进程只靠显式路径重载并复核 SHA。
- `training_frame_range=[44,410]` 和 `source_frame_id=[176,1640]` 显式写入 manifest；输出中的
  Task-local `frame_id=0..366` 不覆盖 source id，432 帧 diagnostic view 带 `training_eligible=false`。

Gate D1 不通过时不得创建训练配置或启动 Isaac Gym。

## 7. 反馈 tracker 的控制合同

### 7.1 Action

policy action 仍为 12 维：

```text
[delta_delta_q6, delta_delta_wrist_translation3, delta_delta_wrist_rotvec3]
```

推荐采用 DexTrack-style 累计 target residual：

```text
c_q(t)  = clip(c_q(t-1)  + scale_q_step  * action_q,  -bound_q,  bound_q)
c_xi(t) = clip(c_xi(t-1) + scale_xi_step * action_xi, -bound_xi, bound_xi)
q_target(t) = clamp(q_ref(t+1) + c_q(t), coupled_joint_bounds)
T_target(t) = T_wrist_ref(t+1) @ Exp_SE3(c_xi(t))
```

reset（无论 frame-0 还是 RSI）后 `c_q=c_xi=0`。提交最终复核的精确初值为：policy action 先逐元素 clip 到
`[-1,1]`；q6 每步增量逐元素上限 `0.01 rad`、累计逐元素 bound `±0.08 rad`；wrist-local translation 每步
向量范数上限 `2.5 mm`、累计范数 bound `15 mm`；wrist-local rotvec 每步向量范数上限 `0.02 rad`、累计范数
bound `0.20 rad`。处理顺序固定为 `action clip -> q elementwise scale / xi radial scale -> cumulative add ->
cumulative project -> reference composition -> URDF position clamp`；最后一步发生 clamp 时必须计入 saturation metric。
这些是 V1.0 的预注册工程初值，不声称由现有数据证明最优；final 后如需改变，只能新建 `V1.0.k` 配置/实验臂。

### 7.2 Observation

首版 MLP observation 只用可部署信息，并按 block 记录 schema offset：

1. actual `q_native18`、`dq_native18`；
2. actual wrist/object pose 与 twist，优先表达在当前 object frame；
3. 五指尖相对 object 的位置/速度与可验证的几何距离；
4. current tracking error：q6、wrist SE(3)、object SE(3)；
5. future reference offsets `[0,1,2,4]`：q6、wrist、object 的相对目标及有效 mask；
6. normalized phase、remaining steps；
7. 上一步累计 residual 和 action。

不含 Cm/OICM/CmDecoder feature，不含 future actual state。姿态使用连续表示（例如 rot6d/rotvec）时必须固定
奇异点、归一化和误差定义；最终 `observation_dim` 由 schema 测试计算，不能手写一个与实现漂移的常数。

### 7.3 Reward 与独立 metric

reward 采用可分解 tracking 项，不再用“lift - tip distance”代表全部目标。提交最终复核的 V1.0 初值为：

```text
e_q        = RMS((q_actual6 - q_ref6) / 0.10 rad)
e_wp       = ||p_wrist_actual - p_wrist_ref||_2 / 0.020 m
e_wr       = geodesic(R_wrist_actual, R_wrist_ref) / 0.20 rad
e_op       = ||p_object_actual - p_object_ref||_2 / 0.020 m
e_or       = geodesic(R_object_actual, R_object_ref) / 0.20 rad
e_tip      = RMS_k(||tip_actual_object(k) - tip_ref_object(k)||_2 / 0.020 m)

r = 0.20 * exp(-e_q^2)
  + 0.10 * exp(-e_wp^2) + 0.10 * exp(-e_wr^2)
  + 0.20 * exp(-e_op^2) + 0.10 * exp(-e_or^2)
  + 0.30 * exp(-e_tip^2)
  - 0.010 * mean((c_t / cumulative_bound)^2)
  - 0.005 * mean((a_t - a_{t-1})^2)
  - 0.020 * saturation_ratio
```

所有姿态误差使用 quaternion-sign-invariant SO(3) geodesic；tip 先转到 actual object frame，避免把 object 的
整体跟踪误差重复计入 tip 项。上式权重和尺度在 Gate P0 前写入 resolved config 并冻结。不得按长训结果静默改
reward；任何修改使用新配置与新 `V1.0.k`，保留原 arm 结果。

与 reward 分开记录以下 metric：

- q6/native18 RMSE、每指 percentile；
- wrist translation mm 与 geodesic rotation deg；
- object translation mm 与 geodesic rotation deg，逐步曲线与 time-AUC；
- link/tip point EPE、reference-relative hand-object distance；
- episode survival、终止原因、物体跌落/穿桌/非有限；
- residual RMS/p95/max、action-rate、joint saturation ratio；
- 若 pairwise contact API 在独立 CPU/GPU gate 中被证明有效，再附加 contact occupancy；否则标为 unavailable。

### 7.4 Termination

终止至少区分：reference 结束、object 超出 workspace/跌落、hand/object 非有限、非法 joint state、仿真错误。
“瞬时 lift > 8 cm”只保留为辅助 task metric，不提前结束 tracking episode，也不作为 base 验收的唯一标准。

### 7.5 PPO 前的定量工程闸门

以下门槛只决定实现是否有资格进入 PPO，不构成科研效果结论：

- D1：第 6 节全部 schema/SE(3)/q/mimic/velocity/acceleration/contact-preservation 门通过；
- P0：4 个确定性 frame-0 playback env 均走完 367 帧，无 non-finite、非法 reset、物体穿桌或 simulator error；
  独立 q6 saturation ratio `<1%`，并完整报告 q/wrist/object/tip metric，不以调 reward 改善 P0；
- P1：抽取不少于 32 个 valid-RSI frame，每个 frame 在独立 env 做 10 control-step zero-action settle；跨 env tensor
  污染次数为 0，non-finite/穿桌/异常退出次数为 0；
- P2：4 env、2 PPO updates，至少完成 1 个 episode；所有 action/observation/reward/gradient/normalizer finite，
  checkpoint 独立进程重载后对固定输入的 action 最大绝对差 `<=1e-6`；
- 任一门失败都记录 `INVALID_IMPLEMENTATION` 或 `REFUTED` 并停止；不得放宽坐标、速度、数据或 GT 合同来让 smoke
  通过。

## 8. 联合 RSI 与扰动合同

RSI 从 `valid_rsi_mask` 采样相位 `tau`，一次性恢复：

- hand/root 与 18 个 DOF 的 q、dq；
- wrist/root linear/angular velocity（若自由 wrist 由六个 DOF 表达，则按同一 URDF 逆映射）；
- object pose、linear velocity、angular velocity；
- phase/progress、累计 residual、previous action/target；
- table 保持固定，其他环境 tensor 不跨 env 污染。

每个候选相位经过 reset 后零 action settle 检查：状态误差有限、无异常冲量、无穿桌、独立 env 未改变。不能
仅凭 kinematic 最近距离决定 valid。

推荐按三条实验臂逐步引入，避免把 RSI 与扰动收益混在一起：

| arm | 初态分布 | 用途 |
| --- | --- | --- |
| `T0-start` | 100% frame-0，无扰动 | 最小 feedback tracker |
| `T1-rsi` | 50% frame-0 + 50% uniform valid-RSI，无扰动 | 测 RSI 本身 |
| `T2-recovery` | 同 T1，RSI 样本叠加 small perturbation | 测局部恢复 |

提交最终复核的 small perturbation 初值为 q `sigma=0.01 rad`、wrist/object translation `sigma=2 mm`、rotation
`sigma=2 deg`，各维/范数按 `3 sigma` clip；采样 seed 写入 manifest。扰动后速度仍取同相位 reference，不另加
速度噪声。这些数值 final 后不因训练失败自动放大；中/大扰动留到后续版本。

### E2：长训与冻结 base

- 运行前再次向用户报告 GPU、精确命令、预算、停止条件和新 run_id，获得长任务确认；

- 每个 seed 用独立输出目录，禁止隐式 resume 和“自动选择最新 checkpoint”；
- checkpoint 选择只依据预先声明的 validation tracking score，不依据最终 test；
- 在同样的 frame-0、valid-RSI 和 small-perturb eval suite 中对比 P0 raw replay。

提交最终复核的 base 冻结闸门：

1. 三个 seed 全部无非有限、schema 漂移或非法 reset；
2. 在同一确定性 frame-0 suite 上，object translation error time-AUC 与 rotation error time-AUC 均相对 P0 至少
   降低 `10%`；q6 RMS、wrist translation 与 wrist rotation p95 任一不得相对 P0 恶化超过 `10%`；
3. 对预先固定的 64 个 valid-RSI 初态和 64 个 small-perturb 初态，定义恢复为 30 control steps 内同时达到
   `q6 RMS <=0.10 rad`、wrist `<=20 mm/15 deg`、object `<=30 mm/20 deg` 并连续保持 10 steps。选中 base
   的恢复率须比 P0 高至少 `10` 个百分点，且跨 3 seeds bootstrap 95% CI 的 improvement 下界 `>0`；
4. action/residual/saturation 均在预设 bound 内，checkpoint 独立重载复现；
5. 结论只限 `s1/airplane_lift` 单轨迹。跨 sequence/object/subject 泛化仍为 `INCONCLUSIVE`。

通过后冻结：policy checkpoint SHA256、normalizer、resolved config、reference manifest、action/observation schema、
URDF/asset SHA 和评估报告。任一项改变都不能沿用同一个 base 身份。

### E3：冻结 base + interaction residual

- base deterministic inference、参数、normalizer、累计 residual state 和 target 输出全部冻结；
- outer action 仍可为 12 维，但定义为较小的、非累计、逐步有界 correction：
  `target_final = target_base (+) delta_interaction`；
