## 1. 准入合同

1. source tensor `interaction_hand_inspire.pt` 的 `205:206` 是 raw object contact flag；主区间 `[44,410]` 中
   至少有一帧且必须参与准入统计。
2. 使用锁定 Inspire URDF、airplane URDF、固定采样 seed `2024`、1538 hand points 和 256 object points，按
   corrected reference 的 `link_pose_world_ref`/`object_pose_world_ref` 计算每帧 hand-object unsigned minimum distance。
3. `training_eligible=true` 仅在 q/速度/加速度/mimic/schema 门全部通过，且 raw-contact 帧中距离 `<=0.020 m` 的比例
   至少 `0.90` 时写入；否则 fail closed。
4. 新产物写入 `data/processed_data/cm_residual/reference_tracking_v2/s1_airplane_lift/`，不修改旧 v1 目录。

## 2. 实现范围

- `src/task/CmResidual/tools/data/build_reference.py`：读取 raw contact label，执行确定性表面距离审计，按门禁计算
  eligibility，并将输入 SHA、采样参数、计数、比例、gate 状态和结论写入 manifest/run manifest。
- `src/task/CmResidual/tests/test_reference_contract.py`：增加 contact 列合同和准入计算的回归断言。
- `third_party/IsaacGymEnvs/isaacgymenvs/cfg/task/CmResidual.yaml`、`CmResidualOnline.yaml`：默认切换到新 artifact
  路径及 SHA，`allowIneligibleFor` 保持空字符串。
- Task README、activity/experiment log 和 `docs/current_versions.yaml`：记录新 artifact 及验证结果。

## 3. 验证与停止条件

- 先运行 builder 到新目录，独立重载 manifest/reference，验证 SHA、shape、finite、contact counts、距离比例和
  `training_eligible=true`。
- 运行 `PYTHONPATH=third_party/IsaacGymEnvs python3 -m pytest -q src/task/CmResidual/tests`、`py_compile`、
  `git diff --check` 和 `audit_diff.py --check-links`。
- 若 raw label、距离门或任何现有合同不满足，停止并保持旧 v1；不把 eligibility 改为 true。
- 本版本只完成 reference/data contract；正式 PPO 训练需在新 artifact 验证通过后另行运行并记录独立 run manifest。
