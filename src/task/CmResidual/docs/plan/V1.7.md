## 执行顺序与停止条件

1. 用同一输入先做 1-env、0-update initialization smoke；初始化或 reference gate 失败则不启动正式训练。
2. 正式 run 写入全新 `outputs/CmResidual/<run_id>/`，记录 resolved config、输入 SHA、metrics、train log、
   TensorBoard、最近/最佳 checkpoint 和终态 manifest。
3. non-finite、Isaac Gym/PhysX 错误、进程异常退出或 reference eligibility 变化时立即停止并标记
   `INVALID_IMPLEMENTATION`；不切设备、不修改研究变量、不追加隐式复跑。
4. 训练完成后独立重载最近 checkpoint，验证 model/optimizer/normalizer/action finite 和 deterministic action
   reload；工程通过不等于抓取或 Cm 科研假设成立。

## 回滚与结论上限

停止或回滚只影响本次新的 output 目录和 V1.7 runner/文档；不删除历史运行和 checkpoint。工程 wiring/数值通过标记
`SUPPORTED`，效果、收敛和抓取结论只有在独立评估后才能判断，当前保持 `INCONCLUSIVE`。
