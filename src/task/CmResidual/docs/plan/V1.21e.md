## 1. 目的与结论边界

本实验只检验：对于 CmResidual 的 one-step native-action ranking，公开的 candidate 前状态
是否足以近似 PhysX 所需的 Markov state。比较同一 collector state、同一 actor-mean action：

```text
A: episode initial state + recorded action prefix + one action
B: fresh simulator + direct public-state restore + one action
```

通过只允许下一阶段把 64-state calibration 和 512-state ranking 改为 snapshot branching；
不证明 Cm ranking、抓取、PPO 或泛化有效，也不自动授权这些运行。失败则保留 V1.21d
`INVALID_IMPLEMENTATION` 证据和 prefix 路径，不放宽既有门禁。

## 2. 固定样本与状态合同

- 使用官方 DExplore checkpoint、固定 runtime、30 Hz control（两个 1/60 s substeps）、
  native 18-D action、既有 reference/坐标/单位/IG/score primitive；
- 新采集 exactly 16 个 active pre-action states：`6 moving / 6 contact / 4 precontact`，
  按 phase、canonical `state_id` deterministic selection；seed 从 5909 递增；
- 每个 state 的 action 固定为 `a0=clip(policy_mu,-1,1)`；不生成其余 candidates；
- snapshot 保存全部 DOF q/dq、全部 actor root pose/twist、`data_id`、`ref_index`、
  `start_time`、`progress_buf`、reset/contact bookkeeping、raw observation、canonical current IG、
  action-prefix identity 和 simulator/input provenance；
- contact force、rigid-body tensor和 PhysX cache 不作为可恢复状态；candidate 的
  `pre_physics_step()` 覆盖本步 PD target/action。

现有 V1.21c 64-state artifact 缺少逐状态完整 snapshot，只作为历史输入证据，不反推、
覆盖或升级；V1.21e 必须产生独立 run_id 和输出目录。

## 3. 四臂 parity 协议

每个 state 在互相独立的 fresh subprocess/simulator 中产生：

- `A1/A2`：两个 env 从 episode initial state replay 相同 prefix，再执行相同 a0；
- `B1/B2`：两个 env 直接恢复 collector snapshot，再执行相同 a0；
- B 不允许先 replay 再覆盖公开 state，以免继承 prefix 建立的 hidden cache；
- 两臂 candidate 前 task/reference indices 必须相同且 finite，否则为合同失败；
- producer 生成并保存 next object pose/twist、q/dq、canonical IG 和 `physics_score`；
  score 始终使用 collector 保存的 shared canonical pre-action baseline、`t+6` object goal、
  `t+1` IG target。offline 汇总器只消费并校验 producer score，不重新计算。

## 4. 指标与 hard gate

对每个 state，先分别计算 A、B duplicate divergence，再计算两臂 duplicate centroid 差异。
比较：object position/rotation/twist、DOF q/dq、canonical IG 和 physics score。

必须同时满足：

1. 所有值 finite，provenance、state/action/task/reference identity 完全一致；
2. A、B 各自 duplicate object divergence 均不超过既有 hard ceiling：
   `5e-4 m / 5e-3 rad`；
3. A/B centroid object divergence 也不超过 `5e-4 m / 5e-3 rad`；
4. 对每个报告 metric，A/B centroid difference 不超过
   `max(5 × max(A duplicate difference, B duplicate difference), numerical_floor)`；
5. numerical floors 固定为：object position `1e-5 m`、rotation `1e-4 rad`、
   object linear/angular velocity `1e-3`（各自 SI 单位）、DOF q `1e-4 rad`、
   DOF dq `1e-2 rad/s`、IG `1e-4 m`、physics score `1e-6`。

16/16 state 全部通过才记为 `SUPPORTED`；任一输入/实现/hard gate 失败为
`INVALID_IMPLEMENTATION`。有效运行但结果不足以支持等价性时为 `REFUTED`，不进行
事后阈值调整或自动扩大样本。
