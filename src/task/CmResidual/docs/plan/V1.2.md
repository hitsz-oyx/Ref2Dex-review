## 1. 目标与保护边界

修正 V1.1.4 中 OI-Cm 适配器的语义错误，使残差 PPO 使用仿真器几何生成的真实物体/手部表面输入，
并保留冻结的 DExplore teacher 与冻结的 OI-Cm checkpoint。DExplore 原生 1442-D observation、18-D
action、URDF/DOF 顺序、控制频率、PD 增益、场景资产和奖励定义保持不变；不修改原始数据、reference
checkpoint、OI-Cm checkpoint、外部 DExplore 工作树、历史 outputs/cache/checkpoint，也不启动长时训练。

## 2. 锁定实现合同

- **Reference observation**：`ReferenceProvider` 继续分别提供 `delta_t=1` 和 `delta_t=16`。link
  velocity 由 reference link pose 按固定 `dt=1/30` 的中心差分得到；reference contact 由同一物体表面
 采样与 5 个 contact link 的 2 cm 几何阈值计算，禁止传入全零占位或当前接触状态。
- **OI-Cm geometry**：新增 Task-local `cm_geometry.py`，从当前配置的 object/hand URDF visual mesh
  做一次确定性表面采样（默认 object 1024 点、hand 1538 点），缓存点、法向和所属 link；每个 observation
  用当前 actor object pose 和实测 19 个 Inspire link pose 做 batched 刚体变换。hand flow 为当前与上次
  仿真几何点的差，reset 时清零；valid mask、坐标系、法向归一化和 5 cm 邻域由 OI-Cm 模型处理。
- **Policy features**：OI-Cm 保持 `eval()` 与 `torch.no_grad()`。actor/critic 输入为
  `obs(1442) + cm_tokens(16*cm_dim) + cm_anchor_pos(16*3) + pooled_pred_obj_flow(3)`，保留 slot、
  anchor 和 object-effect 信息，不重复拼接同一 pooled token；不存在 online/target EMA 或 PPO 梯度路径。
- **Obsolete path**：移除 `CmOnlineTarget`、`cm_adapter.py` 及其 `CmResidualActor` 导出/引用，并删除
  stale 的 online-gradient 注释。OI-Cm 唯一来源为配置中的 V1.3 checkpoint。

## 4. 验证、结论和回滚

先运行静态与合同检查，再运行 CPU 单环境 `max_iterations=1` smoke；另做 zero-residual observation
shape/finite 检查。验证命令至少包括：

```bash
python3 -m py_compile third_party/IsaacGymEnvs/isaacgymenvs/tasks/cm_residual/*.py third_party/IsaacGymEnvs/isaacgymenvs/learning/cm_*.py
PYTHONPATH=third_party/IsaacGymEnvs python3 -m pytest -q src/task/CmResidual/tests
python3 .agents/skills/research-change-control/scripts/audit_diff.py --worktree --check-links
```

工程 smoke 只能证明输入/输出合同、冻结和可运行性，科研结论先标记 `INCONCLUSIVE`；不得以 smoke 或训练
回报声称 OI-Cm/残差效果成立。回滚入口为本次代码与配置提交，恢复 V1.1.4 的 vendor 文件；不删除任何
历史产物。
