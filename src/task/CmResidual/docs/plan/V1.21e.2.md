## 1. 研究问题与结论边界

V1.21e.1 已有效反驳当前 public snapshot 的直接 one-step parity。本微补充只检验：从 full-prefix
路径上冻结的 `state_(t-L)` 恢复后，最多 8 个已记录 control steps 的短 warm-up 是否足以恢复
full-prefix 在 `t` 的 candidate 前状态和相同 actor-mean action 后的 one-step outcome。

固定方法为 `L={0,1,2,4,8,full}`。若所有 `L<=8` 均失败，只能反驳“最多 8 个 warm-up control
steps 足够”；不反驳更长的 `L=16/32` 或其它 snapshot 设计。本实验不测试 Cm ranking，不修改 Cm，
不运行 512-state ranking、PPO、P=3 或 PhysX private-state reverse engineering。

## 2. Frozen inputs 与 canonical snapshot-generation pass

- 复用 V1.21e.1 的 6 个 frozen states，固定 `2 moving / 2 contact / 2 precontact`，不重新选样本；
- 复用其 source episodes 的 initial state、executed action history、state identity、actor mean action、
  reference 与输入 SHA；所有 target frame 均须满足 `t>=8`；
- 在 parity arms 之前按 episode 启动独立 canonical snapshot-generation pass：fresh single-env 从 frozen
  episode initial state 出发，严格 replay 已保存 actions，一次性在每个目标的 `t-8/t-4/t-2/t-1/t`
  截取 q/dq、全部 actor roots、task indices、reset/contact bookkeeping 与 canonical IG；
- generation pass 不计入 72 arms。它生成 run-local `canonical_window_snapshots.npz` 后即冻结只读；
  后续 arms 只能按 snapshot SHA 消费，不能边跑边生成或补写；
- manifest 独立记录 generation commit、episode/action SHA、命令、每个 `(state_id,L)` 的 snapshot SHA。
  缺字段、frame/action identity 漂移、重复 key 或 SHA 漂移均在 arms 前停止。

这些 snapshot 用于本实验的同一 full-prefix 协议路径，不改写旧 collector/source artifacts。未来若该
方案通过，正式 collector 是否原生保存逐 frame snapshot 仍属于后续计划。

## 3. 72-arm 协议

每个 `(state, method)` 使用两个完全独立 fresh subprocess，每个只有 `num_envs=1`：

```text
full: initial state -> actions[0:t] -> pre-candidate -> a0
L:    snapshot(t-L) -> actions[t-L:t] -> pre-candidate -> a0
```

其中 `a0=clip(policy_mu_t,-1,1)`；一个 action 仍为 30 Hz control / 两个 `1/60 s` PhysX substeps。
setter 后、首次 simulate 前禁止 refresh/observation/IG 重算。`L=0` 的 pre-candidate pose/q/dq/IG
直接来自 frozen setter input；`L>0/full` 在正常 post-step refresh 后读取。每个 arm 同时保存：

- source snapshot/action/task identity 与 setter input hash/error/status；
- candidate 前 q/dq/root/twist/canonical IG；
- candidate 后 q/dq/root/twist/canonical IG 与 producer-owned physics score；
- shared score baseline 继续使用 frozen collector `state_t`，object goal 仍为 `t+6`、IG target 为 `t+1`。

## 4. Target、metric 与判定

每个 state 的两个 `full` arms 必须先通过 identity、finite 和 duplicate object hard ceiling。它们的
pre-candidate target 定义为共同值；存在阈值内舍入差时，位置/q/dq/twist/IG 使用算术 centroid，
quaternion 先按 dot product 符号对齐再归一化平均。post-candidate target 同样由 full centroid 定义。

对每个 L 先计算自身 duplicate divergence，再计算其 centroid 对 full centroid 的 candidate 前与后差异。
沿用 V1.21e 的 object position `5e-4 m`、rotation `5e-3 rad` hard ceiling，以及各 metric
`max(5 × max(full duplicate, L duplicate), numerical_floor)` gate。L 只有在 6/6 states 的 candidate
前和 candidate 后全部 gate 通过时才算 pass。pre-candidate endpoint error 随 L 的曲线与 post-candidate
position/rotation/q/dq/IG/score error 全量报告；单调性本身不是数值 hard gate。

结论规则固定为：

- source/generation/setter/task identity、finite 或任一 method duplicate hard ceiling 失败：
  `INVALID_IMPLEMENTATION`；
- 存在最短 L，使该 L 及所有更长已测窗口均 pass：`SUPPORTED`，报告该最小 L；例如
  `1 fail, 2/4/8 pass` 得 `minimal_supported_L=2`；
- 出现“较短 L pass、其后更长 L fail”的非单调 pass/fail 序列且实现门禁正常：`INCONCLUSIVE`；
  例如 `2 pass, 4 fail, 8 pass` 不得宣布 L=2 可用；
- `L=0/1/2/4/8` 全部未通过：`REFUTED`，严格限定为 `warmup<=8 insufficient`。
