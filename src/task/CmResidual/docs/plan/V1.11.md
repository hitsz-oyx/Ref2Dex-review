## 数据、坐标和 retarget 合同

- 输入 shared/right NPZ 的帧数、raw frame id、object name、point identity 和 world/reference-camera frame 必须一致；
- `X_sim_from_dexycb = T_sim_obj0 @ inverse(T_dexycb_obj0)`，对 object pose、hand root 和 hand points使用同一刚体变换；
- `T_sim_obj0` 使用物体 local identity rotation，mesh 最低点置于 z=0 上方 2 mm；桌面顶面固定为 z=0；
- 五指尖 canonical index 在每个 `finger_id=1..5` 的 `region_id=1` fingertip 候选中，按距 canonical wrist
  原点最远确定，整段保持同一 point identity；
- robot wrist 使用 MANO root 加固定 `X_HB`；q6 逐帧 warm-start 最小化五指尖误差，之后应用既有
  `1 rad/s`、`20 rad/s²` 投影和 native18 mimic；
- reference key bodies/rotations来自 retarget 后的 Inspire FK，不用 MANO q 冒充 robot GT；
- 几何近邻为 robot tip/object surface `<=20 mm`，与仿真 net contact force 分开记录。

## 指标与结论

- 工程：reference/source/schema、zero residual parity、finite、正常退出；
- tracking：逐 step wrist/object reference position error、末/均值/最大值；
- interaction：tip distance、仿真 contact occupancy、几何近邻 reference occupancy；
- behavior：relative lift、episode return仅作描述；不应用 0.08 m 成功 gate。

Gate C 合同全通过可标记工程 `SUPPORTED`；tracking/interaction 数值作为单轨迹描述，DexYCB 泛化一律
`INCONCLUSIVE`。实现可运行不等于抓取成功。
