## 1. 目标与边界

本版本在已迁移的 package 基础上修正 DExplore reference contract，并接入已训练的
ObjectInteractionCm V1.3 表征。DExplore Inspire teacher `inspire.pth` 保持冻结；OI-Cm 在首个有效
实验中冻结，特征同时提供给残差 actor/critic，后续再按 replay/supervised 方案开放 online/target 更新。
本次只修改代码和配置，不提交 checkpoint、cache、output 或外部 DExplore 工作树中的文件。

用户已明确确认：取消 vendor `logs*` 忽略、使用 `inspire.pth`、同步 DExplore observation、使用
DExplore 原生 18D action。由此覆盖 V1.0 中旧的 12D residual action 合同；V1.0 数据产物和旧配置
保留为历史，不被新入口静默重解释。

## 2. 锁定合同

- observation：`1442` 维，按 DExplore 两个时间偏移（`delta_t=1`、`delta_t=16`）拼接；由 audited
  reference provider 提供未来 reference pose/object twist/contact 字段，禁止把未来 simulator state 当作 GT。
- action：`18` 维，前 6 维为 wrist，后 12 维为 Inspire finger native action。残差输出同样为
  18D，组合为 `clip(a_dexplore(obs) + delta, -1, 1)`，然后逐字节保持 DExplore
  `_action_to_pd_targets` 映射和 Inspire mimic 比例 `1.05/0.6/0.8`。
- base checkpoint：`inspire.pth`，加载前校验 observation/action 维度、网络 key 和可选 SHA256；参数
  全部 `requires_grad=False`。默认路径通过配置提供，不硬编码为某台机器的绝对路径。
- Cm：首个有效实验加载冻结的 ObjectInteractionCm V1.3 checkpoint；actor 与 critic 都接收 pooled
  Cm token。online/target replay/supervised 更新保留为后续阶段接口，不以 PPO 梯度更新 OI-Cm。
- scene/control：保持 DExplore Inspire URDF、DOF 顺序、30 Hz control（`dt=1/60`、`controlFrequencyInv=2`）、
  PD gains 和 collision filter。当前 Ref2Dex URDF 与 DExplore URDF SHA256 必须一致，否则 fail closed。
