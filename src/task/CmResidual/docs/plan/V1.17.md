## 目标与范围

在不改动外部 DExplore checkout 的前提下，新增 CmResidual Task-local 启动器，运行 DExplore 原始
Inspire state-based PPO teacher 的受控容量 smoke。该运行是 CmResidual 的外部基线，不改变 CmResidual
模型、reference、Cmv2、reward 或 buffer 合同。

固定输入与运行合同：

- external source：`/home2/wyy/oyx_ws/dexplore`，启动时严格记录 Git commit 和 clean 状态；
- GRAB data：`data/processed_data/inspire_rl_object_dexplore`，manifest
  `dexplore_inspire_rl_simulated_object_v1`，660 条 `interaction_hand_inspire.pt`。手 18-DOF 和物体 pose
  来自已有 `inspire.pth` 在 Isaac Gym 中的实际 rollout；本次待训练的 policy 仍从零初始化；
- GPU：physical GPU5；子进程设 `CUDA_VISIBLE_DEVICES=5`，将外部代码固定的逻辑 `cuda:0` 映射到该物理卡；
- runtime：独立环境 `/home2/wyy/oyx_ws/.runtime_envs/dexplore_v117`，固定 `rl-games==1.1.4`；不改动共享
  `graspenv` 的 `rl-games==1.6.5`；
- smoke budget：4 env、horizon 64、minibatch 256、1 PPO iteration、seed 42、从零初始化；
- output：新的 `outputs/Dexplore/<run_id>/`，含 `config.json`、`run_manifest.json`、`train.log`、
  仅含 660 条序列符号链接的 `motion_input/`、DExplore checkpoint/TensorBoard 子目录；
- 不使用 Horovod。若 4 env 无法运行，停止并记录，不能将多个旧 PPO rollout 混合为同一 on-policy batch；
  后续正式训练以更多独立 iteration 累积总环境步。

## 实现

1. 在 `src/task/CmResidual/tools/run_dexplore_grab_teacher.py` 新增 Task-local smoke launcher：验证外部源、
   资产、660 条数据、单样本 `(T,598)` float32 finite 合同、`rl-games==1.1.4` 运行时与 GPU5 空闲门；将
   DExplore YAML 和 CLI override 写入 config snapshot，并在启动前创建 run manifest。
2. launcher 从外部 DExplore 根运行 `dexplore/run.py`，只通过 CLI 传入 `--motion_file`、`--output_path`、
   GPU5、4 env、horizon 64、minibatch 256、max iterations 1 和 seed 42。使用实际支持的 `--output_path`，
   不使用遗留脚本中的 `--output`。`inspire_rl_object_dexplore` 内的 `_logs/` 不是 motion；启动器在新运行
   目录物化只含 660 个 motion 的符号链接视图，避免外部 loader 将日志目录当作样本。
3. 子进程完成后更新 manifest：成功时记录 checkpoint/TensorBoard 路径与 exit code；失败时记录失败原因和
   保留 train log。任何输出目录都必须是新目录，禁止覆盖。
4. 更新本 Task 的版本指针、指导、计划、README 和 activity。新建测试只验证启动器的纯输入/参数合同；实际
   smoke 负责 GPU、Isaac Gym 和 PPO 证据。

## 验证与停止

- 静态：`py_compile`、启动器 `--help`、数据/外部 source/GPU preflight 的 dry run、定向测试、`git diff --check`。
- 运行：单次 smoke 必须生成独立 manifest、config、train log、TensorBoard event 和非空 checkpoint；记录
  退出码、last epoch/frame（可得时）及工程结论。
- OOM、allocator/illegal-memory access、非有限张量、缺失 checkpoint/event 或退出码非零均为
  `FAILED` / `INVALID_IMPLEMENTATION`，不进入正式训练。
- 回滚：删除 V1.17 launcher、测试、指导/计划和本版本 activity/README/版本指针的差异；输出、DExplore
  checkout、GRAB data 和 V1.16.5 停止产物保留。
