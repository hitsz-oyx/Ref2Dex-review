## 1. 目标和已确认原因

本版本只恢复“严格全零 residual 时退化为发布的 DExplore Inspire 基线”这一前提，不训练 PPO，也不据工程
rollout 宣称 Cm 或抓取效果成立。V1.3.2 的 4 env × 367 步 gate 已证明 residual target delta 为零，但没有证明
上游基线等价；源码与数值核对确认以下阻断项：

1. CmResidual 将 hand DOF、object 和 table 全部 reset 到 identity，而 DExplore 从 motion reference reset 完整
   18D DOF、object pose/twist，并从源 tensor 设置 table pose；当前 reference wrist 首帧距 identity 约
   `1.4147 m`。
2. 当前 frozen actor wrapper 使用 ELU 且缺少 rl_games `RunningMeanStd` 的 `[-5,5]` normalization clamp；发布
   DExplore 配置使用 ReLU。
3. 当前 721D builder 只保持宽度，不保持 DExplore 的 heading frame、rotation delta、contact gating、legacy
   reference 字段和 object-surface IG 语义。
4. 当前 corrected reference 将 wrist world pose 与 finger q 分开保存，`q_native_ref[:6]` 为零，不能直接冒充
   DExplore native reset；其科学语义也不能直接作为旧 checkpoint 的训练期 teacher reference。

## 3. 实现合同

### 3.1 冻结 actor parity

- `base_policy.py` 使用与发布配置相同的四层 ReLU MLP。
- 完整复现 checkpoint `running_mean_std` inference：`(obs-mean)/sqrt(var+epsilon)` 后逐元素 clamp 到
  `[-5,5]`；不改写 checkpoint variance。
- 增加固定输入 parity test，直接以 checkpoint 权重构造预期 ReLU 路径，验证 wrapper 输出逐元素一致，并
  断言错误 ELU 路径不会误通过。

### 3.2 Legacy reference provider

- loader 显式校验 source tensor SHA、`[T,598]` shape、frame range和 finite；按 DExplore `_load_motion` 的
  source slices 重建 right-hand root、16 key bodies、contact parts、human rotations、object pose/twist、
  robot 18D q/dq 和 table pose。
- 导数先在完整 432 帧 source 上按原 30 Hz 前向差分生成，再裁剪 `[44,410]`，避免把局部首帧速度静默清零。
- object-surface IG 使用 DExplore 相同的 airplane mesh、256 点和 seed 2024；不以 object center 向量替代。
- provider 同时保留 corrected reference manifest 作为 eligibility/audit 输入，但不混入 legacy teacher tensor。

### 3.3 Observation parity

- `dexplore_observation.py` 逐字段复现 DExplore 的 646D body、39D object、36D IG，共 721D；两个 future
  offset 继续为 `+1/+16`，拼接为 1442D。
- 保留 DExplore checkpoint 实际训练时的 legacy 细节，包括 hard-coded link6/hand-base root 角色、heading-only
  frame、x/z tangent-normal rotation、reference contact gating、rotation delta 方向和 current-body duplicated
  local block，以及末维只有 3 时 `body_pos[..., 6:]` 的空切片 no-op；不在本版本“修正”这些历史语义。
- golden test 使用同一组合成 current/reference tensor，直接调用外部 DExplore 源函数并与本地 builder 比较；
  外部源码只读，不成为运行时依赖。

### 3.4 Scene/reset 和 action parity

- hand actor root 保持 DExplore identity；reset 使用 legacy source 的完整 18D q/dq，object 使用对应 pose/twist，
  table 使用 source tensor 首帧 pose。
- 删除 identity rigid-link 占位。实测确认 `set_dof_state_tensor_indexed` 后刷新 tensor 已得到与离线 FK 一致的
  body position，且 measured velocity 与 DExplore 原路径一致；因此首次 physics step 前后统一使用 Isaac Gym measured
  rigid-body state。离线 FK 只用于 reset 对齐断言，不替代 checkpoint observation。
- 同步发布配置的 `substeps=4`、PhysX 接触参数、plane friction/restitution、asset angular velocity 和原始
  Inspire shape-filter 索引行为，避免“函数一致但 simulator 不一致”的伪 parity。
- base action 到 PD target 保留 DExplore 的 zero offset、finger `(1+a)/2`、wrist current-relative增量和 mimic
  展开；不在 base-only 函数中增加发布源码不存在的最终 joint-limit clamp。
- residual 分支的最终安全 clamp 继续保留；严格零 residual env 逐环境旁路该 clamp，确保 target 与原 base-only
  mapping 精确一致。测试覆盖 source parity、mimic 和零 residual。

### 3.5 Gate 与诊断

- `eval_zero_residual.py` 新增 legacy source 输入、`V1.4.2` manifest、`terminateOnSuccess=false` 覆盖，以及
  t=0 / 首个 reference contact 附近的 wrist/object/tip transform 误差指标。
- 先运行纯 CPU 单测和 1 env 短 smoke；只有 shape、checkpoint、observation、reset 和 zero-target parity 全部通过，
  才运行 CPU PhysX、seed 42、4 env × 367 control steps的正式 gate。
- 正式运行使用新 `outputs/CmResidual/<run_id>/`，不覆盖 V1.3 失败证据。若 Isaac Gym 的显式
  `destroy_sim` 再次阻塞，独立 CLI 允许记录 `process_exit_cleanup` 并由进程退出回收 simulator；不得修改共享
  VecTask singleton 或把绕过 cleanup 冒充根因修复。

正式 gate 只有在以下全部满足时才标记工程 `SUPPORTED`：

1. 367 步完成，observation/action/target/object pose 均 finite，严格零 residual target delta 为零；
2. reset 后 wrist/object/table 与 legacy source 的 t=0 误差在浮点/FK 容差内，不再存在米级 frame 偏移；
3. rollout 不发生 success-triggered reset，出现非零接触或至少到达 source 指定的近物/接触阶段；
4. manifest、metrics、eval log 完整，并记录实际 cleanup 模式和进程终态。

单测失败、golden parity 不成立、reset 仍米级错位、formal gate 无有效近物/接触行为或出现 simulator error 时，
标记 `INVALID_IMPLEMENTATION` 并停止，不启动 PPO。本轮代码回滚入口为 base commit
`b1dac1c7955c9b960481279425f9e4e2e2269a98` 和本计划列出的显式文件；ignored 运行目录独立保留，不删除旧运行。
