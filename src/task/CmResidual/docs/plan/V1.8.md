## 目标与假设

V1.8 只检验一个假设：在冻结 DExplore base 的前提下，18D residual PPO 若从确定性零残差开始，并把探索
标准差固定为 `0.1`，能否在不先破坏 base 抓取/抬升行为的情况下完成局部学习。本版本不是 Cm 实验，
不据此评价 OI-Cm。

## 实现范围

1. `CmResidual` 增加显式 `useOiCmContext` 开关。默认保持 V1.7 的 `true`；V1.8 safe 变体设为 `false`，
   actor/critic 都只接收原始 1442-D DExplore observation，不构造 surface geometry、不加载或推理 OI-Cm。
2. 新增 `CmResidualSafePPO` 配置变体：18D action、mean head 权重和 bias 精确零初始化、
   `logσ=ln(0.1)=-2.302585092994046`，且 sigma 在 stability gate 中不参与梯度更新。
3. `CmBuilder` 仅在配置显式 `learn_sigma=false` 时冻结 state-independent sigma；旧配置缺省保持可学习，
   不改变 V1.7 checkpoint 语义。
4. 新增 V1.8 training/evaluation runner：每次写入独立 `outputs/CmResidual/<run_id>/`，记录配置、输入 SHA、
   checkpoint、metrics、日志与终态 manifest；禁止覆盖旧 run。
5. 增加 Task-local 合同测试，验证默认 Cm 路径兼容、no-Cm 观察维度、零 mean、固定 `σ=0.1`、18D action、
   reward/residual scale/clamp 合同未漂移。

## 明确保留的不变量

- action 维度仍为 18；mimic/null directions、`compose_physical_residual()` 和 zero/nonzero clamp 行为不改。
- physical residual scale 保持 `0.015 m / 0.20 rad / 0.08 rad`。
- reward 保持 `20*lift - 2*tip_distance - 0.01*mean(residual^2)`；success 阈值和 reset 语义不改。
- DExplore checkpoint、eligible v2 reference、legacy-parity source tensor及其 SHA 不改。
- seed42、physical GPU5、64 env、horizon32、minibatch2048、PhysX buffer `8388608/5.0` 不改。
- 不加载 V1.7 residual checkpoint；V1.8 stage 20 只允许从同一 V1.8 stage 10 checkpoint 恢复。
- 不修改 OI-Cm checkpoint/模型、指导、共享 `src/base/`、外部 DExplore checkout 或其他 Task。

## 后续运行顺序与 gate

本轮只实现和验证代码，不启动 GPU 实验。后续 `run-only/operation` 按以下顺序执行，每步使用独立 run：

1. **B0 same-protocol baseline**：GPU5、64 env、seed42、367 control steps、`terminateOnSuccess=true`、
   no-Cm、全零 residual；保存 `mean_env_max_lift_m`、mean contact occupancy、tip distance 和 success 指标。
   `mean_env_max_lift_m` 定义为每个环境在完整 367 步内（跨 success reset）达到的最大 object lift，再对
   64 个环境等权平均；每个环境从 `0 m` 起累计最大值，避免 reset 后的失败/下落阶段把 preservation 指标变负。
2. **T10**：随机初始化 V1.8 safe residual PPO，训练 10 epochs；训练前 deterministic mean action 必须全零，
   初始 sigma 必须逐维等于 `0.1`。
3. **E10**：加载 T10 checkpoint，执行与 B0 完全相同的 deterministic mean-action rollout。
   若 `mean_env_max_lift_m` 或 mean contact occupancy 任一低于 B0 的 `80%`，立即 `STOPPED`，不启动 T20。
4. **T20/E20**：仅在 E10 通过时，从显式 T10 checkpoint 恢复到总 epoch 20，并重复 deterministic evaluation；
   使用相同 `80%` preservation gate。

baseline 与 evaluation 的配置快照必须逐项验证 GPU、env 数、seed、367 steps、reset、reference/source SHA、
reward、residual scale、no-Cm observation 和 preservation metric schema 一致。整段 batch/time `mean_lift_m`
继续记录为诊断量，但不得用于 preservation ratio。工程 gate 通过只能标记 residual stability `SUPPORTED`；
是否改善抓取仍为 `INCONCLUSIVE`，需要重复 seed 和独立 benchmark。

## 停止条件

- observation、target、reward、模型、optimizer 或 action 出现 non-finite；
- deterministic 初始 mean 非零、sigma 不等于 `0.1` 或 sigma 可训练；
- checkpoint observation/action shape 或输入 SHA 不匹配；
- subprocess/Isaac Gym/PhysX 异常退出；
- E10/E20 任一 preservation ratio `<0.8`。

任一条件触发时停止后续阶段，写入 `FAILED`/`STOPPED` 和 `INVALID_IMPLEMENTATION` 或 `REFUTED` 的对应终态，
不得静默换卡、改 reward、改 residual scale、启用 Cm 或追加长训。
