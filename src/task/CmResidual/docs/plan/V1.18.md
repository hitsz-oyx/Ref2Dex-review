## 目标

实现指导定义的主线：reference-conditioned PPO 以 `+1/+16` future reference 产生 18-D Gaussian residual
proposal；冻结的 Cmv2 仅在交互激活环境中批量评估 proposal 周围的 K=8 个 feasible candidates，产生
stop-gradient soft teacher；PPO rollout 仍执行自身采样 action，actor 更新时才加入带 valid weight 的 distillation
loss。Cm 不进入 actor observation、critic、reward 或 optimizer。

实现按以下阶段交付，避免在基础 contract 未验证时启动正式训练：

1. V1.18 reference/observation、reward/termination、PPO loss/buffer 和 frozen planner 的 CPU/GPU smoke；
2. Stage A：`lambda_cm=0` 的 64-frame reference PPO warm-up；
3. Stage B：从明确 pin 的 Stage-A checkpoint 恢复，`K=8` 和 `lambda_cm>0` 的 distillation；
4. Stage C：在 A/B 的固定输入、seed、reward 和 authority 不变时依次将 window/horizon 从 64 提至 128、366；
5. Stage D：只在 transition-only buffer 的离线 Cmv2-vs-PhysX 检查支持其可靠性时，评估 fast actor 与 planner mode；不在线微调 Cmv2。

每阶段均独立输出到 `outputs/CmResidual/<run_id>/`，不覆盖 V1.16/V1.17 运行或 checkpoint。

## 保持不变的合同

- 数据 scope 固定为训练可用的 `s1_airplane_lift` GRAB retargeted reference、其 source tensor、airplane/table
  资产、世界坐标、米、弧度、30 Hz、随机 reference window 采样和固定 reference clock `t -> t+1`。
- action 仍为 `[-1,1]^18` residual；`q_target=q_ref[t+1]+Delta q(a)`，V1.14.4 feasible authority、joint/mimic
  coupling/limits、400/40 wrist PD、18-D action 行为语义和 PhysX 控制频率不变。zero residual 必须严格保留
  reference target。不得因本版本扩大 authority。
- Cmv2 checkpoint/SHA/schema/model config 固定；始终 `eval()`、`requires_grad_(False)`、`inference_mode()`。
  它不在线更新、不进入 critic/reward、不会直接产生训练 rollout action，也不被写入 planner candidate
  point cloud 到 transition buffer。
- V1.16 的 `[base68, Cmv2-token/effect] -> 214-D actor` 保留为旧 ablation 配置；不重解释、覆盖或加载为
  V1.18 checkpoint。旧 config、runner、buffer shard、output 和用户已有未提交文件保持。
- candidate 与 teacher 只使用 pre-action simulator state、pinned future reference、actor old-policy mean 和 frozen
  Cmv2 output；禁止读取 post-action simulator state。teacher 在一个 PPO rollout/mini-epoch 内固定，并对其
  detach/stop-gradient。

## 需先冻结的 V1.18 新合同

### 1. Reference-conditioned observation

- 新 raw actor/critic observation 均为 1442-D：两个 721-D blocks，对应 `r[t+1]` 与 `r[t+16]`。每个 block
  固定为 hand/body 646-D、object 39-D、interaction graph 36-D；每一字段必须明确 source、world/local frame、
  单位、normalization 与 mask。PPO network 不再做 V1.16 的 726->214 token encoder/attention。
- 现有 `RetargetedReferenceProvider` 的 `frame()` 仍返回旧 source tensor 重建的 428-D legacy DExplore reference；
  它与 `robot_q/object_state/link_pose` 的 retargeted reference 并非同一轨迹。因此新增 V1.18 reference builder
  或 provider method，显式从 retargeted `q_native_ref`、`wrist_pose_world_ref`、`link_pose_world_ref`、
  `object_pose_world_ref/object_twist_world_ref` 及 pin 的 contact/reference fields 构建 721-D contract。不得静默把
  旧 `hoi_data` 当成新 actor 的 future reference。
- `+16` 超过尾帧时的 clamping 与 stage window/reset sampling 必须确定性、可测试；观测只使用所选 reference
  index 的合法帧，所有形状和 finite 条件 fail-fast。

### 2. Frozen one-step Cmv2 planner

- 以 old policy Gaussian mean `mu[B,18]` 为中心构造 `[B,K=8,18]`：包括 `mu`、zero-reference baseline，以及
  antithetic bounded perturbations。候选先经过同一 feasible-authority mapping；无法执行、非有限、无 interaction
  support 或无有效 token 的 candidate 为无效。
- 新 Torch GPU FK 接口处理 `[B,K,18] -> [B,K,L,4,4]`，继而批量构造 1538 hand surface sweep；严禁 V1.18
  热路径调用 `InspireKinematics`、`.cpu()`、`.numpy()` 或逐 candidate Python/Cmv2 forward。
- 所有 active candidates flatten 为一个 `[B_active*K,...]` Cmv2 batch。Cmv2 输出 `delta_xi_root`、token mask/mass
  和 finite status 后恢复 `[B_active,K,...]`；token 全空的 root-head effect 必须视为 invalid，不能参与 teacher cost。
- desired effect 固定为 current object local `log(inv(T_ref[t]) @ T_ref[t+1])`；effect translation/rotation cost
  分别按 `0.02 m`、`0.05 rad` 标准化，rotation 使用 SO(3) relative angle。candidate IG 使用 candidate hand 与
  Cmv2-predicted next object pose；reference IG 使用 `t+1` reference hand/object，并在 root-heading local frame
  比较 6 个 key points 的 nearest-surface displacement。
- planner activation 由 reference/current proximity、reference effect 或 candidate swept-path proximity 决定。
  inactive 或没有任何 valid candidate 时，teacher action/weight 必须为安全的 zero weight，绝不将 invalid effect
  解释成改进。softmax 仅对 valid costs 运算，teacher 为加权 action，另记录 entropy/valid fraction。

### 3. PPO buffer、network 和 loss

- 扩展 V1.18 的 rl_games rollout buffer，增加每 step `cm_teacher_action[B,18]` 和 `cm_teacher_weight[B]`；只由
  rollout 时的 old-policy mean/planner 产生。teacher target 在 PPO mini-epochs 内不得重算。
- actor loss 为 `L_PPO + lambda_cm * mean(weight * ||mu_theta(obs)-stopgrad(teacher)||^2)`；critic 只优化标准 PPO
  value loss，不读取 teacher action、Cmv2 token/effect/cost。`lambda_cm=0` 时实现必须与 V1.18 reference-PPO
  baseline 在相同 seed/action sampling 下数值等价。
- 新 task/train config、专用 PPO agent/model builder 和 Task-local launcher 必须显式声明 1442-D input、18-D action、
  `K`、noise/temperature、planner gate、cost weights、`lambda_cm`、random seed、Stage-A initial checkpoint 与
  Stage-B resume checkpoint。旧 rl_games agent/model/config 不改写。

### 4. Bounded reward、scope termination 与 transition-only evidence

- 用有界 DExplore-style dense reward 替换当前 unbounded reference-transition reward：hand/reference、object
  position/rotation/velocity、IG、五个 contact、actual-vs-reference transition、residual magnitude/smoothness 各自
  独立记录未加权/加权 term；所有 metric 的 frame、单位和 normalizer 固定在 config/manifest。
- reference clock 不 freeze。actual hand/object tracking error 超过固定阈值，或 reference-contact phase 触发更严格
  阈值时 done；done 之后从另一有效 reference start reset。success、超时和 scope-divergence 原因分别记录。
- 保留 V1.16 transition-only field 集及不写候选点云的约束；若为 planner 诊断新增字段，必须新增 versioned buffer
  schema，保留 V1.16 reader/shard 兼容。离线重建 executed action 的 Cmv2-vs-PhysX error，不能在 rollout 中额外
  运行 executed-action Cmv2。

## 冻结的第一版参数与边界

1. **721-D field contract。**每个 block 严格复用 `dexplore_observation.build_dexplore_observation` 的字段顺序：
   646-D hand/body、39-D object、36-D IG（当前六个 key link 的 18-D heading-local nearest-surface displacement，
   以及同一坐标系的 future-reference minus current 18-D displacement）。reference 的 428-D transport 由 retargeted
   `wrist_pose_world_ref`、`link_pose_world_ref`、`object_pose_world_ref`、`object_twist_world_ref` 和相邻帧差分构建；
   不读取 legacy source `hoi_data`。16-D reference contact 由对应 retargeted link 到 reference object sampled
   surface 的距离阈值 `0.02 m` 重建，保留 source contact 仅作 legacy audit，绝不混入 V1.18 actor input。
2. **Reward/termination。**所有 tracking term 均用 `exp(-error/scale)`：hand position/rotation/linear velocity/
   angular velocity 为 `0.02 m/0.10 rad/0.50 m s^-1/2.0 rad s^-1`，object 为
   `0.02 m/0.05 rad/0.50 m s^-1/2.0 rad s^-1`，IG 为 `0.02 m`，transition 为 `0.02 m/0.05 rad`。
   初始权重固定为 hand `0.25`、object `1.0`、IG `0.50`、contact `0.25`、transition `0.50`，residual magnitude/
   smoothness penalty 各 `0.01`。scope divergence 为 hand-tip mean `0.12 m` 或 object `0.15 m`；reference-contact
   phase 时分别收紧为 `0.06 m` 与 `0.08 m`。成功仍只作 lift `>0.08 m` 指标，不作为提前终止条件。
3. **Planner。**`K=8`，candidate 为 `mu`、zero 及三对 antithetic `N(0,0.15^2)` perturbation，经既有 feasible
   mapping 后去重/掩码；gate 为 current/reference tip-object min distance `<=0.04 m`、reference local translation
   effect `>=0.002 m`、rotation effect `>=0.01 rad` 或 candidate swept path 距离 `<=0.04 m`。temperature `tau=1.0`，
   effect/IG/trust 权重 `1.0/0.5/0.05`，translation/rotation normalizer `0.02 m/0.05 rad`，`lambda_cm=0.10`。
   Stage A 设 `lambda_cm=0`；Stage B 才启用 `0.10`。单 rank 同时 active 环境上限为 `16`，超过时按确定性轮转选择，
   每个被选环境的 K=8 candidates 仍合成一次未分块 Cmv2 forward；未被选环境的 teacher fallback 是 actor mean，weight `0`。
4. **运行阶段。**实现验收仅运行 128 env、64 horizon 的一个 rollout/update smoke。正式阶段预算固定为 A `50M`、
   B `50M`、C-128 `100M`、C-366 `100M` env steps，128 env/rank，双 GPU DDP；每 `5M` steps 保存 checkpoint。
   A/B 只在此前阶段 checkpoint、输入 SHA、finite loss 和 transition audit 已记录时进入。每次正式运行另写
   `run_manifest.json` 与 activity；本计划本身不启动长训。
5. **C evaluation。**C 仅在完成 A/B 后评估。planner-invalid state 执行 actor mean，`teacher_weight=0`；该 fallback
   同时写入 metrics，避免把 invalid Cmv2 root-head 输出当作 action。
