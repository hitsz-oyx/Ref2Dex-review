## 目标

修正 V1.20b 的 tracked-only vendor snapshot 不包含 DExplore 刻意忽略的运行时对象网格这一资产闭包缺口，且不把原始数据或生成资产提交进 vendor。

## 范围与不变量

- 每次 `--execute` 前，仅从 `data/raw_data/GRAB/objects/{airplane,table}/mesh.obj` 字节复制到 DExplore 约定的、Git 忽略的 `dexplore/data/assets/mjcf/objects/<name>/<name>.obj`。
- 固定 SHA256：airplane `dcbb1cce38e65b3ee608e20f0846cbf93aa3b7bbf863a67582d9944f9a0d64f0`；table `25c6fb8b774a04f5314a13a538b9c26886716d196d46a68979e817755cf0e383`。源文件、目标文件或已有目标哈希不符即停止，绝不覆盖。
- 不使用软链接；不修改 DExplore tracked 源码、URDF、数据 tensor、reward、observation、action、physics、seed、checkpoint 语义或外部 checkout。该 ignored asset 目录保持不纳入 Git。
- 每个 run manifest/config 记录 raw source、目标、哈希及本次是否实际物化；运行仍使用新的不可覆盖 run_id。
