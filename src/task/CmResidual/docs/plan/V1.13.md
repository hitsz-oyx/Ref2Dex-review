## 目标与本版顺序

将 GRAB `reference_tracking_v2/s1_airplane_lift/reference.npz` 的重定向轨迹作为确定性的名义 PD target，取消 DExplore 网络在 CmResidual 新路线中的 base 推理。每个控制步的参考索引固定前进；手指取 `q_native_ref[t+1, 6:18]`，腕部从 `wrist_pose_world_ref[t+1]` 经锁定 URDF 的零位 hand-base 变换逆解为 native `joint1:6`。两部分合成 18-D native base target，再叠加 residual。末帧结束 episode，不重复末帧目标。只训练 residual，不训练新的 base 策略。保留已有运行和旧 checkpoint 的可复现入口，不把新旧 base 的指标直接混作同一基线。

先实现新的确定性 base 路径与零 residual 评估。先在无物体接触或 ghost object 条件下测手腕、关节与指尖追踪误差；若无法稳定追踪，停止 PPO，先诊断控制器动力学或参考目标。随后在有物体条件下检查接触、漂移、物体运动和 residual 可行域。只有上述门禁通过并另行确定训练协议，才进入局部窗口 residual PPO。

## 拟固定的科学边界

- 沿用既有 30 Hz 控制、Inspire/YCB 资产、世界坐标和米/弧度单位；不修改重定向数据、GT、split、物体 pose、Cmv2 权重或共享 `src/base`。
- 名义目标从上述 GRAB `reference.npz` 的 `q_native_ref` 和 `wrist_pose_world_ref` 共同构建，并校验 18-D native 顺序、mimic、关节范围、腕部 FK 回代、长度、finite、SHA 和 manifest；不再用 `interaction_hand_inspire.pt` 重建 DExplore teacher reference 作为新 base 的事实来源。该产物现有 manifest 为 `split=train`、`training_eligible=true`、367 帧、30 Hz。
- residual 继续在物理目标空间叠加，保持现有 18-D 动作及 `0.015 m / 0.20 rad / 0.08 rad` 尺度；对零 residual 和非零 residual 使用一致的关节/耦合约束，记录请求值、实际值与饱和情况。不得通过裁剪把不可行动作伪装成有效候选。
- 参考时钟每个控制步前进一帧；不由接触、Cmv2 或策略失败冻结 phase。随机起始帧仅用于未来训练窗口，完整评估从 frame 0 开始。
- Cmv2 保持冻结并用于局部候选 effect 信息或评分的后续比较；当前没有证据让它控制 phase，也不把其预测当成 Isaac Gym 真值 reward。
- DexYCB 本版不用于训练或 Gate；其 evaluation-only 72 帧参考仍保持 `training_eligible=false`。GRAB 的随机窗口分布、horizon、早停阈值与 reward 在启动 PPO 前按 Gate 结果补充确定，不翻转旧 manifest。

## 拟修改范围

1. 在 Task 内 reference provider 增加直接读取、验证重定向 `q_native_ref` 的新路径；保留旧 DExplore 路径供历史运行复现。

3. 为新 base 设计仅含当前物理状态与允许的 reference 误差/期望局部变化的 residual observation；不得把未来 GT 或执行后的状态作为当步策略输入。observation 的确切字段、维度与 checkpoint 兼容边界在定稿前冻结。
4. 新增 Task 局部零 residual/ghost object 评估入口与定向合同测试；运行写独立 `outputs/CmResidual/<run_id>/`，包含配置快照、manifest、逐步误差和日志。

## 已确认与阶段边界

用户确认使用 GRAB 现有重定向数据、直接以重定向结果为 base。`q_native_ref` 的腕部六维实测全为零，而腕部运动单独存于 `wrist_pose_world_ref`；因此按既有 URDF 逆解补足腕部，合成绝对 18-D PD target，是实现用户目标所必需的语义修正。该逆解对 367 帧的 FK 回代最大矩阵误差为 `8.71e-08`。本版先落地确定性 base 和无接触追踪 Gate；Gate 失败时停止 PPO，训练阶段参数须根据结果修订本最终计划并再次协商。

## 验证、停止与回滚

- 静态检查：reference SHA/manifest/schema、目标维度和有限值、索引 `t→t+1`、末帧行为、mimic/关节限制；定向 `pytest src/task/CmResidual/tests/`。
- 工程 Gate：zero residual 的 target parity、无接触手腕/关节/指尖误差、物理对象开启后的接触与跟踪差异，全部记录逐帧数据；任何数据合同不符或无接触追踪明显失败时停止训练。
- 科研 Gate：只有完整帧 0 轨迹和必要对照产生独立结果后，才评估 residual/Cmv2 的作用；工程 smoke 不支持效果结论。
- 回滚仅撤销 V1.13 新路线的 Task 局部代码、配置、测试和记录；旧 run、旧 checkpoint、用户未提交改动及数据产物不覆盖、不删除。

用户在了解增益对照后的分阶段流程及 GPU5 方案后回复“可以”，批准先做隔离的低层控制修正 Gate：

1. 只为 `CmResidualGrabRetargeted` 将腕部六个 DOF 的 position drive stiffness/damping 从硬编码提取为 Task 配置；原值 `200/20` 保持默认。手指 `100/10`、30 Hz、物理资产、reference clock、`q_ref[t+1]`、residual 尺度、reward、Cmv2 和旧 DExplore 任务不变。
2. 在独立无接触 GPU5 运行中预先固定比较 `200/20`、`300/30`、`400/40` 三组腕部增益，均从 frame 0 跑 366 步，seed 42、1 env、GPU pipeline；使用 canonical `num_subscenes=4`，不设置已知会在 GPU `prepare_sim` 崩溃的 `num_subscenes=1`。三组均在同一 GPU/PhysX 协议下比较，不拿此前 CPU 运行的误差直接计算增益收益。输出腕部/指尖误差、相位滞后、接触与饱和。按追踪误差与有限性选择候选，不用抓取 reward 挑选。

4. 满足无接触 Gate 后再用同一配置和 GRAB 物体做零 residual 全轨迹评估，检查实际接触、tip distance、object pose、相对 lift 与目标饱和；此时仍不直接启动 PPO。训练窗口、早停、reward、对照与预算需要再写入明确的训练修订计划。

## V1.13.3 之后的速度前馈提议（`draft`，尚未批准执行）

GPU5 预定三组增益在 GRAB 接触标记帧的腕部/指尖 p95 均未达到 `0.015/0.020 m`，最佳对齐仍滞后两帧，已按上述停止条件结束增益搜索。下一步建议保持 `400/40` 增益作为单一诊断候选，在原 `q_ref[t+1]` position target 之外，给六个腕部 DOF 设置从同一重定向轨迹计算的 `dq_ref[t+1]` velocity target，手指 velocity target 和其他控制、资产、参考时钟、reward、Cmv2 均不变。Isaac Gym 当前接口存在 `set_dof_velocity_target_tensor`；输入前必须校验 finite、native/sim 顺序及速度限幅，不得裁剪后冒充原参考。现有 GRAB 腕部相邻帧速度最大值按 DOF 为 `0.56/0.76/0.53 m/s` 和 `1.80/1.17/1.97 rad/s`，未见 Euler wrap，仍须在仿真中核实该接口的实际 drive 语义。
