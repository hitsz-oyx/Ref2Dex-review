## 1. 目标与结论上限

V1.5 先验证非零 residual 的 simulator-side physical target 合同，再以最小 PPO budget 验证训练链路。工程 gate
通过不代表 residual 改善抓取；2-update pilot 也不构成收敛或效果证据。两阶段均保持 V1.4 frozen DExplore
baseline 不变，并把科研结论固定为 `INCONCLUSIVE`。

## 2. Reference 准入与保持不变项

- canonical task config 默认 `reference.allowIneligibleFor=""`；当 corrected manifest 为
  `training_eligible=false` 时，普通环境创建必须 fail closed。
- V1.4/V1.5 诊断工具只可显式覆盖为 `diagnostic`；本计划的训练 wrapper 只可覆盖为 `ppo_pilot`。用途和值写入
  config snapshot 和 run manifest，禁止静默把 corrected artifact 标为 eligible。
- teacher observation/reset 继续来自 checksummed legacy DExplore source `[44,410]`；corrected artifact 仅保留
  provenance/eligibility 身份，不作为旧 checkpoint 的 teacher tensor。
- 不修改 18D action schema。wrist indices `0..5` 和独立 finger indices `[6,8,10,12,14,15]` 有 physical
  authority；mimic outputs `[7,9,11,13,16,17]` 不直接请求 delta，最终 target 由既有 mimic mapping 重建。
- reward、termination、scale、模型宽度、PPO canonical defaults、checkpoint 和数据文件保持不变；pilot 的短预算
  通过独立配置/CLI override 表达。

## 3. Gate A：固定非零 residual

新增 Task-local `eval_nonzero_residual.py`，固定 CPU PhysX、seed 42、4 env × 32 steps，关闭 success reset：

- env 0/1：严格全零 residual，作为重复对照；env 2/3：全部 18 维恒定 `+0.25/-0.25`；
- 每步核对 requested delta 等于 scale 后的预期值；mimic indices/source/scale 直接读取 runtime contract，
  mimic action 维没有独立 requested delta，最终 target 满足同一 mapping；
- 零对照 target delta 精确为 0；在 rollout 前单独 reset env 3，确认 env 0..2 的 DOF/root/target/progress 等
  张量不变，以此作为跨环境隔离验收。独立 PhysX 环境在接触后的 trajectory 差异只记录、不作等值 gate；
- 非零环境 effective requested/applied delta 非零，target 保持 joint limit 内，saturation 必须如实记录；
- observation/action/target/object pose 和全部指标 finite，32 步无 reset、无 simulator error；
- 写入 `outputs/CmResidual/<run_id>/config.json`、`run_manifest.json`、`metrics.jsonl`、`eval.log`。

只有以上条件全部通过，Gate A 才为工程 `SUPPORTED`，并允许 Gate B；否则标记
`INVALID_IMPLEMENTATION` 并停止。

## 4. Gate B：PPO wiring pilot

新增独立 `CmResidualPilotPPO.yaml`，继承 canonical PPO，只冻结 pilot budget/save 设置；新增 Task-local
`run_ppo_pilot.py` 负责新输出目录、resolved config、输入 SHA、子进程日志、TensorBoard 标量导出、checkpoint
验证和终态 manifest。

- 固定 seed 42、64 env、horizon 32、minibatch 2048、mini-epochs 4、max epochs 2；随机初始化 residual PPO；
- 使用单张空闲 GPU，通过 `CUDA_VISIBLE_DEVICES` 隔离，进程内统一 `cuda:0`；不并行 seed；
- V1.5.3 仅在独立 pilot wrapper 的 CLI overrides 中设置
  `task.sim.physx.max_gpu_contact_pairs=8388608`、`task.sim.physx.default_buffer_size_multiplier=5.0`。
  对照 DExplore 小批量 export 的内存容量设置，验证 V1.5.2 原生崩溃的 buffer 假设；保持 physical GPU5、
  seed 42、64 env × 2 updates、解释器、其他 resolved 配置和全部输入 SHA 不变，新建目录复跑一次。
  canonical Task YAML、PPO 配置、solver/接触语义不变；仍失败即停止，不切卡、不切 CPU、不追加复跑。
- V1.5.4 删除 pilot wrapper 的 `num_subscenes=1` override，使 Hydra canonical `num_subscenes=4` 生效；GPU
  PhysX 在启用 GPU 时会自行强制单场景。除该字段和输出路径外，resolved config、输入 SHA、GPU5、seed42、
  64 env × 2 updates、buffer `8388608/5.0` 与其他训练变量保持不变。先做 1-env prepare smoke，再做唯一一次
  原预算 pilot；任一初始化或训练错误立即停止。
- 保持 `terminateOnSuccess=true`，至少完成 1 个 episode；
- 从 TensorBoard event 导出每 epoch `metrics.jsonl`，要求 observation/action/reward、actor/critic/bounds loss、KL、
  normalizer、checkpoint model 和 optimizer state 全部 finite；
- 保存终态 checkpoint，独立 CPU 构造两份 2005D/18D policy，加载同一 checkpoint 后对固定输入的 deterministic
  mean action 最大差 `<=1e-6`，并记录 SHA256；
- 输出目录固定为 `outputs/CmResidual/<run_id>/`，包含 `config.json`、`run_manifest.json`、`metrics.jsonl`、
  `train.log`、TensorBoard summaries、checkpoint 和 `checkpoint_validation.json`。

Gate B 通过只标记 PPO wiring `SUPPORTED`；reward 趋势、抓取改善、Cm 增益和收敛均为 `INCONCLUSIVE`。
