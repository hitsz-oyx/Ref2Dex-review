# CmResidual V1.17 用户指导：外部 DExplore GRAB teacher 基线

本版本先复现外部 DExplore 自己的 Inspire state-based PPO teacher，以建立与 CmResidual 后续路线可比较的
GRAB 基线。用户已确认先停止 V1.16.5 长训，再执行本版本；若并行环境受显存限制，以较少并行环境和更多
独立 PPO iteration 累积总环境步，不把旧 rollout 重复并入同一个 PPO batch。

## 目标

- 直接使用 `/home2/wyy/oyx_ws/dexplore` 的原始 DExplore teacher 训练代码；不改写外部 checkout。
- 使用 DExplore-compatible 的 GRAB Inspire 训练根
  `data/processed_data/inspire_rl_object_dexplore`，固定其中 660 条过滤序列。该根保留已有
  `inspire.pth` rollout 的手与物体实际状态；本版本不从该 checkpoint 续训。
- 先在空闲 GPU5 进行单卡、从零初始化的容量与一 iteration 工程 smoke；确认环境可创建、rollout、PPO 更新、
  checkpoint 与日志均正常后，再协商正式训练的并行环境数与固定预算。

## 保持不变

- DExplore 原始 teacher 的 1442-D observation、18-D action、reward、物理配置、DExplore 数据字段语义和
  训练样本筛选不修改。
- 不使用 `inspire.pth` 续训；smoke 从零初始化。
- 不改写 GRAB 输入、外部 DExplore checkpoint、外部 DExplore 源码、CmResidual V1.16.5 的停止产物或其
  checkpoint。
- `inspire_rl_object_dexplore/_logs/` 不属于 GRAB motion；训练只读取由启动器从 660 条序列生成的运行内
  符号链接视图。
- 不使用 Horovod 多卡训练；当前环境未安装 Horovod，且多卡路径尚未验证。

## 证据与停止条件

- 容量 smoke 固定为 GPU5、4 env、horizon 64、minibatch 256、1 PPO iteration、seed 42。
- 通过条件：输入与资产完整、GPU 预检通过、子进程正常退出、训练日志无 traceback、生成有限的 checkpoint
  和 TensorBoard event。
- 出现 OOM、Isaac Gym allocator/illegal-memory error、非有限指标、缺少 checkpoint 或输入/资产合同不匹配时，
  停在 smoke，不启动正式训练。
- smoke 只证明工程链路，不作为 DExplore teacher 成功、收敛或抓取效果的科学结论。
