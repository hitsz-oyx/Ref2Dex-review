# CmResidual V1.11 研究指导

## 用户目标

在不影响当前 `s1/airplane_lift` V1.10 实验的前提下，选择一条 DExplore 未见过的 DexYCB 人手—物体轨迹，
将其 retarget 为 Inspire reference，并测试 frozen DExplore base policy 的 zero-residual 物理 rollout。

## 已确认实验对象

- 数据：本地修复版 DexYCB `subject-10/right` cache；
- 序列：`subject-10/20201022_110806/right`，72 帧、30 Hz；
- 物体：`002_master_chef_can`；
- 选择规则：修复版 manifest 中第一条合格 right-hand sequence，不按结果挑选；
- base：发布的 frozen DExplore Inspire checkpoint；严格 zero residual，不训练 PPO，不使用 Cm 改变 action。

## 研究边界

1. 复用现有 Inspire wrist/finger 几何 retarget、q6/mimic、速度/加速度约束、DExplore observation、
   reference provider 和 zero-residual evaluator；新建 DexYCB 专属 adapter、产物、配置和运行目录。
2. DexYCB reference-camera 坐标不是 z-up 仿真世界。使用首帧物体位姿建立唯一刚体变换：保持整段手—物相对运动，
   将首帧 YCB 物体规范到 z-up、放置到独立桌面/地面场景。变换、物体 mesh 和全部输入 SHA 写入 manifest。
3. MANO surface 只用于几何 retarget。由固定 canonical point identity 提取五指尖目标，不把 MANO q 当作 Inspire GT。
4. DexYCB candidate mask/距离只能作为几何近邻证据，不得改名为真实接触力 GT。
5. 主要指标为 wrist/fingertip/object reference tracking、几何近邻/仿真接触、finite/reset；lift 仅报告相对首帧高度。
   不复用 airplane 的固定 `0.08 m` 成功阈值形成 DexYCB 成败结论。

## 隔离与禁止事项

- 不修改 canonical `CmResidual.yaml`、V1.10 plan、airplane reference/source、当前 B0 进程或其 outputs；
- 不覆盖 DexYCB raw/Stage4 cache/split，不改 frozen DExplore/OI-Cm checkpoint；
- 不启动 residual PPO、critic-Cm、T10/T20、多 seed 或 OI-Cm V2；
- 新物理运行不得占用当前 B0 的 GPU5，使用独立 GPU6，且每个 gate 使用新 run_id；
- retarget、asset、reference 或 reset 合同失败时停止，不能靠换序列、阈值或手工修轨迹绕过。

## 结论上限

单条 subject-10/right、单个 YCB 物体、单 seed 的结果只回答该未见轨迹上 frozen DExplore base 是否具备可运行的
工程迁移行为。无论成功或失败，都不能外推为 DexYCB、跨物体或跨人群泛化结论。
