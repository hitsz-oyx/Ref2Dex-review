可以，方案就收敛到这一版：

$$
\boxed{
\text{Retargeted Base}
+
\text{Cmv2-conditioned PPO Actor}
+
\text{Transition-only Buffer}
}
$$

不做 MPPI、不做 chunk、不做二阶段 proposal/correction，也不让 buffer 额外跑 Cmv2。

### 需要改的内容

1. **保留 V1.15 actor 架构不变。**
   Raw observation 仍然是：

   $$
   68+16\times40+6+6+6=726D
   $$

   网络内部：

   $$
   16\times40
   \rightarrow
   \text{token encoder + self-attn + effect-conditioned pooling}
   \rightarrow128D
   $$

   最终 actor：

   $$
   [68,\;128,\;\hat\xi^{base}_6,\;\xi^{ref}_6,\;e^\xi_6]
   =
   \boxed{214D}.
   $$

   Critic 继续只看 68-D。这个当前已经实现，不改。

2. **Actor-side Cmv2 仍然只预测 nominal base effect。**

   $$
   q^{base}_{t+1}=q^{ref}_{t+1}
   $$

   Cmv2 输入：

   $$
   (O_t,H_t,\Delta H^{base}_t)
   $$

   输出：

   $$
   Z_t^{Cm},\quad \hat\xi_t^{base}.
   $$

   Reference 给：

   $$
   \xi_t^{ref}
   =
   \log\left[(T^{ref}_{obj,t})^{-1}T^{ref}_{obj,t+1}\right].
   $$

   Actor 学：

   $$
   \delta a_t=
   \pi_\theta
   (o^{base},Z^{Cm},\hat\xi^{base},\xi^{ref},
   \xi^{ref}-\hat\xi^{base}).
   $$

   最终：

   $$
   q^{target}_{t+1}
   =
   q^{ref}_{t+1}
   +
   \Delta q(\delta a_t).
   $$

3. **把 actor 的 nominal-base Cmv2 路径改成纯 GPU。**
   这是正式规模训练前最重要的工程改动。

   当前 evaluator 仍经过：

   $$
   GPU\rightarrow CPU\rightarrow NumPy\ FK
   $$

   不适合大量 env。

   但 nominal base 根本不需要重新 FK，因为 reference 已经有：

   $$
   H^{ref}_{t+1}.
   $$

   所以直接：

   $$
   H_t^{actual}
   \quad+\quad
   H_{t+1}^{ref}
   $$

   在 GPU 上生成 current/next hand surface：

   $$
   \Delta H^{base}
   =
   H^{ref}_{t+1}-H_t^{actual}
   $$

   再送 Cmv2。

   即 actor hot path 必须做到：

   ```text
   Isaac Gym state GPU
          +
   reference link pose GPU
          ↓
   hand surface / sweep GPU
          ↓
        Cmv2 GPU
          ↓
        actor
   ```

4. **CmBuffer 改成 `transition_only`。**
   正式训练每一步只保存真正不可替代的 transition：

   $$
   (s_t,a_t,s_{t+1},reference_t).
   $$

   我建议字段固定为：

   * `q_pre`, `dq_pre`
   * `object_pose_pre`
   * `residual_action`
   * `reference_target`
   * `pd_target`
   * `applied_delta`
   * `authority_limited`
   * `reference_index`
   * `reference_start_index`
   * `window_progress`
   * `reference_delta_xi`
   * `q_post`, `dq_post`
   * `object_pose_post`
   * `actual_delta_xi`

   **删除在线 buffer 需要的：**

   $$
   predicted\_delta\_xi,
   predicted\_effect\_score,
   candidate\_valid
   $$

   等 executed-action Cmv2 prediction。

   因为这些以后都可以由保存的：

   $$
   q_{pre},q_{target},object\ pose
   $$

   离线重建。

5. **Buffer 不再额外调用 `evaluate_cmv2_actions(actions)`。**
   现在 `pre_physics_step()` 为 buffer 又对 executed residual 跑一次 Cmv2。这个删除。

   正式训练每一步只有：

   $$
   \boxed{1\times Cmv2}
   $$

   ——就是 actor 必须使用的 nominal-base Cmv2。

   PhysX step 后只计算：

   $$
   actual\_delta\_xi
   $$

   并写 transition。

6. **Buffer 写盘改成批量 staging。**
   当前 `append()` 会立即：

   ```python
   tensor.detach().to("cpu").numpy()
   ```

   单环境没问题，大量 env 会产生很多 GPU/CPU 同步。

   改成：

   ```text
   GPU transition staging
          ↓
   累积一批
          ↓
   一次 batched CPU copy
          ↓
   NPZ shard
   ```

   每个 rank 独立目录：

   ```text
   cm_buffer/rank_000/
   cm_buffer/rank_001/
   cm_buffer/rank_002/
   ```

7. **Base 68-D normalization 单独处理。**
   当前 V1.15 因 structured token 关闭了整个 observation 的 `normalize_input`。

   我建议正式训练时：

   $$
   base68\rightarrow RunningMeanStd
   $$

   但：

   * 16×40 token 不做全局 running normalization；
   * predicted/reference/error effect 使用现在显式的 \(0.02m/0.05rad\) normalization。

   这样不会破坏 token mask / geometry semantics，同时保留 PPO 对 base state 的正常尺度处理。

8. **做真正的 multi-GPU runner。**
   当前 runner 仍锁死 GPU5 / 64 env。

   正式版本改成 `torchrun` / rl_games multi-GPU：

   $$
   rank_i
   \rightarrow
   \text{local Isaac Gym}
   +
   \text{local frozen Cmv2}
   +
   \text{local transition buffer}
   $$

   PPO 参数做 DDP 同步。

   第一轮容量建议先：

   $$
   3\times128=384\text{ envs}
   $$

   如果 Cmv2 forward 和显存余量稳定，再升：

   $$
   3\times256=768.
   $$

---

### 不需要改的东西

以下都冻结：

$$
\boxed{q^{base}=q^{ref}_{t+1}}
$$

18-D residual、V1.14.4 feasible authority、mimic/joint limits、400/40 wrist PD、reference-transition reward、random reference-window curriculum、Cmv2 checkpoint 和 Cmv2 参数都不改。

也不再增加：

* 5 cm hard gate；
* MPPI；
* action chunk；
* proposal/correction head；
* Cmv2 reward shaping；
* Cmv2 critic input。

---

最终正式训练链路就是：

```text
current PhysX state
       +
retargeted reference
       |
       +------> 68-D base state
       |
       +------> actual hand + next ref hand
                    |
                    v
              frozen Cmv2
             /           \
        16×40 tokens    predicted effect
             \           /
              attention pool
                    |
         desired effect + error
                    |
                    v
               214-D actor
                    |
             18-D residual
                    |
        q_ref[t+1] + residual
                    |
                  PhysX
             /             \
          reward       transition_only buffer
```

我认为把上面 **GPU nominal sweep、transition-only buffer、分批写盘、多卡 runner** 四块完成后，就具备正式规模训练条件了。
