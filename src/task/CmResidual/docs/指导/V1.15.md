可以，而且我觉得这样以后结构会清楚很多。核心是：**Cm 不只是提供 token，还应该显式提供“base 预计产生的 effect”；reference 再提供“我们希望产生的 effect”。Actor 学的是两者之间需要什么 residual correction。**

我建议最终 actor 输入这样组织：

$$
\boxed{
o_t^{actor}
=
[
o_t^{base},
z_t^{Cm},
\hat{\xi}^{base}_t,
\xi^{ref}_t,
e^\xi_t
]
}
$$

其中五部分职责完全不同。

### 1. Base observation

继续用现在的 68-D：

$$
o_t^{base}
=
[
q_t,\dot q_t,
q^{ref}_{t+1}-q_t,
T^{obj}_t,
T^{obj,ref}_{t+1}
].
$$

这个负责告诉 actor：

> 当前机器人和物体在哪里，reference 下一步要去哪。

不改。

---

## 2. Cmv2 tokens：不要 flatten，做 attention pooling

Cmv2 当前有：

$$
Z_t\in\mathbb R^{16\times40}.
$$

40 维包括：

$$
32\text{-D learned token}
+3\text{ anchor}
+3\text{ normal}
+1\text{ mass}
+1\text{ valid}.
$$

先做 token embedding：

$$
z_i^{0}
=
\mathrm{MLP}_{token}(Z_i)
\in\mathbb R^{128}.
$$

然后 1–2 层轻量 self-attention：

$$
Z^{attn}
=
\mathrm{TransformerEncoder}(Z^0).
$$

最后不要简单 mean pool，我更推荐 **conditioned attention pooling**。

也就是用“当前任务需要什么 effect”作为 query。

---

# 3. Cmv2 预测的 effect

这里用的不是 residual action 的 effect，因为 actor 此时还没输出 residual。

而是 **nominal base action 的 predicted effect**：

$$
q^{base}_{t+1}=q^{ref}_{t+1}.
$$

计算：

$$
H_t^{actual}
\rightarrow
H_{t+1}^{base}
$$

得到：

$$
\Delta H_t^{base}.
$$

然后：

$$
C_m(
O_t,H_t,\Delta H_t^{base}
)
\rightarrow
\boxed{
\hat{\xi}^{base}_t
}
$$

其中：

$$
\hat{\xi}^{base}_t
=
[
\hat{\Delta x},
\hat{\Delta\omega}
]
\in\mathbb R^6.
$$

这句话很关键：

> **Cmv2 告诉 actor：如果什么 residual 都不加，只按照重定向轨迹走，物体预计会怎么动。**

---

# 4. 期待的 effect

这个直接来自 reference object trajectory，不需要学习。

$$
\xi^{ref}_t
=
\log
\left[
(T^{obj,ref}_t)^{-1}
T^{obj,ref}_{t+1}
\right].
$$

也是：

$$
\boxed{
\xi^{ref}_t\in\mathbb R^6
}
$$

前三维：

$$
\Delta x^{ref}
$$

后三维：

$$
\Delta \omega^{ref}
$$

所以 actor 同时看到：

```text
Cmv2 predicts:
object should move like A

reference wants:
object should move like B
```

这就是 residual 最直接的输入。

---

# 5. 我还会显式给 effect error

虽然神经网络理论上可以自己算：

$$
\xi^{ref}-\hat{\xi}^{base},
$$

但我建议直接输入：

$$
\boxed{
e^\xi_t
=
\xi^{ref}_t-\hat{\xi}^{base}_t
}
$$

也是 6-D。

因为它直接表达：

> **base 缺的 object effect 是什么？**

例如：

$$
e^\xi=
[
+0.008,\,
-0.003,\,
+0.012,\,
0.02,\,
-0.05,\,
0.01
].
$$

Actor 可以学：

> 要补这么一个 object effect，我该怎样改 wrist/fingers。

所以 effect 相关一共：

$$
6+6+6=18D.
$$

---

# 6. Attention pooling 的 query 就可以用 effect mismatch

这里反而是最漂亮的一点。

不要使用固定 learned `[CLS]` token 做 pooling。

生成 query：

$$
q_t^{attn}
=
MLP(
[
o_t^{base},
\hat{\xi}^{base}_t,
\xi^{ref}_t,
e^\xi_t
]).
$$

然后：

$$
\alpha_i
=
\operatorname{softmax}
\left(
\frac{
q_t^{attn}K_i^\top
}{\sqrt d}
\right)
$$

最后：

$$
z_t^{Cm}
=
\sum_i\alpha_iV_i.
$$

这样 attention 的语义就是：

> **针对当前“缺失的 object effect”，哪几个局部 hand-object interaction token 最重要？**

这比 unconditional mean pooling 强很多。

比如：

* 需要向上 lift 时，它可能关注 thumb/index contact token；
* 需要 object rotation 时，可能关注另一侧的 contact geometry；
* 远离物体时 token mask 大量无效，pool 自然退化。

# 7. 最终 actor 大概只有 214-D

假设 attention pool 输出：

$$
z^{Cm}\in\mathbb R^{128}.
$$

那么：

$$
68
+
128
+
6
+
6
+
6
=
\boxed{214D}.
$$

比现在直接 flatten：

$$
68+640=708D
$$

还更紧凑。

结构：

```text
              current state + reference
                       |
                     68-D
                       |
        +--------------+----------------+
        |                               |
        |                     nominal base sweep
        |                               |
        |                              Cmv2
        |                        /               \
        |                 16 x 40 tokens       predicted effect
        |                        |                  6-D
        |                 token encoder
        |                        |
        |                  self-attention
        |                        |
desired ref effect 6-D ----> conditioned attn pooling
        |                        |
        |                      128-D
        |
pred - desired -> effect error 6-D
        |
        +------------ concatenate ----------+
                                           |
                                        214-D
                                           |
                                        PPO actor
                                           |
                                     18-D residual
                                           |
                                           v
                             q_ref[t+1] + residual
```

## 8. Effect 一定要统一坐标系

这个是硬要求。

不能出现：

* Cmv2 predicted effect 是 object-local；
* reference effect 是 world-frame；

然后直接相减。

两边都应该统一为目前 evaluator 已经采用的：

$$
T_t^{-1}T_{t+1}
$$

即 **current object local frame** 下的 one-step rigid transform。

translation：

$$
\Delta x_{local}
$$

rotation：

$$
\Delta\omega_{local}
$$

这样：

$$
e^\xi
=
\xi^{ref}-\hat\xi^{base}
$$

才有物理意义。

---

## 9. 还应该做 normalization

不要把原始米和 rad 直接拼进去。

按照我们现在 reward 已经使用的尺度：

$$
s_x=0.02\,m,
\qquad
s_R=0.05\,rad.
$$

所以输入 actor 的 effect 用：

$$
\bar\xi
=
[
\Delta x/0.02,\;
\Delta\omega/0.05
].
$$

最好再 clamp，例如：

$$
[-5,5].
$$

那么 predicted、desired、error 三组都在相似数值尺度。

这个非常重要，否则 128-D token embedding 和 6-D effect 的数值分布差别会比较乱。

---

# 10. Actor 最终学的其实是一个很明确的函数

$$
\boxed{
\delta a_t
=
\pi_\theta
\left(
s_t,
r_{t+1},
\underbrace{Z^{Cm}_t}_{哪里在交互},
\underbrace{\hat\xi^{base}_t}_{base会造成什么},
\underbrace{\xi^{ref}_t}_{希望造成什么},
\underbrace{e^\xi_t}_{还差什么}
\right)
}
$$

我觉得这才是我们一直想要的 **Object-Interaction-Cm Residual Policy**。

Cm 不再只是“一个 640-D feature”。

它给 actor 两种不同的信息：

$$
\boxed{\text{tokens = interaction structure}}
$$

和

$$
\boxed{\text{effect = interaction consequence}}
$$

Reference 则提供：

$$
\boxed{\text{desired consequence}}.
$$

然后 PPO 学：

$$
\boxed{\text{怎么修改 hand action 来补 effect error}}.
$$

这版我认为已经足够清晰，也适合直接扩展成正式大规模训练架构。
