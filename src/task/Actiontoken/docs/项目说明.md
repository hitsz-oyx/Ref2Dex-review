# Actiontoken 项目说明

## 1. 目标

V2 从单个 transition 的 root-local 解析 surface flow 编码纯 articulation motion，不读取 PoseToken、trajectory context、root motion、物体或 contact。V1 的 frozen PoseToken pair 路径保留用于历史复现。

指导入口：[`指导/V1.md`](指导/V1.md)、[`指导/V1.1.md`](指导/V1.1.md)、[`指导/V2.md`](指导/V2.md)。研究记录：[`../research/log.md`](../research/log.md)。

## 2. 数据与模型

V2 数据为 beta=0、30 Hz 的 independent synthetic MANO pose pairs。PCA increment 按 small/medium/large=`0.02/0.06/0.12` mixture 采样，概率为 `0.4/0.4/0.2`，其中 50% 样本只激活 1–5 个 PCA 分量。两帧分别减去 wrist joint，解析相减后乘 100 转为 cm，再按 canonical `64×32` atlas gather。

`FlowActionEncoder` 对 `[B,64,32,3]` patch flow flatten 后独立执行 `96→256→384`，输出 `[B,64,384]`；decoder 为 `384→256→96`。encoder 和 decoder 都使用 odd projection，解析保证 static token/flow 为零且反向输入严格变号。模型无时间维、无 patch 常量 embedding。

旧 `ActionTokenModel`、`DynamicActionEncoder`、trajectory generator 和 V1 配置均保留，不影响已有 InteractionDynamics V14 checkpoint 的复现。

## 3. 当前结果

32 trajectories controlled overfit 使用 V2 morphology-normalized PoseEncoder，6000 steps / 5:48。最佳 checkpoint 为 step 5808：val RMSE `0.00865 cm`，zero `0.03576 cm`，改善 `75.1%`，EPE `0.0991 mm`；slow/medium/fast RMSE 为 `0.00261/0.00999/0.02378 cm`。static/reverse residual 均严格为零。

改用 V1 fixed-morphology PoseEncoder 的 4000-step 对照，最佳改善为 `74.0%`，没有改善瓶颈。

V1.1 在同一批 32 条轨迹上完成归因对照。去除 temporal Transformer、直接由 local/global PoseToken pair 预测 flow 的 A 组改善 `94.54%`；只读取 local PoseToken pair 的强 MLP B 组改善 `92.90%`；surface-pair oracle 在 4000/20000 steps 分别改善 `90.00%/97.74%`；不训练、分别解码两帧 PoseToken 后作差的 D 组改善 `82.55%`。因此 frozen PoseToken 保留了足够的相邻运动信息，原 ActionToken 的约 `75%` 上限主要来自 temporal readout，而不是 PoseToken 压缩。当前仍不运行 full generalization、RootToken 或 InteractionDynamics 回接。

V2 controlled overfit 使用 32 transitions，4000 steps / 44 秒。最终 val RMSE `0.00190 cm`，zero `0.04376 cm`，改善 `94.85%`，EPE `0.0192 mm`，通过 >90% 门槛。4096/1024/1024 small generalization 训练 3200 steps / 27 秒；独立 test seed 的 RMSE `0.00306 cm`，zero `0.06534 cm`，改善 `95.29%`，EPE `0.0276 mm`。test slow/medium/fast RMSE 为 `0.000878/0.003193/0.008553 cm`，static/reverse token 与 flow 残差均严格为零。

## 4. 运行

```bash
conda run -n graspenv python -m src.task.Actiontoken.train \
  --config src/task/Actiontoken/configs/mano_v1_overfit.yaml --device cuda
```

默认从 `output/Posetoken/research/pose_encoder_v2_morph.pt` 加载 encoder。可以通过 `--set meta.pose_encoder_checkpoint=<path>` 更换。

V2 controlled overfit 与 small generalization：

```bash
conda run -n graspenv python -m src.task.Actiontoken.train \
  --config src/task/Actiontoken/configs/mano_v2_overfit.yaml --device cuda
conda run -n graspenv python -m src.task.Actiontoken.train \
  --config src/task/Actiontoken/configs/mano_v2_small.yaml --device cuda
```

V2 encoder-only checkpoint 已导出到 `output/Actiontoken/research/action_encoder_v2_flow.pt`，schema version 为 `action_token_v2_flow`；产物不提交 Git。

V1.1 probe 示例：

```bash
conda run -n graspenv python -m src.task.Actiontoken.probes \
  --mode no_temporal --steps 4000 --device cuda \
  --output output/Actiontoken/research/v11_no_temporal.json
```

`--mode` 可选 `no_temporal`、`pose_pair`、`surface_pair`、`pose_diff`；其中 `pose_diff` 不训练。

## 5. 下一步

V2 的纯局部表示假设已经在 controlled overfit 和 unseen pair generalization 上通过。下一步若扩大到 100k+，应把数据改成只保存 `(theta_t, delta_theta)`、batch 内执行 MANO forward，避免预生成 surface；之后再单独设计 RootToken，并以 V2 encoder 替换 InteractionDynamics 的 V1 ActionEncoder 做归因实验。
