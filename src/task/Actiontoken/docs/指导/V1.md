# ActionToken V1：基于预训练 PoseToken 的动态手部动作表示

## 0. 当前阶段

目前静态 PoseToken 已经完成独立预训练：

[
H_t^{root}
\rightarrow
E_{\text{pose}}
\rightarrow
(P_t,z_t)
]

其中：

[
P_t\in\mathbb R^{64\times384}
]

表示 64 个稳定手表面区域的局部静态姿态，

[
z_t\in\mathbb R^{128}
]

表示整只手的全局静态姿态。

PoseToken 已完成：

* synthetic MANO V1 固定 morphology 训练；
* 随机 (\beta) 的 morphology normalization；
* local surface reconstruction；
* global full-surface reconstruction；
* encoder-only checkpoint 导出。

下一阶段不再继续扩展静态 PoseToken 主架构，而是开始训练：

[
\boxed{\text{ActionToken}}
]

目标是把：

[
\text{两个相邻静态姿态}
]

转换为：

[
\text{详细的局部动态动作表示}.
]

# 2. 本阶段最重要的表示分解

完整手部动作拆为：

[
\boxed{
A_t=
\left{
A_t^{art},
A_t^{root}
\right}
}
]

其中：

## Articulation Action

[
A_t^{art}
]

表示：

> 手自身局部关节和表面 configuration 如何变化。

例如：

* 食指屈曲；
* 拇指 opposition；
* pinch closing；
* 五指张开；
* palm/finger relative deformation。

---

## Root Action

[
A_t^{root}
]

表示：

> 整只手作为一个刚体如何平移和旋转。

例如：

* 整只手向前移动 3 cm；
* wrist 绕自身轴旋转；
* 手保持姿势不变但整体靠近物体。

两者必须分开。

# 7. MANO pose trajectory

生成：

[
\theta_0,\theta_1,\dots,\theta_8
]

共 9 帧。

建议：

首先：

[
\theta_0\sim p(\theta)
]

使用 PoseToken 当前已经验证过的 MANO PCA mixture sampling。

随后：

[
\theta_{t+1}
=

\theta_t+\delta\theta_t.
]

其中：

[
\delta\theta_t
\sim
\mathcal N(0,\Sigma_{\Delta}).
]

并进行合理 clamp。

---

# 8. 不要直接做 Brownian noise

简单逐帧独立：

[
\delta\theta_t\sim N(0,\sigma^2)
]

容易形成明显 jitter。

推荐加入速度状态：

[
v_{t+1}
=

\alpha v_t+\epsilon_t
]

[
\theta_{t+1}
=

\theta_t+v_{t+1}.
]

例如：

[
\alpha=0.8\sim0.95.
]

这样生成：

```text
open
  ↓
slightly closing
  ↓
further closing
  ↓
pinch
```

而不是：

```text
open
↓
random pose
↓
random pose
↓
random pose
```

---
