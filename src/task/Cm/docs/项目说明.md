# Cm 任务说明

## 任务目标与边界

Cm 学习 hand-side 的动作原因表征 `C_m`：给定已知 target object、当前单手状态和未来手表面 point flow，预测目标物体在短时间跨度内的 point flow。

```text
(O_t, H_t, delta_H_t, delta_t) -> C_m -> predicted_F_obj,t
```

当前主路线 V1.2 明确采用 object-only 职责边界：目标 object 由上游选择，桌面、地面和 clutter 不进入 Cm。ARCTIC articulated object 保留，左右手仍作为两个独立 sample，不拼成 3076 点。`dataset_id` 只用于 GRAB/ARCTIC 分开统计，不进入模型。

未来 object 仅用于 Dataset 构造 `obj_flow_gt`，不能输入 DenseToken 或 Cm；所有 current/future geometry 都表达在当前 `hand_root_t` 中，不能把 future hand 转到 `hand_root_{t+s}` 后消掉整体动作。

## 当前数据合同

一个 V1.2 sample 包含：

```text
obj_points       [512,3]
obj_normals      [512,3]
obj_flow_gt      [512,3]
hand_points      [1538,3]
hand_normals     [1538,3]
hand_flow        [1538,3]
obj_valid_mask   [512]
delta_time_s     scalar
dataset_id       diagnostics only
```

GRAB 和 ARCTIC Stage4 均先固定 4096 个跨帧 correspondence 稳定的 object surface points。每个 hand side 以当前帧 5cm candidate 形成 ragged index，再通过 `uint32`、`B=4` sampling bank 取 512 点。stride 为 1--10；GRAB 使用 `120 Hz / ds_rate=4`，ARCTIC 使用 30 Hz，因此统一对应约 33--333 ms。

V1.2 cache：

```text
cm_object_v2/
├── grab/<subject>/<sequence>/
└── arctic/<subject>/<sequence>/
    ├── shared/                  # object mmap + sequence meta
    ├── left/                    # hand mmap + ragged candidate + sampling bank
    └── right/
```

train/val/test 在每个 dataset 内按 sequence 划分后再组合，不能随机打散 frame。混合采样比例必须基于 full-data 有效 transition 数决定；当前候选规则是 `p_d` 与 `sqrt(N_d)` 成正比，但尚未由全量统计确认。

## 模型与训练

V1.2 不修改模型和 loss，以隔离数据变化：

```text
current object + current hand
    -> Frozen DenseToken
hand token + hand geometry + hand flow + contact prior
    -> Slot Attention (16 slots)
    -> C_m
object token + C_m
    -> object point flow
```

DenseToken 保持 `eval/no_grad`，Cm checkpoint 不保存其权重。Cm 使用 hard-gated Slot Attention；若全部 slot 低于阈值，deterministic fallback 保留得分最高的一个。Loss 仍为米制 object point-flow vector SmoothL1，不增加 articulation、contact、rigidity 或 dataset-specific loss。

三个 scale 职责独立：

- `geometry_input_scale`：Cm head 的坐标输入缩放。
- `hand_flow_input_scale`：hand flow 输入缩放。
- `object_flow_target_scale`：flow target/loss normalization；公开预测仍为米制。

正式 scale 只能从 train split 统计。GRAB 与 ARCTIC RMS 若接近，可使用统一 global scale；若差异显著，应先分析 sampler 与有效梯度权重，不能直接引入 dataset-specific normalization 改变监督语义。

## 评估

主指标为有效 object point 加权的 EPE（mm），并报告：

- overall、GRAB、ARCTIC EPE 与 GT norm；
- zero-flow baseline；
- action shuffled 与 action reverse EPE；
- stride 1/5/10 及 mean-stride EPE；
- slot active count、fallback、usage 和 assignment entropy。

`relative_epe`、`norm_ratio` 必须在完整 loader/epoch 聚合后计算，不能平均 batch ratio。完整 stride 指标写入 JSONL，W&B 只保留摘要和关键 stride。最佳 checkpoint 使用 `val/mean_stride_epe_mm`；test 不参与模型选择。

## 运行方式

以下命令使用：

```bash
PY=/home2/wyy/miniconda3/envs/graspenv/bin/python
```

生成 Stage4：

```bash
$PY -m process.GRAB.stage4_cm \
  --grab-root dataset/GRAB --output-root data/processed_data/cm_stage4_v2/grab \
  --num-obj-points 4096 --ds-rate 4 --candidate-threshold 0.05 --device cuda:0

$PY -m process.ARCTIC.stage4_cm \
  --output-root data/processed_data/cm_stage4_v2/arctic \
  --num-obj-points 4096 --ds-rate 1 --candidate-threshold 0.05 --device cuda:0
```

ARCTIC root 会自动从 `data/raw_data/ARCTIC/arctic` 探测，也可显式设置 `REF2DEX_ARCTIC_ROOT`。

转换、sampling 和统计：

```bash
$PY -m process.common.object_cache_v2 \
  --input-root data/processed_data/cm_stage4_v2 \
  --output-root data/processed_data/cm_object_v2

$PY -m src.task.Cm.tools.data.build_object_sampling_bank \
  --root data/processed_data/cm_object_v2 --bank-size 4 --num-points 512 --seed 42

$PY -m src.task.Cm.tools.data.compute_object_v2_stats \
  --root data/processed_data/cm_object_v2 --min-stride 1 --max-stride 10
```

训练与相关测试：

```bash
$PY -m src.task.Cm.train --config src/task/Cm/configs/object_v2_grab_arctic.yaml

/home2/wyy/miniconda3/bin/conda run -n graspenv \
  python -m pytest -q tests/test_cm_object_v2.py tests/test_cm_scene.py
```
