# Cm 任务说明

## 任务目标

Cm 从当前 hand-object 状态和未来 hand action chunk 学习交互原因表征 `C_m`，并预测未来点流。模型仍接收 512 个点和 1538 个 hand 点；Scene Cache V1 将前者的语义从 manipulated object 扩展为当前手附近的 local scene points（object + environment），不增加额外 environment loss。

## V1 数据链

```text
raw GRAB -> scene mmap -> ragged 5cm candidates -> sampling bank -> online Frozen DenseToken -> Cm
```

V1.1 的 index 顺序是 manipulated asset 后接各 environment asset；每个 asset 的 4096 点和 `asset_offsets` 写入 sequence metadata，因此不同 sequence 可以有不同 scene pool 大小。environment 在 GRAB backend 中通过通用 asset 接口读取；Cm 模型不读取 `scene_source_id` 或 `scene_asset_id`，这些字段只用于分开统计。Sampling bank 使用 `uint32`。V1.1.2 的正式路线只保留 geometry/candidate 与 sampling 两层 cache，训练时在线运行 Frozen DenseToken；feature bank 代码仅保留给诊断和显式消融。

V1.2 改为 object-only multi-dataset 合同：复用 GRAB/ARCTIC Stage4 的 `shared.npz/left.npz/right.npz`，转换为 mmap geometry、ragged 5cm candidate 和 B=4 sampling bank。`dataset_id` 只用于分开统计，不进入模型；首阶段保持 Frozen DenseToken。

## 运行方式

```bash
python3 -m process.GRAB.stage4_cm_scene --grab-root dataset/GRAB --output-root data/processed_data/cm_scene_v1_1 --num-obj-points 4096 --points-per-asset 4096 --candidate-threshold 0.05 --ds-rate 4 --device cuda:0
python3 -m src.task.Cm.build_sampling_bank --root data/processed_data/cm_scene_v1_1 --bank-size 4 --num-points 512 --seed 42
python3 -m process.GRAB.build_cm_split --data-root data/processed_data/cm_scene_v1_1_full --output-root data/processed_data/cm_scene_v1_1_full/splits/full_grab_v1 --source-split-json data/processed_data/stage4/splits/full_grab_v1/split.json
python3 -m src.task.Cm.compute_flow_scale --train-path data/processed_data/cm_scene_v1_1_full --split-json-path data/processed_data/cm_scene_v1_1_full/splits/full_grab_v1/split.json --min-stride 1 --max-stride 10 --num-obj-points 512
python3 -m src.task.Cm.train --config src/task/Cm/configs/sequence_full_grab_scene_v1_1_16slot.yaml
```

正式训练前应将 flow calibration 写入 train root 的 `metadata.json`，并把配置中的 target scale 与校准值同步。当前全量前两层 cache 包含 `1255/1335` 条 sequence、`2510` 个 hand stream 和 `765512` 个 side-frame；另有 80 条 sequence 因 environment 持续移动而不满足 `static_world` schema。正式 split 复用旧 `full_grab_v1` 的 sequence 归属并过滤缺失缓存，得到 `998/130/127` 条 train/val/test sequence；train-only 校准值为 `flow_target_rms_m=0.0925246432`、`object_flow_target_scale=10.8079314`。
