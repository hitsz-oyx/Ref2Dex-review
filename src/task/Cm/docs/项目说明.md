# Cm 任务说明

## 任务目标

Cm 从当前 hand-object 状态和未来 hand action chunk 学习交互原因表征 `C_m`，并预测未来点流。模型仍接收 512 个点和 1538 个 hand 点；Scene Cache V1 将前者的语义从 manipulated object 扩展为当前手附近的 local scene points（object + environment），不增加额外 environment loss。

## 主要入口

- 旧 NPZ 数据集：`src/task/Cm/dataset.py`
- Scene Cache V1 数据集：`src/task/Cm/dataset_scene.py`
- Scene cache 构建：`process/GRAB/stage4_cm_scene.py`
- Sampling bank：`src/task/Cm/build_sampling_bank.py`
- DenseToken bank：`src/task/Cm/build_dense_cache.py`
- flow 校准：`src/task/Cm/compute_flow_scale.py`
- 模型与训练：`src/task/Cm/model.py`、`src/task/Cm/runner.py`、`src/task/Cm/train.py`
- V1 指导：[`指导/V1.md`](指导/V1.md)
- V1.1 指导：[`指导/V1.1.md`](指导/V1.1.md)

## V1 数据链

```text
raw GRAB -> scene mmap -> ragged 5cm candidates -> sampling bank -> dense bank -> Cm
```

V1.1 的 index 顺序是 manipulated asset 后接各 environment asset；每个 asset 的 4096 点和 `asset_offsets` 写入 sequence metadata，因此不同 sequence 可以有不同 scene pool 大小。environment 在 GRAB backend 中通过通用 asset 接口读取；Cm 模型不读取 `scene_source_id` 或 `scene_asset_id`，这些字段只用于分开统计。Sampling bank 使用 `uint32`，dense bank 使用 active-frame-only 的 sparse mmap 映射，所有 cache 都有 schema/fingerprint 校验，失配时直接报错。

## 运行方式

```bash
python3 -m process.GRAB.stage4_cm_scene --grab-root dataset/GRAB --output-root data/processed_data/cm_scene_v1_1 --num-obj-points 4096 --points-per-asset 4096 --candidate-threshold 0.05 --ds-rate 4 --device cuda:0
python3 -m src.task.Cm.build_sampling_bank --root data/processed_data/cm_scene_v1_1 --bank-size 4 --num-points 512 --seed 42
python3 -m src.task.Cm.compute_flow_scale --train-path data/processed_data/cm_scene_v1_1 --min-stride 1 --max-stride 10 --num-obj-points 512
python3 -m src.task.Cm.build_dense_cache --root data/processed_data/cm_scene_v1_1 --dense-checkpoint src/task/Cm/densetoken_ckpt/best.pt --bank-size 4 --batch-size 64 --dtype float16 --device cuda:0
python3 -m src.task.Cm.train --config src/task/Cm/configs/sequence_full_grab_scene_v1_1_16slot.yaml
```

正式训练前应将 flow calibration 写入 train root 的 `metadata.json`，并把配置中的 target scale 与校准值同步。当前工作区未发现 GRAB 原始 `.npz`，因此本次只完成合成 cache parity 实验，未运行真实数据建 cache 或训练。
