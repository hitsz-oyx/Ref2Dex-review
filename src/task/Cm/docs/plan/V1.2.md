# Cm V1.2 执行计划（最终版）

- status: final
- date: 2026-08-30
- guidance: `src/task/Cm/docs/指导/V1.2.md`
- approval: user-approved（用户授权按 Agent 方案执行）
- change_level: L3（仓库治理、目录和版本线规则）

## 目标

建立以 `Vn.m` 为计划边界、以 `Vn.m.k` 为细分操作边界的可追溯工作流：

1. 建立版本线、操作类别、架构快照和 AI 交接规则，不修改用户指导文档。
2. 将 Task 的研究脚本、数据入口和外部资产按职责归档；配置直接声明外部路径。
3. 不移动或删除当前训练、历史输出、cache、数据和 checkpoint。

## 版本规则

- `Vn` 是用户确认创建的大版本。
- `Vn.m` 必须有 `docs/plan/Vn.m.md`；该计划可在协商期间修改，定稿后才执行。
- `Vn.m.k` 是该计划下的细分操作、并行实验或状态变更，不单独创建 plan，但必须写入 status、experiment、decision 或 modification 记录。
- `architecture/Vn.m.md` 只在用户明确要求更新架构时创建或更新；AI 不因普通参数实验自动改全局架构。
- `指导/Vn.m.md` 只由用户更新，或在用户明确指令下更新。

## 文件范围

- 数据入口：由训练/评估配置直接声明外部数据、cache 和资产路径。
- Task 专属资产入口：`src/task/Cm/assets/<kind>/<asset_id>/`；根 `assets/` 只保留迁移期兼容软链接。
- 运行追溯：run manifest 的配置快照、输入引用和输出入口。
- 治理：`AGENTS.md`、目录规范、AI 交接清单、Task 说明和根/Cm 日志。

## 不变量与兼容策略

- 保持现有训练入口、数据语义和 checkpoint 解释；路径迁移只改变 canonical 位置，旧路径保留软链接。
- 训练生成的 `run_manifest.json` 必须包含版本、配置快照、输入引用和 checkpoint/asset 引用。
- 数据实际文件仍在配置声明的 data/cache root；本次不在 Task 内新增路径索引或便捷链接。
- 外部资产不复制进 Git；迁移只移动入口并保留软链接，不移动运行中的大型 checkpoint。Task-local 资产软链接是本规则允许的兼容入口，不是数据路径索引。
- 当前 `V1.2.1` 旧 plan 文件作为历史兼容记录保留，不修改用户指导版本。
