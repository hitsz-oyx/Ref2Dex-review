可以。建议不要把 MANO 逻辑直接写死在通用 `CmFlowHead` 里面，而是拆成三层：

```text
通用 Cm hand decoder
    └── 输出自由点流 + 通用手动作特征

MANO pose auxiliary head
    └── 通用手动作特征 + 当前 MANO pose → Δpose

MANO differentiable forward
    └── 当前 pose + Δpose → MANO 合法点流
```

最终：

[
\boxed{
L=
L_{\text{free-flow}}
+\lambda_ML_{\text{MANO-flow}}
+\lambda_CL_{\text{consistency}}
+\lambda_PL_{\text{pose}}
}
]

当前 `Cm` 已经把手动作拆成 wrist rigid flow 和 articulation flow，并且 `decode_hand_from_cm()` 没有读取 GT future flow，正好可以在此基础上增加辅助分支。

# 三、新建 MANO 可微前向模块

新建：

```text

```

第一版代码可以写成：

```python
from __future__ import annotations

from pathlib import Path

import torch
from smplx import MANO
from torch import nn


class ManoForwardAuxiliary(nn.Module):
    """Convert predicted MANO pose increments into legal hand point flow.

    This module has no trainable parameters. Gradients flow from generated
    MANO points back to the predicted pose increment.
    """

    def __init__(
        self,
        model_dir: str | Path,
        *,
        num_pca_comps: int = 24,
    ) -> None:
        super().__init__()

        common = {
            "model_path": str(model_dir),
            "use_pca": True,
            "num_pca_comps": int(num_pca_comps),
            "flat_hand_mean": True,
        }

        self.right_mano = MANO(
            is_rhand=True,
            **common,
        )
        self.left_mano = MANO(
            is_rhand=False,
            **common,
        )

        self.right_mano.requires_grad_(False)
        self.left_mano.requires_grad_(False)
        self.right_mano.eval()
        self.left_mano.eval()

        self.register_buffer(
            "right_faces",
            torch.as_tensor(
                self.right_mano.faces,
                dtype=torch.long,
            ),
            persistent=False,
        )
        self.register_buffer(
            "left_faces",
            torch.as_tensor(
                self.left_mano.faces,
                dtype=torch.long,
            ),
            persistent=False,
        )

    @staticmethod
    def _apply_wrist(
        points: torch.Tensor,
        rotation: torch.Tensor,
        translation: torch.Tensor,
    ) -> torch.Tensor:
        # 与当前 Cm wrist decoder 使用完全相同的行向量约定。
        return (
            torch.einsum(
                "bni,bij->bnj",
                points,
                rotation,
            )
            + translation.unsqueeze(1)
        )

    @staticmethod
    def _face_centres(
        vertices: torch.Tensor,
        faces: torch.Tensor,
    ) -> torch.Tensor:
        # [B, 778, 3] -> [B, 1538, 3]
        return vertices[:, faces].mean(dim=2)

    def _forward_side(
        self,
        layer: MANO,
        faces: torch.Tensor,
        hand_pose: torch.Tensor,
        betas: torch.Tensor,
    ) -> torch.Tensor:
        batch_size = hand_pose.shape[0]
        zeros = torch.zeros(
            batch_size,
            3,
            device=hand_pose.device,
            dtype=hand_pose.dtype,
        )

        output = layer(
            global_orient=zeros,
            hand_pose=hand_pose,
            betas=betas,
            transl=zeros,
        )

        # 转换到腕关节局部坐标，避免 global orient/transl 重复进入。
        vertices = output.vertices - output.joints[:, :1]
        return self._face_centres(vertices, faces)

    def forward(
        self,
        *,
        current_pose: torch.Tensor,
        delta_pose: torch.Tensor,
        betas: torch.Tensor,
        is_right: torch.Tensor,
        mirror_x: torch.Tensor,
        wrist_rotation: torch.Tensor,
        wrist_translation: torch.Tensor,
    ) -> dict[str, torch.Tensor]:
        next_pose = current_pose + delta_pose

        # 第一版为实现简单，左右都算，再按照 mask 选。
        current_right = self._forward_side(
            self.right_mano,
            self.right_faces,
            current_pose,
            betas,
        )
        next_right = self._forward_side(
            self.right_mano,
            self.right_faces,
            next_pose,
            betas,
        )

        current_left = self._forward_side(
            self.left_mano,
            self.left_faces,
            current_pose,
            betas,
        )
        next_left = self._forward_side(
            self.left_mano,
            self.left_faces,
            next_pose,
            betas,
        )

        side_mask = is_right[:, None, None]
        current_local = torch.where(
            side_mask,
            current_right,
            current_left,
        )
        next_local = torch.where(
            side_mask,
            next_right,
            next_left,
        )

        # 与 Stage4 的 left→right 镜像保持一致。
        mirror_scale = torch.ones(
            current_local.shape[0],
            1,
            3,
            device=current_local.device,
            dtype=current_local.dtype,
        )
        mirror_scale[..., 0] = torch.where(
            mirror_x,
            mirror_scale.new_tensor(-1.0),
            mirror_scale.new_tensor(1.0),
        )

        current_local = current_local * mirror_scale
        next_local = next_local * mirror_scale

        rigid_next = self._apply_wrist(
            current_local,
            wrist_rotation,
            wrist_translation,
        )
        full_next = self._apply_wrist(
            next_local,
            wrist_rotation,
            wrist_translation,
        )

        mano_articulation_flow = full_next - rigid_next
        mano_total_flow = full_next - current_local

        return {
            "pred_mano_current_points": current_local,
            "pred_mano_next_points": full_next,
            "pred_mano_articulation_flow": mano_articulation_flow,
            "pred_mano_flow": mano_total_flow,
            "pred_mano_next_pose": next_pose,
        }
```

注意：

```python
self.right_mano.requires_grad_(False)
```

只冻结 MANO 模型参数，并不会阻断：

```text
pred_delta_pose
→ MANO forward
→ vertices
→ loss
```

这条梯度路径。

不要写：

```python

    output = layer(...)
```

否则才会真正切断梯度。

# 四、当前 GRAB 的 `v_template` 问题

上面的最小代码使用标准 MANO template，但你的 GRAB 预处理明确使用了每个 subject 独有的 `v_template`。如果缺失，会退回平均 MANO 手型。

因此正式训练前一定要检查：

[
E_{\text{current-fit}}
======================

\frac1N
\sum_i
|
P_{t,i}^{MANO}-P_{t,i}^{dataset}
|
]

如果重建流程正确，它应非常小。

建议第一版先：

```text
只取一个 subject
只取 right hand
加载该 subject 对应的 v_template
```

确认整个梯度和 loss 逻辑正常。

正式多 subject 时，有两条路线：

1. 使用 `smplx.lbs.lbs()` 实现 batch-varying `v_template`；
2. 按 subject 分组 batch，每个 subject 使用固定 `MANO(v_template=...)` layer。

第二种实现简单，但 batch sampler 需要按 subject 分组。第一种更适合最终版本。

不要直接忽略这个问题，否则 MANO flow loss 会同时包含：

* 动作预测误差；
* 手型模板误差。

# 十、修改 Runner 的 Loss

先抽一个加权 loss：

```python
def _weighted_point_flow_loss(
    prediction: torch.Tensor,
    target: torch.Tensor,
    point_weight: torch.Tensor,
    *,
    beta: float,
) -> torch.Tensor:
    loss_map = F.smooth_l1_loss(
        prediction,
        target,
        beta=beta,
        reduction="none",
    ).mean(dim=-1)

    return (
        loss_map * point_weight
    ).sum() / point_weight.sum().clamp_min(1e-6)
```

当前 runner 已经生成了接触和 articulation 加权的 `point_weight`，可以直接复用。

在计算完 `hand_loss` 后加入：

```python
mano_flow_loss = pred_flow.new_zeros(())
mano_consistency_loss = pred_flow.new_zeros(())
mano_pose_loss = pred_flow.new_zeros(())
mano_current_fit_mm = pred_flow.new_zeros(())
mano_epe_mm = pred_flow.new_zeros(())

if bool(getattr(self.cfg.meta, "use_mano_aux", False)):
    pred_mano_flow = prediction["pred_mano_flow"]
    pred_mano_articulation_flow = prediction[
        "pred_mano_articulation_flow"
    ]

    # MANO前向分支同样由GT点流约束。
    mano_flow_loss = _weighted_point_flow_loss(
        pred_mano_flow,
        batch["hand_flow"].float(),
        point_weight,
        beta=beta,
    )

    # 只比较 articulation，避免重复约束共享 wrist 分支。
    mano_consistency_loss = _weighted_point_flow_loss(
        prediction["pred_hand_articulation_flow"],
        pred_mano_articulation_flow.detach(),
        point_weight,
        beta=beta,
    )

    target_delta_pose = (
        batch["next_mano_hand_pose"].float()
        - batch["mano_hand_pose"].float()
    )

    mano_pose_loss = F.smooth_l1_loss(
        prediction["pred_mano_delta_pose"],
        target_delta_pose,
        beta=beta,
    )

    # 极其重要：检查MANO前向与数据中的当前点是否一致。
    mano_current_fit_mm = (
        torch.linalg.norm(
            prediction["pred_mano_current_points"]
            - batch["hand_points"].float(),
            dim=-1,
        ).mean()
        * 1000.0
    )

    mano_epe_mm = (
        torch.linalg.norm(
            pred_mano_flow
            - batch["hand_flow"].float(),
            dim=-1,
        ).mean()
        * 1000.0
    )
```

总 loss 改成：

```python
total_loss = (
    float(self.cfg.meta.loss_object_weight)
    * flow_smooth_l1

    + float(self.cfg.meta.loss_hand_weight)
    * hand_loss

    + float(self.cfg.meta.loss_mano_flow_weight)
    * mano_flow_loss

    + float(self.cfg.meta.loss_mano_consistency_weight)
    * mano_consistency_loss

    + float(self.cfg.meta.loss_mano_pose_weight)
    * mano_pose_loss
)
```

Metrics 增加：

        "mano_consistency_loss": mano_consistency_loss,
        "mano_pose_loss": mano_pose_loss,

# 十一、训练时不要一开始就开 consistency

MANO pose head 初始是随机的，如果立刻使用：

[
L_{\text{consistency}}
======================

d(
F_{\text{free}},
F_{\text{MANO}}
)
]

会让错误的 MANO 流污染自由点流。

分两阶段。

## 阶段 A：两个分支分别对齐 GT

```yaml
loss_mano_flow_weight: 0.5
loss_mano_consistency_weight: 0.0
loss_mano_pose_weight: 0.05
```

训练目标：

[
L=
L_{\text{free}}
+
0.5L_{\text{MANO}}
+
0.05L_{\text{pose}}
]

## 阶段 B：MANO 分支稳定后加入一致性

从阶段A的 checkpoint 恢复：

```yaml
loss_mano_consistency_weight: 0.1
```

再逐步尝试：

```yaml
loss_mano_consistency_weight: 0.2
```

一致性中先保留：

```python
pred_mano_articulation_flow.detach()
```

这样 MANO 分支作为 teacher，把自由点流拉向合法流形。

# 十二、开始训练前必须做的单 batch 检查

先不训练，直接打印：

```text
mano_current_fit_mm
```

正确结果应非常小：

```text
约 0～0.5 mm
```

如果出现：

```text
5 mm
10 mm
20 mm
```

不要继续训练。通常意味着：

* subject-specific `v_template` 没有加载；
* left/right MANO 使用错误；
* left→right 镜像没处理；
* PCA维度不一致；
* `flat_hand_mean` 不一致；
* MANO点没有减去 wrist joint；
* face顺序不一致。

只有：

[
P_t^{MANO}\approx H_t^{dataset}
]

成立时，MANO辅助 loss 才有物理意义。

# 十三、当前修改后的完整梯度路径

自由分支：

[
C_m
\rightarrow
F_{\text{free}}
\rightarrow
L_{\text{free}}
]

MANO分支：

[
C_m
\rightarrow
\Delta\theta
\rightarrow
MANO(\theta_t+\Delta\theta)
\rightarrow
F_{\text{MANO}}
\rightarrow
L_{\text{MANO}}
]

一致性：

[
F_{\text{free}}
\leftrightarrow
\operatorname{detach}(F_{\text{MANO}})
]

因此网络的最终输出仍然是跨执行体的自由点流；MANO只提供人手特有的可微前向约束。

未来换到机器人手时，保持：

```text
CmFlowHead
free point-flow decoder
```

不变，只替换：

```text
mano_pose_head + MANO forward
```

为：

```text
robot_delta_q_head + differentiable FK
```

不过要明确：当前 frozen dense encoder 固定要求512个物体点和1538个手点，当前配置也把 `num_hand_points` 固定为1538。真正迁移到不同结构手时，还需要统一表面采样数量，或者将 dense encoder 改成支持变长点集和 mask；仅增加 MANO/FK 辅助分支还没有完全解决输入端的跨手问题。
