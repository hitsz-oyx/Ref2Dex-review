[
q_i\rightarrow j(i)=\arg\min_j|q_i-c_j|

[
\hat{\Delta o}_{i,k}

r*{i,k}

局部 residual 只输入：

[
C_{j(i)},\quad
o_i-c_{j(i)},\quad
n_i,\quad
t_k

所以现在不能再说：

> “是不是 decoder 偷看 absolute xyz，所以不需要局部 token？”

这个问题 V4 已经基本排除了。

## 现在真正关键的发现，是 target energy decomposition

仓库新加了 `target_diagnostics.py`。

它把每个时间步的 64 个 patch motion：

[
D_j^{local}=D_j-\bar D

这个结果非常重要。

# 这基本解释了为什么一直 collapse

我们一直要求：

[
C_1,C_2,\ldots,C_{64}
]

表示不同 object patch 上的 interaction。

但是我们给它的主要监督：

[
\Delta O_j
]

本身却近似：

[
\Delta O_1
\approx
\Delta O_2
\approx
\cdots
\approx
\Delta O_{64}.
]

那么 MSE 最容易学到的当然就是：

[
C_1
\approx
C_2
\approx
\cdots
\approx
C_{64}.
]

换句话说，我们之前一直把 collapse 当成：

> 模型没有按照我们的期望学习局部结构。

但现在更准确的解释应该是：

[
\boxed{
\text{当前监督目标本来就几乎不要求局部结构。}
}
]

这不是单纯的 optimization failure（优化失败）。

而是 representation identifiability（表征可辨识性）的问题——也就是：

> 仅从当前这些 GT，能不能唯一地、稳定地推出我们想让 latent 表示的东西？

目前答案偏向：

[
\boxed{\text{不能。}}
]

[

实际上整个 4096-point object flow 的自由度，本质上只有：

网络学习：

[
\boxed{

\rightarrow

已经足够解释几乎全部 object-flow loss。

根本没必要学：

哪个 patch 是 push
哪个 patch 是 support

我最推荐下面这一套，而且可以直接从 GRAB 现有点云轨迹里算，不需要人工标注。

## 1. 第一主监督：Hand–Object Relative Motion

对每个 hand patch (i)，找它附近的 object patch (j)。

定义当前相对位置：

[
r_{ij}=h_i-o_j
]

物体表面法向：

[
n_j
]

把手的相对运动分解成两个分量。

法向运动：

[
v^n_{ij}
========

(\Delta h_i-\Delta o_j)\cdot n_j
]

切向运动：

[
v^t_{ij}
========

## (\Delta h_i-\Delta o_j)

v^n_{ij}n_j
]

其中：

* (v^n)：沿物体法向靠近/压入/离开的速度；
* (v^t)：沿物体表面滑动的速度。

这两个量实际上比 object flow 更接近我们想要的“作用方式”。

例如同样让杯子向右运动：

### 抓住搬运

手和物体一起走：

[
\Delta h_i\approx \Delta o_j
]

所以：

[
v^n\approx0,\qquad
v^t\approx0
]

表示局部接触近似 sticking（粘着：接触后两者基本没有相对滑动）。

### 从左侧推

接触建立时可能：

[
v^n<0
]

之后：

[
v^n\approx0
]

同时局部切向运动可能很小。

### 手指沿表面滑动

[
|v^t|\gg0
]

所以即使最终：

[
\Delta O
]

一样，这三个 mechanism（作用机制）也可以被区分。

这正是我们现在缺的监督。

---

# 2. 第二主监督：Contact State + Contact Change

我们现在已经有点间距离，所以不需要人工 contact label。

对于 hand patch (i) 和 object patch (j)，定义距离：

[
d_{ij}=|h_i-o_j|
]

可以产生一个 soft contact target（软接触标签：不是简单 0/1，而是距离越近接触概率越高）：

[
c_{ij}
======

\exp
\left(
-\frac{d_{ij}^2}{2\sigma^2}
\right)
]

例如：

[
\sigma=1\text{ cm}
]

或者第一版直接 threshold：

[
c_{ij}
======

\mathbf 1[d_{ij}<2\text{ cm}]
]

然后最重要的不只是当前 contact，而是整个 chunk：

[
c_{ij}^{1:8}
]

这样可以区分：

```text
未接触 → 接触
接触 → 保持
接触 → 滑动
接触 → 分离
```

也就是：

[
\Delta c_{ij,k}
===============

c_{ij,k}-c_{ij,k-1}
]

我会明确让 interaction token 预测：

[
\boxed{
\hat c_{ij,1:8}
}
]

或者预测：

[
\boxed{
\hat d_{ij,1:8}
}
]

距离回归甚至比二分类更稳定。

---

# 3. 我最推荐的 target：Relative Interaction Trajectory

把上面几个量组合起来：

[
\boxed{
y_{ij,k}
========

[
d_{ij,k},
v^n_{ij,k},
v^t_{ij,k}
]
}
]

其中：

[
v^t\in\mathbb R^3
]

所以每个 hand-object interaction pair 每个时间步监督：

[
1+1+3=5
]

维。

如果再加 contact：

[
y_{ij,k}
========

[
d,
c,
v_n,
v_t
]
]

就是 6 维。

于是你的 interaction token 学的就不再是：

> object patch 最后移动了多少。

而是：

> 这个 hand region 与这个 object region 在未来 8 帧里如何建立、维持和改变物理关系。

这和我们真正想做的 cross-embodiment representation 更一致。

[
\boxed{
C_{ij}

\text{hand patch }i
\rightarrow
\text{object patch }j
\text{ 的 interaction}
}

但没必要真的建立：

[

[

[

[

# 5. Human Action 自身仍然应该有 supervision

这个我建议继续保留。

但是不能再用：

[
\Delta H_i
]

直接监督，因为你刚才的 diagnostics 已经发现 hand patch motion 也是 98% 左右 global motion。

应该先把 hand 的 global rigid motion 去掉。

也就是先求 wrist/global transform：

[
T_t
]

把未来 hand 运动分成：

[
\Delta H
========

\Delta H^{global}
+
\Delta H^{articulation}
]

真正监督 Action Token 的是：

[
\boxed{
\Delta H^{articulation}
}
]

也就是 finger articulation（手指相对手掌的关节/形变运动）。

最简单的做法不是数学拟合 SE(3)，因为你本来就有 MANO wrist pose。

直接：

1. 每帧都变到该帧自身的 hand-root frame；
2. 比较 canonical hand surface。

即：

[
{}^{H_{t+k}}H_{t+k}
-------------------

{}^{H_t}H_t
]

这样 wrist translation / rotation 基本被去掉，只剩：

* finger bending；
* finger spreading；
* local articulation。

这比现在：

[
{}^{H_t}H_{t+k}
---------------

{}^{H_t}H_t
]

更加适合作为 action-preservation supervision。

注意：

模型 action 输入仍然可以保留当前设计，因为它需要知道真实 global action；

只是 auxiliary target 改成 articulation residual。

# 7. 我不推荐的几个监督

### 不推荐单纯 variance loss

例如：

[
L_{var}
=

-\operatorname{Var}(C)
]

只是逼 token 不一样。

但：

[
C_1\neq C_2
]

并不代表它们学的是物理 interaction。

之前的 local gain 已经证明这一点。

---

### 不推荐单纯 contrastive loss

比如不同 patch 拉开：

[
C_i\neq C_j

同样没有明确物理语义。

contrastive learning（对比学习：让应该相似的样本靠近、不同的样本分开）以后可以用，但必须先知道：

> 谁是 positive，谁是 negative。

目前这个定义还没稳定。

---

### 不推荐继续主要监督 raw object patch flow

已经有非常强的证据：

[
97%-99%
]

都是 global rigid component。

继续加权只是在重复强调 SE(3)。

# 9. 三类监督各自解决的问题非常清晰

```text
Human hand articulation
        ↓
L_action
        ↓
“手到底怎么动”


Hand ↔ Object relative trajectory
        ↓
L_relative
        ↓
“手到底怎么作用物体”


Object future motion
        ↓
L_effect
        ↓
“这种作用最后造成什么效果”
```

用公式就是：

[
\boxed{
\text{Action}
\rightarrow
\text{Interaction}
\rightarrow
\text{Effect}
}
]

三层分别有自己的 observable target（可直接从数据计算的监督量）。

这其实比现在更接近我们想从 Fast-WAM 借鉴的精神：

> 不要让一个没有直接语义约束的 latent 只靠最终 world loss 自己“悟”出 mechanism。

# 10. 如果只让我选一个新监督

那我不会先选 contact classification，也不会选 hand reconstruction。

我会选：

[
\boxed{
\text{未来 8 帧的 hand-object relative motion trajectory}
}
]

具体就是：

[
\boxed{
[d_{ij,k},,v^n_{ij,k},,v^t_{ij,k}]
}
]

因为它同时包含：

* 是否靠近；
* 是否接触；
* 是否压向物体；
* 是否离开；
* 是否滑动；
* 是否与物体一起运动。

而且最重要的是，它天然消除了大量共同 global motion。

如果手和物体一起整体平移：

[
\Delta h_i
\approx
\Delta o_j
]

那么：

[
\Delta h_i-\Delta o_j
\approx0.
]

所以我们现在最头疼的：

[
98%\ global\ motion
]

会直接被消掉。

这正是它比 raw hand flow / raw object flow 更合适的地方。

---

因此我下一版会把核心 representation 定义进一步收紧为：

[
\boxed{
C_m
===

\text{local hand-object relative interaction dynamics}
}
]

中文就是：

> **Cm 表示一段人手动作中，局部手部表面与局部物体表面之间的相对接触与运动关系，而不是手或物体自身的全局运动。**

如果按这个定义推进，下一步最有信息量的实验甚至不是立刻训练，而是先对现有 small20 数据做一次统计：计算 (d)、(v_n)、(|v_t|)、contact transition 的分布和局部能量比例。只要这些量相比 raw patch flow 有显著更强的局部差异，再开始 V5 才是合理的。
