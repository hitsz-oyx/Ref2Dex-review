当前我们代码里的 (r) 和 (d) 都是针对**每一个 object anchor** 定义的，而且使用同一组 hand-surface soft correspondence 权重。

假设第 (i) 个物体 anchor 是

[
o_i\in\mathbb R^3
]

手表面有点

[
h_j\in\mathbb R^3.
]

先根据距离计算 soft correspondence：

[
w_{ij}
======

\frac{
\exp\left(-\frac{|h_j-o_i|^2}{2\tau^2}\right)
}{
\sum_k
\exp\left(-\frac{|h_k-o_i|^2}{2\tau^2}\right)
}.
]

这里 (\tau) 控制“这个 object point 主要关注多大范围内的手表面”，目前大约是 (1.5) cm。

### (r)：relative geometry vector

[
\boxed{
r_i
===

\sum_j
w_{ij}(h_j-o_i)
}
]

它是一个三维向量：

[
r_i\in\mathbb R^3.
]

直观上：

> 从 object anchor (o_i) 指向它附近“加权平均手表面位置”的向量。

所以 (r) 同时包含：

* 手在 object point 的哪个方向；
* 大致有多远；
* 局部 interaction 的空间结构。

例如：

[
r_i=
\begin{bmatrix}
2\
0\
0
\end{bmatrix}\text{cm}
]

大致表示这个 object anchor 附近的手表面主要位于它 (+x) 方向约 2 cm。

---

### (d)：soft distance

[
\boxed{
d_i
===

\sum_j
w_{ij}|h_j-o_i|
}
]

它是一个标量：

[
d_i\in\mathbb R.
]

直观上：

> 这个 object anchor 到附近手表面的“加权平均距离”。

例如：

[
d_i=0.5\text{ cm}
]

说明这里已经非常靠近手，可能接近 contact；

[
d_i=5\text{ cm}
]

说明这里基本还没有 interaction。

我们现在很多 contact 判断，本质上就是从 (d) 派生：

[
d_i<2\text{ cm}
]

认为该 anchor 是近接触状态。

---

## (r) 和 (d) 最大的区别

最简单地记：

[
\boxed{
r=\text{方向 + 相对位置}
}
]

而

[
\boxed{
d=\text{纯距离}
}
]

如果只看：

[
d=2\text{ cm},
]

你不知道手是在物体左边还是右边。

但：

[
r=[2,0,0]\text{ cm}
]

和

[
r=[-2,0,0]\text{ cm}
]

就完全不同。

---

## 为什么 (d\neq|r|)

这个点现在尤其重要。

因为：

[
r_i
===

E_w[h-o]
]

而：

[
d_i
===

E_w[|h-o|].
]

所以：

[
|r_i|
=====

|E_w[h-o]|
]

一般不等于：

[
E_w[|h-o|].
]

根据三角不等式一定满足：

[
\boxed{
|r_i|\le d_i
}
]

举个简单例子。

假设一个 object anchor 左右两侧各有一个手表面点：

[
h_1-o=[1,0,0]
]

[
h_2-o=[-1,0,0]
]

权重都是 (0.5)。

那么：

[
r
=

0.5[1,0,0]
+
0.5[-1,0,0]
===========

[0,0,0].
]

所以：

[
|r|=0.
]

但是：

[
d
=

0.5\times1
+
0.5\times1
==========

1.

]

因此：

[
d=1,\qquad |r|=0.
]

这就是为什么不能简单写：

[
d=|r|.
]

---

所以现在我们的 (Y) 可以理解为：

[
Y_t=
\boxed{
{r_t,d_t,u_t}
}
]

其中：

* (r)：**手相对于物体局部在哪里**
* (d)：**手离物体局部多近**
* (u)：**这个对应的手表面正在怎么运动**

而 V18.2 发现的问题就是：真实数据一定满足

[
|r|\le d,
]

但 Diffusion 生成结果大约 30% 的 anchor-step 违反这个关系，说明它把本来有几何耦合的 (r,d) 当成两个普通连续变量分别生成了。
