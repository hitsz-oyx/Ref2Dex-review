# 二、三列一定使用 object-centric 坐标

这一点我建议定死。

不要把三个结果放在 world trajectory 里面直接比较。

当前代码已经有：

```python
vertices_object = (
    (vertices_world - object_translation[frame])
    @ object_rotation[frame]
)
```

这样的 world → object 坐标转换。

所以 viewer 中统一：

[
x^O=(x^W-t_O^W)R_O^W
]

然后三列分别加一个 visualization offset：

[
\begin{aligned}
x_{GT}^{vis} &= x^O + [-0.25,0,0]\
x_{Yopt}^{vis} &= x^O + [0,0,0]\
x_{PredH}^{vis} &= x^O + [+0.25,0,0].
\end{aligned}
]

具体间距根据物体大小动态设，例如：

[
\Delta x=1.5\times\text{object bbox diameter}.
]

这样：

```text
GT                   Y-opt                  Pred-H
 ↓                     ↓                      ↓

 hand                  robot                  hand
 object                object                 object
```

三列里的 object 都是**同一个 canonical object**，只是在空间中复制三份。

这特别适合你现在的目的：

> 看 interaction，而不是看世界坐标轨迹。
