# 1. V18 要学习的东西

把 V17 的

[
p(R\mid S,O,G)
]

改成

[
\boxed{
R_{t:t+H}\sim p_\theta(R_{t:t+H}\mid S_t,O)
}
]

其中

[
S_t=[r_t,d_t],
]

未来仍然是

[
F_t=
[u_t,r_{t+1},d_{t+1},\cdots].

继续使用 V16.7 已经验证成功的 residual：

[
R_t=F_t-F_t^{persist}.
]

这样模型的意思很简单：

> 给定当前手和物体的相对 interaction 状态，以及物体几何，生成接下来可能发生的抓取建立过程。

这里的多模态正是我们需要 Diffusion 的原因。

# 4. 我建议这样定义 stable grasp

不要上来引入神经分类器，也不要使用 GRAB action label。

直接从我们自己的 (Y) 定义。

对完整 sequence 先计算：

[
Y_t=(r_t,d_t,u_t).
]

### 条件一：已经发生真实近距离 interaction

例如：

[
N_c(t)
======

\sum_{j=1}^{128}
\mathbf 1[d_{t,j}<2\text{ cm}].
]

第一版先定义：

[
\boxed{
N_c(t)\ge4
}
]

即至少 4 个 object anchors 距手表面小于 2 cm。

这里 `4` 和 `2 cm` 只是第一版 operational definition（操作性定义），先通过 audit 看分布，不要马上调一堆参数。

---

### 条件二：hand-object interaction 已经稳定

因为我们的坐标系是 object-centric，所以一旦手和物体稳定绑定，

[
u_t
]

应该非常小。

定义：

[
v_Y(t)
======

\sqrt{
\frac1{128}
\sum_j|u_{t,j}|^2
}.
]

第一版：

[
\boxed{
v_Y<0.3\text{ cm/frame}.
}
]

连续：

[
W=6
]

帧满足：

```text
contact = True
interaction velocity small
```

才叫 stable。

现有 processed GRAB 实际是 120 Hz source、`ds_rate=4`，也就是训练数据约 **30 Hz**，所以连续 6 帧约 0.2 s。

---

# 5. 再增加一个“这确实是抓住了”的验证，不作为模型条件

我建议加这个，否则：

```text
摸了一下物体
停着
```

也可能被识别为 stable grasp。

要求稳定 interaction 建立后：

[
30\text{ frames}
]

内物体确实发生比较明显的运动，例如：

[
\Delta x_O>1\text{ cm}
]

或者：

[
\Delta R_O>5^\circ.
]

注意：

[
\boxed{\text{这只是 dataset annotation，不是模型输入。}}
]

它的作用只是告诉我们：

> 这个 interaction 后来确实能够带动物体，可以合理认为是 functional grasp。

因此与 V17 完全不同。

模型不知道：

```text
物体未来往哪里走
```

甚至不知道：

```text
物体未来会不会往上走
```

它只从成功的人类 demonstration 里学习抓取建立。

# 6. Stable grasp onset 定义

所以第一版直接：

```python
stable[t] = (
    contact_count[t] >= 4
    and interaction_motion_rms[t] < 0.3
)
```

然后找：

```text
连续 6 frames stable
+
未来 30 frames 内 object 有明显 motion
```

第一个满足条件的：

[
\boxed{t_g}
]

就是 stable grasp onset。

大致：

```python
for t in range(T):
    stable_run = stable[t:t + 6].all()
    object_moves = has_object_motion(t, min(t + 30, T))

    if stable_run and object_moves:
        t_grasp = t
        break
```

# 7. Dataset 不要只取一个 sample

这是一个比较重要的点。

如果每个 demonstration 只取：

[
t_g-H\rightarrow t_g
]

那即便 GRAB 很大，样本利用率还是低。

第一版我建议：

[
\boxed{H=8}
]

保持现有 Dataset 的 8-step contract。

然后一个 stable grasp event 产生：

[
t=t_g-8,\ldots,t_g-1
]

这 **8 个 sample**。

例如：

```text
t_g-8 → ... → t_g
t_g-7 → ... → t_g+1
t_g-6 → ... → t_g+2
...
t_g-1 → ... → t_g+7
```

这样所有训练样本都有一个共同性质：

> 未来 8 帧内会进入或者已经进入稳定抓取。

所以不需要：

```text
active=1
```

因为 **dataset selection 本身就是 intent**。

数学上相当于训练：

[
p(
Y_{t+1:t+8}
\mid
Y_t,O,
\text{eventually stable grasp}
).
]

最后这个条件不是作为 token 输入，而是数据分布本身定义的。

### 第一：它能不能形成稳定抓取？

对生成轨迹最后 3 帧算：

[

以及：

[

这应该成为最主要指标。

---

### 第二：是不是只复制 persistence？

比如输入还是未接触：

[
d_t=5\text{ cm}.
]

Persistence 永远还是：

[
Y_{future}=Y_t.

所以它永远不会形成 grasp。

我们比较：

```text
GT
Persistence
Diffusion
```

的：

* terminal contact count；
* terminal (d)；
* terminal (u)；
* stable grasp success rate。

如果 Diffusion 连这个都打不过，就直接失败。

---

### 第三：Diffusion 有没有学出多模态？

每个 test state 采：

[

]

记录：

[
\text{single-sample RMSE}
]

和：

[
\boxed{
\text{best-of-8 RMSE}
}
]

再记录 8 个 sample 之间：

[
\text{pairwise trajectory RMS}.
]

理想情况应该是：

```text
多个 sample 不完全一样
         +
大部分都能到 stable grasp
```

而不是：

```text
八条完全一样
```

或者：

```text
很 diverse，但大部分抓不住
```

# 15. 如果 Gate 2 过了，下一步才接我们刚刚说的物体轨迹

```text

    ↓
V18 Grasp Diffusion
    ↓

    ↓

```

    ↓

[

+
\lambda_sL_{\rm smooth}
+

+
