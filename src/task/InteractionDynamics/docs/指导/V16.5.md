# V16.5：State-Conditioned Interaction Diffusion 最小实现

## 0. 本阶段目标

V16.4 建模：

[
p_\theta(Y\mid O,E)
]

即：

> 给定物体和目标效果，从零生成完整 interaction trajectory。

这一 formulation 更接近 interaction knowledge generation，但与最终 embodiment 使用方式存在距离。

实际目标是：

> 已知当前 embodiment 与物体的交互状态，预测为了实现目标 Effect，接下来应该发生怎样的 interaction。

因此 V16.5 改为：

[
\boxed{
p_\theta(
Y_{\mathrm{future}}
\mid
S_t,Z_O,E
)
}
]

其中当前 interaction state：

[
\boxed{
S_t=[r_t,d_t]
}
]

而未来 interaction 包括：

[
\boxed{
u_t,\ S_{t+1},
u_{t+1},\ S_{t+2},\ldots
}
]

最终目标不是复现 Human trajectory，而是为任意 embodiment 提供一个短时 interaction target。

---

# 1. Interaction State / Transition 重新定义

原 Y-Teacher：

[
Y={r,d,u}.
]

现在正式拆分。

## 1.1 Interaction State

[
\boxed{
S_t=[r_t,d_t]
}
]

其中：

[
r_{t,m}\in\mathbb R^3
]

描述当前 hand surface 相对 object anchor (x_m) 的局部几何。

[
d_{t,m}\in\mathbb R
]

描述当前 hand surface 与 anchor 的距离。

因此：

[
S_t\in\mathbb R^{M\times4}.
]

当前：

[
M=128.
]

(S_t) 只依赖当前：

[
H_t,O_t
]

不包含未来信息。

---

## 1.2 Interaction Transition

当前：

[
u_{t,m}
=

\sum_i
w_{tmi}
(h_{t+1,i}-h_{t,i}).
]

因此：

[
\boxed{
U_t=u_t
}
]

表示：

> 当前靠近 object anchor (x_m) 的 hand surface，下一步如何运动。

它依赖：

[
H_t,H_{t+1}
]

因此不能作为当前 condition。

它属于 future prediction target。

---

# 2. V16.5 学习目标

对于当前时刻 (t)，输入：

[
\boxed{
S_t,\ Z_O,\ E.
}
]

预测未来 (H) 个 interaction transitions：

[
\boxed{
F_t^H
=====

[
U_t,S_{t+1},
U_{t+1},S_{t+2},
\ldots,
U_{t+H-1},S_{t+H}
].
}
]

学习：

[
\boxed{
p_\theta(F_t^H\mid S_t,Z_O,E).
}
]

Diffusion 本身建模该条件分布，因此不增加显式 latent (z)。

---

# 3. 最小 Horizon

第一版：

[
\boxed{H=4}
]

并做成 configurable 参数。

原因：

* 不需要生成完整 demonstration；
* 仍有足够未来信息表达“正在往哪个 grasp mode 演化”；
* 比纯 one-step (U_t) 更有长程约束；
* 后续 embodiment 可以采用 receding horizon，只执行第一步。

如数据接口修改成本明显更高，可以暂时：

[
H=8
]

复用现有 chunk。

但模型结构不得依赖固定 8。

---

# 4. Future Target Packing

对于每个 object anchor (m)，定义：

[
f_{t,m}^{H}
=

[
u_{t,m},
r_{t+1,m},
d_{t+1,m},
\ldots,
u_{t+H-1,m},
r_{t+H,m},
d_{t+H,m}
].
]

每一步：

[
3+3+1=7
]

维。

因此：

[
\boxed{
F_t^H
\in
\mathbb R^{M\times7H}.
}
]

若：

[
H=4
]

则：

[
\boxed{
F_t^4
\in
\mathbb R^{128\times28}.
}
]

这就是唯一进行 diffusion 的变量。

[
\boxed{

}
]

Knowledge model 不直接读取：

[
H_t.
]

Human：

[

]

Robot：

[

]

模型统一读取：

[

]

因此 embodiment morphology 不直接进入 knowledge model。

# 7. Object Geometry Encoding

Object encoder 只负责：

[
\boxed{\text{object geometry context}}
]

不负责当前 hand interaction。

输入 object point cloud：

[
O=
{p_i,n_i}_{i=1}^{N}.
]

继续使用 deterministic FPS 得到：

[
X_O=
{x_m}_{m=1}^{128}.
]

对每个 anchor (x_m) 使用 KNN 获取局部 patch：

[
P_m
===

{p_k\mid k\in\mathcal N(x_m)}.
]

局部输入采用：

[
\boxed{
[
p_k-x_m,\ n_k
]
}
]

而不是只使用：

[
[x_m,n_m].
]

# 10. Effect E

V16.4 使用完整未来 8-step object SE(3) trajectory：

[
E_{0:8}.
]

V16.5 不继续这样做。

原因：

> 完整 future trajectory 是过强条件，而且会人为区分本应属于同一个目标的不同 demonstration。

第一版使用 endpoint desired effect：

[
\boxed{
E=
(T_{O,t})^{-1}T_{O,t+H}
}
]

表示：

> 从当前时刻开始，希望物体最终发生什么变化。

提取：

[
\boxed{
e_E=
[
\Delta p,\Delta\omega
]
\in\mathbb R^6.
}
]

translation 使用 cm，rotation 使用 axis-angle / rotation vector。

---

# 11. Effect 不作为普通 Attention Token

第一版不再使用：

```text
Effect token
    ↓
cross attention
```

作为唯一 conditioning 方法。

Effect 与 diffusion timestep 联合构造 global condition：

[
c=
E_C(
e_E,e_\tau
).
]

然后用于每一个 DiT block 的 AdaLN。

AdaLN（Adaptive Layer Normalization，条件控制的归一化）：

[
\boxed{
AdaLN(h;c)
=

(1+\gamma(c))LN(h)+\beta(c).
}
]

这样 Effect 直接调制所有 denoising layers，而不是成为一个可被网络忽略的普通 token。

---

# 12. Diffusion Variable

只对未来：

[
F_t^H
]

加噪。

Forward diffusion：

[
F_\tau
======

\sqrt{\bar\alpha_\tau}F
+
\sqrt{1-\bar\alpha_\tau}\epsilon.
]

其中：

[
\epsilon\sim\mathcal N(0,I).
]

当前状态：

[
S_t
]

始终保持 clean。

Object：

[
Z_O
]

保持 clean。

Effect：

[
E
]

保持 clean。

# 15. 为什么继续对全部 Anchors 做 Self-Attention

每个 anchor 不能独立预测。

例如：

```text
handle附近：
当前 d 很小

body另一侧：
当前 d 很大
```

模型需要整体判断当前 interaction mode。

Self-attention 允许：

[
\boxed{
F_{t,m}
=

f(
S_{t,1:M},
Z_{O,1:M},
E
).
}
]

因此能够形成 coherent interaction：

> 当前已经在 handle 附近建立 interaction，则未来不同 anchors 应形成一致的 handle grasp evolution。

# 34. V16.5 核心定义

最终不再把知识定义为：

[
\boxed{
O+E\rightarrow\text{一个完整抓取轨迹}
}
]

而定义为：

[
\boxed{
\text{在当前 interaction state 下，
为了产生目标 Effect，
接下来哪些 interaction transitions 是合理的？}
}
]

数学上：

[
\boxed{
p_\theta(
U_t,S_{t+1},
\ldots,
U_{t+H-1},S_{t+H}
\mid
S_t,Z_O,E
).
}
]

其中：

[
S_t=[r_t,d_t]
]

表示当前状态；

[
U_t=u_t
]

表示 interaction transition；

[
Z_O
]

表示物体局部几何 context；

[
E
]

表示 desired effect；

diffusion noise 表达未来 continuation 的随机性和潜在多模态。

最终系统：

```text
Current Embodiment
       ↓
Analytic Interaction State S_t
       │
       ├── Object Geometry Z_O
       ├── Desired Effect E
       ↓
State-Conditioned Interaction Diffusion
       ↓
Short-Horizon Interaction Plan
       ↓
Embodiment Optimization
       ↓
Action
```

这就是 V16.5 的最小主链路。
