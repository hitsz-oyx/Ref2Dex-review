# V16.7：Clean Residual Regression 最小实验

## 0. 实验目标

V16.6 已确认：

[
G_t=[a_t,\Xi_t]
]

其中：

* (a_t)：active，表示当前是否需要操作该物体；
* (\Xi_t)：next meaningful (\Delta T)，表示物体接下来最近一小段有效运动目标；

具有一定可读信息。

但直接预测 absolute future（绝对未来）：

[
(S_t,O,G_t)\rightarrow F_t
]

仍然无法超过 persistence baseline（保持当前状态基线）。

因此 V16.7 **不修改 Goal，不修改 Y，不使用 Diffusion**。

只验证：

[
\boxed{
(S_t,O,G_t)\rightarrow R_t
}
]

是否比直接预测完整未来更容易。

其中：

[
\boxed{
R_t=F_t-F_t^{persist}
}
]

中文：

> 不预测“未来完整 Y 是什么”，只预测“未来相比保持当前状态需要改变多少”。

# 2. Persistence Future

当前：

[
S_t=[r_t,d_t].
]

定义一个最简单的“未来什么都不发生”预测：

[
\boxed{
F_t^{persist}
=============

[
0,S_t,
0,S_t,
0,S_t,
0,S_t
].
}
]

其中每一步：

[
u=0
]

表示 hand-object interaction 没有相对运动；

[
S_{t+k}=S_t
]

表示未来 interaction state 保持当前状态。

代码直接复用 V16.6：

```python
def persistence_future(state, horizon):
    return torch.cat([
        torch.cat([
            torch.zeros_like(state[..., :3]),
            state
        ], dim=-1)
        for _ in range(horizon)
    ], dim=-1)
```

输出：

```text
[B, 128, 28]
```

---

# 3. Residual Target

真实 future：

[
F_t^{GT}
]

已经由 V16.6 的：

```python
pack_state_future(...)
```

生成。

定义：

[
\boxed{
R_t
===

## F_t^{GT}

F_t^{persist}.
}
]

Shape：

```text
R_t: [B, 128, 28]
```

物理含义：

### Stable grasp

如果未来几乎不变：

[
F^{GT}\approx F^{persist}
]

则：

[
R\approx0.
]

### Approach

未来 hand-object relation 明显变化：

[
R\neq0.
]

### Contact formation

[
R\neq0.
]

### Release

[
R\neq0.
]

因此模型只需要学习：

[
\boxed{\text{什么时候、在哪里、往什么方向改变 interaction}}
]

而不需要重新生成整个已经基本正确的当前 interaction。

# 15. Gate C：Goal Dependency

保留 V16.6 Goal intervention（条件干预）。

但这次增加更强的 motion intervention。

---

## Correct Goal

[

]

---

## Motion Zero

[
G=(a,0).
]

---

## Motion Shuffle

保留原有：

[
\Xi_i\rightarrow\Xi_j.
]

但不要只依赖它。

---

## Motion Reverse

新增：

[
\boxed{
\Xi\rightarrow-\Xi
}
]

对于：

[
\Delta p
]

直接反向。

对于 rotation vector：

[
\Delta\omega\rightarrow-\Delta\omega.
]

目的：

> 构造明显不同的目标运动，避免相邻时间帧 Goal 太相似导致 shuffle 干预太弱。

重点看 dynamic active subset：

[
\boxed{
correct
<
motion\ zero
}
]

以及：

[
\boxed{
correct
<
motion\ reverse.
}
]

这里“小于”表示 GT RMSE 更低。

# 22. 实验判定

## 情况 A：Residual Regression 超过 Persistence

如果：

[
\boxed{
RMSE_{\rm residual}^{dynamic}
<
RMSE_{\rm persistence}^{dynamic}
}
]

并且 Goal intervention 有明显退化：

[
correct < zero/reverse
]

则结论：

[
\boxed{
S+O+G
\text{ 已经足以预测 interaction change。}
}
]

下一步：

[
\boxed{
\text{V16.8：Residual Diffusion}
}
]

学习：

[
p(R|S,O,G).
]

---

## 情况 B：Residual Regression 仍打不过 Persistence

则：

[
\boxed{
\text{暂时禁止继续 Diffusion。}
}
]

按顺序检查：

1. residual 是否确实具有可预测结构；
2. Goal 和 Y change 是否时间对齐；
3. active interval 是否过宽；
4. H=4 是否过短；
5. 远距离 Y 是否退化。

不要增加模型容量掩盖 formulation 问题。

# 23. 最终核心公式

当前：

[
S_t=[r_t,d_t].
]

Goal：

[
G_t=[a_t,\Xi_t].
]

Persistence：

[
F_t^{persist}
=============

[0,S_t,\ldots,0,S_t].
]

Residual：

[
\boxed{
R_t
===

## F_t^{GT}

F_t^{persist}.
}
]

模型：

[
\boxed{
\hat R_t
========

f_\theta(S_t,Z_O,G_t).
}
]

恢复：

[
\boxed{
\hat F_t
========

F_t^{persist}
+
\hat R_t.
}
]

V16.7 只回答一个问题：

> **知道当前 interaction、物体几何和目标运动以后，我们能不能预测“接下来需要改变多少”，而不是从头预测整个未来 interaction？**

只有这个问题得到肯定答案，才继续做 Residual Diffusion。
