我建议下一版不要同时改太多训练结构。**最小实现应先把“系统机制”跑通：保留现有 (Y={r,d,u}) 和 V18.6 checkpoint，把 (p) 做成由 MANO+object mesh 解析得到的 penetration field（穿透量），用于诊断和 stable latch；viewer 在 latch 后进入 object-driven 阶段，因此时间轴可以远超 8 帧。**

当前 V18 数据本来就是围绕 stable event 取局部 8-frame chunk，stable detector 也是基于 contact 和 (u) 连续若干帧判断。 当前 V18.6 loss 只有 (Y) loss，没有 penetration 项。 因此这版先不要重新定义整个训练 target。

## 最小系统应该变成

```text
                  GRASP FORMATION
 current state ──────────────────────────────┐
      │                                      │
      ▼                                      │
 V18.6 predicts 8-frame local H^O chunk      │
      │                                      │
      ▼                                      │
 execute / visualize local hand trajectory   │
      │                                      │
      ▼                                      │

      │

      │
```

[
\boxed{8\text{ frames = local planning horizon}}

而不是完整任务长度。

## 1. `p` 先不要改 Y 的维度

第一版我建议定义：

[
\phi_j=\operatorname{SDF}_O(h_j)
]

规定：

[
\phi_j>0:\text{outside},\qquad
\phi_j<0:\text{inside}.
]

然后：

[
q_j=\max(0,-\phi_j)
]

就是每个 hand surface point 的 penetration depth。

再沿用当前 (Y) 的 soft correspondence：

[
\boxed{
p_i=\sum_jw_{ij}q_j
}
]

这样 (p_i\ge0)，语义非常明确：

> object anchor (i) 对应区域发生了多少穿透。

同时直接统计：

```python
penetration_max_mm
penetration_mean_mm
penetrating_point_ratio
p_anchor_mean
p_anchor_max
```

当前 (d) 的 correspondence 权重本来就是由 object anchor 到 hand surface 的距离算出来的，所以可以直接复用。

我会先做：

```text
Y = {r,d,u}        # 不变
P = penetration    # derived physical field
```

而不是立刻：

```text
Y = {r,d,p,u}
```

这样旧 checkpoint 完全可用。

如果最终发现 (p) 对穿模特别敏感，下一版甚至也未必需要改 Y，直接：

[
L=L_Y+\lambda_pL_p
]

可能更干净。

## 3. StableDetector 不需要神经网络 head

建议新增：

```text
viewer_v2/
    stable.py
```

核心接口：

```python
@dataclass
class GraspObservation:
    d_cm: np.ndarray
    u_cm: np.ndarray
    p_mm: np.ndarray | None


@dataclass
class StableState:
    contact_count: int
    u_rms_cm: float
    penetration_max_mm: float | None
    stable_now: bool
    stable_count: int
    latched: bool
```

先复用现有定义：

[
N_c=\sum_i[d_i<2\text{ cm}]
]

[
u_{\rm rms}<0.3\text{ cm/frame}.
]

这两个阈值和当前 stable-grasp event detector 一致。

第一轮：

```python
stable_now = (
    contact_count >= 4
    and u_rms_cm < 0.3
)
```

然后连续：

```python
if stable_now:
    stable_count += 1
else:
    stable_count = 0

if stable_count >= N:
    latched = True
```

### `p` 第一轮先显示，不参与 gate

这一点我建议克制。

不要现在随便拍一个：

```text
p < 2 mm
```

然后宣布 stable。

先统计：

```text
GT stable p distribution
Pred stable p distribution
明显穿模 sample p distribution
```

如果 GT stable 的 `p_max` 基本很低，而 prediction 穿模样本明显高，再确定：

```python
stable_now &= penetration_max_mm < p_threshold
```

阈值最好从 GT stable 分布定，例如 percentile，而不是拍脑袋。

## 4. Viewer 时间轴拆成两个阶段

当前 viewer slider 明确是：

```python
frame_slider = ...
min=0
max=8
```

所以当前 UI 天然只能播放 current+8 future。

改成：

```text
0 ---------------- g --------------------------- T
| model grasp      | object-driven manipulation |
| prediction       |                            |
```

假设预测在 frame (g) 触发 latch。

### frame `0...g`

继续显示：

[
\hat H_0^W,\ldots,\hat H_g^W.
]

### frame `g+1...T`

不再请求网络生成新的 grasp。

先把 latch 时刻 hand mesh 转到 object frame：

[
V_{H,g}^{O}
===========

(V_{H,g}^{W}-t_{O,g})R_{O,g}.
]

你当前 viewer 的 object world transform 用的是：

```python
world_vertices = vertices @ R.T + t
```

所以继续严格沿用这套 row-vector convention，不要自己混另一套矩阵习惯。

之后每帧：

[
\boxed{
V_{H,k}^{W}
===========

V_{H,g}^{O}R_{O,k}^{T}+t_{O,k}
}
]

也就是说：

```python
for k in post_latch_frames:
    hand_world[k] = (
        latched_hand_object @ object_R[k].T
        + object_t[k]
    )
```

这样 finger articulation 也自然冻结在 latch 时刻。

## 5. 物体轨迹不要只读取当前 9 帧

现在 provider 只恢复：

```python
raw_ids = item["raw_frame_ids"]
```

也就是当前 sample 对应的 9 帧。

而 V18 cache 本身保存了 sequence 中的 `raw_frame_id` 映射；原 GRAB 还先从 120 Hz 默认降到了 30 Hz。

因此 provider 应该额外恢复：

```python
full_raw_frame_ids
```

然后从 latch 对应的 sequence frame 往后取，例如：

```python
--post-latch-frames 60
```

在当前 30 Hz cache 下大约就是 2 秒。

不要：

```python
raw_id + 4
```

自己猜。

直接读取 sequence cache 中的：

```python
shared["raw_frame_id"]
```

做映射。

## 9. 这版的验收标准

我只要求四件事：

1. 同一 sample 能看到 `0~8` 的真实模型 grasp formation；
2. 一旦 detector latch，timeline 自动继续到 >8，并且物体抬起时 MANO 手保持 object-relative grasp 一起移动；
3. 没 latch 的 sample 不允许伪造后续 manipulation；
4. viewer 能同时显示 GT/Pred 的 penetration，确认“明显穿模的 prediction 是否真的有更大的 (p)”。

只要这四件事成立，我们就已经回答两个重要研究问题：

\boxed{
\text{Y 是否足够产生可检测的 stable interaction event？}
}
]

以及：

[
\boxed{
\text{object-centric grasp 是否能自然接到后续 object trajectory？}
}
]
