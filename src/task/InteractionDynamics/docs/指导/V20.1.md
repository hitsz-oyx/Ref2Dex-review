[

## 1. V20.1 的完整架构

保持当前：

[
(Y_t,O_t)
\rightarrow Z_{1:N}
\rightarrow \Delta\tilde Y_{1:H}
]

得到：

[
\tilde Y_{1:H}
==============

Y_t+\Delta\tilde Y_{1:H}.
]

然后新增独立 MANO projector：

[
\boxed{
\tilde Y_{1:H}
\xrightarrow{\text{optimize }H_{1:H}}
H^**{1:H}
\xrightarrow{MANO}
Y^H*{1:H}
}
]

注意几个原则：

* **不改 V20 network**
* **不训练 `Z→H`**
* **不使用 GT-H loss**
* **不把 H 输入回 V20**
* **不 backprop through V20**
* 第一阶段就是一个 offline feasibility evaluator

所以 V20 和 projector 完全解耦。

# 6. 第一版 optimization 不优化 p

当前 `penetration.py` 是 numpy ray casting / triangle distance，不可微。

所以第一版：

[
\boxed{
E_Y
===

E_r+E_d+E_v
}
]

不要为了 p 再引入复杂 SDF。

具体最好用 V20 checkpoint 的 channel std 做 normalization：

[
E_r=
\left|
\frac{r_H-\tilde r}{\sigma_r}
\right|^2,
]

[
E_d=
\left|
\frac{d_H-\tilde d}{\sigma_d}
\right|^2,
]

[
E_v=
\left|
\frac{v_H-\tilde v}{\sigma_v}
\right|^2.
]

也就是：

```python
field_error = (
    (mano_y[..., :7] - predicted_y[..., :7])
    / field_std[..., :7]
).square().mean()
```

这样不会因为 r/d/v 数值尺度不同而被某一个 channel 主导。

# 7. 再加两个很轻的 H regularizer

第一版不要堆物理 loss。

总 energy：

[
\boxed{
E=
E_Y
+
\lambda_sE_{\rm smooth}
+
\lambda_pE_{\rm prior}
}
]

### Smoothness

对整段 (\Delta H) 联合优化：

[
D_0=0,\qquad D_k=\Delta H_k
]

然后：

[
E_{\rm smooth}
==============

\sum_{k=1}^{H}
|D_k-D_{k-1}|^2.
]

但 position、rotation、pose 单位不同，因此分开 normalize：

[
E_s=
E_{\Delta p}
+
E_{\Delta\omega}
+
E_{\Delta\theta}.
]

初始可以用：

```text
translation scale = 1 cm
rotation scale    = 0.2 rad
pose scale        = 0.2
```

作为数值尺度，不是硬阈值。

### Prior

先只限制极端 hand PCA：

[
E_{\rm prior}
=============

|\Delta\theta/0.5|^2
]

权重要很弱。

先不要 GT H prior。

# 10. 最关键的判断表

最终我们可能得到四种情况：

| free Y | projection gap | projected Y→GT | 结论                              |
| ------ | -------------: | -------------: | ------------------------------- |
| 好      |              小 |              好 | 最理想，Y 本身基本可实现                   |
| 好      |              大 |             变差 | MANO projector/optimization 有问题 |
| 一般     |              大 |         **变好** | MANO constraint 很有价值            |
| 差      |              小 |             仍差 | dynamics/Y representation 才是问题  |

尤其第三种：

[
D(\tilde Y,Y^{GT}) >
D(Y_H,Y^{GT})
]

如果大量出现，就很强地支持你刚才的判断：

[
\boxed{\text{H constraint 确实在纠正 free-field 的不可实现预测}}
]

# 13. 两个当前 bug 一起修

这两个我建议现在就放进同一个改动。

### Bug 1：p normalization statistics 被 invalid 0 污染

当前：

```python
mean, std = values.mean(0), values.std(0)
```

会把 invalid window 中默认填的 `p=0` 也算进 p statistics。

改成：

```python
def channel_statistics(dataset):
    values = torch.cat([
        dataset[i]["delta_y"].reshape(-1, 8)
        for i in range(len(dataset))
    ])

    mean = values[:, :7].mean(0)
    std = values[:, :7].std(0).clamp_min(.01)

    valid_p = torch.cat([
        dataset[i]["delta_y"][..., 7].reshape(-1)
        for i in range(len(dataset))
        if bool(dataset[i]["p_valid"])
    ])

    if valid_p.numel():
        p_mean = valid_p.mean().reshape(1)
        p_std = valid_p.std().clamp_min(.01).reshape(1)
    else:
        p_mean = torch.zeros(1)
        p_std = torch.ones(1)

    mean = torch.cat([mean, p_mean])
    std = torch.cat([std, p_std])

    return (
        mean.reshape(1, 1, 1, 8),
        std.reshape(1, 1, 1, 8),
    )
```

---

### Bug 2：persistence p metric 没有 mask invalid

现在 prediction p 会 mask：

```python
value = value[mask]
```

但 persistence p 没 mask，最后却除以 masked count。

改成类似：

```python
p_target = target[..., 7]
p_mask = batch["p_valid"][:, None, None].expand_as(p_target)

absolute[3] += (
    pred[..., 7] - p_target
)[p_mask].abs().sum()

persistence[3] += p_target[p_mask].abs().sum()

count[3] += p_mask.sum()
```

最好把 r/d/v/p 的 evaluator 分开写清楚，别继续一个循环里特殊判断 p，减少这种 bug。
