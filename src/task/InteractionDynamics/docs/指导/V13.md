\boxed{
\text{Static Pose Pair}
\rightarrow
\text{Incremental ActionToken}

这条路线基本成立。

而且当前实现确实已经是你之前设想的形式：

[
S_t,S_{t+1}

所以这部分**先不要再大改**。

# 所以下一步我建议直接做 V13

我会把目标定义成：

[
\boxed{
\textbf{Local ActionToken → embodiment-agnostic interaction bottleneck}
}
]

而不是再做一个 Action reconstruction V13。

具体结构我推荐：

```text
Static Pose Pair
      ↓
V12 Action Encoder
      ↓
A_t = 64 local ActionTokens
      │
      │
      │ KV
      ▼
Object Tokens O = 64 patches ── Q
      ↓
Object→Action Cross Attention
      ↓
I_t = 64 object-indexed interaction tokens
      ↓
K latent slots / Perceiver pooling
      ↓
C_m,t = K × D_c
      ↓
Object SE(3)
```

关键区别：

以前：

[
64\ A
\rightarrow
\text{mean}
\rightarrow
1\ C.
]

现在：

[
\boxed{
64\ A
+
64\ O
\rightarrow
64\ I
\rightarrow
K\ C.
}
]

我第一版会取：

[
\boxed{K=8}
]

或者最多 16。

所以最终：

[
C_m\in\mathbb R^{8_{\text{time}}\times8_{\text{slot}}\times128}.
]

# 为什么我推荐 slot，而不是直接让 (C_m=64) 个 hand patches

因为你最终还是要跨 embodiment。

如果直接：

[
C_{m,j}\leftrightarrow hand\ patch_j,
]

那么又会遇到：

```text
MANO 64 patches
Allegro 64 patches
LEAP 64 patches
```

之间没有对应关系。

而 learnable latent slots（可学习潜变量槽：固定几个查询向量从任意数量输入 token 中聚合信息）没有这种要求：

[
A_H^{64}
\rightarrow
C^{8}
]

[
A_R^{N}
\rightarrow
C^{8}.
]

所以：

[
\boxed{
\text{ActionToken 可以 embodiment-specific；
C slot 应该 embodiment-independent。}
}
]

这个正好符合我们前面定下来的职责边界。

沿用现在已经验证成功的 Action supervision。

暂时只通过 object effect 学。

                    L_action
                       ↑

先把结构本身验证清楚。

# V13 最重要的不是 ADE，而是 intervention

这是这一阶段特别关键的地方。

我们以前已经吃过这个亏：

> token variance 看起来很漂亮，但 decoder 实际只使用 global mean。

所以 V13 必须同时做四个 intervention（干预测试：人为破坏 token 结构，看性能是否下降）：

正常：

]

把 64 个 ActionToken 全替换成均值：

[
ADE_{\text{mean}}
]

随机 shuffle ActionToken：

[
ADE_{\text{shuffle}}
]

跨 sample 换 ActionToken：

[
ADE_{\text{cross}}.
]

真正通过 V13 的条件不是仅：

[
ADE<42.29\text{ mm}.
]

而应该同时满足：

[
\boxed{
ADE_{\text{normal}}
<
ADE_{\text{mean}}
}

以及：

[
\boxed{
ADE_{\text{normal}}
<
ADE_{\text{shuffle}}
}
]

而且差距应该足够明显。

否则：

> “我设计了 8 个 slot”

但模型实际上还是只学 global mean，那就没有意义。

# 我建议接下来的顺序

只有三步。

**第一步，V13：Local Action → Interaction Slots。**

保留 V12 PosePairActionEncoder，不再改它。去掉 `action_temporal.mean(2) → C` 这个硬 global bottleneck，用 object-query cross-attention + 8 latent slots，让 (C_m) 真正有机会保留 local interaction。

**第二步，做严格 intervention。**

目标是证明：

[
\boxed{\text{local ActionToken identity 真正影响 object effect}}

而不是只看 feature variance。

把 surface pipeline 推广到：

[
C_m^H\approx C_m^R.
]
