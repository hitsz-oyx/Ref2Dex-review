# 1. 项目当前核心思想

必须继续严格区分三个概念。

## 1.1 Action

[
\boxed{
A=\text{执行体具体怎么运动}
}
]

例如：

* wrist translation；
* wrist rotation；
* finger articulation；
* local surface motion。

Action 应保留较高 motion fidelity。

---

## 1.2 Analytic Interaction Y

[
\boxed{
Y=\mathcal I(H,O)
}
]

表示：

> 执行体的运动在当前物体附近形成了怎样的相对交互。

Y 必须：

* object-centric；
* 可微；
* 解析；
* 动态；
* 不依赖 Human ↔ Robot 手部 patch index。

---

## 1.3 Learned Interaction Representation C

[
\boxed{
C=E_C(Y)
}
]

C 的第一阶段职责只是：

> 将高维解析 Y 压缩成 compact representation。

后面才要求：

[
\boxed{
C_H\approx C_R
}
]

表示 interaction equivalence。

不要一开始就要求 C 同时承担：

* Y reconstruction；
* Action reconstruction；
* cross-embodiment metric；
* object effect prediction；
* RL reward。

# 5. Fix 2：增加真实 soft distance

当前：

[
r_{t,m}
=

\sum_iw_{tmi}(h_{t,i}-x_m).
]

不能严格使用：

[
|r_{t,m}|
]

作为 hand-object surface distance。

原因是：

[
\left|
\sum_iw_ir_i
\right|
\neq
\sum_iw_i|r_i|.
]

例如两个相反方向的 relative vectors 可能发生抵消：

[
r_1\approx-r_2
]

导致：

[
r\approx0
]

从而产生错误的“contact”。

因此增加：

[
\boxed{
d_{t,m}
=

\sum_i
w_{tmi}
|
h_{t,i}-x_m
|_2
}
]

其中：

[
d\ge0.
]

继续复用当前 soft correspondence：

[
w_{tmi}
=

softmax_i
\left(
-\frac{|h_{t,i}-x_m|^2}{\tau^2}
\right).
]

# 6. Y-Teacher V1 最终定义

Phase A 完成后冻结：

[
\boxed{
Y=
{
r_{0:T},
d_{0:T},
u_{0:T-1}
}
}
]

其中：

### Relative vector

[
r_{t,m}
=

\sum_i
w_{tmi}(h_{t,i}-x_m)
]

描述：

> 附近 hand surface 相对于 object anchor 的方向和空间关系。

### Relative distance

[
d_{t,m}
=

\sum_i
w_{tmi}|h_{t,i}-x_m|
]

描述：

> 附近 hand surface 距 object anchor 的真实连续距离。

### Relative motion

[
u_{t,m}
=

\sum_i
w_{tmi}
(h_{t+1,i}-h_{t,i})
]

描述：

> 当前 object anchor 附近的 hand surface 接下来如何运动。

所以：

[
\boxed{
Y=
[
\text{where},
\text{how far},
\text{how moving}
]
}
]

而不再只是静态 contact。

[

> 用一个线性低维子空间保存数据中变化最大的方向。

[

\rightarrow

# 20. Compression Encoder

将解析 Y 转换成 input tokens。

对于 geometry：

[
z^r_{t,m}
=========

MLP(
[
x_m,
e_t,
r_{t,m},
d_{t,m},
e_{\text{geometry}}
]
).
]

对于 motion：

[
z^u_{t,m}
=========

MLP(
[
x_m,
e_t,
u_{t,m},
e_{\text{motion}}
]
).
]

其中：

* (x_m)：object-frame anchor coordinate；
* (e_t)：time embedding；
* type embedding 区分 geometry / motion。

然后使用 K 个 learned latent queries：

[
Q_C\in\mathbb R^{K\times128}
]

执行：

[
\boxed{
C=
CrossAttn(
Q=Q_C,
KV=Z_Y
).
}
]

第一版只用：

```text
1 cross-attention block
1~2 latent self-attention blocks
```

不要先做大模型。

# 28. 用解析 Y 定义 teacher metric

先定义：

[
\boxed{
D_Y(Y_1,Y_2)
}
]

例如：

[
D_Y=
\lambda_rD_r+
\lambda_dD_d+
\lambda_uD_u.
]

再要求 latent 保持这种 relative ordering。

例如：

[
D_Y(Y_a,Y_p)
<
D_Y(Y_a,Y_n)
]

则希望：

[
\boxed{
D_C(C_a,C_p)
<
D_C(C_a,C_n).
}
]

可以加入 ranking / triplet loss。

Ranking loss：

> 只要求“哪个 interaction 更接近”，不要求 latent distance 数值严格等于解析 Y distance。

# 32. 为什么是 p(C|O,E)，而不是唯一 C

同一个物体和目标通常存在多个有效 interaction。

例如：

```text
cup + lift
    ↓
handle grasp
side grasp
power grasp
pinch grasp
...
```

因此长期目标不应强制：

[
(O,E)\rightarrow C_{unique}.
]

而应该允许：

[
\boxed{
(O,E)\rightarrow
{C_1,C_2,\ldots}
}
]

后续才考虑：

* flow matching；
* diffusion；
* mixture model；

用于生成多个 interaction modes。

当前不要实现。
