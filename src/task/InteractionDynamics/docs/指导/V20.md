## 新的 causal Y

定义：

[
\boxed{
Y_t(o_i)=
[r_t,\ d_t,\ v_t,\ p_t]

}

其中：

[
r_t\in\mathbb R^3,\quad
d_t\in\mathbb R,\quad
v_t\in\mathbb R^3,\quad
p_t\in\mathbb R.

### (r,d)

完全继承现有定义。当前代码已经正确地区分：

[

]

### 把原来的未来 (u_t) 改成 causal (v_t)

旧：

[
u_t=
E_{w_t}[h_{t+1}-h_t].
]

[
\boxed{
v_t=
E_{w_t}[h_t-h_{t-1}]

[

这样：

```text

p : cm
```

训练再逐 channel normalization（逐通道归一化）。

[



# 三、预测 residual，不直接预测 absolute Y

定义：

[
\Delta Y_{t+k,i}
================

Y_{t+k,i}-Y_{t,i}.
]

[
\boxed{
\Delta\hat Y
\in

[

所以 conceptual 上依然是：

[

# 四、V20 网络结构

这就是最关键的修改。

输入每个 anchor：

[

[

[

]

[
e_i^O=f_O(o_i),

[

然后：

[
Z_i^0=e_i^Y+e_i^O+e_i^P.

## 不再有 `current_h` condition

当前网络是：

```python
condition = self.current_h(current_h)

tokens = ...
for block:
    tokens = block(tokens, condition)

tokens.mean(1)
```

V20 主干中：

[
\boxed{current_h\ 不进入 network}
]

否则网络还是会通过一个 embodiment-specific（依赖具体手形的）全局变量走 shortcut。

---

## Transformer 只做 anchor↔anchor 通信

建议新增普通 self-attention block：

```python
class FieldBlock(nn.Module):
    def __init__(self, dim, heads):
        super().__init__()
        self.norm1 = nn.LayerNorm(dim)
        self.attn = nn.MultiheadAttention(
            dim, heads, batch_first=True
        )
        self.norm2 = nn.LayerNorm(dim)
        self.ffn = nn.Sequential(
            nn.Linear(dim, 4 * dim),
            nn.GELU(),
            nn.Linear(4 * dim, dim),
        )

    def forward(self, x):
        y = self.norm1(x)
        x = x + self.attn(y, y, y, need_weights=False)[0]
        x = x + self.ffn(self.norm2(x))
        return x
```

经过 (L) 层：

[
Z_i=\mathcal F_\theta(X_{1:N})_i.
]

因此：

[
Z\in\mathbb R^{B\times128\times D}.
]

# 五、Z 怎么输出 Y

非常简单。

每个 (Z_i) 独立通过同一个 shared head：

[
g_Y:\mathbb R^D\rightarrow\mathbb R^{H\times8}.
]

代码结构：

```python
self.output = nn.Sequential(
    nn.LayerNorm(dim),
    nn.Linear(dim, dim),
    nn.GELU(),
    nn.Linear(dim, horizon * y_dim),
)
```

forward：

```python
tokens = (
    self.y_encoder(current_y)
    + self.anchor_encoder(anchors_cm)
    + self.object_encoder(object_patches).amax(2)
)

for block in self.blocks:
    tokens = block(tokens)

delta_y = self.output(tokens)

return delta_y.reshape(
    B, N, horizon, y_dim
)
```

注意，没有：

```python
tokens.mean(1)
```

没有：

```python
global_token
```

没有：

```python
CLS token
```

没有：

```python
H head
```

整个模型：

```text
[B,128,8]
      +
[B,128,geometry]
      ↓
Field Transformer
      ↓
Z [B,128,D]
      ↓
shared pointwise head
      ↓
[B,128,8,8]
```

这就是我们真正想测试的东西。

# 六、Loss 第一版尽量简单

先算 train-set residual statistics：

[
\mu_{\Delta Y},\sigma_{\Delta Y}
]

shape：

[
[8].
]

训练：

[
\hat z=
\frac{\Delta\hat Y-\mu}{\sigma}.
]

或者直接模型输出 normalized residual。

主要 loss：

[
\boxed{
L_{\rm field}
=============

\operatorname{MSE}
\left(
\frac{\Delta\hat Y-\Delta Y^{GT}}
{\sigma_{\Delta Y}}
\right)
}
]

先不要：

* diffusion；
* stable loss；
* contact classifier；
* MANO loss；
* trajectory condition；
* grasp phase；
* H loss。

## p channel 单独记录

因为 (p) 很稀疏，而且 GT 自身可能存在穿模。

因此第一版：

[

建议：

[

]

作为初始实验量级，而不是让 p 主导模型。

```text

d MAE
v MAE
p MAE

p positive recall
false penetration rate
```

如果 p 完全学成 0，再决定要不要 positive weighting。

不要一开始堆复杂 loss。

# 七、V20 必须做的三个架构验收实验

这一部分比单纯看 RMSE 更重要。

你之前仓库已经发现旧结构对 token 做 mean replacement 几乎没损失，说明存在明显 global shortcut。研究日志里已有这个现象。

所以 V20 必须重新做 intervention。

## 1. Mean-token replacement

推理时：

[
Z_i\rightarrow\bar Z
]

即：

```python
z[:] = z.mean(dim=1, keepdim=True)
```

如果 V20 真正使用 object-indexed structure，性能应该**明显下降**。

---

## 2. Token shuffle

随机：

[
Z_i\rightarrow Z_{\pi(i)}
]

但 target anchor 不动。

性能也应该明显下降。

这是最强的验证之一。

---

## 3. Permutation equivariance

同时 permutation：

```text
anchor
object patch
current Y
```

然后把输出逆 permutation 回来。

理论上：

[
P^{-1}\mathcal F(PX)
\approx
\mathcal F(X).
]

这个应该几乎不变。

所以：

```text
shuffle Z only        → 应该坏
shuffle whole field   → 不应该坏
```

如果做到这两个同时成立，就能很好地证明：

[
\boxed{\text{网络真的把 object index 当成 field coordinate 使用}}
]

而不是又偷偷学了 sample-level global feature。

# 十、MANO forward 约束具体怎么工作

优化变量：

[
H_k=[p_k^O,R_k^O,\theta_k].
]

对于整个未来：

[
H_{1:H}.
]

每次 iteration：

```text
H
 ↓
MANO forward
 ↓
hand surface points
 ↓
新的 causal Phi
 ↓
Y_H = [r,d,v]
 ↓
compare with predicted Y~
```

即：

[
Y_H=\Phi(H,O).
]

然后：

[
L_r
===

|\hat r_H-\tilde r|^2,
]

[
L_d
===

|\hat d_H-\tilde d|^2,
]

[
L_v
===

|\hat v_H-\tilde v|^2.
]

加：

[
L_{\rm smooth}
==============

\sum_k|H_k-H_{k-1}|^2.
]

所以：

[
\boxed{
\text{不是 }Z\rightarrow H
}
]

而是：

[
\boxed{
Z\rightarrow Y
\rightarrow
\text{all local constraints}
\rightarrow H^*
}
]

这正是我们想要的。
