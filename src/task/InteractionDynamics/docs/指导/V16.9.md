**提高数据量可能有帮助，但我不认为“只加数据”就足够。** 现在 V16.8 的证据反而说明，应该先把同一批 32 个样本上的高噪声去噪能力压下来，再扩大数据。

原因很直接：V16.7 在**完全相同的 32 个样本**上已经能做到 dynamic 的

[
r/d=0.244/0.109\text{ cm},
]

说明

[
(S,O,G)\rightarrow R
]

这件事在当前数据上是可学的；而 V16.8 同样的数据得到

[
r/d=0.403/0.178\text{ cm}.
]

所以现在这部分差距：

[
0.403-0.244,\qquad 0.178-0.109
]

主要不是“数据里没有信息”，而是 **Diffusion 没把已经存在的信息充分利用出来**。

---

## 1. 为什么单纯扩大数据不一定解决

你可以看最高噪声附近。

V16.8 的 oracle denoising（给真实残差加噪，然后直接让模型恢复）：

[
t=10:\ 0.062
]

[
t=50:\ 0.167
]

[
t=90:\ 0.368.
]

也就是说：

[
\boxed{\text{越接近纯噪声，模型越不会根据 }S,O,G\text{ 把 residual 找回来。}}
]

在 (t\approx90) 时，

[
x_t
]

本身几乎已经没有原来 residual 的信息。

所以模型实际上必须主要依靠：

[
\boxed{S+O+G}
]

回答：

> “这个 residual 应该长什么样？”

而这件事情，V16.7 已经证明它能做到。

因此现在真正的问题更像：

> Diffusion 训练里，高噪声状态下的 condition-to-residual 映射没有学得和 V16.7 那么好。

这不是单纯增加样本量最直接解决的问题。

---

# 2. 我会先做的第一件事：增加高噪声训练比例

现在 timestep 是均匀采样：

[
t\sim U(0,T).
]

也就是说：

```text
低噪声  训练一样多
中噪声  训练一样多
高噪声  训练一样多
```

但真正 sampling 时：

[
x_T\sim N(0,I)
]

**最开始高噪声阶段如果错了，后面会一直带着这个误差。**

所以现在可以直接提高：

[
t\in[70,99]
]

的采样概率。

例如最简单：

[
\boxed{
50%\text{ 均匀采样}
+
50%\text{ 从高噪声 }[70,99]\text{ 采样}
}
]

代码逻辑类似：

```python
if torch.rand(()) < 0.5:
    t = randint(0, 100)
else:
    t = randint(70, 100)
```

这不是最终方法，只是非常好的诊断实验。

如果：

[
t90:\ 0.368\rightarrow0.20
]

并且最终 sampling：

[
r/d:\ 0.403/0.178\rightarrow0.30/0.13
]

那基本就确认问题了：

[
\boxed{\text{high-noise training 不足。}}
]

---

# 3. 第二件事：我甚至会先试“训练更久”，而不是加数据

现在只有：

[
32\text{ samples}
]

训练：

[
4000\text{ steps}.
]

对于普通 deterministic regression 来说已经足够 overfit。

但 Diffusion 一个 sample 实际上不是一个任务，因为还要学：

[
t=0,1,\ldots,99
]

不同噪声等级。

粗略理解：

一个 residual 实际被展开成：

[
100
]

种 denoising problem（去噪问题）。

所以 32 个样本其实对应：

[
32\times100
]

种不同噪声条件。

我会先跑：

[
4000\rightarrow10000
]

甚至：

[
20000
]

steps。

不是为了最终模型，而是看 controlled overfit 能不能进一步逼近 V16.7。

因为我们现在是在做**机制验证**，过拟合反而不是问题。

---

# 4. 第三个非常值得试：让高噪声时直接预测 (x_0) 作为辅助目标

现在网络只优化：

[
L_v=|\hat v-v|^2.
]

但我们真正关心的是：

[
\hat x_0.
]

而且我们已经知道：

[
t=90
]

时 (\hat x_0) 不够准。

所以可以加一个非常简单的辅助 loss：

根据：

[
\hat v
]

恢复：

[
\hat x_0

\alpha_t x_t-\sigma_t\hat v
]

然后增加：

[
\boxed{
L=
L_v+
\lambda(t)|\hat x_0-x_0|^2
}
]

其中：

[
\lambda(t)
]

只在高噪声时比较大。

例如最粗暴的诊断：

[
\lambda(t)=
\begin{cases}
0,&t<70\
1,&t\ge70
\end{cases}
]

这相当于明确告诉模型：

> 高噪声阶段不要只把 v-loss 做小，我真正要求你把 residual 本身恢复正确。

我认为这个比现在直接加 contact loss 更合理。

---

# 5. 为什么我暂时不建议先加 contact loss

目前 contact F1：

[
0.724
]

反而比 persistence：

[
0.807
]

差。

当然以后应该解决。

但当前最核心的问题还是：

[
r/d
]

整体 residual precision（残差预测精度）没有追上 V16.7。

如果先加：

[
L_{contact}
]

可能变成：

> 几何还没生成准，就开始通过额外 loss 强行修 contact。

这样会模糊归因。

我会等：

[
r/d
]

先逼近 V16.7 后再处理 F1。

# 6. Sampling steps 也值得试，但不要把它理解成“越多越好”

现在是：

[
100\text{ steps}.
]

直觉可能认为：

[
100>50>25
]

所以 100 应该最准。

但不一定。

因为模型每调用一次都有误差：

[
e_t.
]

100 次：

[
e_{99}+e_{98}+\cdots
]

可能比 25 次更容易累积。

所以应该测试：

[
100,\quad50,\quad25,\quad10.
]

但这里有个技术注意：

**不能简单把原 sampler 的循环砍掉一半。**

应该做正规的 timestep skipping（时间步跳采样）：

例如 25 steps：

[
99\rightarrow95\rightarrow91\rightarrow\cdots\rightarrow0
]

每一步使用对应：

[
\bar\alpha_t,\bar\alpha_s
]

做 DDIM update。

如果发现：

[
25\text{ steps}
<
100\text{ steps}
]

的最终 RMSE，说明：

[
\boxed{\text{误差累积确实占了很大部分。}}
]

# 7. 那“提高数据量”到底什么时候有用？

它当然有用，但解决的是稍后另一层问题。

现在 32 samples 上主要在验证：

[
\boxed{\text{模型能不能学会这个 formulation。}}
]

以后增加到：

[
32\rightarrow500\rightarrow5000\rightarrow...
]

数据的价值主要是让模型学到：

### 不同当前状态

[
S_t
]

下应该怎么变化。

### 不同物体

[
O
]

需要什么 interaction。

### 不同 Goal

[
G
]

对应什么 interaction strategy。

### 多种合法解

相同：

[
(S,O,G)
]

可能对应：

[
R_1,R_2,R_3.
]

这才是真正需要 Diffusion 的地方。

---

# 8. 数据增加还可能让 Diffusion 的高噪声能力变好

这一点我认同。

因为高噪声：

[
x_t\approx\epsilon
]

时，模型主要只能依靠：

[
(S,O,G)
]

预测：

[
R.
]

如果只有 32 个样本，它可能只是勉强记忆条件。

更多数据能够让它学到：

[
\boxed{
(S,O,G)\rightarrow
\text{interaction residual distribution}
}
]

更稳定的结构。

所以：

[
\boxed{\text{更多数据大概率有帮助}}
]

但我不会现在就把 V16.8 的差距归因于数据不足。

因为：

[
\boxed{
\text{同一 32 个数据，V16.7 已经明显更准。}
}
]

这说明当前 Diffusion 至少还有**训练方式本身可以榨出的性能**。

# 10. 什么时候再增加数据？

当我们能在 32 samples 上做到大概：

[
r\lesssim0.30\text{ cm},
\qquad
d\lesssim0.14\text{ cm}
]

甚至更接近 V16.7 后，我就不会继续死磕单序列。

然后直接进入：

[
\boxed{\text{多序列训练}}
]

因为那时候真正的问题变成：

> 能不能泛化，以及 Diffusion 是否能学出多模态 interaction knowledge。

而不是：

> sampler 有没有把一个已经能记住的 32-sample mapping 生成出来。

---

所以对你问题最简洁的回答是：

[
\boxed{\text{加数据会有帮助，但现在不能靠加数据掩盖生成精度问题。}}
]

当前最应该先压的是：

[
\boxed{
\text{高噪声去噪误差}
+
\text{多步采样误差累积}
}
]

等这两个在 controlled overfit 上基本解决，再扩大数据，那个时候数据量的收益才更有解释性。
