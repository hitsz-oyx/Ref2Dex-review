可以。下面我把方案收敛成一版**可直接实现和做实验的 V20.2**，这次不再同时探索别的 Z/PoseToken 路线。

核心研究问题只有一个：

[
\boxed{
\text{能否保留高带宽 }Y\rightarrow Y\text{ 主路，同时用 }H/MANO\text{ 给 }Y\text{ 加可实现性约束？}
}
]

而且要避免我们刚才说的两个分支互相走捷径。

# V20.2：Frozen H Realizer Regularization

最终结构固定为：

```text
                    Field Dynamics
current Y + Object ────────────────→ predicted future Y
                                         │
                                         │ 主预测路径到这里结束
                                         ▼
                                  H Realizer
                              input: Y_pred, O, H_t
                                         │
                                         ▼
                                  ΔH [8,30]
                                         │
                                        MANO
                                         │
                                  hand surface
                                         │
                                         Φ
                                         │
                                         ▼
                                      Y_H
```

最关键的限制：

[
\boxed{
\hat Y\text{ 的生成永远不经过 }H
}
]

以及：

[
\boxed{
H\text{ realizer 不读取 V20 hidden feature }F
}
]

只允许：

[
\boxed{
R_H(\hat Y,O,H_t)\rightarrow H
}
]

这样才能真正检测：

> 当前 (Y) 是否包含足够信息供一只手实现它？

当前 V20 主干本身已经是无 pooling 的 object-indexed `[B,N,*]→[B,N,*]`，所以主路直接保留。

不要改：

```text
field_state_v20.py

train_field_v20.py
```

当前：

[

保持不变。

主模型：

[

]

恢复：

[

V20 就作为 immutable baseline（固定基线）。

暂时不让 (p) 进入 H realizer。

# 三、H Realizer 不使用单个 global pooling

虽然最终输出 H 是全局量，但不要先：

[
[N,*]\rightarrow1\rightarrow H.
]

而是每个 future timestep 都有自己的 query。

定义：

[
q_1,\dots,q_8.
]

每一个 (q_k) cross-attend 当前第 (k) 帧的所有 object anchors：

[
G_k
===

\operatorname{CrossAttn}
(
q_k,
K_{1:N,k},
K_{1:N,k}
).
]

其中：

[
K_{i,k}
=

E_Y(\hat Y_{i,k})
+
E_O(o_i,\text{patch}_i).
]

所以：

```text
frame k predicted field
128 anchors
    ↓
cross attention
    ↓
G_k
```

得到：

[
G_{1:8}\in\mathbb R^{B\times8\times D}.
]

然后再做一个小 temporal transformer：

[
G_{1:8}
\rightarrow
\tilde G_{1:8}.
]

最后：

[
\tilde G_k
\rightarrow
\Delta H_k\in\mathbb R^{30}.
]

---

# 四、current H 如何进入

不要直接 concat 到每个 anchor。

先：

[
e_H=E_H(H_t)\in\mathbb R^D.
]

然后加到每个 temporal query：

[
q_k'=q_k+e_H.
]

即：

```text
current H
   ↓
embedding
   ↓
q1 q2 ... q8
```

它只告诉 realizer：

> 当前从哪只手姿态出发。

不会污染 object-indexed field tokens。

---

# 五、H 参数化完全沿用 V18.4/V20.1

继续：

[
\Delta H_k
=

[
\Delta p^O_k,,
\Delta\omega^O_k,,
\Delta\theta_k
].
]

维度：

[
3+3+24=30.
]

当前 V20 cache 已经有：

```text
current_h
future_delta_h
betas
object_rotation
object_translation
global_orient
hand_pose
transl
```

所以不用重新设计 cache。

---

# 六、不要监督 GT H

这点继续固定：

[
\boxed{
L_H\neq|\hat H-H^{GT}|^2
}
]

`future_delta_h` 只允许用于：

* normalization；
* parity；
* diagnostic；
* 可视化；
* 统计合理范围。

不能作为主监督。

原因还是：

[
Y\rightarrow H
]

可能是一对多。

我们只要求找到**某个合理 H**。

---

# 七、H normalization

统计训练集中：

[
\sigma_H\in\mathbb R^{30}.
]

模型输出：

[
z_H\in\mathbb R^{B\times8\times30}.
]

再：

[
\boxed{
\Delta H=z_H\odot\sigma_H
}
]

不加 mean。

这样：

[
z_H=0\Rightarrow \Delta H=0.
]

并把最后一层 zero-init：

```python
nn.init.zeros_(head.weight)
nn.init.zeros_(head.bias)
```

训练刚开始就是 repeat-current-hand。

---

# 八、直接复用现有 MANO decoder

不要重新写 MANO→Y。

直接复用：

```text
mano_field_decoder_v20_1.py
```

已有：

[
\Delta H
\rightarrow MANO
\rightarrow surface
\rightarrow [r,d,v].
]

而且 GT parity 已经达到：

[
4.21\times10^{-4}\text{ cm},
]

说明时间索引和坐标系都是对的。

此时：

计算：

# 十、Stage B 第一版 loss 尽量简单

先不要 consistency。

只：

[
\boxed{
L_{\rm realize}
---------------

D(Y_H,Y^{GT})
}
]

具体：

[
L_{\rm realize}
===============

L_r+L_d+L_v.
]

用当前 V20 的 channel std normalize：

[
L_r
===

\left|
\frac{r_H-r_{GT}}{\sigma_r}
\right|^2.
]

其余类似。

再加非常弱的：

[
L_{\rm prior}
=

\operatorname{ReLU}(|z_H|-3)^2.
]

所以：

[
\boxed{
L_B=L_{\rm realize}+10^{-4}L_{\rm prior}
}
]

先别加 smoothness。

也先别加：

[
D(Y_H,\hat Y).
]

因为此阶段我们想问一个最纯的问题：

> **predicted Y 里是否包含足够信息，让一个 learned realizer 找到正确 feasible hand？**

---

# 十一、Stage B 必须做 4 个 input ablation

这非常关键，不然 H branch 很容易靠数据集先验作弊。

正常：

[
R(\hat Y,O,H_t).
]

同时训练/测试以下消融。

### A. No-Y

[
R(0,O,H_t)
]

或者把 Y 全部置零。

---

### B. Shuffle-Y

batch 内：

[
\hat Y_a
\rightarrow
R(\hat Y_b,O_a,H_{t,a}).
]

---

### C. No-object

[
R(\hat Y,0,H_t).
]

---

### D. No-current-H

[
R(\hat Y,O,0).
]

我们最关心：

[
\boxed{
R(\hat Y,O,H_t)
\gg
R(O,H_t)
}
]

以及 shuffle-Y 后 performance 明显下降。

否则说明：

> realizer 根本没有利用 Y。

那这个实验就是无效的。

---

# 十二、Stage B controlled Gate

先当前 controlled event / controlled32。

第一目标：

[
Y_H\rightarrow Y^{GT}
]

达到：

[
r,d,v\lesssim0.1\sim0.2\text{ cm}
]

量级。

并且明显优于 V20.1 Adam projector。

现在 V20.1 oracle/predicted target 的结果仍然在：

[
0.8\sim1.0\text{ cm}
]

附近，且已确认 optimizer 是瓶颈。

所以 learned realizer 至少应该显著超过它。

---

# 十三、Stage B 要记录的核心指标

每个 sample：

### Free field

[
D(\hat Y,Y^{GT})
]

### Realized field

[
D(Y_H,Y^{GT})
]

### Projection gap

[
D(Y_H,\hat Y)
]

分别记录：

```text
r MAE/RMSE
d MAE/RMSE
v MAE/RMSE
```

再加：

```text
free stable
H stable
GT stable

H penetration
GT penetration

normalized H max
>3sigma ratio
```

---

# 十四、Stage B 的成功标准

如果出现：

[
D(Y_H,Y^{GT})
<
D(\hat Y,Y^{GT})
]

说明：

> H branch 不只是“能实现 Y”，而且还真的把 free-field prediction 往正确 feasible solution 拉回去了。

这是最理想结果。

如果：

[
D(Y_H,Y^{GT})
\approx
D(\hat Y,Y^{GT})
]

也可以接受：

> realizer 能把 field 几乎无损映射成 feasible MANO。

如果：

[
D(Y_H,Y^{GT})
\gg
D(\hat Y,Y^{GT}),
]

则说明：

* Y 信息不足；
* 或 realizer capacity 不够；
* 或训练还没学会。

这时不要进联合训练。

---

# 十五、Stage C：冻结 H Realizer，再微调 Field

只有 Stage B 过了，才进入。

此时：

```text
FieldDynamics      trainable
H Realizer         frozen
MANO               frozen
```

计算：

[
\hat Y=D_{\rm field}(Y_t,O)
]

[
Y_H=
\Phi(
R_{\rm frozen}(\hat Y,O,H_t)
).
]

然后：

[
\boxed{
L_C
===

L_{\rm field}
+
\lambda_F L_{\rm feasible}
}
]

这里有两种候选。

---

## 方案 1：realizer output 对 GT

[
\boxed{
L_{\rm feasible}
----------------

D(Y_H,Y^{GT})
}
]

梯度会通过：

[
Y_H
\rightarrow
R_H
\rightarrow
\hat Y
]

回到 field predictor。

但 H realizer 参数冻结。

这个我更推荐。

它的含义：

> field predictor 应该输出一种经过固定 hand realizer 后仍然能得到正确 interaction 的 Y。

---

## 方案 2：free Y 和 feasible Y 一致

[
L_{\rm consistency}
-------------------

D(\hat Y,\operatorname{sg}(Y_H)).
]

可以作为较弱辅助项。

但不要一开始权重大。

---

# 十六、Stage C 推荐 loss

第一版：

[
\boxed{
L=
L_{\rm field}
+
0.2L_{\rm feasible}
+
0.05L_{\rm consistency}
}
]

Field LR：

```text
3e-5
```

不要重新 3e-4 大步训练。

---

# 十七、Stage C 必须有 no-regression Gate

联合 fine-tune 之后：

[
D(\hat Y,Y^{GT})
]

不能明显比原 V20 baseline 变差。

例如如果：

```text
original r = 0.35 cm
hybrid     r = 0.60 cm
```

即使 H branch 很漂亮，也不能接受。

我们的目标是：

[
\boxed{
\text{保持 field accuracy}
+
\text{提高 feasibility}
}
]

不是交换。

---

# 十八、最关键的五组实验

最终建议形成这一张表：

| Experiment        | Field    | H realizer     | H→Field gradient |
| ----------------- | -------- | -------------- | ---------------- |
| V20 baseline      | train    | none           | no               |
| V20.1 Adam        | frozen   | optimizer      | no               |
