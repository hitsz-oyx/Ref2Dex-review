# 5. 怎么随机采 mesh

不是随机 vertex。

而是：

[
\boxed{\text{按 triangle area 从整个 robot visual mesh 随机采表面点}}
]

步骤：

### 第一步

计算每个 triangle 面积：

[
A_f
===

\frac12
|
(v_1-v_0)\times(v_2-v_0)
|.
]

形成概率：

[
p_f=\frac{A_f}{\sum_jA_j}.
]

### 第二步

固定 seed：

```python
generator = torch.Generator(device="cpu")
generator.manual_seed(0)
```

随机采：

```python
face_ids = torch.multinomial(
    face_area_probability,
    num_samples=1538,
    replacement=True,
    generator=generator,
)
```

### 第三步

在 triangle 内随机 barycentric coordinate。

可以：

```python
u = torch.rand(P)
v = torch.rand(P)

sqrt_u = torch.sqrt(u)

w0 = 1 - sqrt_u
w1 = sqrt_u * (1 - v)
w2 = sqrt_u * v
```

得到：

[
w_0+w_1+w_2=1.
]

之后：

[
p=
w_0v_0+w_1v_1+w_2v_2.
]

# 6. 为什么一定要固定 triangle + barycentric

只在 backend 初始化时随机一次：

```text
robot loaded
   ↓
sample 1538 mesh surface locations
   ↓
固定保存 triangle id + barycentric
```

优化过程中绝对不要重新随机。

这样第 (i) 个 surface point：

[
p_i(q)
======

w_{i0}v_{i0}(q)
+w_{i1}v_{i1}(q)
+w_{i2}v_{i2}(q)
]

一直是 robot mesh 上的**同一个物理位置**。

这样：

[
v_{i,t}=p_{i,t}-p_{i,t-1}
]

才有意义。

同时整个过程：

[
q\rightarrow FK\rightarrow vertex\rightarrow surface point
]

保持可微。
