# V16.8：Conditional Residual Diffusion 最小实现

## 0. 实验目标

V16.7 已验证：

[
\boxed{
R_t
===

F_t^{GT}-F_t^{persist}
}
]

比直接预测完整未来：

[
F_t^{GT}
]

更合理。

确定性模型：

[
\hat R_t=f_\theta(S_t,Z_O,G_t)
]

已经在同一 32-chunk controlled experiment（受控小实验）中：

* 超过 persistence baseline；
* static subset 不退化；
* 使用了 motion Goal；
* 使用了 active；
* motion reverse / zero / shuffle 均明显导致性能下降。

因此 V16.8 不再验证 residual formulation 是否成立，而验证：

[
\boxed{
p_\theta(R_t\mid S_t,Z_O,G_t)
}
]

能否通过 Diffusion 正确生成 interaction residual。

# 2. 为什么现在才引入 Diffusion

V16.7 学的是：

[
(S,O,G)\rightarrow\hat R.
]

它实际上学习的是：

[
\boxed{
\mathbb E[R\mid S,O,G]
}
]

也就是给定条件后预测一个确定结果。

但我们的最终 Knowledge 希望允许：

[
\boxed{
(S,O,G)
\rightarrow
{R^{(1)},R^{(2)},R^{(3)},...}
}
]

例如：

> 同样当前手位置、同样杯子、同样目标“向上抬”，可能存在多个合理 approach / grasp / interaction trajectory。

所以最终需要：

[
\boxed{
R\sim p_\theta(R\mid S,O,G)
}
]

V16.8 是第一次测试这个生成 formulation。

但本轮只有单序列 32 chunks。

因此：

[
\boxed{
\text{V16.8 暂时不验证 diversity，只验证 diffusion 能不能正确生成 residual。}
}
]

---

# 3. 为什么不直接复用 V16.6 的 epsilon sampler

V16.6 使用：

[
x_t=
\sqrt{\bar\alpha_t}x_0+
\sqrt{1-\bar\alpha_t}\epsilon
]

预测：

[
\epsilon.
]

然后恢复：

[
\hat x_0=
\frac{x_t-\sqrt{1-\bar\alpha_t}\hat\epsilon}
{\sqrt{\bar\alpha_t}}.
]

问题是高噪声阶段：

[
\bar\alpha_t\rightarrow0.
]

此时：

[
\frac{1}{\sqrt{\bar\alpha_t}}
]

会很大。

很小的：

[
\hat\epsilon-\epsilon
]

也可能被放大成很大的：

[
\hat x_0
]

误差。

V16.6 最终出现几十厘米的生成误差，与这个采样不稳定现象一致。

因此 V16.8 不直接复制旧 sampler。

---

# 4. V16.8 使用 v-prediction

这里的 v-prediction 中文可以理解为：

> 不直接预测噪声，而预测一个由“干净数据”和“噪声”组合而成的速度变量，使高噪声阶段恢复 (x_0) 时不需要除以极小的 (\sqrt{\bar\alpha})。

定义标准化后的 residual：

[
x_0=R^{norm}.
]

加噪：

[
x_t
===

\sqrt{\bar\alpha_t}x_0
+
\sqrt{1-\bar\alpha_t}\epsilon.
]

定义训练目标：

[
\boxed{
v_t
===

## \sqrt{\bar\alpha_t}\epsilon

\sqrt{1-\bar\alpha_t}x_0
}
]

网络预测：

[
\boxed{
\hat v_\theta
=============

f_\theta(
x_t,S,O,G,t
)
}
]

Loss：

[
\boxed{
L_v=
|\hat v-v|^2
}
]

---

# 5. v-prediction 的恢复公式

由：

[
x_t
===

\sqrt{\bar\alpha_t}x_0+
\sqrt{1-\bar\alpha_t}\epsilon
]

以及：

[
v_t
===

\sqrt{\bar\alpha_t}\epsilon-
\sqrt{1-\bar\alpha_t}x_0
]

可以恢复：

[
\boxed{
\hat x_0
========

## \sqrt{\bar\alpha_t}x_t

\sqrt{1-\bar\alpha_t}\hat v
}
]

以及：

[
\boxed{
\hat\epsilon
============

\sqrt{1-\bar\alpha_t}x_t
+
\sqrt{\bar\alpha_t}\hat v
}
]

注意这里没有：

[
\frac{1}{\sqrt{\bar\alpha_t}}.
]

因此高噪声端不会出现 V16.6 那种直接数值放大。

# 6. Sampling

使用 deterministic DDIM-like sampling。

中文：

> 每一步根据预测出的 clean residual 和 noise direction，确定性地从 (x_t) 更新到 (x_{t-1})。

对于 timestep (t)：

先预测：

[
\hat v_t.
]

计算：

[
\hat x_0
========

## \sqrt{\bar\alpha_t}x_t

\sqrt{1-\bar\alpha_t}\hat v_t.
]

计算：

[
\hat\epsilon_t
==============

\sqrt{1-\bar\alpha_t}x_t
+
\sqrt{\bar\alpha_t}\hat v_t.
]

然后：

[
\boxed{
x_{t-1}

\sqrt{\bar\alpha_{t-1}}\hat x_0
+
\sqrt{1-\bar\alpha_{t-1}}\hat\epsilon_t
}
]

最后：

[
x_0=\hat x_0.
]

第一版：

```text
diffusion_steps = 100
```

不加 stochastic noise。

即：

[
\eta=0.
]

# 7. 不允许再使用强行 x0 clamp

V16.6 有类似：

```python
clean = clean.clamp(-5, 5)
```

V16.8 第一版不要使用这种大范围硬截断作为正常 sampling 逻辑。

原因：

> 如果生成开始爆炸，应找到 diffusion/sampling 问题，而不是依靠 clamp 把错误隐藏掉。

允许：

* assert finite；
* 记录最大绝对值；
* 遇到 NaN/Inf 直接报错。

但不要通过 clamp 修正模型。

[

> 给模型一个“确实来自某个 GT residual 的加噪版本”，看它有没有把它去噪回来的能力。

[
