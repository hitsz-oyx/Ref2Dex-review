# InteractionDynamics V15：Contact-Supervised Cm 最小实现

## 0. 本阶段目标

V14 已证明：

[
A^{root}+A^{art}+W
\rightarrow
C_m
\rightarrow
Object\ SE(3)
]

具有足够的拟合能力。

但 intervention 表明：

* `root_zero` 会显著破坏 Object SE(3)；
* `articulation_zero / mean / shuffle` 对 Object SE(3) 几乎没有影响。

这一现象本身是合理的：

[
\boxed{
A^{root}
\text{主要描述物体怎么整体运动}
}
]

而：

[
\boxed{

\text{更可能描述手以什么方式形成抓取和接触}
}
]

因此 V15 不再要求 articulation ActionToken 必须显著改善 Object SE(3)。

V15 只回答：

> **局部 articulation ActionToken 与当前 World 融合形成的 (C_m)，能否预测未来 hand-object contact pattern？**

# 10. 为什么使用 Soft Contact

不要：

[
d<2mm
\Rightarrow1
]

否则 contact GT 会非常稀疏。

使用连续：

[
\exp(-d^2/2\sigma^2)
]

可以同时表达：

* 已接触；
* 接近接触；
* 明显分离。

因此训练更稳定。

# 30. 最终判断原则

V15 不追求复杂的 contact model。

也不要求 articulation 决定物体整体运动。

只验证一件事：

[
\boxed{
A^{art}
+
W
\rightarrow
C_m
\rightarrow
\text{Grasp Contact Pattern}
}
]

如果：

[
articulation_shuffle
]

显著破坏：

[
ContactPrediction
]

那么第一次可以直接证明：

[
\boxed{
C_m
\text{真正使用了 detailed local ActionToken}
}
]

并且这些局部动作信息对应的是：

[
\boxed{
\text{how to grasp}
}
]

而不仅仅是：

[
\boxed{
\text{how the object moves}.
}
]

V15 在这个验收通过以前，不增加其他结构。
