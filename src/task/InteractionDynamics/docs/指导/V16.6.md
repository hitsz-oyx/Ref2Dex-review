# V16.6：Active + Next-Effect Interaction Diffusion 最小实现

## 0. 核心问题

V16.5 建模：

[
p_\theta(F_t^H\mid S_t,Z_O,E_t)
]

其中：

[
E_t=(T_{O,t})^{-1}T_{O,t+H}.
]

实验中：

* Current State dependency 成立；
* Effect dependency 基本不存在；
* generated future 未超过 persistence baseline。

V16.6 暂时不修改：

* Y-Teacher；
* Future target；
* Diffusion；
* Object encoder；
* DiT backbone；
* Loss。

只重新定义控制条件。

---

# 1. V16.6 Goal 定义

定义：

[
\boxed{
G_t=
(a_t,\Xi_t)
}
]

其中：

[
a_t\in{0,1}
]

表示当前 object 是否需要 hand 参与 interaction。

[
\Xi_t=
[
\Delta T_{k^*},
\Delta T_{k^*+1},
\ldots,
\Delta T_{k^*+L-1}
]
]

表示从未来找到的 **next meaningful object motion segment**。

中文含义：

> 当前需要操作哪个物体，以及这个物体接下来最近的一小段有效运动目标是什么。

不输入完整 future trajectory。

---

# 2. Active 的语义

`active=1`：

> 当前 hand 应该参与这个 object 的 manipulation。

包括：

* approach；
* pre-shape；
* contact formation；
* stable grasp；
* push / pull；
* transport。

`active=0`：

> 当前 hand 不应该继续主动操作这个 object。

包括：

* manipulation 尚未开始；
* manipulation 已结束；
* 已 release；
* 当前 object 不是 active object。

注意：

[
\boxed{
active\neq contact
}
]

手还没有接触物体时：

[
a_t=1
]

完全合法。

例如：

```text
hand far
object stationary
future goal = lift
active = 1
```

此时模型应开始 approach。

---

# 3. 不显式定义 Phase

禁止人为构造：

```text
approach
grasp
hold
release
```

作为模型 condition。

这些状态由：

[
S_t=[r_t,d_t]
]

和：

[
G_t=(a_t,\Xi_t)
]

共同决定。

期望：

```text
far + inactive
→ stay / no grasp

far + active + upward effect
→ approach / pre-shape

near + active + upward effect
→ establish grasp

grasped + active + upward effect
→ maintain grasp

grasped + inactive
→ release / withdraw
```

---

# 4. Object Motion Increment

对 object trajectory：

[
T_{O,0:T}^W
]

定义逐帧局部增量：

[
\boxed{
\Delta T_j
=

(T_{O,j}^W)^{-1}T_{O,j+1}^W.
}
]

转为 6D：

[
\xi_j=
[
100\Delta p_j,,
\Delta\omega_j
]
\in\mathbb R^6
]

其中：

* translation：cm；
* rotation：axis-angle / rotation vector。

---

# 5. Next Meaningful Effect

不能简单使用：

[
\Delta T_t.
]

因为 approach 阶段 object 还没动。

从当前 (t) 向未来搜索：

[
\boxed{
k^*(t)
======

\min{k\ge t:
\Delta T_k\text{ is meaningful}}.
}
]

然后从 (k^*) 开始取短 segment。

---

# 6. Meaningful Motion 判定

第一版避免被 mocap jitter 触发。

不直接判断单帧。

使用短累计窗口：

[
W_m=3.
]

定义：

[
\Delta T_{j:j+W_m}
=

T_{O,j}^{-1}T_{O,j+W_m}.
]

如果：

[
|\Delta p|>\epsilon_p
]

或者：

[
|\Delta\omega|>\epsilon_r
]

则认为从 (j) 开始存在 meaningful motion。

初始建议：

```text
motion_check_window = 3
translation_threshold = 0.2 cm
rotation_threshold = 1.0 deg
```

这两个阈值必须先打印数据分布检查。

禁止直接假设阈值正确。

---

# 7. Goal Segment

第一版：

[
\boxed{L=4}
]

找到 (k^*) 后取：

[
\Xi_t=
[
\xi_{k^*},
\xi_{k^*+1},
\xi_{k^*+2},
\xi_{k^*+3}
].
]

所以：

[
\Xi_t\in\mathbb R^{4\times6}.
]

flatten 后：

[
\boxed{
g_t^{motion}\in\mathbb R^{24}.
}
]

最终：

[
\boxed{
G_t=[a_t,g_t^{motion}]
\in\mathbb R^{25}.
}
]

这里取的是 **从第一次 meaningful motion 开始的一小段连续 ΔT**。

不跳过 segment 中间的零运动。

原因：

> 保留最小局部运动结构，但不输入长 future trajectory。

---

# 8. Active=0 时的 Goal

当：

[
a_t=0
]

统一设置：

[
\boxed{
\Xi_t=0.
}
]

即：

[
G_t=[0,0,\ldots,0].
]

禁止出现：

```text
active = 0
motion goal != 0
```

作为正常训练样本。

这种组合只用于 intervention。

---

# 9. Active Label

V16.6 暂时不学习 active selector。

训练阶段直接从 Human demonstration 构造：

[
a_t^{GT}.
]

第一版 active interval：

> 从 Human 明确开始面向该 object 的 manipulation / approach，到完成 release 为止。

优先复用现有：

* hand-object distance；
* contact；
* relative hand motion；
* object motion；

自动确定 manipulation interval。

但 active 只是一个 binary control signal，不允许编码：

* grasp type；
* finger identity；
* future Y；
* human pose。

最终系统中 active 应来自上层 planner / world model。

因此：

[
\boxed{
\text{V16.6 不研究 active prediction，只研究 active-conditioned interaction。}
}
]

# 17. Goal Extraction Sanity Check

训练前必须先输出：

```text

goal segment start frame
goal Δp[0:L]
goal Δω[0:L]
current hand-object distance

```

随机检查至少：

```text
5 inactive-before
5 approach
5 grasp/transport
5 inactive-after
```

必须肉眼确认：

### Approach

```text
object current motion ≈ 0
active = 1
goal segment = future meaningful motion
```

### Stable manipulation

```text
active = 1
goal segment = nearby desired object motion
```

### Finished

```text
active = 0
goal segment = 0
```

若这个 sanity check 不成立，不训练 diffusion。

}

# 25. 如果 Gate B/C 成立但 Gate D 失败

[
\boxed{

F_t-F_{\rm persistence}(S_t).
}
]

[
p(R_t|S_t,O,G_t).
]

解释：

* stable grasp → (R\approx0)；
* approach → 非零；
* contact formation → 非零；
* release → 非零。

[
\boxed{

# 26. 如果 Gate C 仍然失败

先做 deterministic clean regression：

[

]

[

[

# 31. V16.6 最终公式

当前 interaction state：

[
S_t=[r_t,d_t].
]

Goal：

[
\boxed{
G_t=
\left[
a_t,,
\xi_{k^*},
\xi_{k^*+1},
\xi_{k^*+2},
\xi_{k^*+3}
\right].
}
]

其中：

[
k^*
===

\text{next meaningful object-motion onset}.
]

预测：

[
\boxed{
F_t^4
\sim
p_\theta(
F_t^4
\mid
S_t,Z_O,G_t
).
}
]

其语义是：

> **给定当前 hand-object interaction、object geometry、当前是否需要操作该物体，以及该物体接下来最近的一小段有效目标运动，预测下一小段合理 interaction evolution。**

训练阶段：

```text
Human demonstration
       ↓
current S_t
       +
active label
       +
next meaningful object ΔT segment
       ↓
Interaction Diffusion
       ↓
future Y
```

最终系统：

```text
Robot current state ──→ S_t
Object geometry ──────→ Z_O

World Model / Planner
       ↓
active object
       +
next meaningful ΔT
       ↓
       G_t

[S_t, Z_O, G_t]
       ↓
Interaction Prior
       ↓
short future Y
       ↓
Embodiment inverse
       ↓
Robot action
```

V16.6 只验证这条最小链路是否成立。
