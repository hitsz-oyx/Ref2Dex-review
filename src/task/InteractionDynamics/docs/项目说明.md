# InteractionDynamics 项目说明

## 1. 任务定位

InteractionDynamics V1 学习下面的因果链：

```text
当前 Hand-Object World
        +
未来 8 步 Human Hand Action Chunk
        ↓
64 个 object-patch-indexed interaction tokens
        ↓
未来 8 步 Object Effect Chunk
```

V1 只训练 Human action → Object effect，不包含机器人 decoder、human-robot paired dataset、Slot Attention、稀疏 gate 或 action reconstruction loss。训练完成后的首要下游验证是 MANO self-inverse，而不是机器人训练。

文档按下面的递归关系组织：

- 完整设计与论证：[`指导/V1.md`](指导/V1.md)
- 模型架构分支：[`架构/V1.md`](架构/V1.md)
- 数据、训练和验证流程：[`Pipeline/V1.md`](Pipeline/V1.md)

本文档维护已经实现并由实验确认的事实，并作为这些分支文档的 task 级入口。

## 2. 目录职责

- `config.py`、`configs/`：V1 固定参数和实验配置。
- `dataset.py`：读取完整 sequence cache，在运行时构造固定 8 步 chunk 和三个坐标表示。
- `uni3d.py`：Uni3D-S PointNet patch encoder、deterministic FPS/KNN、EVA world transformer 和 checkpoint 加载。
- `model.py`：FrozenDenseToken、Action Encoder、cross-attention、object canonicalization 和 Effect Decoder。
- `runner.py`：双学习率 optimizer、AMP、masked effect loss、ADE/FDE 和 collapse diagnostics。
- `train.py`：共享 BaseRunner 的训练入口。
- `extract.py`：计划中的 representation/attention 导出工具，尚未实现。
- `inverse_mano.py`：计划中的 MANO self-inverse，尚未实现。
- `process/GRAB/build_interaction_dynamics_cache.py`：raw GRAB → 完整 sequence cache。
- `process/GRAB/build_interaction_dynamics_manifest.py`：固定 horizon=8 的 dominant-hand manifest。

## 3. 数据链路

缓存根目录：

```text
data/processed_data/interaction_dynamics_v1/data/grab/
```

每条 sequence 使用一个 `shared.npz` 和左右手 `left.npz` / `right.npz`。缓存保持 world-frame 完整时间轴，不离线枚举 chunk。

Dataset 对每个 current frame `t` 构造：

- World Expert：当前 object frame 中的完整 1538 hand points + 4096 object points；
- Action Expert：当前 hand-root frame 中的当前手和未来 8 步累计 hand displacement；
- DenseToken：当前 hand-root frame 中的 1538 hand points + 512 个 5 cm object points；
- Effect GT：固定在 current object frame 中的未来 8 步 object displacement。

Future object geometry 只进入 loss target，不进入模型 forward。

## 4. 模型链路

1. Uni3D-S 将 hand/object 分别 patchify 为 64 + 64 tokens，并联合通过 EVA Transformer。
2. Action Encoder 复用 World hand 的 FPS/KNN index，对 8 步轨迹进行 spatial PointNet 和 temporal Transformer 编码。
3. Action tokens 查询 128 个 world tokens，得到 action-context tokens。
4. V1 使用 `mean + 10 × local_residual` 放大 action-context 的 patch-local 分量，防止全局动作淹没局部差异。
5. Object world tokens 作为 query，对 action context 做无 object residual 的 canonicalization，得到 64 个 interaction tokens。
6. 512×8 temporal effect queries 读取 interaction tokens，预测 meter 单位的 object displacement。

FrozenDenseToken 始终使用 FP32，避免 bfloat16 autocast 进入不支持的 spconv kernel；其参数被冻结且不写入 InteractionDynamics checkpoint。

## 5. 权重与数值尺度

- Uni3D-S：`src/task/InteractionDynamics/weights/uni3d-s/model.pt`
- DenseToken：复用 `src/task/Cm/densetoken_ckpt/best.pt`
- geometry 保持 meter；hand/object motion 在模型和 loss 内部乘 `motion_scale=100` 转为 centimeter。
- 新模块学习率 `1e-4`；Uni3D pretrained Transformer 学习率 `1e-5`。

Uni3D-S 当前加载结果：22,105,474 个 pretrained 参数，shape mismatch 为 0；150,144 个新参数属于 normal/entity embedding。

## 6. 已验证结果

真实全尺寸 batch 已完成 forward/backward：

```text
world_tokens          [1, 128, 384]
action_tokens         [1, 64, 384]
interaction_tokens    [1, 64, 384]
pred_obj_disp_chunk   [1, 8, 512, 3]
```

32-chunk `toruslarge_lift` controlled overfit：

- Zero-flow ADE/FDE：42.53 / 76.98 mm；
- 400-step epoch ADE/FDE：6.71 / 12.43 mm；
- 改善：84.2% / 83.9%；
- interaction variance/cosine：0.204 / 0.793。

结论：单序列 overfit 和非 collapse 验收已经通过。Canonical query sharpening 与 Effect spatial routing bias 均无实际收益，已经撤回。

## 7. 常用命令

环境：

```bash
conda run -n graspenv <command>
```

生成单条 cache：

```bash
python -m process.GRAB.build_interaction_dynamics_cache \
  --grab-root dataset/GRAB/data \
  --seq s1/toruslarge_lift \
  --device cuda
```

生成 dominant-hand manifest：

```bash
python -m process.GRAB.build_interaction_dynamics_manifest \
  --data-root data/processed_data/interaction_dynamics_v1/data/grab \
  --output-dir data/processed_data/interaction_dynamics_v1
```

运行测试：

```bash
conda run -n graspenv pytest -q \
  tests/test_interaction_dynamics_dataset.py \
  tests/test_interaction_dynamics_frames.py \
  tests/test_interaction_dynamics_model.py \
  tests/test_interaction_dynamics_no_leakage.py \
  tests/test_interaction_dynamics_runner.py
```

运行 overfit：

```bash
python -m src.task.InteractionDynamics.train \
  --config src/task/InteractionDynamics/configs/grab_v1_overfit.yaml \
  --device cuda
```
