# InteractionDynamics 项目说明

## 1. 任务定位

InteractionDynamics V1 学习下面的因果链：

```text
当前 Hand-Object World
        +
未来 8 步 Human Hand Action Chunk
        ↓
64 个 object-patch-indexed interaction tokens
        ↓
未来 8 步 Object Effect Chunk
```

V1 只训练 Human action → Object effect，不包含机器人 decoder、human-robot paired dataset、Slot Attention、稀疏 gate 或 action reconstruction loss。训练完成后的首要下游验证是 MANO self-inverse，而不是机器人训练。

## 2. 目录职责

- `config.py`、`configs/`：V1 固定参数和实验配置。
- `dataset.py`：读取完整 sequence cache，在运行时构造固定 8 步 chunk 和三个坐标表示；样本上限按 sequence 均匀覆盖完整时间轴。
- `action_hand_points_object_sequence`：9 帧手表面分别变换到各帧自身 object frame，是 Y-Teacher V1 唯一的 Dataset 输入语义；不能用固定 current-object-frame displacement 代替。
- `uni3d.py`：Uni3D-S PointNet patch encoder、deterministic FPS/KNN、EVA world transformer 和 checkpoint 加载。
- `model.py`：FrozenDenseToken、Action Encoder、cross-attention、object canonicalization 和 Effect Decoder。
- `runner.py`：双学习率 optimizer、AMP、effect/patch/relative motion loss、ADE/FDE 和 collapse diagnostics。
- `train.py`：共享 BaseRunner 的训练入口。
- `extract.py`：按样本保存 representation、三类 attention 和 object-effect 诊断结果。
- `intervention.py`：执行 mean、shuffle 和 cross-sample interaction token 干预。
- `target_diagnostics.py`：分解 hand/object patch target 的全局与 patch-local motion 能量。
- `relative_diagnostics.py`：统计最近 hand→object patch 边的距离、法向/切向相对运动和接触转移。
- `correspondence_diagnostics.py`：比较固定/逐帧 correspondence、累计/增量 target 和 current/chunk-active mask。
- `DenseEdgeInteractionModel`：V8 诊断分支，在压缩前以全量 hand points 和局部 object KNN 构造 dense interaction set。
- `action_probe.py`：冻结 encoder，以 ridge linear probe 分别读取完整、全局均值和 patch-local residual hand flow。
- V11 interaction reconstruction head：由全局时序 `C` 和 64 个 object world tokens 重建 body-index-free 的 `[rho,d,v_n^local,v_t^local]` 六维场。
- `PosePairActionEncoder`：共享 static surface encoder 产生 9 帧 local/global PoseToken，由相邻 pose、wrist increment 与显式 local point increment 构造 8 步 ActionToken；action decomposition heads 解码 wrist SE(3) 与 wrist-frame articulated patch flow。
- `PretrainedTokenInteractionModel`：V14 独立路径，冻结预训练 Pose/Action encoder，把 1 个 RootToken 与 64 个 articulation tokens 逐 timestep query 当前 WorldToken，直接以 `[B,8,65,384]` 的结果作为 Cm，并预测增量 object SE(3)。
- V15 在该路径中改用冻结的 ActionToken V2 flow encoder；从 articulation Cm 独立预测 `64×64` object-patch/hand-patch soft contact，并保留 V14 的刚体 SE(3) effect 头。V15.1 将 GT 修正为同一当前物体系下的 `H(t+8)` 对 `O(t+8)`，并提供可关闭的正区域加权 MSE 和按 hand patch 的 8-step 有序 attention readout。
- V16 改为 64 个 object patch 查询动态位置编码后的 64 个冻结 ActionToken V2 articulation tokens，得到 `[B,8,64,384]` object-centric interaction field；endpoint head 预测 `[B,64]` object contact。该路径不读取未来 object geometry，并在训练时固定 Uni3D patch encoder 的 BatchNorm running stats，避免小批量统计捷径。
- `inverse_mano.py`：冻结 InteractionDynamics encoder，以 teacher C 监督优化未来 8 帧 MANO PCA pose、global orientation 和 translation，并报告不参与优化的手点 ADE/FDE。
- `interaction_field.py`：冻结定义的 Y-Teacher V1，输出 `r[9,128,3]`、真实 soft distance `d[9,128]` 和 `u[8,128,3]`；contact 只由 `d` 派生。
- `inverse_mano_y.py`：比较 Y-Teacher V1、Direct Full Action 与 ActionToken+Root 的 MANO inverse，并保持冻结 encoder 参数时的输入梯度。
- `eval_interaction_compression.py`、`interaction_autoencoder.py`、`train_interaction_autoencoder.py`：sequence-disjoint PCA baseline 与 coordinate-conditioned slot autoencoder 研究原型。
- `research/y_teacher_parity/diag_parity.py`：比较 raw MANO 与 Dataset 动态物体系产生的 surface 和 `r/d/u`，要求最大差小于 `1e-5 m`。
- `interaction_diffusion.py`：将 Y 按 anchor 整理为 `[128,60]`，以 anchor xyz/normal、全局物体特征和 8 步 object SE(3) effect 为条件预测扩散噪声；不含 anchor index embedding。
- `train_interaction_diffusion.py`、`eval_interaction_diffusion.py`：单 sequence controlled diffusion 训练、DDIM 生成及 correct/shuffle/zero Effect 干预诊断。
- `state_interaction_diffusion.py`、`train_state_interaction_diffusion.py`：V16.5 将当前 `S_t=[r_t,d_t]` 保持为 clean condition，只对 `H=4` 的 `[u_t,S_{t+1},...]` 加噪；以局部 KNN object patch 和 AdaLN endpoint Effect 为条件，并评估 state/effect 干预。
- `research/state_diffusion_v16_5/diag_baselines.py`：计算短时 future 的 persistence baseline 和 state/effect 条件多样性。
- `goal_interaction_diffusion.py`、`train_goal_interaction_diffusion.py`：V16.6 从完整 object pose 时间轴提取 `active + next meaningful 4-step SE(3)` Goal，并在分阶段 32-chunk controlled set 上进行 state/active/motion Goal 干预及 dynamic/static persistence 对比。
- `research/goal_diffusion_v16_6/`：Goal extraction sanity、分层 persistence 和 deterministic clean regression 诊断。
- `residual_interaction_regression.py`、`train_residual_interaction_regression.py`：V16.7 固定 V16.6 数据与 Goal，直接回归相对 persistence future 的 residual，并进行 motion zero/shuffle/reverse 与 active zero 干预。
- `research/residual_v16_7/`：residual 尺度、精确恢复和远场 current-state 分桶诊断。
- `residual_interaction_diffusion.py`、`train_residual_interaction_diffusion.py`：V16.8 对 V16.7 residual 使用 v-prediction 和无 clamp 的 deterministic DDIM-like sampler，保存 oracle denoising、采样稳定性、四 seed 与 Goal 干预诊断。
- `research/residual_diffusion_v16_8/`：从 checkpoint 提取 denoising、sampling 与 intervention 摘要。
- `research/residual_diffusion_v16_9/`：比较 4k/10k、uniform/half-high/x0 auxiliary 训练，并固定 checkpoint 与 initial noise 评估 100/50/25/10-step 正规 DDIM skipping。
- `dataset_v17.py`、`train_v17.py`、`eval_v17.py`：V17 从 dominant-hand sequence 集合恢复全部合法 frame，按 demonstration 目录做固定 80/10/10 split，以四卡 DDP 同时训练 deterministic residual 与 v-diffusion；train-only normalization 由 rank 0 生成并供所有 split 使用。评估覆盖分层误差、远场和 Goal 干预。
- `research/v17/`：full-frame dataset audit、tensor cache、batch stress 与短优化配置对照。
- `viewer/`：浏览器端三维查看器，实时显示 checkpoint 的 8 步物体点流 prediction/GT，并读取 `mano_inverse/*.npz` 对比 MANO 静止初始化、优化结果和 GT。
- `process/GRAB/build_interaction_dynamics_cache.py`：raw GRAB → 完整 sequence cache。
- `process/GRAB/build_interaction_dynamics_manifest.py`：固定 horizon=8 的 dominant-hand manifest。

## 3. 数据链路

缓存根目录：

```text
data/processed_data/interaction_dynamics_v1/data/grab/
```

每条 sequence 使用一个 `shared.npz` 和左右手 `left.npz` / `right.npz`。缓存保持 world-frame 完整时间轴，不离线枚举 chunk。

Dataset 对每个 current frame `t` 构造：

- World Expert：当前 object frame 中的完整 1538 hand points + 4096 object points；
- Action Expert：当前 hand-root frame 中的当前手和未来 8 步累计 hand displacement；
- DenseToken：当前 hand-root frame 中的 1538 hand points + 512 个 5 cm object points；
- Effect GT：固定在 current object frame 中的未来 8 步 object displacement。
- Relative GT：Runner 侧可读取 current-object-frame 的未来 hand displacement，用于构造 hand-object 相对轨迹；该 tensor 不进入模型 forward。
- Dynamic-relative GT：Runner 侧可读取 current-object-frame 的未来 object normals，用于逐帧法向和 correspondence 诊断；同样不进入模型 forward。
- V7 action input：已知未来 hand trajectory 在 current object frame 中的累计位移，进入时空交互场。
- V7 SE(3) GT：相邻未来帧之间的 8 个 object pose increment，只供 Runner 监督，不进入模型 forward。
- V14 action atlas：直接从 cache 的 `hand_cano_points` 建立固定 `64×32` FPS/KNN，返回 `action_hand_cano_points` 和 `action_patch_knn_idx`；与 Uni3D 当前 posed-hand world patch 严格分离。V14-A 只使用与预训练 checkpoint 一致的右手样本。

Future object geometry 只进入 loss target，不进入模型 forward。

## 4. 模型链路

1. Uni3D-S 将 hand/object 分别 patchify 为 64 + 64 tokens，并联合通过 EVA Transformer。
2. Action Encoder 复用 World hand 的 FPS/KNN index，对 8 步轨迹进行 spatial PointNet 和 temporal Transformer 编码。
3. Action tokens 查询 128 个 world tokens，得到 action-context tokens。
4. V1 使用 `mean + 10 × local_residual` 放大 action-context 的 patch-local 分量，防止全局动作淹没局部差异。
5. Object world tokens 作为 query，对 action context 做无 object residual 的 canonicalization，得到 64 个 interaction tokens。
6. V4 将每个 effect point 硬路由到最近 object patch，dense flow 等于对应 patch motion 加局部 residual；residual 只读取对应 interaction token、point-to-patch 相对坐标、normal 和时间编码，不读取 absolute xyz 或全部 interaction tokens。
7. V5 为每个 hand patch 匹配当前最近 object patch，把 action-context、object token 和相对位置/法向融合为 hand→object edge token；线性头直接预测未来 8 步 `[v_n,v_t]`。当前 edge token 是机制监督原型，尚未替换 V4 的 object-effect 主路径。
8. V7 保留 `[B,8,64,D]` temporal action tokens，以 5 cm Gaussian 将手部作用连续 splat 到每个 object patch；field 同时编码相对位置、距离、法向、手部增量及法向/切向分解。全局池化 field 后逐步预测 8 个 SE(3) increment，并以解析刚体变换生成 dense object flow，不使用学习式 point decoder。V7 主路径不依赖 DenseToken。
9. V8 诊断分支完全绕过 Uni3D、DenseToken 和 64-patch bottleneck；1538 个 hand points 各连接 4 个最近 object points，经 point-edge MLP 得到 `[B,8,1538,64]` dense interaction set。当前只预测逐点增量相对运动以检验 dense-first 假设，尚未加入 learned bottleneck `C`。
10. V9 `global_action_only` 保留 V7 的 Action Encoder、全局 object context 和 SE(3) head，但把送入 dynamics head 的 64 个 field token 替换成同一个全局 action token，并将显式 descriptor 清零，用于隔离 object-indexed local field 的贡献。
11. V11 保持 V9 的 `C=[B,8,128]` 和 SE(3) 主路径不变，增加 `C + object token → [B,8,64,6]` 解码头。target 从完整 body surface 构造，不含 MANO joint、finger 或 point identity；density、最近距离和去整体平移后的法向/切向运动三组等权。
12. V12-A 从旧 `[B,8,64,D]` temporal ActionToken 解码相邻 hand-root SE(3) 和 wrist-frame articulated flow；V12-B/C 改为每帧 canonical hand surface → 64 local PoseToken + global pose code，再用相邻 pose pair、wrist increment 和 local point increment 生成 ActionToken。articulation decoder 零初始化，按小目标量级使用 100 倍 loss 权重；static pose 以 64 个稳定 patch center 重建监督。
13. V13 保留 V12 ActionToken，以 object token 查询带手/物 patch 空间编码和距离偏置的 local ActionToken，形成 64 个 object-indexed interaction tokens，再由 8 个 learnable slots 聚合。单个 learned effect query 从 slots 读取 SE(3) 条件，避免 dynamics head 再次硬取 slot 均值；`C_m` 保持 `[B,8,8,128]`。
14. V14 绕过旧 ActionEncoder、interaction field、canonicalizer 和 slots。冻结独立预训练的 Pose/Action encoder，拼接 RootToken 和 64 个 articulation tokens；加入当前 object-frame action patch 位置后逐 timestep query 128 个 WorldTokens，所得 `[B,8,65,384]` 直接定义为 Cm。单个 Effect Query 只从 Cm 读取逐步 object SE(3)。
15. V16 接触分支排除 RootToken。每步手 patch 位置由当前位置加已知 action hand displacement 更新；当前 object token 加当前位置编码后查询 articulation token，形成 object-centric `C_m=[B,8,64,384]`。只从 endpoint `C_m[:, -1]` 预测 object contact，监督为 V15.1 对齐矩阵沿 hand 维取 max。
16. V16.7 固定 V16.6 的 `cup_lift` controlled32 数据、active/Goal 定义和 `H=4` Teacher，把目标改为相对 `[0,S_t]×4` persistence future 的 residual。4000-step clean regression 在 dynamic subset 达到 `u/r/d=0.085/0.244/0.109 cm`，优于 persistence 的 `0.132/0.472/0.252 cm`；9 个 dynamic-active 样本的 correct `r/d=0.064/0.030 cm`，motion zero/reverse 分别恶化至 `0.496/0.222` 和 `0.686/0.325 cm`。因此 residual controlled gate 与 Goal dependency 均通过，但尚无多序列泛化证据。
17. V16.8 在相同 controlled32 上生成 normalized residual。v sampler 全程 finite，dynamic `u/r/d=0.124/0.403/0.178 cm`，超过 persistence，但略未达到相对 V16.7 的 `1.5×` 工程线 `r<0.37,d<0.17 cm`。不同 Goal 干预仍明显恶化 dynamic-active；当前结论是 v-prediction 修复了旧 sampler 的数值爆炸并保留条件依赖，但生成精度 Gate 3 未通过，不扩大数据。
18. V16.9 将 uniform 训练延长到 10k 后，100-step dynamic `u/r/d=0.101/0.321/0.147 cm`，四 seed `r/d=0.325±0.016/0.147±0.009 cm`，明显优于 4k。half-high 把 t90 oracle 从 `0.297` 降到 `0.183`，但最终 `r/d=0.355/0.199 cm`；high-noise x0 auxiliary 为 `0.309/0.164 cm`，均不作为默认。固定 uniform-10k checkpoint 的 10-step skipping 达到 `0.097/0.307/0.150 cm`，说明延长训练是主要收益，采样误差累积只占小部分。
19. V17 使用完整自然帧、固定 16/2/2 demonstration split 和四卡 BF16 训练 30 epochs。最佳 epoch 21 的 validation dynamic diffusion `r/d=4.008/4.676 cm`，差于 persistence `3.706/4.565 cm`；test dynamic diffusion `r/d=4.303/5.158 cm`，也差于 persistence `3.905/4.570 cm`。test dynamic-active 将 Goal active 清零反而把 diffusion `r/d` 改善到 `3.998/4.703 cm`，deterministic 也同向改善，因此 full-data 泛化与 Goal dependency Gate 均未通过，不进入 inverse / C inference。

V3 增加两条直接监督分支：hand-indexed `action_context_tokens` 逐 patch 预测 8 步手部平均位移，object-indexed `interaction_tokens` 逐 patch 预测 8 步物体平均位移。两者与 dense effect loss 均使用厘米内部尺度，默认权重均为 1；future object target 只在 Runner 中按模型产生的稳定 KNN index pooling，不进入模型 forward。

FrozenDenseToken 始终使用 FP32，避免 bfloat16 autocast 进入不支持的 spconv kernel；其参数被冻结且不写入 InteractionDynamics checkpoint。

## 5. 权重与数值尺度

## 6. 已验证结果

真实全尺寸 batch 已完成 forward/backward：

```text
world_tokens          [1, 128, 384]
action_tokens         [1, 64, 384]
interaction_tokens    [1, 64, 384]
pred_obj_disp_chunk   [1, 8, 512, 3]
```

32-chunk `toruslarge_lift` controlled overfit：

- Zero-flow ADE/FDE：42.53 / 76.98 mm；
- 400-step epoch ADE/FDE：6.71 / 12.43 mm；
- 改善：84.2% / 83.9%；
- interaction variance/cosine：0.204 / 0.793。

结论：单序列 overfit 和非 collapse 验收已经通过。Canonical query sharpening 与 Effect spatial routing bias 均无实际收益，已经撤回。

10 序列小规模实验使用 sequence-disjoint 8/1/1 划分，每序列最多 128 个 chunk，训练 5 epochs / 640 steps：

- 训练 ADE：35.53 → 19.54 mm；
- 验证 zero-flow → 模型 ADE/FDE：42.94/66.76 → 32.07/46.03 mm；
- 测试 zero-flow → 模型 ADE/FDE：30.98/54.62 → 25.19/44.81 mm；
- 验证 interaction variance/cosine：0.1108/0.8874；
- 测试 interaction variance/cosine：0.0367/0.9627。

结论：小规模未见序列泛化优于 zero-flow。测试序列 token 多样性较弱，但尚未观察到完全 collapse。

上述 5-epoch 结论已被后续 V2 指导实验修正：旧采样总计训练 20 epochs 后 train ADE 降到 10.87 mm，但最佳验证/测试为 30.78/29.31 mm，存在明确泛化差距。将每序列采样改为均匀时间覆盖后，small10 最佳验证 ADE 为 27.62 mm；均匀测试集模型 46.01 mm，基本等于 zero-flow 45.99 mm。

20 序列 12/4/4 实验使用 1536/362/512 个均匀采样片段训练 20 epochs：

- train ADE：14.38 mm；
- 验证 zero-flow → 模型：49.05 → 46.93 mm；
- 测试 zero-flow → 模型：45.82 → 44.80 mm；
- 验证/测试 interaction cosine：0.9965/0.9987。

post-gain token intervention 的验证 ADE：normal/mean/shuffle/cross-sample 为 27.62/27.34/27.62/30.03 mm。结论是 Decoder 主要使用样本级全局 interaction，并未有效使用 object-indexed token 局部结构。Uni3D 联合单位球输入消融没有改善，已撤回。

V3 三层监督在 small20 上训练 5 epochs 后，最佳 checkpoint（step 384）验证 ADE 为 48.82 mm，弱于仅 effect supervision 的 46.93 mm；interaction cosine 仍接近 1。最佳 checkpoint 的 normal/mean/shuffle/cross-sample ADE 为 48.82/48.81/48.82/49.09 mm。结论：两个直接 patch 预测头可正常优化，但旁路辅助监督本身不足以让主 Effect Decoder 使用局部 token。

V4 把 patch motion 串入 dense effect 主链并移除全局 cross-attention/absolute xyz shortcut。small20 训练 5 epochs 后最佳 checkpoint 位于 step 384：验证 ADE 49.45 mm，测试 ADE 42.94 mm；旧 baseline 分别为 46.93/44.80 mm，因此没有稳定改善。验证 normal/mean/shuffle/cross-sample ADE 为 49.45/49.40/49.42/49.76 mm，测试为 42.94/42.93/42.95/43.74 mm；shuffle 相对变化仅 -0.05%/+0.03%，未达到 +10% 验收线。结论：硬路由改变了计算路径，但上游 interaction token 仍近乎相同，object-indexed 表征需求尚未成立。

后续诊断确认 V4 checkpoint 的 action-context variance/cosine 为 0.592/0.814，而 interaction 为 0.000406/0.99959，原 canonicalizer 是直接坍缩位置。5 cm spatial canonicalization 虽能保留 token 差异，但最佳验证/测试 ADE 为 51.31/43.23 mm，shuffle 只退化 0.07%/0.85%，已撤回。更根本的 target 分解显示：验证 hand/object patch-local motion 仅占总能量 1.16%/1.01%，测试为 1.90%/3.30%；97–99% 是所有 patch 共享的全局运动。当前 raw patch MSE 因而天然鼓励全局一致 token。

V5 先验统计对每个 hand patch 固定匹配当前最近 object patch，并在 current object frame 中计算未来 8 步累计相对运动。验证集法向/切向相对运动的跨边局部能量占 33.11%/22.16%，测试集为 41.58%/37.49%，显著高于 raw patch flow；距离变化局部能量仅 2.92%/3.20%。2 cm 阈值下接触占比为 9.45%/17.86%，接触状态切换仅 0.98%/1.26%。结论：`v_n/v_t` 是值得训练验证的局部 mechanism target；距离可作为辅助，稀疏 contact classification 暂不作为第一主目标。

V5 edge-token 原型在 small20 上进行了两个 5-epoch 实验。监督全部 64 条最近邻边时，最佳验证/测试 relative RMSE 为 1.389/1.178 cm，均差于 zero predictor 的 1.370/1.110 cm。限制到初始距离小于 5 cm 后，验证/测试有效 edge 占 38.66%/56.35%，最佳 relative RMSE 降到 0.999/0.874 cm，但仍差于 masked zero 的 0.968/0.841 cm；对应 effect ADE 为 48.77/44.10 mm。edge token 没有坍缩，最佳验证/测试 variance 为 0.125/0.155、cosine 为 0.871/0.840。结论：相对运动 target 确有局部差异，简单单帧最近邻 fusion 也能保持 token 差异，但累计 `v_n/v_t` raw MSE 没有获得跨序列可预测性；不继续调 loss 权重。

V6 correspondence 诊断显示，验证/测试分别有 51.57%/53.83% 的 hand edges 在 8 步内至少更换一次最近 object patch，fixed correspondence 的逐帧匹配率为 68.29%/66.11%。current-near 5 cm mask 漏掉 chunk-active edges 的 11.91%/6.51%。逐步增量将 current-near target RMS 从累计的 1.331/1.179 cm 降至 0.352/0.300 cm，但 `q99/q50` 仍为 19.53/22.21；动态与固定 correspondence 的增量分布几乎相同。单变量 `increment_fixed` 训练仍未优于零预测：最佳 checkpoint 验证/测试 relative RMSE 为 0.275/0.240 cm，zero 为 0.247/0.206 cm；effect ADE 为 48.62/43.51 mm。因此累计形式不是主要瓶颈，也没有证据支持立即训练动态 nearest。

V7 在相同 small20 划分训练 5 epochs，最佳 checkpoint 为 step 1152。验证 ADE 为 46.70 mm，相比 zero-flow 49.05 mm 改善 4.8%；测试 ADE/FDE 为 42.08/73.09 mm，相比 zero-flow ADE 45.82 mm 改善 8.2%，也优于 V4/V6 的 42.94/43.51 mm。测试逐步 SE(3) translation error 为 0.953 cm，rotation error 为 2.572°。训练 batch ADE 可降至约 10 mm，表明解析坐标链路和模型容量有效。结论：连续交互场与刚体 SE(3) 分解是目前 small20 上最有证据的方向；下一步应先做 field/action 消融确认增益来源，再决定扩大数据。

V8 full-resolution local-edge sanity experiment 在相同 small20 上训练 5 epochs。最佳 epoch 1 的验证/test relative RMSE 为 0.2470/0.2031 cm，对应逐点 zero baseline 为 0.2465/0.2027 cm，均未改善；hand-motion-only 解析基线为 0.5971/0.5507 cm。全量点的有效近场比例为 60.76%/77.85%，明显高于 patch edge，但结论没有改变。因而“64-patch 过早压缩”不是 V6 relative target 难以预测的主要原因；暂不实现 `E_dense → C` compressor，V7 的 SE(3) effect 路径仍是主方向。

V9 global-action-only 在相同 small20 上训练 5 epochs，最佳 checkpoint 为 step 1536。其验证 ADE 为 45.41 mm，优于 V7 full-field 的 46.70 mm；测试 ADE/FDE 为 42.29/73.38 mm，与 full-field 的 42.08/73.09 mm 只差 0.21/0.29 mm。global-only 的 field spatial variance 和 descriptor variance 均严格为 0。结论：object-indexed local field 没有稳定、不可替代的贡献；V7 相对 zero-flow 的主要收益应归因于逐步 SE(3) dynamics 与全局 action/object conditioning，不能再把 8.2% test 改善解释为 local interaction mechanism 已成立。

V10 在冻结 V9 checkpoint 上对 `action_context_tokens` 做 ridge linear probe，并仅用 validation 选择正则系数。token spatial variance/cosine 为 2.370/0.721，未发生 patch collapse。global flow probe 在验证/测试相对 zero 改善 67.0%/60.4%；patch-local residual probe 改善 16.4%/22.8%；raw full-flow probe 仅改善 20.1%/3.1%。结论：后端 field 虽可全局化，Action Encoder 本身仍保留可泛化但较弱的手指局部信息；raw flow 会被 global motion 主导，不适合作为保护局部 action 的单一辅助目标。

V11 在相同 small20 上给 V9 增加 object-centric action field 辅助监督，并已完整训练 20 epochs / 7680 steps，总耗时 40:55。按 local-motion 选择的 epoch 15 checkpoint 在验证/test 上为 0.242/0.277 cm，仍差于 zero 0.223/0.243 cm；test object ADE/FDE 为 44.41/79.28 mm，也弱于 V9 的 42.29/73.38 mm。epoch 15 Action local probe 的 test 改善为 26.1%，略高于 V10 的 22.8%。结论：5 epochs 的确尚未收敛，延长训练使 local field 与 object ADE 部分恢复；但 20 epochs 后两项核心验收仍未通过。当前只能确认 small20 下存在目标冲突，不能外推为该监督在更大数据上必然负优化。

V9 SE(3) 已完成与原 V1 同口径的 32-chunk controlled overfit：400 steps 的 epoch ADE/FDE 为 1.28/1.60 mm，约 200 steps 已到 2.2–2.5 mm。因此 small20 的 29–45 mm train/test 误差不是坐标链或容量导致的“无法过拟合”，而是少序列泛化与短训练结果。Cm 的 10.40 mm 验证 mean-stride EPE 来自 1068 条训练序列、226780 steps，并采用近场 object points、单 endpoint flow 和校准 vector Huber；不能与 small20 的 8 步累计 ADE 直接等价比较。

V12-A 在 small20 训练 5 epochs / 1920 steps（10:06）。局部关节流最佳为 epoch 4：验证/test RMSE 0.0586/0.0599 cm，仍差于 zero 0.0393/0.0354 cm；wrist translation 为 0.2648/0.2555 cm，明显优于 zero 0.6892/0.6637 cm，test rotation error 2.75°。test object ADE/FDE 为 42.72/74.35 mm，接近但弱于 V9 的 42.29/73.38 mm。结论：拆分目标有效确认了现有 token 可读出 root motion，但局部 articulation 尚不能跨序列超过零预测；下一步进入 V12-B/C，而不是继续给当前 cumulative encoder 调 loss 权重。

V12-B/C controlled overfit 在 32 chunks、400 steps 下达到 articulation 0.00990 cm（zero 0.01197，改善 17.3%）、static patch-center 2.910 cm（centered baseline 2.969）、object ADE/FDE 3.11/4.15 mm。small20 最佳 epoch 4 的验证 articulation 为 0.01330 cm（zero 0.03930，改善 66.2%）；test 为 0.01173 cm（zero 0.03537，改善 66.8%），wrist translation 0.2698 cm（zero 0.6637）。但 test static pose 为 3.184 cm，差于 centered baseline 2.943 cm，说明 subject morphology 尚未消除；object ADE/FDE 45.07/78.57 mm，也弱于 V9。结论：详细 incremental ActionToken 已经建立，下一瓶颈是 morphology-invariant static pose 和 interaction/effect 对新 ActionToken 的利用。

V13 首版 local fusion + 8 slots 在 small20 上 test ADE/FDE 为 43.96/76.58 mm，但 mean/shuffle 干预仅改变 -0.03/-0.001 mm，仍是近似全局汇聚。加入 5 cm object-hand 距离偏置并以 learned query 读取 slots 后，32-chunk controlled overfit 为 2.90 mm；small20 训练 5 epochs / 1920 steps（10:27），最佳 epoch 5 的验证/test ADE 为 44.36/43.58 mm。test mean/shuffle/cross-sample 分别为 43.73/43.60/44.01 mm，相对 normal 只退化 0.15/0.018/0.43 mm。结论：结构和动作内容依赖已建立，但 shuffle 差距不显著，V13 的 local identity 核心验收尚未通过；暂不进入多 embodiment 预训练。

V14-A 使用 `pose_encoder_v2_morph.pt` 和 `action_encoder_v1_diagnostic.pt`，两者均冻结。32-chunk 右手 controlled overfit 训练 100 epochs / 800 steps（1:55），最终 train ADE/FDE 为 1.01/1.39 mm，translation RMSE 0.0267 cm、rotation error 0.458°，拟合验收通过。latest checkpoint 在 eval 模式的 Action intervention：normal/root-zero/articulation-zero/articulation-mean/articulation-shuffle/cross-sample ADE 为 1.586/11.721/1.588/1.586/1.586/2.796 mm。结论：Cm→Effect 可拟合且依赖样本动作与 RootToken，但 detailed articulation ActionToken 没有可测贡献；V14 核心科学验收未通过，因此不运行 small20。

MANO self-inverse 已在 V9 global C 上打通。test 第 0 个 chunk 从“未来 8 帧均等于当前 MANO 参数”的静止初始化开始，只用 C matching loss 和标准时间平滑先验优化 200 步；C RMSE 从 0.2377 降至 0.00953，未参与优化的 hand-point ADE/FDE 从 27.52/50.43 mm 降至 10.88/10.63 mm。高学习率、弱先验会出现 C 下降但手轨迹发散，说明 inverse 必须保留合理运动先验。当前仅为单样本流程验收，尚不能代表整个 test split。

dominant-hand manifest 在 8,488 个候选窗口中保留 5,770（67.98%）。主要排除 1,836 个双方不活跃窗口（21.63%）和 841 个双手协作窗口（9.91%）。若为泛化扩大数据，应优先单独建模 bilateral-active，而不是把大量 inactive 窗口无差别加入训练。
