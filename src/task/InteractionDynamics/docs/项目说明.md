# InteractionDynamics 项目说明

## 1. 任务定位

InteractionDynamics V1 学习下面的因果链：

```text
当前 Hand-Object World
        +
未来 8 步 Human Hand Action Chunk
        ↓
64 个 object-patch-indexed interaction tokens
        ↓
未来 8 步 Object Effect Chunk
```

V1 只训练 Human action → Object effect，不包含机器人 decoder、human-robot paired dataset、Slot Attention、稀疏 gate 或 action reconstruction loss。训练完成后的首要下游验证是 MANO self-inverse，而不是机器人训练。

## 2. 目录职责

- `config.py`、`configs/`：V1 固定参数和实验配置。
- `dataset.py`：读取完整 sequence cache，在运行时构造固定 8 步 chunk 和三个坐标表示；样本上限按 sequence 均匀覆盖完整时间轴。
- `uni3d.py`：Uni3D-S PointNet patch encoder、deterministic FPS/KNN、EVA world transformer 和 checkpoint 加载。
- `model.py`：FrozenDenseToken、Action Encoder、cross-attention、object canonicalization 和 Effect Decoder。
- `runner.py`：双学习率 optimizer、AMP、三层 motion loss、ADE/FDE 和 collapse diagnostics。
- `train.py`：共享 BaseRunner 的训练入口。
- `extract.py`：按样本保存 representation、三类 attention 和 object-effect 诊断结果。
- `intervention.py`：执行 mean、shuffle 和 cross-sample interaction token 干预。
- `target_diagnostics.py`：分解 hand/object patch target 的全局与 patch-local motion 能量。
- `inverse_mano.py`：计划中的 MANO self-inverse，尚未实现。
- `process/GRAB/build_interaction_dynamics_cache.py`：raw GRAB → 完整 sequence cache。
- `process/GRAB/build_interaction_dynamics_manifest.py`：固定 horizon=8 的 dominant-hand manifest。

## 3. 数据链路

缓存根目录：

```text
data/processed_data/interaction_dynamics_v1/data/grab/
```

每条 sequence 使用一个 `shared.npz` 和左右手 `left.npz` / `right.npz`。缓存保持 world-frame 完整时间轴，不离线枚举 chunk。

Dataset 对每个 current frame `t` 构造：

- World Expert：当前 object frame 中的完整 1538 hand points + 4096 object points；
- Action Expert：当前 hand-root frame 中的当前手和未来 8 步累计 hand displacement；
- DenseToken：当前 hand-root frame 中的 1538 hand points + 512 个 5 cm object points；
- Effect GT：固定在 current object frame 中的未来 8 步 object displacement。

Future object geometry 只进入 loss target，不进入模型 forward。

## 4. 模型链路

1. Uni3D-S 将 hand/object 分别 patchify 为 64 + 64 tokens，并联合通过 EVA Transformer。
2. Action Encoder 复用 World hand 的 FPS/KNN index，对 8 步轨迹进行 spatial PointNet 和 temporal Transformer 编码。
3. Action tokens 查询 128 个 world tokens，得到 action-context tokens。
4. V1 使用 `mean + 10 × local_residual` 放大 action-context 的 patch-local 分量，防止全局动作淹没局部差异。
5. Object world tokens 作为 query，对 action context 做无 object residual 的 canonicalization，得到 64 个 interaction tokens。
6. V4 将每个 effect point 硬路由到最近 object patch，dense flow 等于对应 patch motion 加局部 residual；residual 只读取对应 interaction token、point-to-patch 相对坐标、normal 和时间编码，不读取 absolute xyz 或全部 interaction tokens。

V3 增加两条直接监督分支：hand-indexed `action_context_tokens` 逐 patch 预测 8 步手部平均位移，object-indexed `interaction_tokens` 逐 patch 预测 8 步物体平均位移。两者与 dense effect loss 均使用厘米内部尺度，默认权重均为 1；future object target 只在 Runner 中按模型产生的稳定 KNN index pooling，不进入模型 forward。

FrozenDenseToken 始终使用 FP32，避免 bfloat16 autocast 进入不支持的 spconv kernel；其参数被冻结且不写入 InteractionDynamics checkpoint。

## 5. 权重与数值尺度

- Uni3D-S：`src/task/InteractionDynamics/weights/uni3d-s/model.pt`
- DenseToken：复用 `src/task/Cm/densetoken_ckpt/best.pt`
- geometry 保持 meter；hand/object motion 在模型和 loss 内部乘 `motion_scale=100` 转为 centimeter。
- 新模块学习率 `1e-4`；Uni3D pretrained Transformer 学习率 `1e-5`。

Uni3D-S 当前加载结果：22,105,474 个 pretrained 参数，shape mismatch 为 0；150,144 个新参数属于 normal/entity embedding。

## 6. 已验证结果

真实全尺寸 batch 已完成 forward/backward：

```text
world_tokens          [1, 128, 384]
action_tokens         [1, 64, 384]
interaction_tokens    [1, 64, 384]
pred_obj_disp_chunk   [1, 8, 512, 3]
```

32-chunk `toruslarge_lift` controlled overfit：

- Zero-flow ADE/FDE：42.53 / 76.98 mm；
- 400-step epoch ADE/FDE：6.71 / 12.43 mm；
- 改善：84.2% / 83.9%；
- interaction variance/cosine：0.204 / 0.793。

结论：单序列 overfit 和非 collapse 验收已经通过。Canonical query sharpening 与 Effect spatial routing bias 均无实际收益，已经撤回。

10 序列小规模实验使用 sequence-disjoint 8/1/1 划分，每序列最多 128 个 chunk，训练 5 epochs / 640 steps：

- 训练 ADE：35.53 → 19.54 mm；
- 验证 zero-flow → 模型 ADE/FDE：42.94/66.76 → 32.07/46.03 mm；
- 测试 zero-flow → 模型 ADE/FDE：30.98/54.62 → 25.19/44.81 mm；
- 验证 interaction variance/cosine：0.1108/0.8874；
- 测试 interaction variance/cosine：0.0367/0.9627。

结论：小规模未见序列泛化优于 zero-flow。测试序列 token 多样性较弱，但尚未观察到完全 collapse。

上述 5-epoch 结论已被后续 V2 指导实验修正：旧采样总计训练 20 epochs 后 train ADE 降到 10.87 mm，但最佳验证/测试为 30.78/29.31 mm，存在明确泛化差距。将每序列采样改为均匀时间覆盖后，small10 最佳验证 ADE 为 27.62 mm；均匀测试集模型 46.01 mm，基本等于 zero-flow 45.99 mm。

20 序列 12/4/4 实验使用 1536/362/512 个均匀采样片段训练 20 epochs：

- train ADE：14.38 mm；
- 验证 zero-flow → 模型：49.05 → 46.93 mm；
- 测试 zero-flow → 模型：45.82 → 44.80 mm；
- 验证/测试 interaction cosine：0.9965/0.9987。

post-gain token intervention 的验证 ADE：normal/mean/shuffle/cross-sample 为 27.62/27.34/27.62/30.03 mm。结论是 Decoder 主要使用样本级全局 interaction，并未有效使用 object-indexed token 局部结构。Uni3D 联合单位球输入消融没有改善，已撤回。

V3 三层监督在 small20 上训练 5 epochs 后，最佳 checkpoint（step 384）验证 ADE 为 48.82 mm，弱于仅 effect supervision 的 46.93 mm；interaction cosine 仍接近 1。最佳 checkpoint 的 normal/mean/shuffle/cross-sample ADE 为 48.82/48.81/48.82/49.09 mm。结论：两个直接 patch 预测头可正常优化，但旁路辅助监督本身不足以让主 Effect Decoder 使用局部 token。

V4 把 patch motion 串入 dense effect 主链并移除全局 cross-attention/absolute xyz shortcut。small20 训练 5 epochs 后最佳 checkpoint 位于 step 384：验证 ADE 49.45 mm，测试 ADE 42.94 mm；旧 baseline 分别为 46.93/44.80 mm，因此没有稳定改善。验证 normal/mean/shuffle/cross-sample ADE 为 49.45/49.40/49.42/49.76 mm，测试为 42.94/42.93/42.95/43.74 mm；shuffle 相对变化仅 -0.05%/+0.03%，未达到 +10% 验收线。结论：硬路由改变了计算路径，但上游 interaction token 仍近乎相同，object-indexed 表征需求尚未成立。

后续诊断确认 V4 checkpoint 的 action-context variance/cosine 为 0.592/0.814，而 interaction 为 0.000406/0.99959，原 canonicalizer 是直接坍缩位置。5 cm spatial canonicalization 虽能保留 token 差异，但最佳验证/测试 ADE 为 51.31/43.23 mm，shuffle 只退化 0.07%/0.85%，已撤回。更根本的 target 分解显示：验证 hand/object patch-local motion 仅占总能量 1.16%/1.01%，测试为 1.90%/3.30%；97–99% 是所有 patch 共享的全局运动。当前 raw patch MSE 因而天然鼓励全局一致 token。

## 7. 常用命令

环境：

```bash
conda run -n graspenv <command>
```

生成单条 cache：

```bash
python -m process.GRAB.build_interaction_dynamics_cache \
  --grab-root dataset/GRAB/data \
  --seq s1/toruslarge_lift \
  --device cuda
```

生成 dominant-hand manifest：

```bash
python -m process.GRAB.build_interaction_dynamics_manifest \
  --data-root data/processed_data/interaction_dynamics_v1/data/grab \
  --output-dir data/processed_data/interaction_dynamics_v1
```

运行测试：

```bash
conda run -n graspenv pytest -q \
  tests/test_interaction_dynamics_dataset.py \
  tests/test_interaction_dynamics_frames.py \
  tests/test_interaction_dynamics_model.py \
  tests/test_interaction_dynamics_no_leakage.py \
  tests/test_interaction_dynamics_runner.py
```

运行 overfit：

```bash
python -m src.task.InteractionDynamics.train \
  --config src/task/InteractionDynamics/configs/grab_v1_overfit.yaml \
  --device cuda
```

运行 10 序列小规模实验：

```bash
python -m src.task.InteractionDynamics.train \
  --config src/task/InteractionDynamics/configs/grab_v1_small10.yaml \
  --device cuda
```

运行 20 序列 12/4/4 实验：

```bash
python -m src.task.InteractionDynamics.train \
  --config src/task/InteractionDynamics/configs/grab_v1_small20.yaml \
  --device cuda
```

运行 token intervention：

```bash
python -m src.task.InteractionDynamics.intervention \
  --checkpoint outputs/interactiondynamics/<run>/checkpoints/best.pt \
  --config src/task/InteractionDynamics/configs/grab_v1_small20.yaml \
  --split test \
  --device cuda
```

诊断 patch target 的局部信号：

```bash
python -m src.task.InteractionDynamics.target_diagnostics \
  --checkpoint outputs/interactiondynamics/<run>/checkpoints/best.pt \
  --config src/task/InteractionDynamics/configs/grab_v1_small20.yaml \
  --split val --device cuda
```

导出测试集诊断结果：

```bash
python -m src.task.InteractionDynamics.extract \
  --checkpoint outputs/interactiondynamics/<run>/checkpoints/best.pt \
  --split test \
  --output-root output/InteractionDynamics/grab_v1/extraction/test \
  --device cuda
```

输出按 `seq_id/side/raw_frame_id.npz` 组织。每个文件保存 V1 规定的 patch centers、action/interaction tokens、object-effect 预测和真值，以及 action-to-world、object-to-action、effect-to-interaction attention。

## 8. 当前状态与下一步

已完成：数据 cache、manifest、均匀时间采样、Uni3D-S、完整模型、Runner、训练入口、表征与注意力导出、token intervention、单序列 overfit、small10 和 small20 sequence-disjoint 实验。

下一步顺序：

2. 只有存在 local residual、contact 或其他能区分 human mechanism 的目标时，才恢复 object-patch token 并对其做 shuffle 验收；
3. 只有 small20 验收改善后才扩大到完整 GRAB；
4. 实现 `inverse_mano.py`；
5. 满足表征与 self-inverse 验收后再进入 Robot FK。
