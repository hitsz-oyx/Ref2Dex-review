下面这版可以直接作为 **Bimanual Point-Flow WAM V1 实现方案** 给 Codex。目标不是继续做消融，而是尽快得到一个能训练、能 overfit、能从 desired object flow 生成双手 MANO action 的模型。

# 1. V1 目标定义

固定时间跨度：

[
\boxed{\Delta t=1/30s=33.3ms}
]

当前状态：

[
S_t=
\left(
P_t^{obj},
\Delta P_{t-1}^{obj},
H_t^L,
H_t^R
\right)
]

目标 object effect：

[
\Phi_t^{obj,*}
==============

P_{t+1}^{obj}-P_t^{obj}
]

双手 action：

[
A_t=
(A_t^L,A_t^R)
]

最终学习：

[
\boxed{
p_\theta
\left(
A_t^L,A_t^R
\mid
P_t^{obj},
\Delta P_{t-1}^{obj},
H_t^L,H_t^R,
\Phi_t^{obj,*}
\right)
}
]

使用 Flow Matching 生成。

生成 MANO action 后：

[
A_t^L,A_t^R
\xrightarrow{\text{MANO}}
\Phi_t^{hand,L},\Phi_t^{hand,R}
]

所以最终物理表示仍然是：

[
\boxed{
\Phi^{obj}
\leftrightarrow
(\Phi^{hand,L},\Phi^{hand,R})
}
]

# 5. MANO action target

每只手定义：

[
A^s_t=
[
\Delta x_t^s,
\Delta r_t^s,
\Delta q_t^s
]
\in\mathbb R^{30},
\qquad
s\in{L,R}
]

### translation

[
\Delta x
========

x_{t+1}-x_t
]

3D。

### global orientation

原始 GRAB：

[
r_t,r_{t+1}
]

先转 rotation matrix：

[
R_t,\quad R_{t+1}
]

relative rotation：

[
R_\Delta=R_t^\top R_{t+1}
]

再：

[
\Delta r=\log(R_\Delta)
]

得到 3D axis-angle。

不要直接：

[
r_{t+1}-r_t
]

### MANO PCA pose

[
\Delta q=q_{t+1}-q_t
]

24D。

所以：

[
3+3+24=30D/hand
]

双手：

[
60D.
]

# 10. noisy MANO action 怎么参与 WAM

Flow Matching 某个时刻：

[
A_\tau^L,\quad A_\tau^R
]

它们不是只做一个 global MLP 后塞进去。

更好的做法是：

[
A_\tau
\xrightarrow{\text{current MANO state}}
H_\tau
]

得到 noisy candidate future hand。

然后：

[
\Phi_{\tau}^{hand}
==================

H_{\tau}-H_t.
]

于是 PTv3 输入实际上包含：

```text
current left/right MANO geometry
+
noisy candidate hand point flow
+
desired object point flow
```

这就真正形成：

[
\boxed{
\tilde\Phi^{hand}_\tau
\leftrightarrow
\Phi^{obj,*}
}
]

的 3D interaction。

# 11. 这里 MANO 的 noisy action 应该解释成 relative action

current MANO 参数：

[
\theta_t
]

Flow Matching noisy relative action：

[
A_\tau
]

构造 candidate future：

### translation

[
x_\tau=x_t+\Delta x_\tau
]

### orientation

[
R_\tau=R_t\exp(\Delta r_\tau)
]

### PCA pose

[
q_\tau=q_t+\Delta q_\tau.
]

然后：

[
MANO(x_\tau,R_\tau,q_\tau,\beta)
]

得到未来手 surface。

这一条必须 differentiable。

# 12. WAM PTv3 输入

最终：

```text
OBJECT TOKENS
[P_t, normal,
 prev_obj_flow,
 desired_obj_flow,
 dist_left,
 dist_right]

LEFT TOKENS
[H_t^L, normal,
 noisy_left_hand_flow]

RIGHT TOKENS
[H_t^R, normal,
 noisy_right_hand_flow]

           ↓
      shared PTv3
           ↓
 object / left / right features
```

每个 token 还加：

```text
object_type_embedding
left_type_embedding
right_type_embedding
```

Flow Matching time：

[
\tau
]

经过：

```python
tau_embed = TemporalEmbedding / sinusoidal MLP
```

然后加到所有 tokens。

注意这里的 (\tau) 是 **生成模型 noise time**，不是物理时间。

物理 (\Delta t) 当前固定，不需要 embedding。

# 13. Action readout

PTv3 后：

[
z_L=\operatorname{pool}(F^L)
]

[
z_R=\operatorname{pool}(F^R)
]

object 可以：

[
z_O=\operatorname{pool}(F^{obj})
]

然后：

[
z=[z_O,z_L,z_R,E(A_\tau),E(\tau)]
]

分别预测：

[
\hat v_A^L\in\mathbb R^{30}
]

[
\hat v_A^R\in\mathbb R^{30}.
]

推荐两个独立 head：

```python
left_action_head
right_action_head
```

不要一个 `Linear(..., 60)` 全混在一起。

共享 backbone，但左右 action readout 分开。

# 14. Flow Matching

先统计每个 action dimension：

[
\mu_A,\sigma_A
]

左右手可以共享统计，也可以分别统计；第一版建议左右分别统计。

normalize：

[
\bar A=
\frac{A-\mu}{\sigma+\epsilon}.
]

采样：

[
A_0\sim\mathcal N(0,I)
]

[
\tau\sim U(0,1)
]

[
A_\tau
======

(1-\tau)A_0+\tau A_1
]

target：

[
v^*=A_1-A_0.
]

Loss：

[
\boxed{
L_{FM}
======

L_L+L_R
}
]

其中：

[
L_L=
|\hat v_L-v_L^*|^2
]

[
L_R=
|\hat v_R-v_R^*|^2.
]

第一版不要再加 effect loss。

# 15. 推理

输入：

[
P_t,\Delta P_{t-1},H_t^L,H_t^R,\Phi^{obj,*}
]

初始化：

[
A_0^L,A_0^R\sim\mathcal N(0,I)
]

然后 Euler / midpoint 积分，例如 10 步：

[
A_{\tau+\Delta\tau}
===================

A_\tau
+
\Delta\tau,
v_\theta(A_\tau,\tau,\cdots)
]

最后得到：

[
A_1^L,A_1^R.
]

反归一化，构造未来 MANO。

第一版用：

```yaml
fm_inference_steps: 10
```

即可。

# 19. 实现顺序

我会让 Codex严格按这一轮做，不扩需求：

1. `dataset_wam.py`：双手、1538+1538、prev object flow、desired object flow、MANO 30D×2。
2. `mano_action.py`：relative translation / SO(3) relative rotation / PCA delta，并提供 differentiable compose → MANO points。
3. `pointworld_bimanual_forward.py`：双手 forward，1024+1538+1538，加入 previous object flow。
4. `wam_v1.py`：desired object point flow + noisy MANO → noisy hand point flow → shared PTv3 → 双 action heads。
5. `train_wam_v1.py`：Flow Matching，只用 (L_{FM})。
6. 先 128/256 transition overfit。
7. 看 hand reconstruction 是否能明显收敛。
8. 能收敛就直接放开 full interaction dataset。
9. 再考虑 forward effect consistency。
10. 最后才升级成 unified forward/inverse WAM。
