# PointWorldWAM 项目说明

## 任务目标

验证 PointWorld 的预训练 3D interaction backbone 能否迁移到 GRAB 的单 MANO 手、
单刚体 forward dynamics。V0 先做 `hand point tracks -> object point tracks`；只有
forward overfit 与 action sensitivity 均通过后才进入 inverse MANO generator。

设计原文见 [`指导/V0.md`](指导/V0.md) 和 [`指导/V0.1.md`](指导/V0.1.md)，运行入口见
[`../README.md`](../README.md)。

## 数据

本地 `data/processed_data/stage2/grab_initonly_4096/` 当前没有有效 sequence，实验读取由
同一 GRAB raw/Stage2 geometry 构建的
`data/processed_data/interaction_dynamics_v1/data/grab/<subject>/<sequence>/` cache：

- `shared.npz`：`obj_points_world/obj_normals_world [T,4096,3]`、稳定 `obj_point_id`；
- `<side>.npz`：`hand_points_world/hand_normals_world [T,1538,3]`、稳定 `hand_point_id`；
- 单位和坐标系分别为 meter、world。

每个窗口固定 11 帧，使用固定线性点 ID 子集得到 1024 object points 和 256 hand
points。整个窗口只减首帧 object centroid，不消除刚体 translation/rotation。overfit
阶段按 endpoint motion 选择两个高运动 sequence 的 64 个窗口，避免静态解主导。

## 模型与 loss

- 上游 PointWorld 固定在 commit `05484826dfef74cbe278a3974179a5a16705d35d`；
- 使用 released small-droid checkpoint；
- partial-load 448 个 PTv3 backbone 参数张量及 dynamics head/FiLM，共 464 个张量；
- object feature：首帧 normal + 11 帧 dist-to-hand；
- hand feature：normal + velocity + acceleration，再加 time/type embedding；
- 按官方 DROID per-timestep mean/variance 将 predictor 输出反归一化为 meter displacement，
  再恢复 11 帧 absolute object tracks；
- loss 为 motion-weighted Huber。

V0.1 geometry 版本在保持数据、loss 和 optimizer 不变的前提下，将 object/hand xyz 同时
作为 adapter feature，使用 5 mm grid、关闭 DropPath/serialization shuffle，并通过
task-local non-flash attention 为 22 个 PTv3 block 打开 RPE。上游 submodule 不修改；
原有 448 个 backbone 参数全部加载，随机初始化 22 个新增 RPE table。

checkpoint 用全部 64 个 overfit 窗口上的 GT-hand ADE 选择；同时保存 `last.pt`。这避免
按随机单 batch loss 选择造成错误结论。训练入口支持 `--resume`，用于把尚未平台化的长训
实验从 task checkpoint 继续到更高总 step。

## 主要入口

- `dataset.py`：GRAB 11 帧固定对应窗口；
- `pointworld_forward.py`：几何 adapter、官方 `DynamicsPredictor` 与 partial load；
- `ptv3_dex.py`：保持 PointWorld architecture/key 的 task-local RPE attention/builder；
- `train.py`：overfit、ADE/FDE/translation/rotation 指标与 action sensitivity；
- `visualize.py`：frame 0/5/10 的 hand、GT object、pred object 对比；
- `research/data_sanity/diag_grab_window.py`：E1 数据 sanity；
- `research/forward_smoke/diag_forward.py`：E0-E3 统一复算。
- `research/long_overfit/run_matrix.py`：pretrained/scratch × 单/双 sequence 四卡矩阵；
- `research/long_overfit/diag_matrix.py`：best checkpoint 指标与收敛曲线；
- `research/long_overfit/diag_heldout.py`：冻结 F0 的未训练 sequence action sensitivity。
- `research/geometry_v1/diag_geometry_v1.py`：V0/V0.1 best、条件矩阵与刚体投影复算。

## 已确认实验结论

E0/E1 通过：官方 DynamicsPredictor 可独立接入，输出 shape 正确且 finite；真实窗口为
object `[11,1024,3]`、hand `[11,256,3]`，稳定 ID 唯一，法向均值为 1。

长训矩阵中，pretrained 双 sequence 在 5000 step 平台化，best（step 4750）GT-hand
ADE/FDE 为 `16.23/28.60 mm`，分别比 static/shuffled ADE 低 `88.35%/89.32%`；单
sequence 在 3000 step 平台化，best（step 2750）为 `13.48/23.50 mm`。对应 scratch
在 7000/5000 step 仅达到 `30.83/24.84 mm` ADE，说明 PointWorld 预训练显著改善点轨迹
拟合。但 pretrained 双/单 sequence rotation error 仍为 `26.58°/21.14°`。

冻结双 sequence best 后，在未训练的 `apple_lift/hammer_use_3` 上，GT-hand ADE 为
`58.37 mm`，仍比 static/shuffled 低 `62.31%/68.48%`；但 rotation error 恶化到
`64.27°`，且差于 static 的 `49.29°`。因此 held-out action sensitivity 没有完全
collapse，但刚体旋转泛化失败。

V0.1 geometry-enhanced 在同一双 sequence/64 windows 上训练 5000 step，best 仍在
step 4750。统一复算得到 ADE/FDE/translation/rotation 为
`14.76/25.80/22.40 mm/19.97°`；相对 V0 指导中的 `16.23/28.60/24.34 mm/26.58°`
均有改善，但 ADE 仍高于 10 mm，更未达到 5 mm gate。GT ADE 比 static/shuffled 低
`89.53%/90.11%`，说明 action sensitivity 保持。预测的非刚体残差为 `4.88 mm`；刚体
投影后 ADE 仅降到 `14.00 mm`，主要误差仍是整体 SE(3) 姿态而非点云形变。

## 当前状态与下一步

保留 F0/V0.1 适配和诊断代码，但 geometry 修改没有通过严格 overfit gate，held-out rotation
也尚未解决。因此停止在 forward，不实现 inverse branch。接口核查确认 T=11 输入、T-1 输出加
零首帧、DROID per-timestep 反归一化以及 `object_t0 + displacement` 的时间/shape 路径一致；
下一步应优先诊断 DROID output stats 的 domain mismatch 和 point-wise head 的 rigid SE(3)
表达，而不是继续增加步数。
