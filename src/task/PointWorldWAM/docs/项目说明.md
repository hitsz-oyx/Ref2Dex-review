# PointWorldWAM 项目说明

## 任务目标

验证 PointWorld 的预训练 3D interaction backbone 能否迁移到 GRAB 的双手 MANO 与刚体
world/action 联合建模。V0–V0.2 验证 forward，V1 验证单步 inverse，V1.1 验证 10 帧
unified chunk WAM，V1.2 用 deterministic regression 分离架构容量与 FM 难度。

设计原文见 [`指导/V0.md`](指导/V0.md)、[`指导/V0.1.md`](指导/V0.1.md) 和
[`指导/V0.2.md`](指导/V0.2.md)，运行入口见 [`../README.md`](../README.md)。
双手 inverse 与 chunk joint 设计见 [`指导/V1.md`](指导/V1.md)、
[`指导/V1.1.md`](指导/V1.1.md) 和 [`指导/V1.2.md`](指导/V1.2.md)。

## 数据

本地 `data/processed_data/stage2/grab_initonly_4096/` 当前没有有效 sequence，实验读取由
同一 GRAB raw/Stage2 geometry 构建的
`data/processed_data/interaction_dynamics_v1/data/grab/<subject>/<sequence>/` cache：

- `shared.npz`：`obj_points_world/obj_normals_world [T,4096,3]`、稳定 `obj_point_id`；
- `<side>.npz`：`hand_points_world/hand_normals_world [T,1538,3]`、稳定 `hand_point_id`；
- 单位和坐标系分别为 meter、world。

每个窗口固定 11 帧，使用固定线性点 ID 子集得到 1024 object points 和 256 hand
points。整个窗口只减首帧 object centroid，不消除刚体 translation/rotation。overfit
阶段按 endpoint motion 选择两个高运动 sequence 的 64 个窗口，避免静态解主导。

## 模型与 loss

- 上游 PointWorld 固定在 commit `05484826dfef74cbe278a3974179a5a16705d35d`；
- 使用 released small-droid checkpoint；
- partial-load 448 个 PTv3 backbone 参数张量及 dynamics head/FiLM，共 464 个张量；
- object feature：首帧 normal + 11 帧 dist-to-hand；
- hand feature：normal + velocity + acceleration，再加 time/type embedding；
- 按官方 DROID per-timestep mean/variance 将 predictor 输出反归一化为 meter displacement，
  再恢复 11 帧 absolute object tracks；
- loss 为 motion-weighted Huber。

V0.1 geometry 版本在保持数据、loss 和 optimizer 不变的前提下，将 object/hand xyz 同时
作为 adapter feature，使用 5 mm grid、关闭 DropPath/serialization shuffle，并通过
task-local non-flash attention 为 22 个 PTv3 block 打开 RPE。上游 submodule 不修改；
原有 448 个 backbone 参数全部加载，随机初始化 22 个新增 RPE table。

V0.2A 将 temporal formulation 改为局部 transition：输入当前 object/hand geometry 与
right-hand point flow，直接预测 metric object point flow。新 3D head 不加载旧
`dynamics_head/log_var_head`，不使用 DROID output statistics；head/new/backbone 学习率分别为
`3e-4/1e-4/1e-5`。数据只保留相邻两帧都 right-active 且 left-inactive 的 transition。

V1 使用完整双手相邻 transition，状态为当前 object、previous object flow 和左右 MANO，
condition 为 desired object flow。relative MANO action 为每手 30D（translation 3 + SO(3)
relative rotation log 3 + PCA pose delta 24）；Flow Matching 的 noisy action 经 subject-specific
MANO 可微还原为 noisy candidate hand point flow，再与 1024 object + 1538×2 hand tokens 共同
进入一个 PTv3。左右 action 使用独立 readout head。

V1.1 把 target 扩为 10 帧 object flow chunk 与左右 MANO action chunk。每个 future step 的
noisy world/action 经反归一化后构造 candidate object/hand coordinate；current xyz、normal、
previous flow、canonical hand xyz、finger/region identity 保留在 feature。10 个 timestep 共享
同一 PTv3，并行展平为 `B×K` spatial batch；每组 8 个 learned queries 压缩成 240 tokens，
再由 4-layer bidirectional World-Action Transformer 联合输出逐点 world velocity 和双手 30D
action velocity。forward/inverse/joint 只改变 world/action noise time，不使用独立 branch。

V1.2 将 world statistics 改为 `[K,1,3]`、左右 action statistics 改为 `[K,30]`；world
candidate coordinate 使用 `P_t + tau_world * noisy_flow`，但完整 noisy flow 仍保留在 feature。
world head 补回 adapter skip；左右各用一个 learned readout query cross-attend 同时刻全部 24 个
world/left/right temporal tokens，不再对 8 个 side queries 求均值。deterministic inverse 使用
clean world + zero metric action，deterministic forward 使用 clean action + zero metric world。

checkpoint 用全部 64 个 overfit 窗口上的 GT-hand ADE 选择；同时保存 `last.pt`。这避免
按随机单 batch loss 选择造成错误结论。训练入口支持 `--resume`，用于把尚未平台化的长训
实验从 task checkpoint 继续到更高总 step。

V1.1 checkpoint 改用固定噪声下 inverse/forward 实际生成 error 相对各自零变化 baseline 的
比值和选择；FM loss 不参与选 best。

## 已确认实验结论

E0/E1 通过：官方 DynamicsPredictor 可独立接入，输出 shape 正确且 finite；真实窗口为
object `[11,1024,3]`、hand `[11,256,3]`，稳定 ID 唯一，法向均值为 1。

长训矩阵中，pretrained 双 sequence 在 5000 step 平台化，best（step 4750）GT-hand
ADE/FDE 为 `16.23/28.60 mm`，分别比 static/shuffled ADE 低 `88.35%/89.32%`；单
sequence 在 3000 step 平台化，best（step 2750）为 `13.48/23.50 mm`。对应 scratch
在 7000/5000 step 仅达到 `30.83/24.84 mm` ADE，说明 PointWorld 预训练显著改善点轨迹
拟合。但 pretrained 双/单 sequence rotation error 仍为 `26.58°/21.14°`。

冻结双 sequence best 后，在未训练的 `apple_lift/hammer_use_3` 上，GT-hand ADE 为
`58.37 mm`，仍比 static/shuffled 低 `62.31%/68.48%`；但 rotation error 恶化到
`64.27°`，且差于 static 的 `49.29°`。因此 held-out action sensitivity 没有完全
collapse，但刚体旋转泛化失败。

V0.1 geometry-enhanced 在同一双 sequence/64 windows 上训练 5000 step，best 仍在
step 4750。统一复算得到 ADE/FDE/translation/rotation 为
`14.76/25.80/22.40 mm/19.97°`；相对 V0 指导中的 `16.23/28.60/24.34 mm/26.58°`
均有改善，但 ADE 仍高于 10 mm，更未达到 5 mm gate。GT ADE 比 static/shuffled 低
`89.53%/90.11%`，说明 action sensitivity 保持。预测的非刚体残差为 `4.88 mm`；刚体
投影后 ADE 仅降到 `14.00 mm`，主要误差仍是整体 SE(3) 姿态而非点云形变。

V0.2A 在相同两个 sequence 的 64 个严格 right-driven transition 上训练至 10000 step，best
在 step 9500。GT-action one-step point/translation/rotation error 为
`5.12/4.27 mm/3.28°`；static action、shuffled action 和 zero-flow point error 分别为
`24.34/19.22/37.86 mm`，证明局部 hand flow 因果信号明确。GT target 刚体残差仅
`4.6e-8 m`，预测非刚体残差 `2.27 mm`；刚体投影后 point error 仍有 `4.54 mm`。

V1 数据链在全部 128 条 debug transition 上，用 zero/GT relative action 分别重建
current/next MANO 1538 face centers；逐样本平均误差均值约 `0.000056–0.000058 mm`，最差
`0.000340 mm`，确认 raw frame、v_template、SO(3)、PCA pose 和 translation 对齐。128 个
debug transition 均匀覆盖 20 sequences；完整合法集合为 6652 transitions。

双手 forward 训练 5000 step 后，GT/static/shuffled effect error 为
`10.09/10.17/10.20 mm`，差于 zero-flow `6.53 mm`，因此 effect evaluator 未通过可信度 gate。
WAM-V1 训练 10000 step，fixed-noise FM loss 从 `3.94` 降至 `1.77`，但 10-step Euler
左/右 hand surface error 为 `6.61/8.68 mm`，仍差于 identity 的 `5.40/7.98 mm`；仅优于
random prior 的 `10.97/13.70 mm`。

V1.1 在宽松 interaction 筛选下得到 6868 个合法 10-frame windows，并均匀抽取 128 个 debug
windows。完整 debug set 的 GT action → MANO surface 重建误差均值为左右
`0.000061/0.000062 mm`；最差单点 `0.00399 mm`。首次 joint backward 的 raw
`L_W/L_A/L_surface=1.256/1.980/0.100`，梯度范数为 `8.86/1.29/0.091`，据此采用
`surface_weight=10`。

128 windows 训练 3000 step，按 8 个固定 eval windows 的实际生成复合指标在 step 2500
选 best。最终在完整 128 windows、20-step Euler 上，inverse hand surface 为 `71.13 mm`，
差于 identity `44.57 mm`；forward object flow 为 `47.96 mm`，差于 zero-flow `40.60 mm`，
但优于 zero-action condition `62.44 mm`，证明 forward 已使用 clean action。joint sampling
全程 finite。两个主 gate 未通过。

V1.2 normalization sanity 显示 world 平均位移从 k1/k5/k10 的
`8.32/38.40/69.44 mm` 随 horizon 增长，但 normalized RMS 均为 `1.000`；左右 action 的
normalized RMS 均约 `0.996`。两个独立 regression 中 forward 训练 3000 step，inverse 继续到
6000 step；完整 128 windows 上 inverse hand surface 为 `23.03 mm`，优于 identity `44.57 mm`，
forward object flow 为 `15.78 mm`，并显著优于 zero-flow/zero-action 的 `40.60/41.80 mm`。
两个 deterministic gate 均通过，全部输出 finite。

随后 inverse-only/forward-only FM 均训练 6000 step。完整 128 windows 上 forward 为
`22.39 mm`，优于 zero-flow `40.60 mm`，且 zero-action 退化到 `48.37 mm`，通过门禁；inverse
为 `47.11 mm`，仍差于 identity `44.57 mm`，未通过。8-window 在线指标曾显示 inverse
`61.48 < 68.49 mm`，说明小评估子集会产生错误乐观结论，最终决策以完整 128 windows 为准。

## 当前状态与下一步

保留 V0–V1.2 实现和诊断。V1.2 的 deterministic inverse/forward 都证明当前架构具备 debug
capacity，且 forward-only FM 已打通；inverse-only FM 在 6000 step 后仍未超过完整 debug set
的 identity baseline。按指导不恢复 joint FM，也不放开 6868-window 全量训练。下一步应只诊断
inverse FM 的 noise-to-action 学习与采样误差，不再修改已通过的 deterministic/forward 路径。
