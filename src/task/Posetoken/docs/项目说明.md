# Posetoken 项目说明

## 1. 目标

从单帧 root-frame 手表面学习静态姿态表示：64 个 `384D` local PoseTokens 保存局部表面构型，单个 `128D` global PoseToken 保存整手构型。root SE(3)、动态、物体和接触均不属于本任务。

设计入口：[`指导/V1.md`](指导/V1.md)。实验记录：[`../research/log.md`](../research/log.md)。

## 2. 当前数据

V1 采用 synthetic MANO，而非 GRAB：只生成右手，`use_pca=True, num_pca_comps=24, flat_hand_mean=True`，固定 `beta=0`、global orientation 为零、translation 为零，并减去 wrist joint。姿态由有界 local/wide/sparse PCA mixture 采样；train/val/test 使用不同随机种子，因此测试的是未见 synthetic pose，不涉及 subject morphology 泛化。

MANO mesh 的 1538 个 face centers 作为稳定 surface correspondence。64×32 patch atlas 只在零姿态 canonical surface 上计算一次，并由所有姿态复用。

## 3. 模型与监督

每个 patch point 输入 `[x, x-c, u, u-ū]` 共 12 维，经 Point MLP 和 max pool 得到 local token；额外的 learnable patch atlas embedding 显式保存固定表面区域身份。learnable global query 对 64 个 local tokens 做 attention，再压缩为 `128D` global token。

- local decoder：每个 local token 重建对应 32 点相对 canonical surface 的 deformation；
- global decoder：只从 global token 重建完整 1538 点 deformation；
- 两项 loss 均为厘米尺度 MSE，权重均为 1；
- zero baseline 等价于直接输出 canonical hand。

## 4. 已确认结果

32-pose controlled overfit 使用 4000 steps、lr `1e-3`。dense RMSE 为 `0.1062 cm`，zero 为 `0.8402 cm`，改善 `87.2%`；global RMSE 为 `0.0248 cm`，zero 为 `1.2345 cm`，改善 `98.0%`；local reconstruction EPE 为 `1.288 mm`。没有 atlas embedding 时，相同预算 dense 只能改善 `77.0%`。

small synthetic 实验使用 1024/256/256 个独立 train/val/test poses，100 epochs / 1600 steps。最佳 checkpoint 的 test dense RMSE 为 `0.2204 cm`，zero 为 `0.9435 cm`，改善 `76.6%`；global RMSE 为 `0.4846 cm`，zero 为 `1.4152 cm`，改善 `65.8%`；local EPE 为 `2.381 mm`。global feature variance/cosine 为 `0.739/0.062`，未发生 collapse。

test global token 的二维 PCA 与第一个 MANO pose 分量呈连续、有序变化，可视化位于 `output/Posetoken/research/global_pose_pca.png`；这只作为 latent 连续性的诊断，不作为训练监督。

结论：V1 的 root-invariant static PoseToken 在固定 morphology 的未见姿态上同时优于 local/global zero baseline。它尚未证明 morphology invariance、左右手共享或真实动作 OOD 泛化。

## 5. 运行方式

```bash
conda run -n graspenv python -m src.task.Posetoken.train \
  --config src/task/Posetoken/configs/mano_v1_overfit.yaml --device cuda

conda run -n graspenv python -m src.task.Posetoken.train \
  --config src/task/Posetoken/configs/mano_v1_small.yaml --device cuda
```

导出不含 decoder 的 encoder 权重或 PCA latent：

```bash
python -m src.task.Posetoken.export_encoder --checkpoint <best.pt> --output <encoder.pt>
python -m src.task.Posetoken.visualize_latent --checkpoint <best.pt> \
  --config src/task/Posetoken/configs/mano_v1_small.yaml --split test
```

## 6. 下一步

V2 已加入随机 MANO beta：输入 `MANO(theta,beta)`，监督同一 theta 的 `MANO(theta,0)`。训练由 V1 small checkpoint 初始化，不增加 consistency loss；val/test 每个 theta 生成两个 beta，用同姿态 token RMSE / 不同姿态 token RMSE 衡量 morphology ratio。

V2 small test dense/global RMSE 为 `0.1741/0.4840 cm`，相对 canonical zero 改善 `82.0%/66.6%`，EPE 为 `2.109 mm`。输入 surface morphology ratio 为 `20.5%`；V2 global/local token ratio 为 `13.3%/17.2%`。相对未微调 V1，EPE 从 `3.402` 降到 `2.109 mm`，global ratio 从 `16.5%` 降到 `13.3%`；local ratio 从 `16.5%` 小幅升到 `17.2%`。因此规范形态重建和 global morphology invariance 改善成立，local invariance 尚未改善。

下一步优先用 GRAB/ARCTIC 做真实姿态 OOD 验证，并单独调查 local token 中残留的 morphology；不要把当前 synthetic 结果直接等同于真实 subject invariance。修改本任务前应先阅读根级 [`docs/项目总览.md`](../../../../docs/项目总览.md) 和本文件。

V2 训练命令：

```bash
python -m src.task.Posetoken.train \
  --config src/task/Posetoken/configs/mano_v2_morph_small.yaml \
  --set model.pretrained_checkpoint=<V1-best.pt> --device cuda
```
