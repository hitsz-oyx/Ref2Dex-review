# Hand context pilot（2026-07-15）

## 目的

检验两个逐步假设是否改善 object-hand correspondence：

```text
A  原始 cross-edge 任务
B  A + object-conditioned dense hand heatmap BCE
C  B + HandGlobalEncoder(H) 的 32-D early-fusion context
```

主指标固定为未参与梯度的 `val_clean/cross_edge_random_qfl`；不使用总 loss 或
contact-aux 指标选择模型。

## 受控设置

- 数据：`grab_subset100_initonly_4096_ds4_smoke12`，hand-root Stage 3
- 按 sequence group 划分：4,418 train frame / 517 validation frame，5/1 group
- seed 42，batch size 8，BF16，AdamW，lr `1e-4`，同一 object perturbation
- A/B/C 分别使用 `baseline.yaml`、`hand_heatmap.yaml`、`hand_context.yaml`
- 每个 run 的 config、metadata、JSONL 和 checkpoint 位于
  `outputs/train/correspondence_ptv3_v2_ablation_*_20260715/`

## 结果

| Run | Steps | val random-edge QFL ↓ | val random-edge BCE ↓ | val hand BCE ↓ |
| --- | ---: | ---: | ---: | ---: |
| A | 600 | 0.002116 | 0.106236 | — |
| B | 600 | 0.001974 | 0.101137 | 0.259159 |
| C | 600 | 0.002838 | 0.118085 | 0.272822 |
| B | 1200 | **0.001399** | **0.064734** | 0.254380 |
| C | 1200 | 0.001933 | 0.082743 | **0.234253** |

600-step 下，B 相对 A 将主 QFL 降低约 6.7%。1200-step 下，C 的 hand heatmap BCE
比 B 低约 7.9%，但 random-edge QFL 高约 38.2%。

## 结论

1. 当前权重 `loss_hand_contact_weight=0.005` 的 object-conditioned heatmap 是有效的辅助任务。
2. 当前“直接 broadcast 32-D global context 到每个 hand token”的 C 实现尚未改善 correspondence；
   在此 pilot 上应拒绝该正向假设。
3. 这不是最终统计结论：C 改变了 PTv3 第一层输入宽度，单 seed 的 B/C 比较仍存在初始化与小数据
   划分方差。下一步应使用多个 sequence split/seed，并优先测试 gated/zero-init context fusion，
   再判断 hand global context 的价值。
