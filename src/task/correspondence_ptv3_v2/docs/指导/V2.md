# V2：GRAB 与 HRDexDB 的 5 cm 手点混合训练

## 目标

从头训练一版以 object 为坐标系中心的 GRAB + HRDexDB 混合模型。HRDexDB 使用 human、Inspire DFTP、Inspire F1、Allegro V5 四个域。

## 数据与采样

- 每帧从完整 4096 点物体池中运行时均匀随机采样 1024 点，不使用接触位置偏采样。
- 使用 clean 几何的 `hand_to_obj_min_dist` 做 5 cm 过滤：一帧所有手点最近距离均大于 0.05 m 时丢弃；其余帧保留所有距离不超过 0.05 m 的手点。
- 手点仍使用固定 1538 槽位；无效槽位由 `hand_valid_mask` 标记并从几何特征、对应关系监督和辅助边候选中排除。
- batch 采样比例为 GRAB 50%，HRDexDB 总计 50%，四个 HRDexDB 域各 12.5%。

## 坐标与扰动

- 输入和 GT 均使用 object-centered 坐标系，物体本身不施加扰动。
- 扰动按 4:4:2 分为手腕根扰动、手姿态扰动、clean，三种模式互斥。

## 监督与训练

- 仅保留核心 `cross_edge_random` 对应关系 loss。
- 关闭 `cross_edge_contact_aux` 与稠密 `hand_contact` loss。
- 核心对应关系监督只使用 5 cm 内有效手点。
- 从头训练，GPU 2/3，按 5000 step 保存 checkpoint；当前配置为 50 epoch，batch size 40。

## 入口

- 配置：`configs/mixed_grab_hrdexdb_object_centered_5cm.yaml`
- 计划：`docs/plan/V2.md`
