# correspondence_ptv3_v2 V2 训练计划（final）

## 范围

- 修改 Dataset/Runner/模型的手点有效性契约，增加固定宽度的 `hand_valid_mask`。
- 增加 GRAB + HRDexDB 四域的 object-centered 训练配置：物体 1024 点、5 cm 手点过滤、无 contact loss、4:4:2 互斥扰动。
- 增加带权 domain-balanced sampler，保证 GRAB 50%、HRDexDB 四域各 12.5%。

## 不变量

- 真实数据、已有 cache、checkpoint 和旧配置不覆盖、不移动。
- 旧配置缺少 `hand_valid_mask` 时默认全部手点有效，保持历史训练兼容。
- 过滤阈值基于 clean `hand_to_obj_min_dist`，不受 1024 点 runtime sampling 或扰动影响。
- padding 手点不进入 PTv3 有效点 mask，也不进入任意监督边 loss。

## 验证

- 运行 Python 编译检查和 correspondence 定向测试。
- 构造一个 batch 核对 1024 object points、1538 hand slots、5 cm mask 与 weighted sampler quotas `[20, 5, 5, 5, 5]`。
- 启动前做短 smoke run；确认 loss 输出不含非零 `contact_aux` / `hand_contact`，再开始完整训练。

## 回滚

删除 V2 配置并恢复本次修改的 Dataset/Runner/模型文件即可；不触碰 NAS 数据及旧训练产物。
