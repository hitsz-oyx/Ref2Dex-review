# 一、当前分支实际上改了什么

## 1. 加入了手部 PCA 扰动参数

数据集新增：

```python
apply_hand_perturb
hand_perturb_pca_std
hand_perturb_prob
mano_model_dir
```

并且只允许在 `hand_root` 坐标系下使用。启用时，Stage 3 数据还必须包含：

```text
mano_hand_pose
mano_betas
mano_v_template
mano_is_right
mano_mirror_x
```

否则会直接报错。

实际扰动方式是：

```python
noisy_pose = clean_pose + Normal(
    0,
    hand_perturb_pca_std,
)
```

然后使用 MANO 重新生成手表面点和法向量。

## 2. 监督关系保持正确

当前实现将：

```text
input_hand_points = PCA 扰动后的手
gt_hand_points    = 原始干净手
```

物体也类似：

```text
input_obj_points = SE(3) 扰动后的物体
gt_obj_points    = 原始干净物体
```

因此输入是有误差的手物几何，GT 仍然是干净接触关系。

在 `perturb_object_geometry()` 中，带噪手只替换输入，干净手仍被保留为 GT，这一部分逻辑没有监督泄漏。

这部分设计是正确的。

# 三、GRAB 的 PCA 参数链路是匹配的

GRAB 原始数据中的 `hand_pose` 明确是 24 维 PCA 压缩参数。

原始预处理使用的 MANO 设置也是：

```python
use_pca=True
num_pca_comps=24
flat_hand_mean=True
```

左右手设置一致。

Stage 2 保存了：

```text
mano_hand_pose
mano_betas
mano_v_template
```

其中 `mano_hand_pose` 就是原始 GRAB 的 PCA 系数。

所以对于当前 GRAB 数据：

```python
clean_pose + PCA_noise
```

在参数语义上是成立的，不存在把 45 维 axis-angle 关节角误当成 PCA 系数的问题。

但当前 Stage 2 文件没有显式保存：

```text
mano_pose_representation = "pca"
mano_num_pca_comps = 24
mano_flat_hand_mean = true
```

它只保存了 pose、betas 和 template。

这意味着以后接入 ARCTIC、OakInk 或其他数据集时，代码无法判断 `mano_hand_pose` 究竟是：

* PCA 系数；
* 45 维关节 axis-angle；
* 完整 MANO pose；
* 其他表示。

建议把上述三个元数据字段加入 Stage 2 和 Stage 3，并在数据集初始化时强制验证。

# 四、当前最大的训练问题：所有 PCA 维度使用相同噪声

现在是：

```python
noisy_pose = clean_pose + rng.normal(
    0.0,
    hand_perturb_pca_std,
    size=clean_pose.shape,
)
```

这意味着 24 个 PCA 系数都使用相同的绝对噪声标准差。

问题在于 PCA 各维度在真实数据中的变化范围不同：

```text
第一批主成分：通常承载主要手型变化
后面的主成分：数据方差更小，表达更细微的姿态变化
```

对所有维度加相同的绝对噪声，可能导致：

* 前几个主要维度扰动很小；
* 后几个低方差维度相对扰动过大；
* 生成不自然的局部手指姿态；
* 噪声大小难以解释。

更合理的是先统计训练集每个维度的标准差：

```python
pose_std = train_mano_pose.std(axis=0)
```

然后使用相对噪声：

```python
noise = rng.normal(
    0.0,
    hand_perturb_scale * pose_std,
    size=clean_pose.shape,
)

noisy_pose = clean_pose + noise
```

配置改成：

```yaml
hand_perturb_pca_scale: 0.10
```

而不是：

```yaml
hand_perturb_pca_std: 0.10
```

含义变成：

> 每个 PCA 维度添加相当于其训练集标准差 10% 的噪声。

第一版建议：

```yaml
hand_perturb_pca_scale: 0.10
```

然后测试：

```text
0.05
0.10
0.20
```

还应限制到训练分布范围：

```python
noisy_pose = np.clip(
    noisy_pose,
    pose_percentile_01,
    pose_percentile_99,
)
```

# 七、缺少扰动状态和扰动幅度记录

数据集返回值目前只有：

```text
points
normals
gt_points
gt_normals
mask
edge indices
hand_min_dist
```

没有返回：

```text
object_perturbed
hand_perturbed
hand_pca_noise_norm
hand_point_displacement_mean
hand_point_displacement_p95
object_point_displacement_p95
```

建议至少增加：

```python
"obj_perturbed": torch.tensor(geometry.obj_perturbed),
"hand_perturbed": torch.tensor(noisy_hand_points is not None),
"hand_perturb_pca_l2": torch.tensor(
    np.linalg.norm(noisy_pose - clean_pose)
),
"hand_displacement_p95": torch.tensor(
    np.percentile(
        np.linalg.norm(noisy_hand_points - hand_points, axis=-1),
        95,
    )
),
```

PCA 系数的数值大小不直接等同于几何误差，所以评估时真正有意义的是：

```text
扰动后手表面点相对干净手移动了多少毫米
```

# 九、MANO 重建应关闭自动求导

`ManoPcaHandPerturber` 调用了：

```python
self.right_mano.eval()
self.left_mano.eval()
```

但 `eval()` 只切换训练/评估行为，不会关闭梯度。

当前 `reconstruct()` 中也没有：

```python
with torch.no_grad():
```

它直接执行 LBS，再在最后 `detach()`。

因为 MANO 层参数仍然可能 `requires_grad=True`，这会构造完全不需要的计算图。

建议在初始化中加入：

```python
self.right_mano.requires_grad_(False)
self.left_mano.requires_grad_(False)
```

并在重建时使用：

```python
with torch.no_grad():
    points_t, normals_t = ...
```

这对 DataLoader 多进程训练的内存和速度都有帮助。
