# 三、Rigid inverse 必须真的把整只手移动过去

这个现在尤其糟糕。

Rigid inverse 已经得到了：

[
t,\omega
]

所以完全可以对整个 MANO mesh：

[
V^*
===

R(\omega)(V-c)+c+t
]

直接得到 **optimized hand mesh**。

因此三路应该真正变成：

```text
INITIAL                 OPTIMIZED                  GT

   hand                    hand*                  hand_GT
  /||||\                  /||||\                  /||||\
     ↓                        ↓                       ↓

 object                   object_pred              object_GT
```

而不是现在三列都是同一只手，然后加箭头。

这会让那个：

[
11.0\text{ mm}\rightarrow1.87\text{ mm}
]

的优化结果肉眼真正可见。

# 四、Free Point Flow 不应该放在正式 Viewer 主界面

不要硬把 Free flow 画成“一只优化后的手”。

否则视觉上漂亮了反而容易误导。
