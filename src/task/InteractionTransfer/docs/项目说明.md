# InteractionTransfer 项目说明

## 目标

验证当前 hand-object relation 是否能调制 hand action，形成动态 edge message，并仅通过 object interaction field 预测 one-step object flow。

## V0 执行路径

`dataset.py` 读取 GRAB one-step cache；`model.py` 构建半径约束 KNN edge、静态关系、zero-preserving action message、attention aggregation 和 object-only effect decoder。静态点编码器在 V0 中冻结，避免 action 泄漏到 Current Relation。

```text
(O_t,H_t) -> R_ij;  (R_ij, Δh_j) -> Cm_ij -> C_i^O -> ΔO
```

## 运行与状态

当前先支持直接导入 `InteractionTransfer` 并运行 forward；V0 的最小 sanity 是 shape、有限值和 `ΔH=0 => Cm=0`。训练脚本和真实 cache 配置在完成该 gate 后再扩展。

V0.1 已加入 GT/zero/reverse/shuffle action intervention。默认静态编码器从本地 DenseToken checkpoint 加载；诊断脚本自动优先使用 CUDA，仅在无 CUDA 时使用 synthetic encoder。

V0.2 已将 DenseToken centroid geometry、pretrained edge/contact prior、512/1538 点数及 right-active/left-inactive transition 筛选对齐到 one-step baseline；训练脚本支持自动 CUDA 或 `--device` 指定。

V0.3 修正了 DenseToken centroid-direction·normal 特征的实际实现，并将 transition 的 `source_fps`、`raw_frame_id` 间隔、object motion 排序和固定点索引与 PointWorld one-step baseline 对齐。真实 GRAB 单序列 CUDA 短训 10 步 loss 从 `0.0561577` 降至 `0.0168040`；完整多序列 EPE 对比尚未完成。

V0.4 固化正式 V0 forward 结构：ActionEncoder 与 MessageEncoder 的 action 路径无 bias 以保证 zero-preserving，effect decoder 仅接收 object 输入和聚合后的 object-side interaction field；dataset 内置固定点采样并固定 `gap=1`。

V0.4 已补充自包含 direct baseline 与 GT/zero/reverse/shuffle intervention 比较脚本。单序列 100 步 overfit 中 `EPE_Cm/EPE_direct=0.195`，GT/zero/reverse 已分离；shuffle 与 GT 接近，完整 action 语义判据尚未通过，不能据此宣称 V0 完成。

V0.5 修正并严格验证 DenseToken edge/contact head checkpoint 加载，同时强制 frozen encoder 的 eval 状态；新增 action-field 诊断、DirectEdge 公平 baseline 和 sequence-level benchmark。当前已确认 action local ratio 约 `0.0599`，但多序列 benchmark 受 PTv3/cache 显存限制尚未产出 held-out EPE。

V0.6 将 Cm 与 DirectEdge 拆为独立 subprocess，解决重复 PTv3 导致的 CPU RSS 滞留；worker 已能完成 held-out evaluation。两个未见 sequence 的 Cm/DirectEdge 容量比为 `0.518/0.620`，但 GT 未稳定优于 zero/reverse/cross-sample，因此 V0.5 causal gate 尚未通过。offline DenseToken static cache 已列为下一步。

V0.6.1 修正了 val 单 transition 时 `cross_sample=GT` 的 evaluation bug，并使用 64 train / 16 held-out transitions、1000 steps 重跑。Cm GT/cross/zero/reverse EPE 为 `5.44/22.13/28.16/57.95 mm`，DirectEdge GT 为 `34.53 mm`；主要 causal gate 通过，point-shuffle/mean-flow 仍属于弱干预，offline static cache 尚未实现。

V0.7 增加 rigid-twist 的 translation-only/rotation-only intervention 和 best-validation checkpoint 选择。1000-step 实验中 Cm GT/cross/zero/reverse EPE 为 `9.12/24.40/27.53/59.20 mm`，translation-only `8.57 mm`、rotation-only `27.53 mm`；DirectEdge GT `34.05 mm`。主要 action gate 通过，但局部旋转 interaction 尚未被证明。

## 可视化

`visualize_intermediate.py` 使用 Viser 提供 Intermediate / Inverse Optimization 两种模式。viewer 现在按 Stage4 原始帧顺序读取轨迹（不再按物体运动量筛选），支持序列/帧切换、播放/停止、Reset Rollout，以及从当前帧开始每次追加一步的自回归 object rollout；预测轨迹使用紫色，GT flow 使用绿色。坐标控件默认 World，可切换 Hand Root/Object Centered。Hand Embodiment 控件列出 Allegro、LEAP、Shadow、Barrett 等跨灵巧手选项；InteractionTransfer 专用 comparison cache 尚未生成时会明确提示，不会伪造跨手结果。

启动示例：

```bash
python -m src.task.InteractionTransfer.visualize_intermediate \
  --root data/processed_data/stage4/data/grab \
  --split src/task/InteractionTransfer/splits/grab_seed42/test.txt \
  --checkpoint outputs/InteractionTransfer/v08_full_20ep/best.pt \
  --device cuda:0 --port 8080 --fps 6
```

V0.8 落地 offline DenseToken static cache：`model.py` 拆分 `encode_static`/`forward_core`，`precompute_static.py` 离线缓存全部 1335 序列 175,529 transitions 的静态特征（fp32 memmap，cache 保真度 < 2e-6），`cached_dataset.py` 直接读 cache 训练，`train_full.py` 在与 Cm 一致的 1068/134/133 序列划分上全量 20 epoch 训练。val EPE 从 V0.7 小样本的 ~9 mm 提升到 3.42 mm（epoch 16 best）。

V0.9 新增 `eval_ckpt.py` 和 `visualize_intermediate.py`。正式 test（17,164 transitions，best.pt epoch 16）：GT `3.28 mm`、zero `11.15 mm`、reverse `21.58 mm`、cross-sample `4.35 mm`，Quantitative Gate（GT < zero/reverse/cross）通过；last.pt epoch 17 GT `3.47 mm` 与 best 接近，训练稳定。Viser viewer 支持在 ΔH→M→C_obj→ΔO 链路上实时切换四种 action 并显示 M norm/attention Top-K edges、C_obj norm heatmap、GT/Pred flow 与 sample EPE（`http://localhost:8080`）。

V0.10 将 viewer 升级为 Forward+Inverse 一体化，并新增独立 inverse optimization backend：`inverse_optimize.py` 冻结 forward model、以 hand action 为优化变量（Rigid SE(3) 6 参数 twist 与 Free Point Flow 两种参数化，Effect / C_obj 双 target），`eval_inverse.py` 在 test split 均匀抽样评估。500 test transitions（zero init、target=GT object flow、300 steps）：zero action `11.00 mm`、optimized rigid `1.87 mm`、optimized free `1.74 mm`、GT action forward `3.27 mm`。optimized rigid 优于 GT action forward，说明 learned forward map 中存在比 GT action 更精确产生目标 effect 的解；free 仅比 rigid 低 0.13 mm，可优化空间几乎全部位于 6 维 rigid 子空间。Viewer 增加 Inverse Optimization 模式：Initial/Optimized/GT 三路并排（各自 EPE、C_obj difference heatmap、optimization history）、Optimize/Reset 交互与 point shape/size 控制。
