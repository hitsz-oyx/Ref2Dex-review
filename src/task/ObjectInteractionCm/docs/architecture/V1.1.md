## 1. 科学定义

V1.1 的 Cm 是 object-centric interaction representation：

\[
\text{所有真实可用 hand points 的当前运动证据}
\rightarrow
\text{object-side local interaction}
\rightarrow
C_m\in\mathbb{R}^{16\times32}.
\]

同一组 `C_m` 同时服务两个监督头：

\[
C_m\rightarrow\Delta P_o,
\qquad
(C_m,P_h)\rightarrow\Delta P_h,
\quad P_h=\bigcup P_{hand}.
\]

V1.1 不使用旧 Cm 的 DenseToken、contact prior、hand/finger/source identity、HardConcrete gate、slot pruning、
TopK、fallback slot 或旧 checkpoint 兼容路径。

## 2. 数据合同

### 2.1 样本单位

一个样本固定为 `(source, sequence, current_frame, stride)`，读取该 source/frame 的 shared object 流和所有真实可用
hand 流。GRAB 使用 left/right union；Inspire-F1 使用单一机器人 hand 流。每个 source 的公共 frame timeline、
object pose 和 hand geometry 必须严格对齐，缺失、损坏或长度不一致时显式失败，不改变数据语义。

Dataset 统一输出最多 3076 个 hand points。GRAB 的 3076 个真实点全部有效；Inspire 的 1538 个真实点后面追加
padding，并通过 `hand_valid_mask` 屏蔽。padding 不进入 KNN、attention 或 loss。

```text
GRAB left + right: 3076 valid points
Inspire-F1:        1538 valid points + 1538 padding
union tensor:      3076 points + hand_valid_mask
```

不向网络提供 left/right、source 或 finger ID；所有真实手点只是可影响物体的 surface points。

### 2.2 坐标与时间

所有模型输入和监督最终处于当前帧 `object_pose_t`。现有 cache 的 world-frame 文件通过当前帧
`obj_pose_world` 使用仓库已有转换语义映射到 object frame；不引入新坐标系，不使用 future pose 作为输入。

GRAB 使用随机 stride `1..10`；Inspire-F1 使用偶数 stride `2,4,...,20`。同一 source 内所有 hand 流共用
同一 stride；`delta_time_s` 只作为数据元信息，V1.1 默认不作为模型条件。

### 2.3 当前帧筛选与采样

仅用 current frame 的完整 4096 点 manipulated-object surface pool 计算 available-hand union 最小距离：

\[
d_{\min}=\min_{p_h\in \bigcup P_{hand},\;p_o\in P_o^{4096}}
\|p_h-p_o\|.
\]

`d_min > 0.05 m` 的帧从样本索引中移除；future frame 不参与该筛选。GRAB 使用左右 candidate/activity union，
Inspire-F1 使用 episode 的 object candidate mask。

模型每帧从完整 4096 点池采样 1024 个 object points，输出：

```text
obj_points / obj_normals / obj_flow_gt: [B,1024,3]
hand_{points,normals,flow}:              [B,3076,3]
hand_valid_mask:                         [B,3076]
obj_valid_mask:                          [B,1024]
```

3 cm hand-supervision mask 使用完整 4096 点 object pool 计算：

\[
m_j=\mathbf{1}\left[\min_{i\in P_o^{4096}}\|p_j^h-p_i^o\|<0.03\right]\land v_j.
\]

没有 active 3 cm hand point 的样本保留，hand loss 记为零并记录计数；padding 点永远无效，不另加数据筛选条件。

## 3. Object-side local interaction

对每个采样 object point `p_i^o`，在最多 3076 个 hand points 的 union 中取 `K=8` 个最近有效 hand points。
每条 edge 的 11D 输入为：

\[
x_{ij}=[r_{ij},d_{ij},n_j^h,s_{ij},\Delta p_j^h],
\]

其中 `r_ij = p_j^h-p_i^o`、`d_ij=||r_ij||`、`s_ij=n_i^o·n_j^h`。只使用可在推理时获得的 hand flow，
不使用 GT object flow，避免目标泄漏。

超过 5 cm 的 edge 使用 radius mask；`hand_valid_mask=False` 的 padding edge 也无效。KNN 只负责固定
`[B,1024,8]` 形状；若一个 object point 的 8 条 edge 全部无效，其 interaction feature `h_i` 直接置零。

## 4. Feature encoder、attention 与融合

```text
object intrinsic: [xyz, normal] 6 -> 64 -> 32 = o_i
hand-object edge: 11 -> 64 -> 32 = e_ij
```

object query 对同一 object point 的 8 条 edge 做 single-head dot-product cross-attention：

\[
q_i=W_qo_i,\quad k_{ij}=W_ke_{ij},\quad v_{ij}=W_ve_{ij},
\]

\[
\alpha_{ij}=\operatorname{softmax}_j(q_ik_{ij}^{\mathsf T}/\sqrt{32}),
\qquad h_i=\sum_j\alpha_{ij}v_{ij}.
\]

这是标准 cross-attention；与 additive/Bahdanau scalar attention 都属于 query-key 打分后聚合，但不视为
数学等效实现。

object intrinsic 必须显式保留：

\[
u_i=\operatorname{MLP}([o_i,h_i]),\qquad
U_o\in\mathbb{R}^{B\times1024\times32}.
\]

`z_obj`、`z_hand`、contact、future flow 和 hand identity 不得绕过此 token 进入 decoder。

## 5. Slot Attention 与 object anchor

```text
input:       U_o [B,1024,32]
num_slots:   16
slot_dim:    32
slot_iters:  3
output:      C_m [B,16,32]
assignment:  A   [B,16,1024]
```

所有 slot 均参与，不使用 gate、pruning、TopK、L0、fallback 或 active threshold。assignment 回投到
object surface 得到 object-side anchor：

\[
p_k^{Cm}=\sum_i A_{ki}p_i^o,
\qquad
n_k^{Cm}=\operatorname{Normalize}(\sum_i A_{ki}n_i^o).
\]

## 6. Flow decoders 与 loss

### 6.1 Object flow

object decoder 只读取 object geometry、`C_m` 和 object-side anchor geometry，输出：

```text
pred_obj_flow: [B,1024,3]
```

允许复用旧 Cm decoder 的局部 routing/几何实现思路，但不加载旧 Cm checkpoint。

### 6.2 Shared hand flow

所有 source 共用一个 decoder，输入为 padded available-hand union、`C_m` 和 anchor geometry，输出：

```text
pred_hand_flow: [B,3076,3]
hand_valid_mask: [B,3076]
```

按 `hand_valid_mask` 和 source 分别统计，但不引入 side/source-specific 参数或权重。

### 6.3 总损失

\[
L=L_{obj}+1.0\,L_{hand}^{3cm}.
\]

object loss 对 1024 个 object points 计算；hand loss 只对 current-frame 3 cm mask 与 `hand_valid_mask` 的
有效 hand points 计算，空 mask 时该样本 hand loss 为零。slot sparsity/diversity 只作为诊断指标，不进入 V1.1 loss。

## 7. 实现边界与验证

Task-local 实现位于 `src/task/ObjectInteractionCm/`，包含 source adapter、dataset、model、slot attention、
decoder、runner、train/eval/extract、cache index 工具和配置；定向测试覆盖 source 数据对齐、current-only 5 cm
filter、`[B,1024,8]` edge mask、padding/全无效邻居、16×32 slots/anchors、空 3 cm mask 及前反向 smoke。

GRAB 与 Inspire-F1 在同一 run 按 `0.5/0.5` source probability 混合；验证保留各自现有 split，并分别报告
source 指标，以两 source 等权 object-flow EPE 选择 best checkpoint。V1.1 当前不运行 old Cm/OI-Cm 实验矩阵。
任何正式训练或评估都必须另建运行目录，
生成 `config.json`、`run_manifest.json`、`summary.json` 并登记 activity；工程 smoke 不构成科研效果结论。
