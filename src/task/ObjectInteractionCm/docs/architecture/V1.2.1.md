# ObjectInteractionCm V1.2.1 架构

- 状态：`final`
- `modification_version`：`V1.2.1`
- 指导：[指导/V1.2.1.md](../指导/V1.2.1.md)
- 执行计划：[plan/V1.2.1.md](../plan/V1.2.1.md)
- 研究边界：只改 ObjectInteractionCm 任务内模型、loss、配置和诊断；不改坐标系、GT、split、cache schema 或共享 `src/base`。

## 1. 端到端框架

整个 batch 始终保留为 `B`。完整物体池只用于统计采样漏检；模型实际输入仍是随机采样的 `N=1024` 点。`sample_valid` 只屏蔽一个样本的监督，不压缩 batch。

```text
当前帧（object frame）
  O0 [B,N,3], On [B,N,3], Mo [B,N]
  H0 [B,H,3], Hn [B,H,3], Hf [B,H,3], Mh [B,H]
       │                         │
       │                         └─ mask-before-topk KNN(K=8,r=0.05m)
       │                                      │
       └─ object intrinsic 6→64→D              ├─ Egeo [B,N,K,D]
          Ofeat [B,N,D]                        ├─ Eflow[B,N,K,D]
                 │                             └─ edge_valid[B,N,K]
                 └────────────── LocalInteraction
                                  Igeo/Iflow[B,N,D]
                                  vbar[B,N,3], sbar[B,N,1]
                                           │
                              U = LN(Ofeat + MLP388→D(...)) [B,N,D]
                                           │
                              Mp = Mo ∧ any(edge_valid,K) [B,N]
                              sample_valid = any(Mp,N) [B]
                                           │
                  valid sample: U + Mp ─┐  │  ┌─ invalid sample: zero dummy token
                                         └── Masked SlotAttn(S=16,T=3) ──┘
                                             cm_raw [B,S,D]
                                             Cm = Linear(D→C) [B,S,C]
                                                       │
                         ┌─────────────────────────────┴─────────────────────────────┐
                         │                                                           │
       raw object [O0,On], Cm, object/anchor geometry                  hand geometry, Cm,
       [B,N,6]+[B,S,C]+relative/anchor normal                         relative/anchor normal
                         │                                                           │
               additive object decoder                                      additive hand decoder
               contribution [B,N,S,3]                                      contribution [B,H,S,3]
                         │                                                           │
               pred_obj_flow [B,N,3]                                     pred_hand_flow [B,H,3]
                         └────────────── sample_valid 掩码 loss/metric ──────────────┘
```

空样本的 dummy 仅为 SlotAttn 提供一个有限值输入，不能作为语义 Cm、不能作为 fallback 物体池，也不进入任何 loss、EPE 或结论。其预测可保留在 `[B,...]` 输出中，但由 `sample_valid=0` 完全屏蔽。

## 2. 统一张量合同

| 名称 | 尺寸 | 含义 |
|---|---|---|
| `B` | batch size | 全流程固定，不产生 `B'` |
| `N` | 1024 | 当前帧随机采样的物体点数 |
| `P` | 4096 | 完整物体池，仅用于采样漏检统计 |
| `H` | 3076 | 左右手拼接后的最大手点数，padding 由 `Mh=False` 标记 |
| `K` | 8 | 每个物体点保留的手 KNN 数 |
| `r` | 0.05 m | interaction neighborhood；不承担 feature scale 职责 |
| `D` | 128 | intrinsic、edge、interaction、slot_raw 的延迟压缩主宽度 |
| `S` | 16 | Slot 数 |
| `C` | 32 | SlotAttn 后暴露给两个 decoder 的 Cm 宽度 |

所有 object 张量第 2 维都按 `obj_points` 的采样顺序；所有 hand 张量第 2 维都按左右手拼接顺序。`Mo` 只表达 object 输入有效性，`Mp` 只表达 SlotAttn pool，二者不可混用。

## 3. 数据和 mask

数据层沿用现有 `object_interaction_cm_v1_1/index.json` 及其 sequence cache，不重复导出。每个样本先把 world 坐标变到当前物体 frame：

```text
O0 = world_to_frame(obj_world_t[selected], pose_t)                  [B,N,3]
On = normal_world_to_frame(obj_normal_world_t[selected], pose_t)    [B,N,3]
H0 = world_to_frame(hand_world_t, pose_t)                           [B,H,3]
Hn = normal_world_to_frame(hand_normal_world_t)                     [B,H,3]
Hf = world_to_frame(hand_world_{t+stride}, pose_t) - H0             [B,H,3]
```

有效性定义：

```text
Mo                 [B,N]      当前采样物体点有效性（现有数据中全 true）
Mh                 [B,H]      非 padding hand 点
edge_valid         [B,N,K]    Mh 且距离 <= r
Mp = Mo & any(edge_valid,K)   [B,N]      SlotAttn hard pool
sample_valid=any(Mp,N)        [B]        本次采样至少命中一个交互物体点
```

`sample_valid=0` 不是“真实无 interaction”的新类别：它可能对应完整 4096 池有 active 点、但 1024 采样漏掉。训练和评估分别报告 `true_no_interaction` 与 `sampling_miss`，不能把两者合并成 null-Cm。

## 4. Train-only scale calibration

scale 在训练 split 上离线统计一次，写入小型 `scales_train.json`，并由运行 manifest 引用。验证/测试不能参与统计。GRAB、Inspire-F1 和各自 stride 先分别求均方，再对 source/stride group 等权：

```text
s_hand_flow = sqrt(mean_group(mean(||Hf||²)))
s_geo       = sqrt(mean_group(mean(d_ij²)))
s_obj_flow  = sqrt(mean_group(mean(||O_future-O0||²)))
```

其中 `s_hand_flow` 只统计 `Mh=True` 且完整物体池最近距离 `<=0.05m` 的手点；`s_geo` 只统计 radius 内有效 KNN edge；`s_obj_flow` 统计 object target。若统计量为空则终止校准，不写默认经验值。输入 feature scaling 与 target scaling 分开配置：

```text
relative/s_geo, distance/s_geo, local_flow/s_hand_flow
obj_target/s_obj_flow, hand_target/s_hand_flow
```

5 cm 只定义交互邻域，不再写死为 geometry feature scale。

## 5. Mask-before-top-k KNN 和局部 interaction

距离矩阵先排除 padding，再执行 top-k：

```text
d_ij = ||O0_i-H0_j||₂                         [B,N,H]
d_ij = +∞ where Mh_j=False
idx = topk_smallest(d,K)                       [B,N,K]
edge_valid = Mh[idx] & (d[idx] <= r)           [B,N,K]
```

gather 后：

```text
relative = H0[idx] - O0[...,None,:]            [B,N,K,3]
distance = ||relative||₂                       [B,N,K,1]
normal_dot = dot(On, Hn[idx])                  [B,N,K,1]
local_norm = Hn[idx]                           [B,N,K,3]
local_flow = Hf[idx]                           [B,N,K,3]
```

几何分支输入 `[relative/s_geo, distance/s_geo, local_norm, normal_dot]` 为 8 维，独立经 `8→64→D` 得 `Egeo [B,N,K,D]`；flow 分支 `local_flow/s_hand_flow` 经 `3→64→D` 得 `Eflow [B,N,K,D]`。key 只构造 `Ekey=LN(Egeo+Eflow)`；value 不合并：

```text
Q=Wq(Ofeat)                           [B,N,D]
K=Wk(Ekey)                            [B,N,K,D]
Vgeo=Wvg(Egeo), Vflow=Wvf(Eflow)      [B,N,K,D]
alpha=masked_softmax(dot(Q,K)/sqrt(D)) [B,N,K]

Igeo = Σk alpha·Vgeo                   [B,N,D]
Iflow= Σk alpha·Vflow                  [B,N,D]
vbar = Σk alpha·(local_flow/s_hand_flow) [B,N,3]
sbar = Σk alpha·||local_flow/s_hand_flow|| [B,N,1]
```

无有效边的物体点四路输出均为零，`Mp=False`。attention 归一化前必须使用稳定的全无效分支，不能让 `-inf` softmax 产生 NaN。

## 6. Object intrinsic、fusion 和 masked SlotAttn

### 6.1 Object intrinsic

```text
[O0,On] [B,N,6] → MLP 6→64→D → Ofeat [B,N,D]
```

`Ofeat` 只作为 local interaction query 和 fusion 输入，不进入 object decoder。

### 6.2 Fusion

```text
cat(Ofeat,Igeo,Iflow,vbar,sbar)       [B,N,3D+4]=[B,N,388]
delta = MLP 388→D                     [B,N,D]
U = LayerNorm(Ofeat + delta)           [B,N,D]
```

### 6.3 SlotAttn

正常样本对 `U` 使用 `Mp` 做 hard mask；assignment 在 slot 维 softmax，invalid object token 权重为 0，slot update 在有效点维归一化。迭代 `T=3`：

```text
U                 [B,N,128]
Mp                [B,N]
slot_state        [B,S,128]
assignment        [B,S,N]
slot_weight       [B,S,N]
cm_raw            [B,S,128]
Cm=Linear(128→32)  [B,S,32]
```

对 `sample_valid=0` 的行，内部构造 `safe_mask[b,0]=True` 且 `safe_input[b,0]=0`（或等价固定 learned dummy），保持 B 和 finite softmax；该行的 `sample_valid` 不参与梯度监督。SlotAttn 不能把所有 object token 作为空样本 fallback。

## 7. Anchor

用 `slot_weight` 对原始当前物体点求加权 anchor：

```text
Apos  = einsum('bsn,bnd→bsd', slot_weight,O0)       [B,S,3]
Anorm = normalize(einsum('bsn,bnd→bsd',slot_weight,On)) [B,S,3]
```

所有 slot 的 anchor 都用有限归一化；若某 slot 质量接近 0，使用 `eps` 稳定计算，但不新增 null-Cm 语义。

## 8. Additive object decoder

object decoder 只接收原始点/法向、Cm 和 anchor 几何，不接收 `Ofeat/Igeo/Iflow/vbar/sbar/U`：

```text
[O0,On]                           [B,N,6]
Cm_s                              [B,S,32]
relative_obj_anchor              [B,N,S,3]
anchor_normal                    [B,N,S,3]
concat per (i,s)                  [B,N,S,44]
MLP 44→128→128                   [B,N,S,128]
slot_contribution                 [B,N,S,3]
pred_obj_flow = sum_s(contrib)    [B,N,3]
```

没有 route softmax、slot routing 权重或 `sum(alpha_s*flow_s)`。flow head 零初始化保留。只在诊断中计算 `||contribution||` 归一化的 `object_contribution_usage [B,N,S]`。

## 9. Additive hand decoder

hand decoder 保留原始 hand 几何并延迟压缩：

```text
[H0,Hn] [B,H,6] → MLP 6→64→D → Hfeat [B,H,128]
cat(Hfeat,Cm_s,relative_hand_anchor,anchor_normal)
                               [B,H,S,166]
MLP 166→128→128 → contribution [B,H,S,3]
pred_hand_flow = sum_s(contribution)             [B,H,3]
```

不把 GT `Hf` 拼入 hand decoder；`Mh=False` 的输出只作为 padding，占位不计 loss。诊断使用 `hand_contribution_usage`，不参与前向求和。

## 10. Loss、指标和空样本处理

先按样本求点平均的 Huber：

```text
Lobj_b = mean_i(Mo_bi * huber(||pred_obj-target_obj||))
Lhand_b= mean_i((hand_supervision_mask & Mh)_bi * huber(||pred_hand-target_hand||))
```

再做 sample-level mask，保持 B 不变：

```text
L = Σb sample_valid_b*(λobj Lobj_b + λhand Lhand_b)
    / max(Σb sample_valid_b,1)
```

当整个 batch `sum(sample_valid)=0`，返回带零梯度图的 loss，记录 `all_samples_invalid=1`，训练 step 不应更新参数（runner 需跳过 optimizer step）。object/hand EPE、active ratio、slot entropy、贡献 usage 同样按 `sample_valid` 排除；同时记录 `sample_valid_count`、`sampling_miss_ratio`、`true_no_interaction_ratio` 和 `retry_count`。

## 11. 配置、cache 与运行诊断

V1.2.1 active config 至少固定：

```yaml
processing_dim: 128
cm_dim: 32
num_cm_tokens: 16
slot_iters: 3
knn_k: 8
interaction_radius_m: 0.05
sample_loss_mask: true
dummy_token_policy: zero
object_decoder_mode: additive
hand_decoder_mode: additive
scale_manifest_path: data/processed_data/object_interaction_cm_v1_2_1/scales_train.json
sampling_retry_attempts: 0       # 先统计 miss，再决定是否启用 retry
```

cache 优先直接复用 `object_interaction_cm_v1_1/index.json`。只有现有 index/schema 无法满足字段合同时才写读取适配器；不重新导出 geometry/hand cache。每次运行 manifest 记录 cache index、scale manifest、`B/N/P/H/K/r/D/S/C`、mask-before-topk、sample mask 策略及 source/stride split。

诊断脚本先统计：`N_active_4096`、`N_active_1024`、`P(N_active_1024=0|N_active_4096>0)`；若 miss `<0.1%` 保持 dummy+mask，`1%~5%` 才考虑最多 4 次 runtime retry，`>5%` 重新讨论采样策略。smoke 只验证 wiring、有限值、mask 和反向；全量训练结果另行记录，不把 smoke 当科研结论。

## 12. 不变量和禁止事项

1. hand padding 必须在 top-k 前 mask；否则实现无效。
2. `Mp` 只控制 SlotAttn pool；object decoder/loss 仍覆盖全部 `Mo=True` 物体点。
3. hand-flow 在 edge/interaction/SlotAttn 中保持 D=128，只有 SlotAttn 后做 D→C。
4. 两个 decoder 都是 additive slot contribution，不能恢复 route softmax。
5. object decoder 不得接收 intrinsic/interation token 旁路；interaction 只能通过 Cm 到达。
6. 空样本不产生语义 null-Cm；dummy 只保持数值合法，sample mask 决定监督资格。
7. 不改变坐标系、GT、数据 split、cache schema、旧 checkpoint 和旧输出目录。
