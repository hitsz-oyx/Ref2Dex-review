## 1. 端到端总览

V1.2 的核心约束只有一句话：**object decoder 只看原始 object point/normal 和 Cm；interaction + hand flow 必须先经过只看交互物体点的 SlotAttn，再以 Cm 形式进入两个 decoder。**

```text
当前帧输入
  object_points O0 [B,N,3] ─┐
  object_normals On [B,N,3] ├─ Object intrinsic encoder ────────┐       │
  object_valid Mo [B,N] ────┘                                    │       │
                                                                         │
  hand_points H0 [B,H,3] ─┐                                               │
  hand_normals Hn [B,H,3] ├─ KNN(K=8,r=5cm) ─ Edge features ─┐             │
  hand_flow Hf [B,H,3] ──┤                                  │          │
  hand_valid Mh [B,H] ───┘                                  └─ Local interaction
                                                               Igeo/Iflow [B,N,D]
                                                               vbar/sbar [B,N,3]/[B,N,1]
                                                                    │
                                                   hard pool mask Mp [B,N]
                                                                    │
                                                   sample_keep=any(Mp) [B]
                                                   drop/compact batch B→B'
                                                   Masked SlotAttn(S=16,iters=3)
                                                                    │
                                                   cm_raw [B',S,D]
                                                                    │ late projection only here
                                                   Cm [B',S,C]
                                                        ┌───────────┴───────────┐
                                                        │                       │
             raw point/normal [B',N,6] + Cm [B',S,C]       │   hand geometry [B',H,D] + Cm
                         + object/anchor geometry         │         + hand/anchor geometry
                                                        ▼                       ▼
                                                   object decoder           hand decoder
                                                        │                       │
                                                   object flow [B',N,3]  hand flow [B',H,3]
```

图中的 `D` 是主干处理宽度，`C` 是对 decoder 暴露的 Cm 宽度，`B'` 是删去空交互样本后的有效 batch。V1.2 不在局部 interaction 进入 SlotAttn 前把特征压到 `C=32`；唯一固定的 `D→C` 投影位于 SlotAttn 输出之后。

## 2. 统一符号和张量尺寸

| 符号 | 数值 | 说明 |
|---|---:|---|
| `B` | batch-dependent | batch 维 |
| `N` | `1024` | 每帧进入模型的物体点数 |
| `H` | `3076` | 左右手合并后的最大手点数；Inspire-F1 通常只有 1538 个有效点，其余为 padding |
| `K` | `8` | 每个物体点保留的 hand KNN 数 |
| `r` | `0.05 m` | V1.2 首版固定 5 cm；2 cm 只作为后续独立消融 |
| `S` | `16` | Slot 数 |
| `D` | `128` | V1.2 主处理宽度，所有 intrinsic/edge/interaction/slot_raw 使用该宽度 |
| `C` | `32` | Cm 对 decoder 的接口宽度 |

固定输入和输出如下：

| 阶段 | 输入 | 输出 | 后续消费者 |
|---|---|---|---|
| 数据整理 | world 点、当前 pose、hand streams | `O0 [B,N,3]`、`On [B,N,3]`、`H0/Hn/Hf [B,H,3]`、`Mo/Mh` | KNN、intrinsic encoder |
| KNN | `O0 [B,N,3]`、`H0 [B,H,3]`、`Mh [B,H]` | `idx [B,N,K]`、`edge_valid [B,N,K]`、局部 hand 字段 | edge encoder |
| Object intrinsic | `[O0,On] [B,N,6]` | `Ofeat [B,N,D]` | local interaction 的 query、SlotAttn 输入 |
| Edge encoder | geometry `[B,N,K,8]`、flow `[B,N,K,3]` | `Egeo/Eflow [B,N,K,D]` | local interaction |
| Local interaction | `Ofeat [B,N,D]`、`Egeo/Eflow [B,N,K,D]`、`edge_valid` | `Igeo/Iflow [B,N,D]`、`vbar [B,N,3]`、`sbar [B,N,1]`、`has_interaction [B,N]` | residual fusion |
| Residual fusion | `Ofeat/Igeo/Iflow/vbar/sbar` | `U [B,N,D]` | masked SlotAttn，仅此处使用 |
| Hard pool | `Mo [B,N]`、`has_interaction [B,N]` | `Mp [B,N]`、`sample_keep [B]` | batch compaction |
| Batch compaction | 全 batch 的 `U/Mp/hand/GT` | `U [B',N,D]`、`Mp [B',N]` | masked SlotAttn |
| Masked SlotAttn | `U [B',N,D]`、`Mp [B',N]` | `cm_raw [B',S,D]`、`slot_weight [B',S,N]` | late projection、anchor |
| Late projection | `cm_raw [B',S,D]` | `Cm [B',S,C]` | object/hand decoder |
| Anchor | `slot_weight`、`O0/On` | `Apos [B',S,3]`、`Anorm [B',S,3]` | 两个 decoder |
| Object decoder | raw `[O0,On] [B',N,6]`、`Cm [B',S,C]`、object/anchor geometry | `Fobj [B',N,3]` | object loss/eval |
| Hand decoder | hand intrinsic `[B',H,D]`、`Cm`、hand/anchor geometry | `Fhand [B',H,3]` | hand loss/eval |

KNN 和 sample keep 在原始 batch `B` 上计算；完成 batch compaction 后，SlotAttn/decoder/loss 的 batch 维统一为 `B'`。所有点的第 `N` 维保持与 `object_points/object_normals/object_valid_mask` 同序；所有手点的第 `H` 维保持与 `hand_points/hand_normals/hand_flow/hand_valid_mask` 同序。

## 3. 数据整理和有效性

### 3.1 当前帧坐标

数据层先将 world 坐标变换到当前物体 frame：

```text
O0 = world_to_frame(object_world_current, object_pose_current)  [B,N,3]
On = normal_world_to_frame(object_normals_world_current)         [B,N,3]
H0 = world_to_frame(hand_world_current, object_pose_current)     [B,H,3]
Hn = normal_world_to_frame(hand_normals_world_current)           [B,H,3]
Hf = world_to_frame(hand_world_future, object_pose_current)-H0   [B,H,3]
```

`Hf` 是局部 interaction encoder 使用的 hand-flow 特征；未来 object/hand GT 只用于 loss，不进入推理捷径。物体点先从完整 4096 点池采样到 `N=1024`，V1.2 不改变采样坐标和 split。

### 3.2 两类 mask

- `Mo [B,N]`：数据/采样层的 object 有效性。当前实现的 1024 个采样点均为 true，但接口仍保留该 mask。
- `Mh [B,H]`：真实 hand 点有效性。padding 必须为 false，尤其是 Inspire-F1 的 1538 个 zero padding 点。
- `edge_valid [B,N,K]`：某个 KNN 边是否同时满足真实 hand 点和半径条件。
- `Mp [B,N]`：某个 object 点是否进入 SlotAttn，定义为 `Mo & edge_valid.any(dim=-1)`。

`Mp` 不能替代 `Mo`：它只决定 Cm 的聚集范围，不缩小 object decoder 或 object loss 的物体点覆盖范围。

## 4. KNN 和局部边构造

### 4.1 先 mask，再 top-k

对每个物体点 `O0_i` 和 hand 点 `H0_j`：

```text
d_ij = ||O0_i - H0_j||₂                         # [B,N,H]
d_ij = +∞, if Mh_j = False                      # 先排除 padding
idx_i = topK_j(d_ij, K)                          # [B,N,K]
edge_valid_i,k = Mh[idx_i,k] ∧ (d_i,idx_i,k ≤ r) # [B,N,K]
```

当有效 hand 点少于 `K`，多出的边为 false；当某个 object 点没有半径内 hand 邻居，`has_interaction_i=False`，其局部 interaction 输出为零向量。不能先对包含 padding 的距离矩阵做 `topk`，再事后删除无效边。

### 4.2 局部字段

根据 `idx [B,N,K]` gather：

```text
relative_ik = H0[idx_i,k] - O0_i       [B,N,K,3]
distance_ik  = ||relative_ik||₂        [B,N,K,1]
local_norm_ik = Hn[idx_i,k]             [B,N,K,3]
normal_dot_ik = dot(On_i, local_norm_ik)[B,N,K,1]
local_flow_ik = Hf[idx_i,k]             [B,N,K,3]
```

局部 geometry 为 `3+1+3+1=8` 维，局部 flow 单独为 3 维；二者不会在进入第一层时合成一个 11→32 的窄瓶颈。

### 4.3 特征尺度

进入 edge encoder 前显式归一化几何和 flow，避免法向的数值尺度（约 1）压过位置和运动特征：

```text
scaled_relative = relative / geometry_feature_scale_m     [B,N,K,3]
scaled_distance = distance / geometry_feature_scale_m     [B,N,K,1]
scaled_flow     = local_flow / sigma_hand                 [B,N,K,3]
```

V1.2 首版 `geometry_feature_scale_m=0.05`（5 cm）；`sigma_hand` 由 train split 的有效 hand-flow 统计得到，并写入运行配置/manifest。该输入尺度只用于 feature conditioning，不能与 object/hand target scaling 混用。

## 5. Object intrinsic encoder

这是 local interaction query 和 SlotAttn 使用的纯物体几何支路，不包含 hand、contact 或 flow；object decoder 不使用该支路输出：

```text
[O0, On]                         [B,N,6]
      ↓ Linear/MLP 6 → 64        [B,N,64]
      ↓ Linear/MLP 64 → D        [B,N,128]
Ofeat = object_intrinsic         [B,N,D]
```

`Ofeat` 只服务 interaction/SlotAttn 支路：它用于生成 local interaction 的 query，并与 `Igeo/Iflow/vbar/sbar` 融合得到 `U`。它不进入 object decoder。object decoder 重新读取原始 `O0/On`，避免 decoder 使用一个已经经过独立 MLP 的 object 表征，也保持与旧 Cm geometry-only decoder 的输入语义一致。

## 6. Edge encoder 和局部 interaction

### 6.1 两个独立的 edge 编码器

```text
scaled edge_geometry [B,N,K,8]
  → MLP 8 → 64
  → MLP 64 → D
Egeo            [B,N,K,D]

scaled local_flow [B,N,K,3]
  → MLP 3 → 64
  → MLP 64 → D
Eflow           [B,N,K,D]
```

几何和 flow 分支都在 128 维编码，但不能在 value 侧先相加成一个 `E`。只有 key 侧可以构造：

```text
Ekey = LayerNorm(Egeo + Eflow)          [B,N,K,D]
```

`Ekey` 只用于计算 attention 权重；value 必须保持两路。

### 6.2 局部 attention 聚合

```text
Q = Wq(Ofeat)                          [B,N,D]
K = Wk(Ekey)                            [B,N,K,D]
Vgeo = Wvg(Egeo)                        [B,N,K,D]
Vflow = Wvf(Eflow)                      [B,N,K,D]
logit_ik = dot(Q_i, K_ik) / sqrt(D)    [B,N,K]
```

在 `edge_valid` 上做 K 维 softmax：

```text
alpha_ik = softmax_k(logit_ik, valid=edge_valid) [B,N,K]
Igeo_i   = Σ_k alpha_ik · Vgeo_ik                [B,N,D]
Iflow_i  = Σ_k alpha_ik · Vflow_ik               [B,N,D]
vbar_i   = Σ_k alpha_ik · scaled_local_flow_ik   [B,N,3]
sbar_i   = Σ_k alpha_ik · ||scaled_local_flow_ik|| [B,N,1]
```

`vbar` 和 `sbar` 不经过 feature projection，只做 attention-weighted flow statistic；它们使 hand-flow 在 object-side token 中保留一条显式的低阶信息路径。无有效边时令 `Igeo=0`、`Iflow=0`、`vbar=0`、`sbar=0`、`has_interaction=False`。局部 interaction 的输出尺寸固定为 `[B,N,D] + [B,N,D] + [B,N,3] + [B,N,1]`。

## 7. Residual fusion 和 SlotAttn 输入

```text
[Ofeat, Igeo, Iflow, vbar, sbar]
  [B,N,D+D+D+3+1] = [B,N,388]
      ↓ MLP 388 → D          [B,N,128]
delta                        [B,N,D]
U = LayerNorm(Ofeat + delta) [B,N,D]
```

`U` 是含 interaction/hand-flow 条件的 token，只能进入 SlotAttn。代码中应将它与 `Ofeat` 使用不同变量名，避免 decoder refactor 时误接入 `U`。其中 `Ofeat` 仅用于 query/fusion/SlotAttn，不进入 object decoder。

## 8. Hard interaction object mask

```text
Mp_i = Mo_i ∧ any(edge_valid_i, dim=K)       [B,N]
```

这个 mask 的唯一作用是从 1024 个物体点中选出真正有局部 hand 邻居的点，供 SlotAttn 聚集。object decoder 仍为所有 `Mo=True` 的点输出 flow，object loss 仍覆盖所有 `Mo=True` 的点；但前提是该样本至少有一个 `Mp=True` 的点。

定义 sample-level keep mask：

```text
sample_keep_b = any(Mp_b, dim=N)              [B]
```

若 `sample_keep_b=False`，该样本直接从本次 batch 的 SlotAttn、两个 decoder、object loss 和 hand loss 中移除：

1. 不构造、不使用 `null-Cm`，也不把全体物体点作为 fallback；
2. 训练时只对 `sample_keep=True` 的子 batch 做 forward/loss；
3. 一个 batch 全部被移除时，跳过 optimizer step，并记录 `all_samples_dropped=True`；
4. 记录 `dropped_no_interaction_count/ratio`，使训练有效样本数可追溯。

推荐在 KNN 得到 `Mp` 后先做 batch compaction，令保留下来的 batch 维为 `B' = sample_keep.sum()`，再运行 SlotAttn 和 decoder。这样没有有效交互的样本不会生成任何被训练使用的 Cm。若实现为了保持 batch 张量对齐而生成占位输出，占位值不得进入 loss、梯度或指标。

验证/测试默认采用同一规则：空交互样本从 EPE 分母中排除，并单独报告 `dropped_no_interaction_ratio`。若要把空样本纳入评估，必须另行定义不使用 Cm 的推理路径，不能偷偷复用训练时的 drop 逻辑。

## 9. Masked SlotAttn

### 9.1 输入和迭代尺寸

```text
B'                = sample_keep.sum()
U                 [B',N,D] = [B',1024,128]
Mp                [B',N]   = [B',1024]
slot_state^0      [B',S,D] = [B',16,128]
```

默认迭代 `T=3` 次。只有 `sample_keep=True` 的样本进入这一节；每一轮用 slot 与 object token 的相似度产生 assignment：

```text
logits            [B',S,N]
assign = softmax(logits, dim=S)               [B',S,N]
assign[...,~Mp] = 0                           [B',S,N]
weight_s,i = assign_s,i / (Σ_i assign_s,i+ε)  [B',S,N]
update_s = Σ_i weight_s,i · V(U_i)            [B',S,D]
slot_state^(t+1) = SlotUpdate(slot_state^t, update) [B',S,D]
```

要点：

- assignment 在 slot 维归一化，即每个有效物体点可以分配给 16 个 slot；不能错误地在点维先归一化。
- 无效物体点的 assignment 直接置零，不能进入 slot update 的分子或分母。
- `slot_weight [B',S,N]` 用于 anchor 和诊断，最终 slot state 保持 128 维。

### 9.2 Late compression

```text
cm_raw    = slot_state^T       [B',S,D] = [B',16,128]
Cm        = Linear(D → C)      [B',S,C] = [B',16,32]
```

这是 V1.2 唯一的 `128→32` 语义压缩边界。局部 geometry、hand-flow、interaction 和 slot competition 全部在 128 维完成；只有 decoder 接口使用 32 维 Cm。若把 edge 或 `U` 提前压成 32 维，应视为不同架构。

## 10. Anchor 提取

用最终 `slot_weight [B',S,N]` 对当前物体点加权：

```text
Apos  = einsum('bsn,bnd→bsd', slot_weight, O0)   [B',S,3]
Anorm = normalize(einsum('bsn,bnd→bsd', slot_weight, On)) [B',S,3]
```

由于 `sample_keep=True` 保证至少有一个有效交互物体点，正常路径不会出现全空 slot pool。若某个 slot 在有效池中没有质量，使用数值稳定的 `ε` 归一化和已有有效物体点的几何统计生成 anchor；这不是 `null-Cm`，也不改变 sample-level drop 规则。`Apos/Anorm` 只表达当前物体几何锚点，不携带 hand-flow 的旁路特征。

## 11. Object decoder

### 11.1 输入尺寸

object decoder 对每个保留样本的每个物体点和每个 slot 建立候选关系。它不接收 `Ofeat`，而是重新使用原始点和法向：

```text
object_point_i                  [B',N,3]      = [B',1024,3]
object_normal_i                 [B',N,3]      = [B',1024,3]
Cm_s                            [B',S,C]       = [B',16,32]
relative_obj_anchor_i,s         [B',N,S,3]
anchor_normal_s                 [B',S,3]
```

广播后单个 `(i,s)` 的 decoder 输入为：

```text
[object_point_i(3), object_normal_i(3), Cm_s(32), relative(3), anchor_normal(3)]
                                                                  = 44 维
```

推荐 decoder hidden width 为 128；若需要严格复现旧 Cm 的容量，可将 hidden width 固定为 64，但这应作为明确的 parity 配置：

```text
44 → 128 → 128
```

### 11.2 Additive slot contributions

```text
slot_contribution_i,s = FlowHead(hidden_i,s)    [B',N,S,3]
Fobj_i                = Σ_s slot_contribution_i,s [B',N,3]
```

这里没有 `RouteHead`、slot softmax 或归一化的 forward 权重；每个 slot 输出独立的 3D contribution，最终直接沿 `S` 求和。flow head zero initialization 保留训练初期接近零位移的行为。

如果需要统计 slot usage，只计算不参与前向的 diagnostic：

```text
usage_i,s = ||slot_contribution_i,s||₂
            / (Σ_k ||slot_contribution_i,k||₂ + ε)  [B',N,S]
```

`Ofeat`、`Igeo`、`Iflow`、`vbar`、`sbar`、`U`、局部 hand-flow 或其他含 interaction 的中间张量不得作为 object decoder 输入；interaction 信息只能通过 `Cm_s` 进入。

## 12. Hand decoder

hand decoder 使用当前手点几何和 Cm，不把 GT hand-flow 直接拼进 decoder：

```text
[H0,Hn]                         [B',H,6]
  → MLP 6 → 64 → MLP 64 → D     hand_feat [B',H,D] = [B',3076,128]
```

对于每个 hand point 和 slot：

```text
hand_feat_h          [B',H,D]
Cm_s                 [B',S,C]
relative_hand_anchor [B',H,S,3]
anchor_normal_s      [B',S,3]
```

拼接为 `D+C+3+3=166` 维，经过 `166→128→128` hidden layers，生成每个 slot 的独立 contribution：

```text
hand_slot_contribution [B',H,S,3]
Fhand                  = Σ_s hand_slot_contribution_s [B',H,3]
```

hand decoder 不使用 slot softmax 或 route weight 参与 flow 聚合；如需 slot usage，只用各 contribution 的范数计算 diagnostic。`Mh=False` 的 padding 输出不计入 loss；保留子 batch 的输出接口 `[B',H,3]`，左右手的原始顺序/标识不因合并而丢失。若评估器需要恢复原 batch 对齐，使用 `sample_keep` 将结果 scatter 回去，空样本保持“无结果”状态，不填零流。

## 13. Loss 和监督范围

```text
object residual: Fobj - obj_flow_gt         [B',N,3]
object mask:     Mo                         [B',N]

hand residual:   Fhand - hand_flow_gt       [B',H,3]
hand mask:       hand_supervision_mask ∧ Mh [B',H]
```

- object loss 对所有 `Mo=True` 的采样点计算，不因 `Mp` 稀疏而只训练交互物体点。
- hand loss 保留当前 3 cm 接触监督阈值和 Huber 形式，只在真实且满足监督条件的手点上计算。
- target scaling（hand/object）和输入 feature scaling 分开配置、分开写入 manifest；不能通过放大 hand-flow 数值来替代高维保留。
- V1.2 默认不改变 loss 权重、坐标系、split 和评估指标。

## 14. 配置和 manifest 必须能还原架构

```yaml
processing_dim: 128
cm_dim: 32
num_slots: 16
slot_iters: 3
knn_k: 8
knn_radius: 0.05        # V1.2 首版固定 5 cm
slot_pool_policy: hard_has_interaction
empty_interaction_policy: drop_sample
object_decoder_mode: additive
hand_decoder_mode: additive
flow_encoder_dim: 128
geometry_feature_scale_m: 0.05
hand_flow_input_scale: train_split_sigma
```

每次运行至少记录：`N/H/K/r/S/D/C`、KNN 是否 mask-before-topk、`slot_pool_policy`、`empty_interaction_policy`、dropped sample count/ratio、active object count/ratio、target scales 和评估 stride。

## 15. 诊断指标和失败解释

按 source、split、stride 分开记录：

- `mean_valid_neighbors`：每个 `[B,N]` 物体点在 K 个邻居中的有效边数均值；
- `active_object_count/ratio`：`Mp` 中 true 的数量和比例；
- `dropped_no_interaction_ratio`：`Mp` 全 false、被丢弃的样本比例；
- `N_active_4096`、`N_active_1024`：完整物体池和实际采样点池中的 5 cm candidate 数；
- `sampling_induced_drop_ratio = P(N_active_1024=0 | N_active_4096>0)`：区分真实无 interaction 与随机采样漏掉 interaction；
- `slot_entropy`、`slot_max_mass`、每 slot 有效点数；mask 稀疏后 entropy 下降不等于 slot collapse；
- `object_contribution_usage`、`hand_contribution_usage`：由各 slot contribution 范数归一化得到，仅作 diagnostic，不参与 flow 求和；
- hand-flow zero/shuffle ablation 下的 object EPE 变化，确认 object decoder 通过 Cm 使用了 flow；
- object/hand EPE 的 source-level、equal-source 和固定 stride 汇总。

loss 下降、forward/backward 无 NaN、checkpoint 可加载属于工程证据；只有在初始化、global batch、采样、target scaling、监督范围和评估 stride 对齐的 parity 实验中，才形成 `SUPPORTED`、`REFUTED` 或 `INCONCLUSIVE` 的科研结论。

## 16. 不变量和边界

1. hand padding 先 mask 后 top-k；违反即为 `INVALID_IMPLEMENTATION`。
2. `Mp` 只控制 SlotAttn 的聚集池，不控制 object decoder/loss 的点集。
3. hand-flow 在局部 edge 和 SlotAttn 中以 128 维处理，SlotAttn 后才允许 `128→32`。
4. object decoder 不得接收 `Igeo/Iflow/vbar/sbar/U` 等 interaction token 的旁路；hand-flow 只能通过 Cm 到达 decoder。
5. `Mp` 全 false 的样本必须 drop 并记录，不得使用 `null-Cm`、静默改成全物体池或填零流。
6. V1.1、旧 Cm checkpoint、cache、输出目录和用户已有工作区改动保持不变。

任何需要改变坐标/GT/cache/schema、共享 `src/base` 或数据 split 的实现，都必须回到 V1.2 plan 重新协商，不能在本架构下隐式扩大范围。
