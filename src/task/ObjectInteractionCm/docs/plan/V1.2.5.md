# ObjectInteractionCm V1.2.5 修正物体轨迹与 KNN=16 重训计划

- 状态：`final`
- `modification_version`：`V1.2.5`
- 指导依据：用户确认使用修正后的 DExplore RL 实际物体轨迹，并明确要求将 KNN 设置为 16。
- 父计划：[V1.2.3 Dexplore RL 混合训练计划](V1.2.3.md)
- 数据合同：[V1.2.2 数据转换与分组计划](V1.2.2.md)
- 审批：`user-approved`；用户回复“可以，然后把KNN设置为16”。

## 1. 目标与结论边界

使用 `data/processed_data/inspire_rl_object_dexplore` 中修正后的 DExplore RL rollout，重新构建独立的
ObjectInteractionCm geometry/index，并从随机初始化训练新的 Cm。旧 cache、旧 checkpoint 和依赖旧
checkpoint 的 decoder/rollout/classifier 结果全部保留，不能作为本轮修正数据的结论。

本轮只回答“修正物体轨迹后，KNN=16 的 Cm 是否能稳定完成训练并生成 checkpoint”；不训练
CmDecoderV2，不使用 test 指标选 checkpoint，不把工程 smoke 或 Cm loss 单独解释为 decoder 泛化结论。

## 2. 冻结变量

1. 数据使用修正后的 `inspire_rl_object_dexplore`，与旧 parent index、GRAB geometry 和
   `dexplore_grab/sequences` 相交后保留 630 条序列。
2. 沿用 seed=42、parent train/val/test split 和互斥 variant 分配：train `509`（MANO/Inspire
   `254/255`）、val `58`（`28/30`）、test `63`（MANO-only）。
3. MANO/RL-Inspire 均为右手、30 Hz、object pool 4096、runtime object sample 1024、hand 1538；
   stride、source probability、loss、优化器、batch、GPU 和最大 step 沿用 V1.2.3。
4. `knn_k=16` 同时用于模型局部 KNN 与 train-only scale calibration；`interaction_radius_m=0.05`、
   `hand_supervision_radius_m=0.03`、`D=128,C=32,S=16` 保持不变。
5. 从随机初始化训练，不加载任何旧 ObjectInteractionCm checkpoint。

## 3. 产物与保护边界

- 新 geometry/cache：`data/processed_data/object_interaction_cm_dexplore_rl_v1_2_5/`。

  `dexplore_rl_v1_2_5.yaml`。
- 新 train-only scale：`scales_train_v1_2_5.json`，使用 `knn_k=16`。
- 新训练输出：`outputs/objectinteractioncm/object_interaction_cm_dexplore_rl_v1_2_5_<timestamp>/`。
- 不修改旧 `object_interaction_cm_dexplore_rl_v1` cache/index、旧配置、旧 output、旧 checkpoint、
  `src/task/CmDecoderv2/` 用户改动或公共 `src/base`。

## 4. 执行与验证

1. 用修正 RL 根生成单序列 Inspire pilot，检查 `[T,598]`、actual object pose、FK hand、4096/1538
   点、法线、candidate mask 和 object-frame 合同。
2. 生成 full cache/index/run manifest；检查实际 `source_roots.inspire_rl` 指向修正根，计数与
   630 条方案一致，所有 entry 可读且 parent sequence 不跨 variant。
3. 只读 train split 重新校准 scale，`--knn-k 16`、stride `[1..10]`、seed=42。
4. 运行三卡 2-step smoke（GPU 0/1/2，每卡 batch 2）；通过后用同一配置启动正式 202300-step run。
5. 正式 run 的 best 指标仍为等权 source 的 `val/obj/flow_epe_mm`；终态未完成前结论为
   `INCONCLUSIVE`，完成后工程结论最多为 `SUPPORTED`。

## 5. 回滚

删除本计划新增的 cache、scale、配置和新 output 即可回滚；旧 cache/index、旧 checkpoint 和旧运行
目录不受影响。若 pilot/full/训练失败，保留现场并记录失败原因，不自动切换数据、KNN、seed 或 checkpoint。
