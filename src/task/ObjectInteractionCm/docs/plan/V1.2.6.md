## 1. 固定采样合同

### 1.1 共同 Region

两种右手都使用 11 个 Region，编号固定为：

```text
0 palm
1/2 thumb_body / thumb_tip
3/4 index_body / index_tip
5/6 middle_body / middle_tip
7/8 ring_body / ring_tip
9/10 pinky_body / pinky_tip
```

- MANO：沿用 canonical face center 最近关节得到的五指归属；每根手指再沿掌根到指尖方向的主轴投影，将末端 20% 定为 `tip`。
- Inspire：按 URDF visual link 名归属五根手指；`hand_base_link` 为 `palm`；每根手指沿 canonical visual triangles 的主轴投影，将末端 20% 定为 `tip`。
- `tip` 的 20% 是每根手指自身投影范围的比例，不是固定毫米阈值，以便 MANO/Inspire 的区域语义保持尺度相对一致。

### 1.2 点数与权重

总点数固定为 2048：

```text
palm：512
五个 body：1024（205, 205, 205, 205, 204）
五个 tip：512（103, 103, 102, 102, 102）
```

在每个 Region 内，按该 Region 内三角形表面积归一化后有放回抽取三角形，并在三角形内用平方根重心坐标随机采样；因此保留面积加权，不做均匀 FPS。

### 1.3 对应关系与确定性

- `surface_seed=2024`。
- MANO 采样一次 canonical faces+barycentric；Inspire 采样一次 canonical visual face+barycentric，并保存 visual/link ID。
- 预览中只生成 canonical MANO 和 Inspire 零姿态点云；后续正式 cache 若采用该合同，必须把同一 face/barycentric 对应沿帧变换。
- 法线使用被采样三角面的 flat normal。

### 5.1 固定范围

- MANO 采用完整 mesh 表面积均匀采样 `2048` 点；Inspire 采用相同单位表面积密度的 `10135` 点。
- 从现有 Dexplore-RL ObjectInteractionCm index 的 train split 中确定性选择各 `3` 条 MANO 和 `3` 条 Inspire-RL 序列；沿用其物体点池、物体姿态、帧号和原始 q/mesh provenance。
- 新手点按 canonical face + barycentric 对应跨帧重建：MANO 使用 parent cache 的变形 mesh，Inspire 使用同一 URDF 的 FK；每帧重新计算 flat normal 和 5 cm activity mask。
- 生成独立的 research preview index/geometry，不覆盖现有 `object_interaction_cm_dexplore_rl_v1_2_5` cache，不改变训练配置、GT、split 或坐标系。
- 对 viewer 只做读取端兼容：手点数从序列 manifest 读取并允许 2048/10135；物体池仍严格为 4096，KNN 与距离阈值保持动态计算。
