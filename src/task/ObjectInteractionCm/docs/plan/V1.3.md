## 1. 目标与固定边界

基于现有 V1.2.5 index 和 geometry，生成独立的
`data/processed_data/object_interaction_cm_dexplore_rl_v1_3/`，保存全部 630 条 sequence、全部
159476 帧的旧兼容 hand stream、高分辨率 KNN hand stream、`K=32` 邻居索引和 2 cm mask；训练时
从采样 object 点的有效 KNN 边中动态选取并去重 hand 点。

保持不变：

- V1.2.5 的 sequence assignment、train/val/test split 和 test 的 MANO-only 约束；
- `object_pose_t`、右手、30 Hz、object pool 4096、runtime object sample 1024；
- 当前 object trajectory、GT、source probability、stride `[1..10]` 和 optimizer/training 目标；
- 旧 cache、旧配置、旧 checkpoint、旧 output 和 `src/task/CmDecoderv2/`。

## 2. Cache schema

### 2.1 每条 sequence

复用 V1.2.5 的 object geometry 和 1538 点兼容 hand geometry，新增：

```text
geometry/
  obj_points_pool_world.npy       [T,4096,3] float32
  obj_normals_pool_world.npy      [T,4096,3] float32
  obj_pose_world.npy              [T,4,4] float32
  source_frame_id.npy             [T] int32
  frame_time.npy                  [T] float32
  hand_points_world.npy           [T,1538,3] float32
  hand_normals_world.npy          [T,1538,3] float32
  knn_hand_points_world.npy       [T,H_knn,3] float32
  knn_hand_normals_world.npy      [T,H_knn,3] float32
  obj_knn_indices.npy             [T,4096,32] uint16
  obj_candidate_mask_2cm.npy     [T,4096] bool
  hand_supervision_mask_2cm.npy  [T,1538] bool
  hand_min_object_distance_m.npy [T] float32
  manifest.json
```

其中 `H_knn=2048`（MANO）或 `10135`（Inspire）。高分辨率 correspondence 使用固定
`surface_seed=2024` 的全表面积均匀三角形重心采样；MANO 使用 parent mesh topology，Inspire
使用当前 right-hand URDF visual meshes 和 Dexplore q。

`obj_knn_indices[t,i,:]` 是 object-pose frame 中第 `i` 个完整物体点的 32 个 hand index。
不保存对应的 float distance。`obj_candidate_mask_2cm` 由完整 4096 点与 KNN 结果生成；旧
`hand_supervision_mask_2cm` 可以保留作兼容数据，但新的 V1.3 hand supervision 不读取该 mask。

### 2.2 Index 与 manifest

新增 index schema 版本，记录：

- `knn_k=32`、`interaction_radius_m=0.02`、`hand_supervision_radius_m=0.02`；
- `hand_points_per_stream=1538`；
- `knn_hand_points_per_stream={"mano":2048,"inspire_f1":10135}`；
- KNN index dtype、shape、坐标系和 cache source；
- 完整 sequence/frame/source 计数和 split fingerprint；
- worker/finalize 的 `run_id`、`base_commit`、输入资产 hash 和输出入口。

## 3. 代码范围

### 3.1 Cache producer

新增 V1.3 专用 producer 和 train-only scale calibrator，支持：

- `worker`：按确定性 sequence 分片生成 geometry，不写共享 index；
- `finalize`：检查 worker 覆盖完整且不重复，写 assignment/index/validation/run manifest；
- `--resume`：只复用 manifest 完整且校验通过的 sequence；
- 固定 frame batch 的 GPU `pytorch3d.ops.knn_points`；
- 生成 MANO 2048 / Inspire 10135 高分辨率表面点；
- 保留 decoder 1538 的 2 cm supervision mask，供兼容路径使用；不新增高分辨率全量 hand mask；
- 对 `uint16` index 做范围检查，确保最大索引小于 65535。
- `calibrate_v1_3_scales.py` 只读取 train split，分别校准有效 KNN edge hand-flow 与有效边去重后的
  unique hand-flow，不重复导出 geometry。

### 3.2 Dataset/model

扩展 `_SequenceView` 和 `ObjectInteractionCmDataset`：

- 保留固定 1538 hand stream作为旧 cache/旧配置兼容路径；
- 加载 source-specific 完整 KNN hand stream；
- 从完整物体池随机采样 1024 点时同步 gather `obj_knn_indices`；
- 在 Dataset 运行时重算采样 object 点对应的 32 个距离，只保留 2 cm 内有效边；
- 从有效边的 hand ID 中去重，输出唯一 hand points、normals、flow 和局部 `knn_edge_indices`；
- 使用自定义 collate 按 batch 内最大唯一 hand 点数动态 padding，并输出 `hand_valid_mask`；
- 对旧 cache 保留原有 runtime KNN fallback，保证旧配置可读取。

扩展 `LocalHandInteraction`：

- 新 cache 直接使用离线 `knn_edge_indices` gather；
- 只对 32 个邻居重算距离、生成 radius mask 和 edge features；
- 没有 cache index 时保留原有 `knn_points`/`cdist` 路径；
- hand decoder 与 hand loss 使用当前样本有效边去重后的唯一 hand 点；
- 同一 hand ID 被多条有效边引用时，交互特征允许重复引用，但 hand loss 只计一次。

### 3.3 配置与 scale

新增 V1.3 full/smoke 配置：

```text
num_obj_pool=4096
num_obj_points=1024
num_hand_points=1538             # 旧兼容 stream 的 shape 校验
max_hand_points=1538             # 旧 decoder 路径使用；unique KNN 路径不使用
max_knn_hand_points=10135
hand_stream_mode=unique_knn_edges
knn_k=32
interaction_radius_m=0.02
frame_filter_distance_m=0.02
hand_supervision_radius_m=0.02
```

scale calibration 读取新的 cache index，并区分有效 KNN edge hand-flow 与 unique hand-flow 的统计；
不保存任何重复 geometry。旧 scale manifest 的读取保持兼容。

## 4. 执行顺序

1. 静态检查 producer、dataset、model、config 和 schema 测试。
2. 用一条 MANO 和一条 Inspire sequence 做 pilot，核对 geometry、KNN index、2 cm mask 和
   exact recomputation。
3. 在 GPU `2,4,5,6` 启动四个 worker，生成全部 sequence geometry。
4. finalize index、manifest 和 validation summary；检查 sequence/frame/source 计数与 V1.2.5
   完全一致。
5. 重新生成 train-only V1.3 unique-KNN-hand scale manifest。
6. 运行混合 MANO/Inspire loader + model forward/backward smoke，检查动态 padding、边 mask 和
   unique hand supervision。
7. 通过 smoke 后，在物理 GPU `0,2,3` 启动 V1.3 全量训练。

建议 worker 命令形式：

```bash
CUDA_VISIBLE_DEVICES=2 PYTHONPATH=. python -m src.task.ObjectInteractionCm.tools.data.build_dexplore_rl_v1_3_cache \
  --mode worker --shard-index 0 --num-shards 4 --device cuda:0 ...
```

其余 worker 仅替换物理 GPU 和 `--shard-index`；所有 worker 完成后运行 `--mode finalize`。

## 5. 验证与结论边界

必须验证：

- index/cache schema、所有 entry 可读、split/source/frame count 不变；
- KNN index 形状 `[T,4096,32]`、dtype `uint16`、索引范围合法；
- 随机抽帧中，cache index gather 后的 32 个距离与 exact GPU KNN 的邻居集合/距离一致；
- `obj_candidate_mask_2cm` 与 exact 2 cm 判定一致；
- decoder supervision mask、finite 值、法线范数和 object pose 合同；
- 混合 batch 中 hand shape 等于 batch 内最大 unique KNN hand count，padding 不参与 feature/loss；
- 同一个 hand ID 在单个样本内只对应一个 hand loss 项；
- 新 model forward 不调用完整 `cdist`，旧 cache fallback 测试仍通过；
- `git diff --check` 与本地链接审计通过。

cache 和 smoke 成功只属于工程 `SUPPORTED`；不代表模型效果或科研假设已经得到支持。

- 目标：检验混合源训练得到的同一个冻结 object decoder，能否从 MANO / Inspire RL 的完整
  `Cm tokens + anchors` 和原始物体几何预测各自 GT object flow；不将其解释为 unseen-hand 泛化。
- checkpoint 固定为 `outputs/objectinteractioncm/object_interaction_cm_dexplore_rl_v1_3_20260910_020856/checkpoints/best.pt`，
  SHA256 `3a3d6c0f88565b9e41f257e4f8b87a3ca5731fd356a98f4514091754036a7283`。

  replay 一致性、模型 state 前后不变、输入与 scale 文件摘要不变，GT 不传入模型。

- 指标：每源/合并的 object EPE、向量 RMSE（mm）、相对零流改善、样本有效率、hand/object-flow

  2000 次给出 95% CI，避免把相关帧当独立样本。
- matched subset 在看结果前固定：精确 object name、hand RMS 与 GT object RMS 分箱
  `[0,1,2,4,8,16,32,64,128,+inf)` mm、full-pool active fraction 分箱
  `[0,.01,.05,.1,.25,.5,1.000001)`；只用有效交互，每个共同 stratum 两源等量抽样，seed=42。
  保存选择 ID 和覆盖率；CI 条件于本次匹配选择，并按源内 sequence 重采样。GT 仅用于离线
  难度分层，不输入 encoder/decoder。这不是同交互配对实验，不用“不显著”证明等价。
- 修改范围：本节、当前 Task 版本指针、独立 `research/cross_source_effect/` 脚本/定义/README、
  Task-local 定向测试、Task activity/experiment；禁止修改核心 model/dataset、`src/base`、

- 输出：`research/cross_source_effect/output/<run_id>/`，新目录不覆盖；保存 manifest、config、

  匹配清单、统计和图表。smoke 与全量使用不同目录；预算单空闲 GPU、最多 30 分钟/3 GiB，
  异常或超预算停止并记录，不影响现有进程。

## 8. V1.3.2 自主探索的最小机制诊断（final）

- 审批：`user-approved`，用户授权自主探索并再次要求继续；沿用本计划，不另建计划文件。
- 范围：只新增 `research/cross_source_effect/diagnose.py`、诊断定义和 Task-local 测试；维护本节、
  Task 指针/日志。L2 指标/基线定义，运行保守按 L3；不改核心模型、loader、GT、split、cache、
  训练配置、checkpoint、指导和架构，不启动网络训练。
- 输入固定为 V1.3.1 最终冻结运行的 58 个 NPZ、逐样本指标、配置/metadata 和原 V1.3 cache。
  使用相同 seed=42、epoch=0、stride=2、1024 点与 sample-valid 样本，并逐行核对 geometry/GT/ID。
- 对照不使用 GT object flow 预测：有效 unique-hand 点平均 flow；使用现有 SciPy Rotation
  拟合 current hand 到 current+hand-flow 的刚体变换并作用于 object；现有 pred object flow 的
  最佳刚体投影。拟合退化（少于 3 点或中心化点 rank<2）退回平均位移，并记录次数。
- 另以 GT flow 拟合刚体运动仅检查物体数据刚性，明确标记 oracle，不当可用预测基线。
- 量化低接触与 top-error 样本占总 EPE/MSE 的份额，报告固定阈值置零的全体 EPE 改善；
  后验阈值不用于训练/选 checkpoint、不推导新模型的泛化成绩。
- 核对 slot 指标公式，归档 tokens 的跨 slot 方差/谱有效秩和 anchors 扩散；不以这些数值单独
  认定 slot collapse。读取训练曲线时明确 train stride=1..10 与 val stride=2 不可直接对比。
- 仍报告分源 frame micro、sequence macro 和 paired sequence-cluster bootstrap 2000 次 CI，
  不以零流比较代替强基线。CPU 单进程、15 分钟和 100 MiB 预算；独立新 output 不覆盖旧结果。
- 必须生成 config、metadata、run_manifest、逐样本 metrics、summary 和 run.log；合成刚体、
  平移、旋转/退化、单位与配对 bootstrap 测试通过后再执行，并检查数据摘要与结果可复现性。
- 回滚仅涉及上述独立诊断/文档差异和新 output，既有冻结结果与所有保护边界无需恢复。
