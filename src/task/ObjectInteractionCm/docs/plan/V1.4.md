## 3. 代码范围

### 3.1 双手 geometric exporter

新增 Task-local exporter/adapter，统一输出每条序列：

```text
source_frame_id [T]
object pose / articulated object fields
mano_left/right or source hand geometry
inspire_left/right geometric q and hand geometry
merged hand_points_world [T,3076,3]
merged hand_normals_world [T,3076,3]
```

左右 Inspire 分别调用对应 URDF/retarget config；每只手保留独立 FK 诊断，但正式 cache 只暴露拼接后的 hand stream 和统一 source 名。

### 3.2 V1.4 cache producer

基于 V1.3 producer 新建版本，不修改旧 producer：

- 完整 GRAB 1335 条序列和 ARCTIC 训练候选序列进入新的 assignment；旧 val/test 成员按 ID/frame 显式锁定；
- 双手兼容 stream 为 3076 点；高分辨率 KNN stream 为 MANO 4096、Inspire 20270；
- object pool 保持 4096，runtime sample 保持 1024，KNN=32、两个半径 2 cm；
- 左右点 ID 先偏移后拼接，KNN index 指向合并 stream；不保存完整距离矩阵；
- ARCTIC 保存 part/articulation 字段并验证跨帧 point correspondence；
- worker/finalize/resume 和 manifest 记录输入 hash、资产 hash、错误清单、source/split/frame 计数。

### 3.3 Dataset/model contract

将 dataset 的多 offline stream 路径改为“左右流合并为单一 stream”路径；保留 V1.3 读取兼容。`hand_valid_mask`、unique-KNN hand supervision、动态 padding、sample validity 和 loss 语义保持。模型结构和 decoder 维度保持不变。

### 3.4 配置与预算

新建 `dexplore_arctic_v1_4.yaml` 与 smoke 配置，声明双手合并、GRAB+ARCTIC geometric source、新 index/scale 路径。生成 train rows 后计算：

```text
max_steps_v1_4 = ceil(old_epochs * new_train_rows_per_epoch / global_batch)
```

实际使用的 epoch 上限保持旧 V1.3 的 120；公式和实际 loader 长度写入 config/manifest/activity。若 loader 的 sampler 定义使上述公式不适用，使用等价的“完成相同 epoch 数”计算并记录依据。

## 4. 执行顺序

1. 静态检查新 adapter、TopoRetarget pilot 入口和依赖。
2. InterAct GRAB canonical smoke；不覆盖现有 canonical cache。
3. GRAB/ARCTIC 各一条序列双手 Inspire geometric pilot；检查两只手 FK、距离、finite 和 object pose。
4. 建立 V1.4 双手 merged index；先锁定旧 val/test ID 和 raw frame ID，再分配新增 train。
5. GPU worker 生成新 cache，finalize manifest 和 validation summary。
6. train-only scale calibration；确认 MANO/ARCTIC-MANO 与 Inspire-geometric source 计数和概率。
7. 新 loader/model 混合 smoke；运行 Task-local tests 和必要的 integration tests。
8. 生成新的 max_steps，启动独立正式训练；不恢复 V1.3 checkpoint，除非另行确认初始化语义。

## 5. 验证与停止条件

- 任何左右手长度不一致、双手 FK 偏移、ARCTIC articulation 丢失、point ID 不稳定、坐标/单位不一致、缺失 object/hand future frame 或错误静默丢弃时停止。
- pilot 必须证明双手合并 shape、KNN index 范围/集合、2 cm mask、object pose_t 和 future flow 正确。
- smoke 必须证明动态 padding、空交互样本、forward/backward、checkpoint save/load 和 manifest 合法。
- 全量导出必须报告 sequence/frame/source/split 计数、失败清单、输入/资产 hash 和可复现命令。
- 导出/cache/smoke 成功只属于工程证据；正式训练完成后再在 experiment log 记录科研结论。
