## 1. 目标

在不覆盖现有 GRAB/HRDexDB cache、split、checkpoint 和训练配置的前提下，构造一个右手、30 Hz、固定 1538 个 Inspire 表面点的 ObjectInteractionCm 数据源：

1. 以现有 ObjectInteractionCm GRAB source split 的 1255 条序列为母集合；只使用同时存在于旧 object cache、`dexplore_grab/sequences` 与 `inspire_rl` 的序列，缺失项排除并记录。
2. 保留现有 GRAB train/val/test 母 split（1004/126/125）。train/val 内按 subject/object/action 分层、seed=42、近似 1:1 分为 MANO variant 与 Dexplore RL-Inspire variant；同一 `parent_seq_id` 不跨 variant 出现。test 全部使用 MANO variant。
3. MANO 与 RL-Inspire 都转换为统一的 `object_pose_t` 几何合同：object pool 4096、hand 1538、world points/normals、5 cm candidate mask、当前/未来 hand flow；RL q 使用 `interaction_hand_inspire.pt[:, 373:391]`，不使用 `inspire_geometric`。
4. 先生成单序列 pilot 并验证帧数、有限值、点数/法线、object-frame 对齐和 flow；pilot 通过后再生成完整转换 cache 与兼容 `ref2dex_object_interaction_cm_index_v1_1` index。

本计划不实现 `CmDecoderV2`，不训练模型，不生成 MANO↔Inspire paired target，也不将测试阶段的肉眼可视化误记为定量结论。

## 2. 科研与数据不变量

- 右手单手；输出 hand 点数固定 1538，法线与点一一对应。
- Dexplore RL 是唯一 Inspire 来源；`inspire_geometric`、旧 before-fix/partial/test 输出不得进入 index。
- RL native q 仍保留在转换 manifest/逐序列 provenance 中；q 到表面点由 Dexplore Inspire right URDF/mesh 的确定性 FK 与固定面积采样完成。native→URDF 关节顺序使用 Dexplore 已验证映射 `[0,1,2,3,4,5,10,11,12,13,16,17,14,15,6,7,8,9]`。
- 所有 frame 使用 Dexplore object pose 构造统一世界坐标；MANO hand/object 先转换到自身 object frame，再重投到相同 Dexplore pose，避免把两个世界系直接混用。
- 当前/未来 flow 按同一 30 Hz 帧序计算；不改变 ObjectInteractionCm 现有 future-flow 条件语义。
- index 每条 entry 显式记录 `parent_seq_id`、`variant`、`source`、split、subject/object/action 和数据根；同一母序列不会同时有 MANO 与 RL entry。
- 若 train/val 的 parent cache 右手 MANO 文件不可读，则不伪造 MANO GT，强制该 parent 进入 RL variant；test 若缺少右手 MANO 则直接失败。该例外必须写入 assignment/manifest。
- 现有 cache、旧 index、旧 split、`src/base`、CmDecoder 用户改动均只读保护。

## 3. 影响等级、审批与回滚

- 影响等级：`L2`（数据 split、坐标系、GT/几何 cache 和 index schema 扩展）；脚本本身为 Task 内 `L1`，完整运行属于 `operation`。
- 审批：`user-approved`；依据为本轮用户明确确认默认分组和转换执行。
- 回滚：删除本次新增的 Task-local 转换脚本、该计划/活动条目以及 `data/processed_data/object_interaction_cm_dexplore_rl_v1[_pilot]` 生成目录；不触碰旧 cache/index。脚本对已存在非空输出目录拒绝覆盖。

## 5. 执行与验证

1. 只读检查旧 index、Dexplore RL q schema、URDF/mesh、工作区 dirty 状态。
2. 运行单序列 pilot；验证 source intersection、q slice、帧映射、FK 输出 finite、1538 点/normal、object-frame 误差、candidate mask 和 flow shape。
3. pilot 失败时只修正脚本/计划，不生成 full cache；记录 `INVALID_IMPLEMENTATION` 或 `INCONCLUSIVE`，不把可运行当作科研效果。
4. pilot 通过后运行 full conversion；生成 split assignment、cache manifest、compatible index、run manifest；检查计数（train/val/test、MANO/RL）、sequence disjoint、variant disjoint、所有 entry 路径可读。
5. 运行现有 dataset/index probe（不启动训练）；随后仅进行可视化所需的只读抽样检查。Cm 训练与未来 decoder 作为后续独立计划。

工程验证的结论最多为 `SUPPORTED`（数据合同与转换 wiring 通过）；不能据此宣称 Cm 表征或跨 embodiment 解码效果成立。

## 6. 运行入口（草案）

```bash
python src/task/ObjectInteractionCm/tools/data/build_dexplore_rl_cache.py \
  --mode pilot --sequence s1/airplane_fly_1 \
  --output data/processed_data/object_interaction_cm_dexplore_rl_v1_pilot

python src/task/ObjectInteractionCm/tools/data/build_dexplore_rl_cache.py \
  --mode full \
  --output data/processed_data/object_interaction_cm_dexplore_rl_v1
```

实际输入路径、pilot 序列、采样 seed 和 Dexplore 资产路径必须写入生成的 `run_manifest.json` 与 activity；full 运行不得覆盖已有目录。
