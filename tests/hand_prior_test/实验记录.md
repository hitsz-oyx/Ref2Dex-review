# Hand context pilot（2026-07-15）

## 目的

检验两个逐步假设是否改善 object-hand correspondence：

```text
A  原始 cross-edge 任务
B  A + object-conditioned dense hand heatmap BCE
C  B + HandGlobalEncoder(H) 的 32-D early-fusion context
```

主指标固定为未参与梯度的 `val_clean/cross_edge_random_qfl`；不使用总 loss 或
contact-aux 指标选择模型。

## 受控设置

- 数据：`grab_subset100_initonly_4096_ds4_smoke12`，hand-root Stage 3
- 按 sequence group 划分：4,418 train frame / 517 validation frame，5/1 group
- seed 42，batch size 8，BF16，AdamW，lr `1e-4`，同一 object perturbation
- A/B/C 分别使用 `baseline.yaml`、`hand_heatmap.yaml`、`hand_context.yaml`
- 每个 run 的 config、metadata、JSONL 和 checkpoint 位于
  `outputs/train/correspondence_ptv3_v2_ablation_*_20260715/`

## 结果

| Run | Steps | val random-edge QFL ↓ | val random-edge BCE ↓ | val hand BCE ↓ |
| --- | ---: | ---: | ---: | ---: |
| A | 600 | 0.002116 | 0.106236 | — |
| B | 600 | 0.001974 | 0.101137 | 0.259159 |
| C | 600 | 0.002838 | 0.118085 | 0.272822 |
| B | 1200 | **0.001399** | **0.064734** | 0.254380 |
| C | 1200 | 0.001933 | 0.082743 | **0.234253** |

600-step 下，B 相对 A 将主 QFL 降低约 6.7%。1200-step 下，C 的 hand heatmap BCE
比 B 低约 7.9%，但 random-edge QFL 高约 38.2%。

## 结论

1. 当前权重 `loss_hand_contact_weight=0.005` 的 object-conditioned heatmap 是有效的辅助任务。
2. 当前“直接 broadcast 32-D global context 到每个 hand token”的 C 实现尚未改善 correspondence；
   在此 pilot 上应拒绝该正向假设。
3. 这不是最终统计结论：C 改变了 PTv3 第一层输入宽度，单 seed 的 B/C 比较仍存在初始化与小数据
   划分方差。下一步应使用多个 sequence split/seed，并优先测试 gated/zero-init context fusion，
   再判断 hand global context 的价值。

## Relation feature + paired global-context follow-up（2026-07-15）

在同一 smoke12 split、seed=42、BF16、1200 step 条件下，以 B 的 11-D local
input 为参照，比较 runtime opposite-cloud descriptors：

| Input feature | clean QFL ↓ | clean zero p99 ↓ | clean strong MAE ↓ | hand BCE ↓ | perturbed QFL ↓ |
| --- | ---: | ---: | ---: | ---: | ---: |
| full：distance + query-normal/NN + query-normal/centroid | **0.001399** | **0.193249** | 0.576264 | 0.254380 | **0.001583** |
| none：只保留 xyz/type/normal | 0.001409 | 0.198034 | 0.570620 | 0.241638 | 0.001606 |
| nearest distance only | 0.001682 | 0.229662 | **0.547316** | **0.222174** | 0.001889 |

`none` 在第一轮 553 step 的 QFL 为 0.005297，而 full-B 的同阶段为
0.001974；虽然到 1200 step 基本追平，显式 hand-object relation feature 显著加快了
优化。只保留距离会改善强正例和 dense heatmap，却明显提高近而不接触的 zero false
positive。因此三个 feature 不应称为“额外 token”：它们是附着在已有 hand/object point
token 上的 3 个 runtime 几何标量；法向/整体朝向通道主要承担零边校准。

尝试以最近对侧 normal-facing score 替代 centroid channel 的 `nn_surface` 在 553 step
取得 clean QFL 0.016474，远差于上述全部设置，故在该数据的 normal 约定下暂不继续。

为排除 optional module 初始化改变 DropPath RNG 的干扰，`late_gated` 全局手姿态分支会在
构建其额外模块后恢复 RNG；B/D 的 shared backbone/head 与随后随机训练流一致。严格配对
的 600-step 结果为：

| Variant | clean QFL ↓ | zero p99 ↓ | strong MAE ↓ | hand BCE ↓ | perturbed QFL ↓ |
| --- | ---: | ---: | ---: | ---: | ---: |
| B, heatmap | **0.002166** | **0.224463** | 0.544816 | 0.254263 | **0.002391** |
| D, hand-only late-gated global context | 0.002181 | 0.228125 | **0.539983** | **0.251269** | 0.002443 |

此时 D 的 gate 仅为 `-0.00716`。它改善了强正例与 heatmap，却没有改善主 QFL，并轻微恶化
zero false positive 和 perturbation。结合早先 C 的 early-concat 结果，应拒绝“将 pooled
whole-hand context broadcast 到所有 hand token 会提升 correspondence”的正向假设；但不能
据此得出手部先验无用。更合理的下一假设是：保留 full local relation feature，并将 MANO
canonical position / finger / region 作为**逐点** anatomy prior（而非整手 pooled bias），同时用
zero-edge constrained 指标评估是否在固定 false-positive 预算内提高强接触预测。

## Hand-pose prior data probe（2026-07-15）

在尝试更多 global fusion 前，先测试数据中是否存在可迁移的 H-only prior。新增
`analyze_hand_pose_prior.py`：它只读取 `hand_points - hand_cano_points` 的 surface-pose
signature，不读 object point / normal / distance；target 为 per-finger contact topology 和固定
surface anchors 的 dense heatmap。左、右手分开，所有 split 均按完整 sequence。

先前 smoke12 的任意 sequence holdout 未显示出 H-only 预测优于均值。更有意义的 full-data
检验在 `grab_subset100_initonly_4096_ds4_hand_root` 上进行：对每个有至少两条轨迹的
`(object_name, side)`，留出一整条 sequence、以同 object+side 的其他 sequence 训练；共 44
组、4,332 held-out frame。基线是该 object+side 的训练接触均值，故已经控制 object identity。

| H-only pose probe（64 surface anchors，train-fitted PCA 16D） | object-conditional mean MSE ↓ | pose-kNN MSE ↓ | kNN 相对均值 |
| --- | ---: | ---: | ---: |
| per-finger topology | **0.073496** | 0.088255 | -20.1% |
| anchor heatmap | **0.073537** | 0.086974 | -18.3% |

raw 192-D residual 与 PCA-16 的结论一致；线性 ridge 也没有收益。虽然 pose-kNN 优于随机
target match，且约 43% topology group 能击败各自均值，但 aggregate 上没有 H-only generalizable
prior。这个负结果不等价于“手姿态不重要”：绝对接触取决于相对于 hand 的 object pose/geometry，
而该 probe 尚未给模型 object geometry。因此当前证据拒绝的是
`P(contact topology | H)` 或 `P(contact topology | H, object identity)` 的强假设；下一步应测试
`P(C_ij | local H-O geometry, H-global)` 的条件残差，而不是再次 broadcast 一个无条件 global bias。

## Edge-conditioned hand-pose residual（2026-07-16）

针对上节的条件假设，新增 `edge_residual` fusion。它**不改变** B 的 11-D PTv3 输入、backbone 或
原始 local edge logit，而是在最后加入零初始化的逐边修正：

```text
logit_ij = logit_local_ij + Δ(edge_shared_ij, a_j, g_hand)
```

其中 `a_j` 是 HandGlobalEncoder 在该被选中 hand surface point 的 64-D anatomy/pose feature，
`g_hand` 是 pooled 32-D whole-hand context。`Δ` 的最后一层 weight/bias 均为零，因此 step 0 的
每一个 edge logit 与 B 精确相同；额外模块构建后恢复 CPU RNG，避免它改变 B 的后续 DropPath 随机流。

为避免把“有更多参数/有逐点 anatomy”误认为“whole-hand pose prior”，在同一 smoke12、seed=42、
BF16、600 step 设置下运行四个版本。表中 B 是这次代码版本重新运行的参照，所有数值取末次
step-600 clean/perturbed validation；这是单 seed pilot，不能替代多 split/seed 结论。

| Variant | clean QFL ↓ | clean zero P99 ↓ | clean nonzero MAE ↓ | clean strong MAE ↓ | hand BCE ↓ | perturbed QFL ↓ |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| B：local edge head | 0.0022810 | 0.2334890 | **0.1510641** | **0.5359985** | **0.2483803** | 0.0025154 |
| local residual, `g_hand=0` | 0.0022520 | 0.2278305 | 0.1514208 | 0.5412452 | 0.2530351 | 0.0024565 |
| local residual + matched `g_hand` | 0.0021547 | 0.2254533 | 0.1516310 | 0.5424897 | 0.2496412 | 0.0023821 |
| local residual + batch-rolled `g_hand` | **0.0019972** | **0.2121566** | 0.1532670 | 0.5576001 | 0.2600613 | **0.0022210** |

对应输出目录：

- `outputs/train/correspondence_ptv3_v2_ablation_edge_residual_baseline_600_20260716_rerun`
- `outputs/train/correspondence_ptv3_v2_ablation_edge_residual_zero_600_20260716`
- `outputs/train/correspondence_ptv3_v2_ablation_edge_residual_matched_600_20260716_rerun`
- `outputs/train/correspondence_ptv3_v2_ablation_edge_residual_batch_roll_600_20260716_rerun`

这里的 `batch_roll` 只打乱 `g_hand`；同一个 edge 的 local geometry、selected point 的 `a_j`、模型容量和
训练目标完全不变。`g_hand=0` 进一步去除了 pooled context，故能把局部 anatomy residual 与 whole-hand
information 区分开。

### 解释与下一步

1. `g_hand=0` 相比 B 的 QFL/P99 有小幅下降，但 nonzero/strong MAE 和 heatmap 变差：逐点 anatomy
   residual 有价值，不过它把模型推向更保守的 zero calibration，牺牲强接触幅值。
2. matched `g_hand` 相比 `g_hand=0` 的 QFL、P99、hand BCE 和 perturbation 都有小幅改善，但强接触
   MAE 没有改善；证据不足以接受“whole-hand pose 是强且可直接使用的先验”。
3. 更关键地，rolled `g_hand` 的 QFL/P99 最低，却将 strong MAE 从 0.5425 恶化到 0.5576、nonzero MAE
   从 0.1516 恶化到 0.1533。这不是正确 hand pose 带来的收益，而是残差分支在极不均衡目标上更保守/
   近似忽略全局向量后得到的 zero-edge 优势。

因此目前不应把 `g_hand` 直接作为全局加性 bias 用于长训。若继续验证它的细小正例信息，应将残差限制为
只在 local model 已认为可能接触的 edge 上起作用，例如
`logit = logit_local + sigmoid((logit_local - t)/T) * Δ(...)`，并同时报告固定 zero-P99 预算下的
strong/nonzero MAE；这可以检验 global pose 是否只在候选接触区域有条件增益，而不让它污染大量 zero edges。

## Full-data clean warm-start probe（2026-07-16）

600-step smoke12 只有约一个 epoch，且验证仅含一条 sequence，不能回答 whole-hand context 是否只是学习太慢。
因此在 hand-root full data（12,407 frames、sequence-group validation）上，从同一个兼容 B step-600
模型 checkpoint 出发运行 `g_hand=0` 与 matched `g_hand`。两组的 residual 均为零初始化，前 1,000 step
冻结 B、随后联合微调至 5,000 step；BF16、seed 42、cosine restart `3e-5 -> 3e-6`。

为避免磁盘与中途恢复影响公平性，最终采用 clean rerun：每 1,000 step 只记录验证 scalar，checkpoint 只在
完整 epoch 边界写入且每个 run 最多保留两个。两组均完整结束，无写入失败。

| Checkpoint time | Variant | clean QFL ↓ | zero P99 ↓ | nonzero MAE ↓ | strong MAE ↓ | perturbed QFL ↓ |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| step 3,000 | `g_hand=0` | 0.0016158 | **0.1779334** | 0.1672827 | 0.6364910 | 0.0018226 |
| step 3,000 | matched `g_hand` | **0.0015762** | 0.1800275 | **0.1667271** | **0.6324428** | **0.0017850** |
| step 5,000 | `g_hand=0` | **0.0017764** | **0.2210954** | **0.1543671** | **0.5831983** | **0.0019577** |
| step 5,000 | matched `g_hand` | 0.0018702 | 0.2244404 | 0.1545299 | 0.5836295 | 0.0020514 |

step 3,000 时 matched 对正例与 QFL 有小幅优势，但付出约 0.0021 的 zero-P99；到训练终点该优势没有保持，
`g_hand=0` 在表中所有五项指标都更好。这个结果与 H-only probe 一致：whole-hand pose 可能含有很弱的
条件信息，但当前直接的 additive edge residual 没有产生稳定、可长训利用的收益。因此目前拒绝
“直接将 pooled `g_hand` 加入每条 edge logit”的正向假设；若继续，应只测试由 local candidate score
显式门控的 `g_hand` residual，而不是将此分支加入主线长训。

clean outputs：

- `outputs/train/correspondence_ptv3_v2_global_prior_full_zero_clean_5k_20260716`
- `outputs/train/correspondence_ptv3_v2_global_prior_full_matched_clean_5k_20260716`
