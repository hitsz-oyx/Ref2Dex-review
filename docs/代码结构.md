# Ref2Dex 代码结构文档

## 一、整体 Pipeline 概览

```
原始资产 (GRAB / ARCTIC)
    │
    ▼
Stage 1: 数据预处理 ──→ processed_data/
    │   (grab_preprocess.py / arctic_preprocess.py)
    │
    ▼
Stage 2: MANO 拟合 ──→ outputs/mano_fit/
    │   (mano_smplx_fit.py)
    │
    ▼
Stage 3: 静态 Correspondence 训练数据 ──→ outputs/train_corr_static/
    │   (prepare_corr_static.py)
    │
    ▼
模型训练 / 评估 ──→ outputs/train/
    (correspondence_ptv3)
```

## 二、Stage 1 — 数据预处理

### 2.1 脚本位置

- `process/preprocess/grab_preprocess.py` — GRAB 数据集
- `process/preprocess/arctic_preprocess.py` — ARCTIC 数据集

### 2.2 处理流程

```
原始 GRAB .npz 序列文件
    │
    ├── 1. 解析原始 GRAB npz（包含 rhand/object 参数）
    ├── 2. SMPLX/MANO forward 生成手顶点 (778) 和 face-center 采样点 (1538)
    ├── 3. 对物体网格均匀采样 2048 个表面点
    ├── 4. 计算双向 KNN：
    │       obj_points <-> hand_points（每帧独立）
    ├── 5. 统计接触帧（距离 < 接触阈值）
    └── 6. 保存为单文件 .npz（含双手所有字段）
```

### 2.3 输出格式（Stage 1）

每条序列输出一个 `.npz`，字段示例：

```python
{
    "seq_id": "s1/airplane_pass_1",          # str
    "frame_id": (T,) int,                     # 原始帧索引

    # 物体（每一帧）
    "obj_points": (T, 2048, 3),               # 物体表面点 world 坐标
    "obj_normals": (T, 2048, 3),             # 物体法向
    "obj_point_id": (2048,) int,             # 原始顶点 ID（用于跨帧追踪）
    "obj_root_pose": (T, 4, 4),               # 物体 world 变换矩阵
    "obj_flow": (T, 2048, 3),                 # 物体表面 flow（ARCTIC 铰接体用）

    # 右手（face-center 采样 1538 点）
    "right_hand_points": (T, 1538, 3),
    "right_hand_normals": (T, 1538, 3),
    "right_hand_finger_id": (1538,) int,     # 0-4: 拇指/食指/中指/无名指/小指
    "right_hand_region_id": (1538,) int,     # 0-5: 手掌分区
    "right_hand_cano_points": (T, 1538, 3),  # canonical MANO 模板坐标
    "right_hand_joint_axis_angle": (T, 15, 3),
    "right_hand_joint_quat": (T, 16, 4),     # 世界系 16 关节四元数 [w,x,y,z]
    "right_hand_verts": (T, 778, 3),         # MANO 模板顶点
    "right_hand_valid": (T,) bool,            # 3cm 接触掩码
    "right_hand_to_obj_nn_id": (T, 1538),    # 每帧: hand[i] -> 最近 obj 点 ID
    "right_hand_to_obj_dist": (T, 1538),     # hand 到最近 obj 点的距离

    # 双向 NN（跨类型）
    "obj_to_right_hand_nn_id": (T, 2048),    # obj[i] -> 最近 right_hand 点 ID
    "obj_to_right_hand_dist": (T, 2048),
}
```

**元数据文件**：`processed_data/<dataset>/meta.json`，记录数据源路径、采样参数等。

## 三、Stage 2 — MANO 优化拟合

### 3.1 脚本位置

- `process/opti/mano_smplx_fit.py` — 核心 MANO fitting 脚本
- `process/opti/run_mano_fit_batch.py` — 批量提交 jobs

### 3.2 处理流程

```
Stage 1 .npz 文件
    │
    ├── 1. 读取 Stage 1 的mano参数 + 物体网格
    ├── 2. 构建 SDF 网格（object_sdf_grid.py，网格分辨率可配置）
    ├── 3. 优化变量：global_orient + hand_pose + transl + betas
    ├── 4. 优化目标：
    │       - 关节先验损失
    │       - shape 先验损失
    │       - SDF 穿透惩罚（可选）
    │       - 几何对应损失（contact point 匹配）
    ├── 5. 多轮重启动（repetition），保留最优结果
    └── 6. 保存 .pkl（用于 Stage 3 读取）
```

### 3.3 输出格式（Stage 2）

```
outputs/mano_fit/<dataset>_<suffix>/<subject>/<seq>_<side>.pkl
```

每个 `.pkl` 包含：
- `opt_hand_verts`: 优化后的手顶点 (T, 778, 3)
- `opt_hand_joint_*`: 优化后的关节参数
- `opt_hand_cano_points`: 优化后的 canonical 手点 (T, 1538, 3)
- `opt_obj_*`: 优化后每帧 obj 相关信息
- `fitting_err`: 拟合误差统计

**元数据文件**：`outputs/mano_fit/<dataset>_<suffix>/meta.json`

## 四、Stage 3 — 静态 Correspondence 训练数据

### 4.1 脚本位置

- `process/train/prepare_corr_static.py`

### 4.2 处理流程

```
Stage 2 pkl 文件 + Stage 1 npz 文件
    │
    ├── 1. 读取优化后的手/物几何
    ├── 2. 以物体为中心裁剪：只保留 8cm 接触区域内的点
    ├── 3. 接触区域均衡采样：256 个 near 点 + 256 个 context 点（共 512）
    │       - near: 距离 < 3cm 的点
    │       - context: 3-8cm 内的点
    ├── 4. 生成 GT contact label（soft distance decay）：
    │       label = 1 if d <= 5mm
    │             = ((1-(d-5mm)/(30mm-5mm))^2) if 5mm < d < 30mm
    │             = 0 if d >= 30mm
    ├── 5. 生成 KNN 图（stage3 实时计算，不预存）：
    │       - hand_local_knn_idx (K=16, 同类型 hand 内部)
    │       - obj_local_knn_idx (K=16, 同类型 obj 内部)
    │       - hand_to_obj_knn_idx (K=32, hand -> obj 跨类型)
    ├── 6. 转为以物体为原点的坐标系
    └── 7. 保存单帧单手 .npz
```

### 4.3 输出格式（Stage 3）

每帧每手一个 `.npz`，典型字段：

```python
{
    # 坐标框架（网络输入 = 物体原点系）
    "points": (2050, 3),         # obj_points(512) + hand_points(1538)
    "normals": (2050, 3),        # obj_normals + hand_normals
    "point_type_id": (2050,) int, # 0=obj, 1=hand
    "point_valid_mask": (2050,) bool,

    # Canonical 对应（网络输入）
    "hand_cano_points": (1538, 3), # MANO 模板空间坐标（仅 hand 位置有值）

    # GT 标签（来自优化后的 clean 手）
    "obj_contact_label": (512,) float, # soft label (0~1)
    "obj_label_valid_mask": (512,) bool,
    "obj_to_hand_nn_id": (512,) int,   # obj[i] -> 最近 hand 点
    "obj_to_hand_cano_points": (512, 3), # 对应 hand 的 canonical 坐标
    "obj_to_hand_finger_id": (512,) int,
    "obj_to_hand_region_id": (512,) int,

    # 调试/辅助
    "T_world_from_obj": (4, 4) float,  # world <- obj 变换矩阵
    "gt_points": (2050, 3),             # GT clean 几何（与 points 相同）
}
```

**注意**：Stage 3 **不预存 KNN**（`obj_local_knn_idx` / `hand_local_knn_idx` / `hand_to_obj_knn_idx`），而是在 dataset 加载时**实时计算**，允许动态增强后重新 KNN。

**元数据文件**：`outputs/train_corr_static/<dataset>/meta.json`，记录：
- 坐标系策略（网络输入 = 物体原点系）
- 点数配置（512 obj + 1538 hand）
- contact label 公式参数
- KNN 生成策略

## 五、模型训练与评估

### 5.1 代码位置

```
src/task/correspondence_ptv3/
├── config.py      # 超参数配置
├── model.py       # 模型架构 (StaticHOCPTv3)
├── dataset.py     # 数据加载 + 增强
├── runner.py      # 训练/评估逻辑 + Loss 计算
├── train.py       # 训练入口
└── eval.py        # 评估入口
```

### 5.2 模型架构 (StaticHOCPTv3)

整体是 **Object-Centric PTv3 Backbone + Cross Interaction**：

```
输入: points + normals + hand_cano_points
  │
  ├── Stem: obj_stem([xyz, n]) -> 96D
  │         hand_stem([xyz, n, hand_cano]) -> 96D
  │
  ├── PTV3DenseBackbone: 加载自 /home/oyx/test_ws/PointTransformerV3
  │   - 多层 PointTransformer Encoder-Decoder
  │   - 输出: per-point 96D tokens
  │
  ├── Object Cross Interaction（核心）
  │   - 对每个 obj 点 token z_obj[i]，通过 Cross Attention 聚合 hand context
  │   - q = obj token
  │   - k/v = hand neighbor tokens + 几何 edge 特征 + hand_cano_embed
  │   - 输出: cross-enriched obj tokens
  │
  ├── Heads:
  │   ├── contact_head: obj_cross_token -> sigmoid(contact_prob)
  │   ├── finger_head: obj_cross_token -> finger_id (分类, 可选)
  │   ├── region_head: obj_cross_token -> region_id (分类, 可选)
  │   └── cross_edge_head: edge_feature -> contact_on_cross_edge (边分类)
  │
  └── 输出: pred_obj_contact, pred_obj_to_hand_cano, pred_cross_contact
```

### 5.3 Loss 函数

| Loss | 方向 | 说明 |
|------|------|------|
| `obj_contact` | obj → hand | 每个 obj 点预测是否接触（soft BCE，GT 来自 clean 手） |
| `obj_cano` | obj → hand | 预测 obj 点对应 hand 的 canonical 坐标（SmoothL1） |
| `obj_finger` | obj → hand | 预测手指 ID（CE，可选） |
| `obj_region` | obj → hand | 预测手掌区域 ID（CE，可选） |
| `cross_edge_contact` | hand → obj | hand 点对周围 K 个 obj 点的接触预测（soft BCE，GT 来自增强后输入） |

**Oracle BCE**：label 本身的熵作为下界，`excess = actual - oracle` 用于监控模型学习效率。

### 5.4 数据增强

| 增强 | 目标 | 参数 |
|------|------|------|
| 手部扰动 | 模拟 GT 手位置不确定性 | rot_std=10°, trans_std=1cm, prob=1.0 |
| 全局旋转 | 旋转不变性 | range=180° |
| 全局平移 | 平移不变性 | range=0.1m（默认关闭） |
| 全局缩放 | 尺度不变性 | range=(0.9, 1.1)（默认关闭） |
| 重新计算 KNN | 增强后动态更新邻居 | recompute_input_cross_knn=True |

### 5.5 训练入口

```bash
python src/task/correspondence_ptv3/train.py \
    --config src.task.correspondence_ptv3.config:Config \
    --data /path/to/outputs/train_corr_static/<dataset>/ \
    --output-dir outputs/train/correspondence_ptv3_<exp_name> \
    --set meta.hand_rot_std_deg=10.0 \
          meta.hand_trans_std=0.01 \
          meta.recompute_input_cross_knn=True \
          train.epochs=100 \
          train.lr=1e-4
```

### 5.6 评估入口

```bash
python src/task/correspondence_ptv3/eval.py \
    --checkpoint outputs/train/<exp_name>/checkpoints/best.pt
```
