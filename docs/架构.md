# Ref2Dex 静态 Correspondence 整体流程

## 1. 总体流向

```text
原始数据集
-> Stage 2: 各数据集独立的 opti / hand preparation 脚本
-> Stage 2 公共格式:
   processed_data/generated/stage2/<dataset_variant>/<subject>/<seq>_<side>.pkl
-> Stage 3:
   processed_data/generated/stage3/<dataset_variant>/<subject>/<seq>_<side>.npz
-> 训练时按 epoch 从物体点池重采样 512 点
-> noisy-hand KNN / label / mask 在 dataloader 中生成
-> correspondence_ptv3
```

不再生成独立的 Stage 1 中间数据集。

每类数据集直接从原始数据读取，由自己的 opti 脚本完成：

```text
原始字段解析
-> 坐标和单位统一
-> 物体表面固定采样
-> 左右手拆分
-> MANO 重建或可选优化
-> 输出统一的 Stage 2 schema
```

当前训练版本约定：

```text
1. Stage 2 / Stage 3 文件单位：single_sequence_single_hand
2. 训练样本单位：single_frame_single_hand
3. GRAB 当前使用 init-only hand，不执行接触优化
4. Stage 2 保存完整 4096 个物体表面点
5. Stage 2 直接滤除整只手到物体最近距离大于 5cm 的帧
6. Stage 3 保存完整物体点池，不提前固定训练使用的 512 点
7. Stage 3 的 clean object-hand KNN 落盘，用于监督和可视化
8. 每个 epoch 从 5cm 候选池确定性随机采样 512 个物体点
9. 训练输入：clean object + noisy hand
10. 训练监督：clean object + clean hand
11. cross 方向：object -> hand
```

## 2. Stage 2：数据集独立的 opti / hand preparation

### 2.1 路径

```text
raw dataset
-> process/<DATASET>/optimize.py
-> processed_data/generated/stage2/<dataset_variant>/<subject>/<seq>_<side>.pkl
```

不同数据集使用独立脚本，例如：

```text
GRAB   -> process/GRAB/optimize.py
ARCTIC -> process/ARCTIC/optimize.py
```

脚本实现可以不同，但必须输出相同的 Stage 2 公共字段。

### 2.2 作用

```text
1. 直接读取原始数据集
2. 统一长度单位为 meter
3. 统一坐标和法向定义
4. 把左右手拆成独立样本
5. 在原始物体 mesh 上固定采样 4096 个表面点
6. 重建 MANO hand，或按数据集需要执行优化
7. 计算每帧整只手到物体的最近距离，直接滤除距离大于 5cm 的帧
8. 输出完整物体点和 clean hand
9. 保存数据来源、处理模式和质量诊断
```

GRAB 当前配置：

```python
processing_mode = "init_only"
```

`init_only` 表示直接使用原始 GRAB MANO 重建结果，不执行 contact / repulsion
优化。Stage 2 仍保留为数据集适配层，负责左右手拆分和公共 schema 输出。

### 2.3 物体 4096 点采样约定

```text
1. 在每个物体的原始 mesh 表面做均匀面积采样
2. 每个物体只生成一套固定的 4096 个 sample
3. 同一物体的所有序列和所有帧共享 sample identity
4. 刚体物体只变换 sample 坐标和法向
5. 铰接物体按固定 sample identity 随 mesh 变形
6. obj_point_id 表示这套预采样点的稳定 id，不等价于 mesh vertex id
```

采样必须使用稳定 seed，并在 Stage 2 meta/config 中保存 seed 和采样策略。

### 2.4 Stage 2 公共字段

```python
stage2_seq = {

    "schema_version": str,

    "dataset_name": str,
    "seq_id": str,                       # "{subject_id}/{seq_name}"
    "subject_id": str,
    "seq_name": str,
    "object_name": str,
    "side": str,                         # "left" 或 "right"

    # ------------------------------------------------------------
    # 2. 帧索引
    # ------------------------------------------------------------
    "raw_frame_id": Int[T_stage2],       # 原始数据集帧号
    "stage2_frame_idx": Int[T_stage2],   # Stage 2 文件内部帧号

    # ------------------------------------------------------------
    # 3. 完整物体点，世界坐标
    # ------------------------------------------------------------
    "obj_points_world": Float[T_stage2, 4096, 3],
    "obj_normals_world": Float[T_stage2, 4096, 3],
    "obj_point_id": Int[4096],           # 固定表面 sample id，通常为 0..4095
    "obj_root_pose": Float[T_stage2, 4, 4],  # object root -> world

    # ------------------------------------------------------------
    # 4. 当前单手 clean geometry，世界坐标
    # ------------------------------------------------------------
    "hand_points_world": Float[T_stage2, 1538, 3],   # MANO face centers
    "hand_normals_world": Float[T_stage2, 1538, 3],
    "hand_point_id": Int[1538],                      # 固定 MANO face id

    # ------------------------------------------------------------
    # 5. 手部 canonical / topology
    # ------------------------------------------------------------
    "hand_cano_points": Float[1538, 3],
    "hand_finger_id": Int[1538],
    "hand_region_id": Int[1538],

    # ------------------------------------------------------------
    # 6. 帧筛选诊断
    # ------------------------------------------------------------
    "frame_min_hand_obj_dist": Float[T_stage2],  # meter，所有保存帧均 <= 0.05

    # ------------------------------------------------------------
    # 7. 质量诊断
    # ------------------------------------------------------------
    "penetration_depth": Float[T_stage2], # meter；允许使用近似指标，但需在 config 注明
    "processing_success": Bool[T_stage2],
    "processing_message": List[str],

    # ------------------------------------------------------------
    # 8. 可复现配置
    # ------------------------------------------------------------
    "config": Dict,                       # MANO、采样、优化及阈值配置
}
```

Stage 2 在写文件前已经完成 5cm 帧筛选，因此不再保存 `hand_valid`。这里的
`frame_min_hand_obj_dist` 是每帧一个标量；Stage 3 的
`obj_to_hand_min_dist` 是每个物体点一个标量，两者不可混用。

`hand_cano_normals` 不保存。当前模型仅把 `hand_cano_points` 注入手部 stem 和
cross-attention；canonical 法向既不作为输入，也没有对应监督用途。

如果某个数据集执行了真实优化，可以额外保存：

```python
optional_optimization_fields = {
    "init_hand_points_world": Float[T_stage2, 1538, 3],
    "init_hand_verts_world": Float[T_stage2, 778, 3],
    "hand_verts_world": Float[T_stage2, 778, 3],
    "init_jt_rms": Float[T_stage2],
    "final_jt_rms": Float[T_stage2],
    "init_vert_rms": Float[T_stage2],
    "final_vert_rms": Float[T_stage2],
    "final_loss": Float[T_stage2],
}
```

这些是优化审计字段，不是 Stage 3 的必需输入。

### 2.5 Stage 2 不保存的字段

```text
1. 不保存 object-frame 几何；Stage 3 用 obj_root_pose 统一转换
2. 不保存 object crop；Stage 2 始终保留完整 4096 点
3. 不保存 obj->hand 1NN / KNN；Stage 3 统一计算
4. 不保存 hand->obj NN
5. 不保存训练 contact label
6. 不保存训练期随机采样的 512 点
```

## 3. Stage 3：静态 Correspondence 点池

### 3.1 路径

```text
processed_data/generated/stage2/<dataset_variant>/<subject>/<seq>_<side>.pkl
-> process/stage3/prepare_corr_static.py
-> processed_data/generated/stage3/<dataset_variant>/<subject>/<seq>_<side>.npz
```

### 3.2 作用

```text
1. 读取 Stage 2 已经通过 5cm 整帧筛选的数据
2. 把完整 object 和 clean hand 转换到 object frame
3. 保留完整 4096 个 object points
4. 计算每个 object point 到 clean hand 的最小距离
5. 生成 5cm object candidate mask
6. 为 5cm candidate points 计算并保存 clean obj->hand KNN
7. 为按 epoch 重采样和可视化提供确定的 clean 数据
```

Stage 3 不提前选择最终训练使用的 512 个 object points。

### 3.3 点数和阈值

```python
N_obj_pool = 4096
N_obj_train = 512
N_hand = 1538
K_cross = 32
N_runtime_total = N_obj_train + N_hand  # 2050

obj_candidate_threshold = 0.05          # meter
contact_d_pos = 0.005
contact_d_neg = 0.03
contact_gamma = 2.0
```

5cm candidate 定义：

```python
obj_to_hand_min_dist[i] = min_j ||obj_point[i] - clean_hand_point[j]||
obj_candidate_mask_5cm[i] = obj_to_hand_min_dist[i] <= 0.05
```

`3cm < distance <= 5cm` 的点保留在候选池中，但 contact soft label 为 0，
因此自然形成接触区域周围的负样本，不再做人为 near/context 均衡采样。

### 3.4 Stage 3 落盘字段

```python
stage3_seq = {

    # 1. 来源和样本索引
    # ------------------------------------------------------------

    "schema_version": str,

    "processing_mode": str,              # 当前为 "init_only"
    "dataset_name": str,
    "seq_id": str,
    "subject_id": str,
    "seq_name": str,
    "object_name": str,
    "side": str,
    "raw_frame_id": Int[T_train],
    "stage2_frame_idx": Int[T_train],

    # ------------------------------------------------------------
    # 2. 完整 object pool，object frame
    # ------------------------------------------------------------
    "obj_points": Float[T_train, 4096, 3],
    "obj_normals": Float[T_train, 4096, 3],
    "obj_point_id": Int[4096],

    # ------------------------------------------------------------
    # 3. clean hand，object frame
    # ------------------------------------------------------------
    "hand_points": Float[T_train, 1538, 3],
    "hand_normals": Float[T_train, 1538, 3],
    "hand_point_id": Int[1538],
    "hand_cano_points": Float[1538, 3],
    "hand_finger_id": Int[1538],
    "hand_region_id": Int[1538],

    # ------------------------------------------------------------
    # 4. 5cm 候选池
    # ------------------------------------------------------------
    "obj_to_hand_min_dist": Float[T_train, 4096],
    "obj_candidate_mask_5cm": Bool[T_train, 4096],

    # ------------------------------------------------------------
    # 5. clean GT KNN
    # ------------------------------------------------------------
    "gt_obj_to_hand_knn_idx": Int16[T_train, 4096, K_cross],
    # 对每个 5cm candidate point，按 clean 欧氏距离从近到远保存 hand local index。
    # 有效 index 范围为 0..1537；非 candidate 行全部填 -1。

    # ------------------------------------------------------------
    # 6. 可视化和调试
    # ------------------------------------------------------------

```

`gt_obj_to_hand_knn_idx` 使用 `int16` 即可容纳 `-1..1537`。读取到
PyTorch 后统一转为 `torch.long`。

不落盘完整 KNN distance。可视化或检查时根据：

```python
obj_points
hand_points
gt_obj_to_hand_knn_idx
```

重新计算选中边的距离。只单独保存用于候选筛选和 contact label 的
`obj_to_hand_min_dist`。

### 3.5 Stage 3 不落盘的字段

```python
not_saved_in_stage3 = {

    "points": None,

    "edge_normal_dot": None,

```

### 3.6 Stage 3 数据检查

每个 Stage 3 文件至少检查：

```text
1. 所有坐标和法向均为 finite
2. obj_point_id 在同一物体上稳定
3. obj_candidate_mask_5cm 与 obj_to_hand_min_dist <= 0.05 完全一致
4. candidate 行的 gt_obj_to_hand_knn_idx[..., 0] 对应真实最近 clean hand point
5. KNN index 范围为 -1 或 [0, 1537]
6. KNN 按距离非递减排序
7. T_world_from_obj 能把 object-frame 几何还原到 Stage 2 world frame
```

## 4. 训练时按 epoch 重采样

### 4.1 epoch seed

每个训练样本的 object 采样 seed：

```text
seed = stable_hash(
    base_seed,
    seq_id,
    side,
    raw_frame_id,
    epoch,
)
```

不能只使用 `raw_frame_id + epoch`，因为不同 subject / sequence / side 可能有
相同帧号。

必须使用稳定哈希，例如 BLAKE2；不能直接使用受
`PYTHONHASHSEED` 影响的 Python `hash()`。

训练集每轮开始前：

```python
train_dataset.set_epoch(epoch)
```

验证集固定：

```python
val_dataset.set_epoch(0)
```

验证集不随训练 epoch 改变采样点，也不启用随机 hand perturb。

Stage 3 的单个 sequence npz 包含较大的 KNN 数组。训练默认先随机打乱 sequence
顺序，再在单个 sequence 内打乱帧顺序，以避免全局随机帧顺序导致每个 sample
都重新解包另一个 npz。若确实需要全局 `RandomSampler`，可设置：

```python
data.sequence_locality_shuffle = False
```

### 4.2 512 点选择

对一帧：

```python
candidate_idx = nonzero(obj_candidate_mask_5cm)
```

如果候选点不少于 512：

```python
selected_obj_idx = random_choice(
    candidate_idx,
    size=512,
    replace=False,
    seed=frame_epoch_seed,
)
runtime_obj_valid_mask = ones(512)
```

如果候选点少于 512：

```python
selected_obj_idx[:num_candidates] = deterministic_shuffle(candidate_idx)
selected_obj_idx[num_candidates:] = -1
runtime_obj_valid_mask[:num_candidates] = True
runtime_obj_valid_mask[num_candidates:] = False
```

padding 约定：

```text
1. padding 坐标和法向填 0
2. padding point id 填 -1
3. padding clean KNN index 填 -1
4. 所有 object-level / edge-level loss 必须乘 runtime_obj_valid_mask
5. 不使用有放回采样，不复制真实点
```

### 4.3 runtime 几何

先从 Stage 3 完整点池中 gather clean object：

```python
safe_selected_obj_idx = selected_obj_idx.clamp(min=0)

clean_obj_points = obj_points[safe_selected_obj_idx]       # [512, 3]
clean_obj_normals = obj_normals[safe_selected_obj_idx]     # [512, 3]
clean_gt_knn_idx = gt_obj_to_hand_knn_idx[safe_selected_obj_idx]  # [512, K]
clean_obj_min_dist = obj_to_hand_min_dist[safe_selected_obj_idx]  # [512]

clean_obj_points[~runtime_obj_valid_mask] = 0
clean_obj_normals[~runtime_obj_valid_mask] = 0
clean_gt_knn_idx[~runtime_obj_valid_mask] = -1
clean_obj_min_dist[~runtime_obj_valid_mask] = 0
```

再保留 clean GT，并只对 input hand 加噪：

```python
gt_obj_points = clean_obj_points
gt_obj_normals = clean_obj_normals
gt_hand_points = hand_points
gt_hand_normals = hand_normals

input_obj_points = clean_obj_points
input_obj_normals = clean_obj_normals
input_hand_points, input_hand_normals = perturb(hand_points, hand_normals)
```

最后拼接模型输入：

```python
points = concat([input_obj_points, input_hand_points], dim=0)  # [2050, 3]
normals = concat([input_obj_normals, input_hand_normals], dim=0)

gt_points = concat([gt_obj_points, gt_hand_points], dim=0)
gt_normals = concat([gt_obj_normals, gt_hand_normals], dim=0)
```

### 4.4 runtime noisy-hand KNN

模型候选边必须基于加噪后的 input hand 重新计算：

```text
query = selected input object points
key   = noisy input hand points
```

```python
input_obj_to_hand_knn_idx:
    Int[B, 512, K_cross]

input_obj_to_hand_knn_valid_mask:
    Bool[B, 512, K_cross]
```

padding object point 的所有 KNN index 填 `-1`，valid mask 填 `False`。

clean KNN 和 input KNN 含义不同：

```text
gt_obj_to_hand_knn_idx:
    clean geometry 的 GT correspondence，来自 Stage 3

input_obj_to_hand_knn_idx:
    noisy geometry 的候选邻域，训练时实时计算
```

## 5. 模型

当前任务的目标是训练 hand-object 交互后的 object dense token。

```text
去噪和 correspondence 监督是训练 dense token 的手段
最终保留 z_obj_cross 作为 object dense token
```

### 5.1 输入特征

```python
obj_raw_i = [
    input_obj_xyz_i,
    input_obj_normal_i,
]                                                     # 6D

hand_raw_j = [
    noisy_hand_xyz_j,
    noisy_hand_normal_j,
    hand_cano_j,
]                                                     # 9D
```

### 5.2 Two-stem

```python
obj_feat = obj_stem(obj_raw)       # [B, 512, hidden_dim]
hand_feat = hand_stem(hand_raw)    # [B, 1538, hidden_dim]
```

padding object points在进入 backbone 前由 `runtime_obj_valid_mask` 屏蔽。

### 5.3 Unified PTv3 backbone

```python
coord = concat([input_obj_points, noisy_hand_points], dim=1)
feat = concat([obj_feat, hand_feat], dim=1)
point_valid_mask = concat([
    runtime_obj_valid_mask,
    ones(B, 1538),
], dim=1)

tokens = PTv3(coord, feat, point_valid_mask)

z_obj = tokens[:, :512]             # [B, 512, token_dim]
z_hand = tokens[:, 512:]            # [B, 1538, token_dim]
```

### 5.4 runtime object-hand edge

对每个 input KNN edge `(object i, noisy-hand neighbor j)`：

```python
delta_ik = noisy_hand_xyz[j] - object_xyz[i]            # [3]
dist_ik = ||delta_ik||                                   # [1]
signed_dist_ik = dot(object_normal[i], delta_ik)         # [1]
normal_dot_ik = dot(object_normal[i], hand_normal[j])    # [1]

edge_geo_ik = [
    delta_ik,
    dist_ik,
    signed_dist_ik,
    normal_dot_ik,
]                                                        # 6D
```

### 5.5 object-centric cross attention

```python
q_i = cross_q(z_obj[i])
k_ik = cross_k([z_hand[j], edge_geo_embed_ik])
v_ik = cross_v([
    z_hand[j],
    edge_geo_embed_ik,
    hand_cano_embed[j],
])
b_ik = cross_bias(edge_geo_ik)

attn_ik = masked_softmax(
    dot(q_i, k_ik) / sqrt(token_dim) + b_ik,
    input_obj_to_hand_knn_valid_mask,
)

cross_ctx_i = sum_k attn_ik * v_ik
z_obj_cross_i = z_obj_i + cross_out(cross_ctx_i)
```

最终：

```python
obj_dense_tokens = z_obj_cross       # [B, 512, token_dim]
hand_dense_tokens = z_hand           # [B, 1538, token_dim]
```

### 5.6 输出 heads

#### Object contact head

```python
pred_obj_contact = contact_head(obj_dense_tokens).squeeze(-1)
# [B, 512]
```

#### Object canonical correspondence head

Cano 由 interaction 后的 object dense token 通过一个 head 输出：

```python
pred_obj_cano = cano_head(obj_dense_tokens)
# [B, 512, 3]
```

它不是 edge-level 的 K 个输出，也不再使用 `pred_cross_cano`。

#### Cross-edge contact head

```python
edge_shared_ik = edge_backbone([
    obj_dense_tokens[i],
    z_hand[j],
    edge_geo_ik,
])

pred_cross_contact_ik = cross_edge_head(edge_shared_ik)
# [B, 512, K_cross]
```

#### Optional finger / region heads

```python
pred_obj_finger = finger_head(obj_dense_tokens)
# [B, 512, num_fingers]

pred_obj_region = region_head(obj_dense_tokens)
# [B, 512, num_regions]
```

### 5.7 模型输出

```python
model_output = {
    "obj_dense_tokens": Float[B, 512, token_dim],
    "hand_dense_tokens": Float[B, 1538, token_dim],
    "ptv3_obj_tokens": Float[B, 512, token_dim],

    "pred_obj_contact": Float[B, 512],
    "pred_obj_cano": Float[B, 512, 3],
    "pred_cross_contact": Float[B, 512, K_cross],
    "obj_to_hand_attn": Float[B, 512, K_cross],

    "pred_obj_finger": Float[B, 512, num_fingers],   # optional
    "pred_obj_region": Float[B, 512, num_regions],   # optional
}
```

## 6. 训练监督和 Loss

### 6.1 Object contact target

对 epoch 选中的 object 点：

```python
obj_contact_label = soft_contact_label(
    selected_obj_min_dist,
    d_pos=0.005,
    d_neg=0.03,
    gamma=2.0,
)
```

padding 点标签填 0，并由 `runtime_obj_valid_mask` 屏蔽。

### 6.2 Cano target

每个 object 点使用 clean GT KNN 的 rank-0 hand point：

```python
gt_hand_idx = gt_obj_to_hand_knn_idx[..., 0]       # [B, 512]
target_obj_cano = gather(hand_cano_points, gt_hand_idx)
# [B, 512, 3]
```

有效 mask：

```python
corr_valid_mask =
    runtime_obj_valid_mask
    & (gt_hand_idx >= 0)
    & (obj_contact_label > corr_contact_label_min)
```

当前：

```python
corr_contact_label_min = 0.1
```

### 6.3 Dynamic cross-edge contact target

cross-edge target 不按 clean KNN rank 对齐，而是使用 noisy input KNN 的实际
hand index，到 clean hand geometry 中取对应点：

```python
edge_hand_idx = input_obj_to_hand_knn_idx
clean_edge_hand_points = gather(gt_hand_points, edge_hand_idx)

edge_dist = ||clean_edge_hand_points - gt_obj_points||
edge_contact_label = soft_contact_label(
    edge_dist,
    d_pos=0.005,
    d_neg=0.03,
    gamma=2.0,
)
```

这保证：

```text
候选邻域来自 noisy hand
监督距离来自 clean hand
```

### 6.4 Object contact loss

```python
loss_obj_contact =
    BCEWithLogits(
        pred_obj_contact,
        obj_contact_label,
        weight=runtime_obj_valid_mask,
        reduction="sum",
    )
    / sum(runtime_obj_valid_mask)
```

### 6.5 Object cano loss

```python
cano_diff = SmoothL1(
    pred_obj_cano,
    target_obj_cano,
    reduction="none",
).sum(dim=-1)

loss_obj_cano =
    sum(cano_diff * corr_valid_mask)
    / sum(corr_valid_mask)
```

### 6.6 Cross-edge contact loss

```python
edge_valid_mask =
    input_obj_to_hand_knn_valid_mask
    & runtime_obj_valid_mask.unsqueeze(-1)

loss_cross_edge_contact =
    BCEWithLogits(
        pred_cross_contact,
        edge_contact_label,
        weight=edge_valid_mask,
        reduction="sum",
    )
    / sum(edge_valid_mask)
```

### 6.7 Optional finger / region loss

target 同样来自 clean KNN rank-0：

```python
target_finger = gather(hand_finger_id, gt_hand_idx)
target_region = gather(hand_region_id, gt_hand_idx)
```

只在 `corr_valid_mask` 内计算交叉熵。

### 6.8 总 Loss

```python
loss =
    loss_contact_weight * loss_obj_contact
  + loss_cano_weight * loss_obj_cano
  + loss_cross_edge_weight * loss_cross_edge_contact
  + loss_finger_weight * loss_obj_finger
  + loss_region_weight * loss_obj_region
```

当前默认：

```python
loss_contact_weight = 1.0
loss_cano_weight = 1.0
loss_cross_edge_weight = 1.0
loss_finger_weight = 0.25
loss_region_weight = 0.25
```

finger / region head 关闭时，对应 loss 为 0。

## 8. 评估可视化

### 8.1 可视化模式与按键开关

visualizer 提供两种显示模式，通过按键切换：

| 按键 | 功能 |
|------|------|
| `G` | 切换 GT / Eval 显示模式 |
| `C` | object contact 概率热力图 ↔ cross-edge contact 可视化 |
| `↑` / `↓` | 调节概率阈值（0.0 ~ 1.0，步长 0.05） |
| `←` / `→` | 逐帧切换 |
| `R` | 重置视角 |

### 8.2 Object contact 概率热力图

对每个物体点，按 pred_obj_contact 概率着色 [0, 1]：

```text
蓝色 (0.0) = 无接触
白色 (0.5) = 不确定
红色 (1.0) = 确定接触
```

**GT 模式**：显示 GT contact label（硬标签 0/1），红色=接触，灰色=非接触。

**Eval 模式**：显示 pred 概率热力图

### 8.3 Cross-edge contact 概率可视化

选中一个物体点（鼠标点击），显示它到 K_cross 个手部候选点的边。

**GT 模式**：显示 clean GT KNN 边，根据 GT edge contact label 着色。

**Eval 模式**：显示 noisy input KNN 边，按 pred_cross_contact 概率渐变着色（蓝→红），透明度随概率降低。高于当前阈值的边高亮显示。

考虑到你的需求只是"点击物体点 → 显示其到手的 cross-edges"， VisualizerWithVertexSelection 或 VisualizerWithEditing 加一个 折中方案 其实是够用的：

用一个 独立的 pick 模式 — 按 P 键进入点选模式，选中后高亮该点并显示它的 K_cross 条边，再按 P 退出选点模式回到正常浏览。这样就不用纠结于"左键单击"这种交互细节。
