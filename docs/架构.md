# Ref2Dex 静态 Correspondence 整体流程

## 1. 总体流向

```text
原始数据
-> Stage 1: processed_data/<dataset>/<subject>/<seq>.npz
-> Stage 2: processed_data/generated/mano_fit/<dataset_variant>/<subject>/<seq>_<side>.pkl
-> Stage 3: processed_data/generated/train_corr_static/<dataset>/<subject>/<seq>_<side>.npz
-> 训练时 dataloader / model forward 生成 runtime 字段
```

当前训练版本的约定：

```text
1. 训练样本单位：single_frame_single_hand
2. 统一坐标系：object frame
3. 训练输入：clean object + noisy hand
4. 训练监督：clean object + clean hand
5. KNN 不落盘，训练时实时计算
6. cross 方向：obj -> hand
```

## 5. 训练时 runtime 流向

### 5.1 dataloader 输入

```text
读取 Stage 3 clean sample
-> 复制出 gt_points / gt_normals
-> 只对 input hand 做扰动

```

```python
runtime_sample = {

    "normals": Float[B, N_total, 3],        # 网络输入法向

    "obj_to_hand_knn_valid_mask": Bool[B, No_train, K_cross],  # 运行时 KNN 有效 mask

```

### 5.3 runtime KNN 计算口径

```text
query = input object points
key   = input hand points
```

也就是：

```text
候选邻居来自 noisy hand
监督标签来自 clean GT
```

## 6. 模型

当前训练任务的目的不是单独做去噪输出，而是训练 hand-object 交互后的 dense token 编码。

```text
最终要保留的是交互后的 dense token
去噪式监督只是训练这个编码的手段
```

### 6.1 模型输入

```python
model_input = {
    "points": Float[B, N_total, 3],              # 统一输入点云，clean object + noisy hand
    "normals": Float[B, N_total, 3],             # 统一输入法向
    "hand_cano_points": Float[B, N_total, 3],    # 手 canonical 坐标，object 部分为 0
    "point_valid_mask": Bool[B, N_total],        # 点有效 mask

    "obj_contact_label": Float[B, No_train],         # 物体点 contact GT
    "obj_to_hand_cano_points": Float[B, No_train, 3], # 物体点 canonical correspondence GT
    "obj_to_hand_finger_id": Int[B, No_train],       # 物体点 finger GT
    "obj_to_hand_region_id": Int[B, No_train],       # 物体点 region GT
    "obj_label_valid_mask": Bool[B, No_train],       # 物体点监督有效 mask

    "gt_points": Float[B, N_total, 3],           # clean GT 点云，用于 runtime edge label
    "gt_normals": Float[B, N_total, 3],          # clean GT 法向

    "obj_to_hand_knn_idx": Int[B, No_train, K_cross],         # runtime obj->hand KNN
    "obj_to_hand_knn_valid_mask": Bool[B, No_train, K_cross], # runtime KNN mask
}
```

### 6.2 输入拆分

```python
obj_points   = points[:, :No_train]                 # [B, No_train, 3]
obj_normals  = normals[:, :No_train]                # [B, No_train, 3]
hand_points  = points[:, No_train:No_train+Nh_train]   # [B, Nh_train, 3]
hand_normals = normals[:, No_train:No_train+Nh_train]  # [B, Nh_train, 3]
hand_cano    = hand_cano_points[:, No_train:No_train+Nh_train] # [B, Nh_train, 3]
```

### 6.3 输入特征

```python
obj_raw_i  = [obj_xyz_i, obj_normal_i]                 # 6 维
hand_raw_j = [hand_xyz_j, hand_normal_j, hand_cano_j]  # 9 维
```

### 6.4 Two-stem

```python
obj_stem:
    Linear(6, hidden_dim)
    LayerNorm(hidden_dim)
    GELU
    Linear(hidden_dim, hidden_dim)

hand_stem:
    Linear(9, hidden_dim)
    LayerNorm(hidden_dim)
    GELU
    Linear(hidden_dim, hidden_dim)
```

输出：

```python
obj_feat:  Float[B, No_train, hidden_dim]
hand_feat: Float[B, Nh_train, hidden_dim]
```

### 6.5 Unified PTv3 backbone

```python
coord = concat([obj_points, hand_points], dim=1)   # [B, N_total, 3]
feat  = concat([obj_feat, hand_feat], dim=1)       # [B, N_total, hidden_dim]
tokens = PTv3(coord, feat, point_valid_mask)       # [B, N_total, token_dim]
```

再拆分为：

```python
z_obj  = tokens[:, :No_train]                      # [B, No_train, token_dim]
z_hand = tokens[:, No_train:No_train+Nh_train]    # [B, Nh_train, token_dim]
```

### 6.6 runtime obj->hand edge 几何

对每个 object 点 `i` 的第 `k` 个 hand 邻居 `j`，实时计算：

```python
delta_ik       = hand_xyz[j] - obj_xyz[i]          # [3]
dist_ik        = ||delta_ik||                      # [1]
signed_dist_ik = dot(obj_normal[i], delta_ik)      # [1]
normal_dot_ik  = dot(obj_normal[i], hand_normal[j])# [1]
```

拼成：

```python
edge_geo_ik = [delta_ik, dist_ik, signed_dist_ik, normal_dot_ik]   # 6 维
```

批量张量：

```python
edge_geo: Float[B, No_train, K_cross, 6]
z_hand_neighbors: Float[B, No_train, K_cross, token_dim]
hand_cano_neighbors: Float[B, No_train, K_cross, 3]
```

### 6.7 object-centric cross attention

先做边几何和 hand canonical 的嵌入：

```python
edge_geo_embed  = edge_geo_mlp(edge_geo)             # [B, No_train, K_cross, edge_geo_dim]
hand_cano_embed = hand_cano_mlp(hand_cano_neighbors) # [B, No_train, K_cross, cano_embed_dim]
```

然后构造 Q / K / V：

```python
q_i   = cross_q(z_obj[i])                                            # [token_dim]
k_ik  = cross_k([z_hand_neighbor_ik, edge_geo_embed_ik])             # [token_dim]
v_ik  = cross_v([z_hand_neighbor_ik, edge_geo_embed_ik, hand_cano_embed_ik]) # [token_dim]
b_ik  = cross_bias(edge_geo_ik)                                      # [1]
```

注意力 logit：

```python
logit_ik = dot(q_i, k_ik) / sqrt(token_dim) + b_ik
```

只在 `obj_to_hand_knn_valid_mask` 有效位置做 masked softmax：

```python
attn_ik = masked_softmax(logit_ik, obj_to_hand_knn_valid_mask)
```

聚合 hand 邻域得到 cross context：

```python
cross_ctx_i = sum_k attn_ik * v_ik
cross_update_i = cross_out(cross_ctx_i)
z_obj_cross_i = z_obj_i + cross_update_i
```

批量输出：

```python
obj_to_hand_attn: Float[B, No_train, K_cross]     # object 对 hand 邻域的注意力
z_obj_cross: Float[B, No_train, token_dim]        # cross 更新后的 object token
```

这里的 `obj_to_hand_attn` 是通用 hand-object 交互权重，不是 `cano` 专用注意力。

### 6.8 最终 dense token

当前版本里：

```python
z_obj_cross = z_obj + cross_update
```

这个 `z_obj_cross` 就是最终的 object dense token。

后续 object 相关监督都基于这个 token 或基于它参与构造的 edge 特征来计算。

### 6.9 shared edge backbone

为了让 `cross edge contact` 和 `cano correspondence` 共用 hand-object 交互骨干，先构造共享 edge 输入：

```python
edge_input_ik = [z_obj_cross_i, z_hand_neighbor_ik, edge_geo_ik]
```

维度：

```python
dim(edge_input_ik) = token_dim + token_dim + 6
```

对应共享 edge backbone：

```python
edge_shared_backbone:
    Linear(2 * token_dim + 6, token_dim)
    GELU
    Linear(token_dim, edge_shared_dim)
    GELU
```

输出：

```python
edge_shared_ik: Float[edge_shared_dim]
```

### 6.10 输出 head

#### 1. object contact head

```python
contact_head:
    Linear(token_dim, token_dim // 2)
    GELU
    Linear(token_dim // 2, 1)
```

输出：

```python
pred_obj_contact = contact_head(z_obj_cross).squeeze(-1)   # [B, No_train]
```

#### 2. object-to-hand canonical correspondence head

`cano` 不再只看 object token，也不再聚合回 object 级输出。

当前实现是：

1. 每条 object-to-hand 候选边先经过 shared edge backbone。
2. 再通过单独的 `cano_edge_head` 输出该边的 canonical 预测。

对应 head：

```python
cano_edge_head:
    Linear(edge_shared_dim, 3)
```

逐边输出：

```python
pred_cano_edge_ik = cano_edge_head(edge_shared_ik)   # [3]
```

输出：

```python
pred_cross_cano: Float[B, No_train, K_cross, 3]
```

#### 3. cross edge contact head

`cross edge contact` 和 `cano` 共用 `edge_shared_backbone`，再单独出一个 contact 头：

```python
cross_edge_head:
    Linear(edge_shared_dim, 1)
```

输出：

```python
pred_cross_contact: Float[B, No_train, K_cross]
```

#### 4. optional finger / region head

如果开启 `use_finger_region_head=True`：

```python
pred_obj_to_hand_finger: Float[B, No_train, num_fingers]
pred_obj_to_hand_region: Float[B, No_train, num_regions]
```

### 6.11 模型输出

```python
model_output = {
    "obj_dense_tokens": Float[B, No_train, token_dim],     # 最终 object dense token，交互后特征
    "hand_dense_tokens": Float[B, Nh_train, token_dim],    # hand dense token，PTv3 输出
    "ptv3_obj_tokens": Float[B, No_train, token_dim],      # 交互前的 object PTv3 token

    "pred_obj_contact": Float[B, No_train],              # 物体点 contact logit
    "pred_cross_cano": Float[B, No_train, K_cross, 3],  # obj->hand 候选边 canonical correspondence
    "pred_cross_contact": Float[B, No_train, K_cross],  # obj->hand 候选边 contact logit
    "obj_to_hand_attn": Float[B, No_train, K_cross],    # object 对 hand 邻域注意力

    "pred_obj_to_hand_finger": Float[B, No_train, num_fingers], # 可选
    "pred_obj_to_hand_region": Float[B, No_train, num_regions], # 可选
}
```

## 7. Loss

### 7.1 corr_valid_mask

`corr_valid_mask` 在 runner 里动态构造：

```python
corr_valid_mask =
    obj_label_valid_mask
    & (obj_to_hand_nn_id >= 0)
    & (obj_contact_label > corr_contact_label_min)
```

默认当前阈值：

```python
corr_contact_label_min = 0.1
```

### 7.2 object contact loss

输入：

```python
pred = pred_obj_contact                # [B, No_train], logits
target = obj_contact_label             # [B, No_train], soft label
weight = obj_label_valid_mask.float()  # [B, No_train]
```

计算：

```python
loss_obj_contact =
    BCEWithLogits(pred, target, weight=weight, reduction="sum")
    / sum(weight)
```

### 7.3 object-to-hand canonical loss

输入：

```python
pred = pred_cross_cano                                  # [B, No_train, K_cross, 3]
target = obj_to_hand_cano_points.unsqueeze(2)          # [B, No_train, 1, 3]
target = expand_to_K(target)                           # [B, No_train, K_cross, 3]
mask = obj_to_hand_knn_valid_mask                      # [B, No_train, K_cross]
mask = mask & (edge_contact_labels > corr_contact_label_min)
```

先计算逐边逐维 SmoothL1：

```python
cross_cano_diff = SmoothL1(pred, target, reduction="none").sum(dim=-1)   # [B, No_train, K_cross]
```

再做 mask 平均：

```python
loss_cross_cano =
    sum(cross_cano_diff * mask) / sum(mask)
```

### 7.4 dynamic cross edge label

cross edge label 不落盘，训练时用 clean GT 几何动态生成。

使用：

```python
obj_points = gt_points[:, :No_train]
hand_points = gt_points[:, No_train:No_train+Nh_train]
obj_to_hand_knn_idx
```

对每条候选边：

```python
delta_ik = hand_points[j] - obj_points[i]
dist_ik = ||delta_ik||
```

再用 soft contact 公式生成 edge label：

```python
if dist <= d_pos:
    label = 1
elif dist < d_neg:
    u = (dist - d_pos) / (d_neg - d_pos)
    label = (1 - u) ** gamma
else:
    label = 0
```

得到：

```python
edge_contact_labels: Float[B, No_train, K_cross]
```

### 7.5 cross edge contact loss

输入：

```python
pred = pred_cross_contact                        # [B, No_train, K_cross], logits
target = edge_contact_labels                     # [B, No_train, K_cross]
weight = obj_to_hand_knn_valid_mask.float()     # [B, No_train, K_cross]
```

计算：

```python
loss_cross_edge_contact =
    BCEWithLogits(pred, target, weight=weight, reduction="sum")
    / sum(weight)
```

### 7.6 optional finger loss

只有开启 finger head 才计算：

```python
finger_valid = corr_valid_mask & (obj_to_hand_finger_id >= 0)
loss_map = CrossEntropy(pred_obj_to_hand_finger, obj_to_hand_finger_id, reduction="none")
loss_obj_finger = sum(loss_map * finger_valid) / sum(finger_valid)
```

### 7.7 optional region loss

只有开启 region head 才计算：

```python
region_valid = corr_valid_mask & (obj_to_hand_region_id >= 0)
loss_map = CrossEntropy(pred_obj_to_hand_region, obj_to_hand_region_id, reduction="none")
loss_obj_region = sum(loss_map * region_valid) / sum(region_valid)
```

### 7.8 总 loss

当前代码中总 loss 为：

```python
loss =
    loss_contact_weight * loss_obj_contact
  + loss_cano_weight * loss_cross_cano
  + loss_finger_weight * loss_obj_finger
  + loss_region_weight * loss_obj_region
  + loss_cross_edge_weight * loss_cross_edge_contact
```

当前默认权重：

```python
loss_contact_weight = 1.0
loss_cano_weight = 1.0
loss_finger_weight = 0.25
loss_region_weight = 0.25
loss_cross_edge_weight = 1.0
```

如果 finger / region head 没开，对应两项就是 0。

### 7.9 训练日志里的辅助指标

runner 还会额外记录两个 oracle BCE 下界：

```python
obj_contact_oracle_bce
cross_edge_oracle_bce
```

它们是 soft label 自身的熵下界：

```python
entropy(target) = - target * log(target) - (1 - target) * log(1 - target)
```

以及 excess 指标：

```python
obj_contact_excess_bce = loss_obj_contact - obj_contact_oracle_bce
cross_edge_excess_bce = loss_cross_edge_contact - cross_edge_oracle_bce
```
