# V1.2g 治理计划：停止远端 CI，保留本地门禁与工作树生命周期

状态：`FINAL`（用户已确认实施）

work version：`V1.2g`

影响等级：`L3`（仓库工作流、AGENTS、Skill 与远端 workflow）

## 决策

用户决定不再使用远端 CI：GitHub Actions 的依赖、环境差异和日志权限维护成本不再值得继续承担。
删除仓库的 verify workflow，并从现行 AGENTS、change-control Skill 与测试目录规范中移除 CI
运行、轮询、结果交接和 CI 收集范围要求。

`python tools/verify.py --changed` 保留为本地机器验证入口；它不再被表述为或依赖远端 CI。已合并的
V1.2e 计划、Activity 和指导中的 CI 文字保留为只读历史审计事实，不构成现行规则。

## 范围与保持项

### 拟议变更

1. 删除 `.github/workflows/verify.yml`，停止 GitHub Actions verify workflow。
2. 从根 AGENTS 和 `research-change-control` Skill 移除每次推送后查询、等待或汇报 CI 的合同。
3. 从当前测试目录规范移除 CI 相关表述；保留本地 `verify.py --changed` 的测试选择边界。
4. 保留并验证顺序工作复用干净 AI worktree、清理须经用户授权、分支删除须单独确认的规则。
5. 将根 work_version 更新为 V1.2g，新增 Activity 和计划；撤回尚未提交的 V1.2f CI 闭环与 NumPy 2
   CI 兼容改动。

### 保持不变

- 不删除 `tools/verify.py`、治理测试、Task 测试或完整运行时的显式测试。
- 不反写已合并 V1.2e 的历史计划、Activity 或用户指导；它们只保留审计价值。
- 不删除、移动或改写任何现有 worktree、分支、数据、cache、checkpoint 或 outputs。
- 不改变研究语义、Task 实现或现有测试归属。

## 风险、验证与回滚

| 风险 | 缓解与验证 |
| --- | --- |
| 误以为仍有远端自动验证 | 删除 workflow，并审计现行 AGENTS、Skill 和测试规范不再规定 CI。 |
| 本地验证被误删 | 保留 `python tools/verify.py --changed`，运行治理测试及该入口。 |
| worktree 清理规则随 CI 一并丢失 | 治理测试单独断言 worktree 生命周期条款。 |
| 回滚 | 反转独立 V1.2g 提交即可恢复 workflow 和之前的现行表述，不触及任何工作树或研究产物。 |

## 验收标准

1. 仓库不再跟踪 GitHub Actions verify workflow，现行 AGENTS、change-control Skill、测试规范不再要求 CI。
2. 本地 `python tools/verify.py --changed` 和 `tests/governance` 仍可运行。
3. 治理测试仍能发现 worktree 复用与清理授权规则。
4. 未删除或移动任何 worktree、分支、研究产物或历史审计记录。

## 实施授权

用户已明确确认停止 CI、删除此前现行规范中的 CI 测试/结果要求，并保留本地验证与工作树规则。
