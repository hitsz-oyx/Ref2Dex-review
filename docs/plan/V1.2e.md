# V1.2e 治理计划：从轻量 CI 门禁移出非 hermetic 框架测试

状态：`FINAL`（用户已确认实施）

work version：`V1.2e`

影响等级：`L3`（统一机器门禁、CI 测试选择与版本合同）

## 背景与决策

`oyx` 推送的 verify CI 在干净的 GitHub Actions runner 上失败。`tools/verify.py` 在检测到
`src/base/` 变更时会自动选择 `tests/test_framework_contracts.py`，而该测试需要 `torch`；
CI 工作流刻意只安装 `pytest`、`PyYAML` 和 `numpy`。本机 Conda `graspenv` 含有 torch，因此
本地验证未暴露这个环境差异。

决定保持 CI 为轻量、可从干净检出重建的 hermetic 门禁，不把本机 `graspenv` 直接复制或作为
CI 依赖。`test_framework_contracts.py` 保留为完整研究运行时中的显式验证，不再由
`tools/verify.py --changed` 因 `src/base/` 变更自动选择。基础运行时变更的自动范围保留
`tests/test_run_manifest.py`；治理变更继续自动选择 `tests/governance/`。

## 范围与保持项

### 拟议变更

1. 修改 `tools/verify.py` 的 `_select_tests`：`src/base/` 变更只加入真正 hermetic 的
   `tests/test_run_manifest.py`，不再自动加入 `tests/test_framework_contracts.py`。
2. 修改 `tests/governance/test_verify.py`，断言基础运行时变更的自动选择不包含 framework
   contracts 测试、仍包含 run-manifest 测试。
3. 更新 `tests/README.md`，明确 `test_framework_contracts.py` 是需要完整运行时（含 torch）的
   显式验证，不属于轻量 CI 自动门禁。
4. 更新根 work_version、V1.2e Activity 和计划；CI workflow 保持轻量依赖，不安装或复制
   本机 Conda 环境。

### 保持不变

- 不删除、移动、弱化或跳过 `tests/test_framework_contracts.py` 本身；完整环境仍应显式运行它。
- 不把 Conda `graspenv`、本机路径、数据、cache、checkpoint、outputs 或机器私有配置提交给
  GitHub Actions。
- 不改变研究语义、Task 代码、公共运行时实现或 V1.2d 的 tracked-source 门禁。
- 每次推送后的 CI 查询和汇报作为操作行为执行；若要把它写入仓库强制合同，另行由用户确认
  独立治理变更，避免在本计划中扩大范围。

## 风险、验证与回滚

| 风险 | 缓解与验证 |
| --- | --- |
| CI 漏掉基础框架回归 | 保留 run-manifest 与治理测试的自动选择；完整运行时中显式运行 framework contracts；CI 不把轻量门禁冒充全量回归。 |
| framework contracts 被误认为删除或禁用 | 文档明确其保留位置和运行条件；添加测试选择断言。 |
| CI 环境再度漂移 | 保持 workflow 依赖最小化；推送后查询对应 run 并报告成功、失败或运行中状态。 |
| 回滚 | 反转独立 V1.2e 提交即可恢复原自动选择，不影响测试文件、数据或运行产物。 |

## 验收标准

1. `src/base/` 变更的 `_select_tests` 包含 `tests/test_run_manifest.py`，不包含
   `tests/test_framework_contracts.py`。
2. Conda `graspenv` 中可显式运行 framework contracts 测试；轻量 CI 的依赖清单不新增 torch。
3. `conda run -n graspenv python -m pytest -q tests/test_run_manifest.py tests/governance` 和
   `VERIFY_BASE=origin/oyx python tools/verify.py --changed` 通过。
4. 推送后查询与该 commit 对应的 GitHub Actions run，并在交接中报告结果。
