checkpoint 应该用 best val，不要用 latest

这一点现在非常明确。

你的 checkpoint metric 是：

```text
val_clean/cross_edge_random_qfl
```

那么必须：

[
\boxed{\arg\min_{\rm epoch}L_{\rm val,random}^{QFL}}
]

绝对不要拿：

```text
epoch 28 latest
```

去做最终 downstream evaluation。

从我们现在看得到的数据：

[
\text{epoch17}=0.0001827
]

已经明显优于：

[
\text{epoch26}=0.0002053
]

[
\text{epoch27}=0.0002221
]

[
\text{epoch28}=0.0002344
]

所以当前 latest model 比 epoch 17 best checkpoint **差约 28% QFL**：

[
\frac{0.0002344-0.0001827}{0.0001827}
\approx28.3%
]

我的建议是：

> **这轮实验结论用 best checkpoint，不用 final checkpoint。**
