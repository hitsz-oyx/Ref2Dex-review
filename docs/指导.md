你的设计可以收敛为：

```text
Base 只新增一个文件：
src/base/performance.py

轻量模式：
长期运行，只记录 5 个指标

Profile 模式：
短时间记录 DataLoader、H2D、前向、反向、优化器时间线

Task：
继续负责 sequence、缓存、NPZ 读取、采样策略
```

当前 `BaseRunner` 只记录了整个训练总耗时，`for batch in self.train_loader` 也没有单独计算等待 batch 的时间，因此需要小幅修改训练循环。

# 一、Base 只保留 5 个轻量指标

建议只记录：

```text
perf/step_ms
perf/data_wait_ms
perf/data_wait_ratio
perf/samples_per_s
perf/eta_hours
```

含义：

| 指标                | 用途                  |
| ----------------- | ------------------- |
| `step_ms`         | 每个训练 step 平均耗时      |
| `data_wait_ms`    | 每步等待 DataLoader 的时间 |
| `data_wait_ratio` | 总时间中等待数据的比例         |
| `samples_per_s`   | 实际训练吞吐量             |
| `eta_hours`       | 预计剩余训练时间            |

暂时不要加入：

```text
CPU 内存
GPU allocated/reserved
cache hit rate
文件读取次数
H2D 精确毫秒数
forward/backward 精确毫秒数
```

原因是：

* 内存可临时用 `nvidia-smi`、`ps` 看；
* cache 指标具有 Task 语义；
* H2D、forward、backward 精确计时需要 CUDA 同步或 CUDA Event，不适合长期轻量模式；
* Profile 模式已经可以诊断这些阶段。

PyTorch 官方说明，CUDA 精确测速需要同步或使用 CUDA Event；而 profiler 的 shape、stack 和内存追踪会增加额外开销。因此轻量模式不做阶段级精确计时，Profile 模式也默认关闭这些重型选项。([PyTorch Documentation][1])

# 二、只新增 `src/base/performance.py`

```python
from __future__ import annotations

from contextlib import nullcontext
from pathlib import Path
from time import perf_counter
from typing import ContextManager

import torch


class PerformanceMonitor:
    """Shared lightweight timing and optional torch.profiler integration.

    Base only observes generic training phases. It does not know anything
    about sequences, files, cache layouts, or task-specific Dataset schemas.
    """

    VALID_MODES = {"off", "light", "profile"}

    def __init__(
        self,
        *,
        mode: str,
        device: torch.device,
        output_dir: str | Path,
        total_steps: int,
        log_every_steps: int,
        warmup_steps: int = 20,
        profile_wait_steps: int = 5,
        profile_warmup_steps: int = 5,
        profile_active_steps: int = 10,
        is_primary: bool = True,
    ) -> None:
        mode = str(mode).lower().strip()
        if mode not in self.VALID_MODES:
            raise ValueError(
                f"performance.mode must be one of "
                f"{sorted(self.VALID_MODES)}, got {mode!r}"
            )

        self.mode = mode
        self.device = device
        self.output_dir = Path(output_dir)
        self.total_steps = int(total_steps)
        self.log_every_steps = max(1, int(log_every_steps))
        self.warmup_steps = max(0, int(warmup_steps))
        self.is_primary = bool(is_primary)

        self.profiler = self._build_profiler(
            wait_steps=profile_wait_steps,
            warmup_steps=profile_warmup_steps,
            active_steps=profile_active_steps,
        )

        self._profiler_started = False
        self._reset_window()

    @property
    def enabled(self) -> bool:
        return self.mode != "off"

    def _build_profiler(
        self,
        *,
        wait_steps: int,
        warmup_steps: int,
        active_steps: int,
    ):
        if self.mode != "profile" or not self.is_primary:
            return None

        activities = [
            torch.profiler.ProfilerActivity.CPU,
        ]

        if self.device.type == "cuda":
            activities.append(
                torch.profiler.ProfilerActivity.CUDA
            )

        trace_dir = self.output_dir / "profiler"
        trace_dir.mkdir(parents=True, exist_ok=True)

        return torch.profiler.profile(
            activities=activities,
            schedule=torch.profiler.schedule(
                wait=max(0, int(wait_steps)),
                warmup=max(0, int(warmup_steps)),
                active=max(1, int(active_steps)),
                repeat=1,
            ),
            on_trace_ready=torch.profiler.tensorboard_trace_handler(
                str(trace_dir)
            ),

            # 默认关闭高开销选项。
            record_shapes=False,
            profile_memory=False,
            with_stack=False,
        )

    def start(self) -> None:
        if self.profiler is None or self._profiler_started:
            return

        self.profiler.start()
        self._profiler_started = True

    def stop(self) -> None:
        if self.profiler is None or not self._profiler_started:
            return

        self.profiler.stop()
        self._profiler_started = False

    def section(
        self,
        name: str,
    ) -> ContextManager:
        """Create a named range visible in profile mode."""

        if self.profiler is None:
            return nullcontext()

        return torch.profiler.record_function(name)

    def observe_step(
        self,
        *,
        global_step: int,
        batch_size: int,
        data_wait_seconds: float,
    ) -> dict[str, float] | None:
        """Update the lightweight window and optionally return log metrics."""

        if self.profiler is not None:
            self.profiler.step()

        if not self.enabled:
            return None

        global_step = int(global_step)

        # CUDA 初始化、worker 启动和文件冷缓存不用于稳定吞吐估计。
        if global_step <= self.warmup_steps:
            if global_step == self.warmup_steps:
                self._reset_window()
            return None

        self._window_steps += 1
        self._window_samples += int(batch_size)
        self._window_data_wait_seconds += float(
            data_wait_seconds
        )

        if global_step % self.log_every_steps != 0:
            return None

        # 每个日志窗口只同步一次，使窗口总时间包含真正的 CUDA 执行。
        if self.device.type == "cuda":
            torch.cuda.synchronize(self.device)

        elapsed_seconds = max(
            perf_counter() - self._window_start,
            1e-8,
        )

        num_steps = max(self._window_steps, 1)
        step_seconds = elapsed_seconds / num_steps
        data_wait_seconds = (
            self._window_data_wait_seconds / num_steps
        )

        remaining_steps = max(
            self.total_steps - global_step,
            0,
        )

        metrics = {
            "perf/step_ms": 1000.0 * step_seconds,
            "perf/data_wait_ms": (
                1000.0 * data_wait_seconds
            ),
            "perf/data_wait_ratio": (
                self._window_data_wait_seconds
                / elapsed_seconds
            ),
            "perf/samples_per_s": (
                self._window_samples
                / elapsed_seconds
            ),
            "perf/eta_hours": (
                remaining_steps
                * step_seconds
                / 3600.0
            ),
        }

        self._reset_window()
        return metrics

    def _reset_window(self) -> None:
        self._window_start = perf_counter()
        self._window_steps = 0
        self._window_samples = 0
        self._window_data_wait_seconds = 0.0
```

这个文件同时包含：

```text
轻量窗口统计
torch.profiler 创建和关闭
profile 阶段标签
```

不再拆成：

```text
performance.py
profiling.py
benchmark.py
```

# 六、修改 `learn()` 启停 profiler

在真正训练开始前启动：

```python
def learn(self) -> dict[str, float]:
    self._require_train_ready()

    if self.performance is not None:
        self.performance.start()

    try:
        return self._learn_impl()
    finally:
        if self.performance is not None:
            self.performance.stop()
```

为了不大改现有结构，可以把当前 `learn()` 主体移动到：

```python
def _learn_impl(self) -> dict[str, float]:
    ...
```

结构变成：

```python
def learn(self) -> dict[str, float]:
    self._require_train_ready()

    if self.performance is not None:
        self.performance.start()

    try:
        return self._learn_impl()
    finally:
        if self.performance is not None:
            self.performance.stop()


def _learn_impl(self) -> dict[str, float]:
    start_time = time.time()

    # 原 learn() 的剩余内容原样放在这里。
    ...
```

这样即使训练中途异常，profiler 也能正常停止。

PyTorch 官方支持通过 `schedule()` 只采集长训练中的有限步骤，并要求每个 iteration 调用 `profiler.step()` 推进采集状态。([PyTorch Documentation][1])

# 七、修改 `train_epoch()` 统计 DataLoader 等待时间

目前：

```python
for batch in self.train_loader:
```

要改为显式 iterator，否则无法准确包围 `next()`。

核心结构改成：

```python
def train_epoch(
    self,
    epoch: int,
) -> dict[str, float]:
    self._require_train_ready()
    self._set_train_epoch(epoch)
    self.train_mode()

    averager = MetricAverager()
    loader_iterator = iter(self.train_loader)

    while self.global_step < self.total_steps:
        data_wait_start = time.perf_counter()

        try:
            with self._performance_section(
                "data_wait"
            ):
                batch = next(loader_iterator)
        except StopIteration:
            break

        data_wait_seconds = (
            time.perf_counter()
            - data_wait_start
        )

        with self._performance_section(
            "host_to_device"
        ):
            batch = self.prepare_batch(batch)

        batch_size = self.batch_size(batch)

        with self._performance_section(
            "train_step"
        ):
            metrics = self.train_step(batch)

        averager.update(
            metrics,
            n=batch_size,
        )

        self.global_step += 1

        performance_metrics = None
        if self.performance is not None:
            performance_metrics = (
                self.performance.observe_step(
                    global_step=self.global_step,
                    batch_size=batch_size,
                    data_wait_seconds=data_wait_seconds,
                )
            )

        if (
            self.global_step
            % self.cfg.train.log_every_steps
            == 0
        ):
            logged = {
                f"train_step/{key}": value
                for key, value
                in self.select_step_metrics(
                    self._reduce_step_metrics(
                        metrics
                    )
                ).items()
            }

            if performance_metrics is not None:
                logged.update(performance_metrics)

            self._record_metrics(
                logged,
                epoch + 1,
            )

        if (
            self.val_loaders
            and self._step_due(
                self.cfg.train.eval_every_steps
            )
        ):
            val_metrics = self.evaluate_all()

            if self._handle_validation(
                val_metrics,
                epoch + 1,
            ):
                break

        if self._step_due(
            self.cfg.train.save_every_steps
        ):
            self.save(
                epoch=epoch + 1,
                is_best=False,
            )

    epoch_metrics = self.select_epoch_metrics(
        self._compute_averager_metrics(
            averager,
            prefix="train_epoch/",
        )
    )

    self._record_metrics(
        epoch_metrics,
        epoch + 1,
    )

    return epoch_metrics
```

轻量模式下，长期新增的每步操作只有：

```text
两次 perf_counter
几个浮点数累加
```

每个日志窗口才执行一次 `torch.cuda.synchronize()`。

# 八、在 `train_step()` 中加 Profile 标签

这些标签在 light 模式下会退化成 `nullcontext()`，基本不做事。

## 前向和损失

把：

```python
with autocast_ctx:
    output = self.step(
        self.model,
        batch,
        mode="train",
    )
    loss = output.loss
```

改成：

```python
with self._performance_section(
    "forward_and_loss"
):
    with autocast_ctx:
        output = self.step(
            self.model,
            batch,
            mode="train",
        )
        loss = output.loss
```

## 反向传播

把：

```python
self.scaler.scale(loss).backward()
self.scaler.unscale_(self.optimizer)
```

改成：

```python
with self._performance_section(
    "backward"
):
    self.scaler.scale(loss).backward()
    self.scaler.unscale_(self.optimizer)
```

## 梯度裁剪和优化器

```python
with self._performance_section(
    "optimizer"
):
    grad_clip_norm = (
        self.cfg.train.grad_clip_norm
    )

    grad_norm = (
        torch.nn.utils.clip_grad_norm_(
            self.model.parameters(),
            grad_clip_norm,
        )
        if grad_clip_norm is not None
        else compute_grad_norm(
            self.model.parameters()
        )
    )

    self.scaler.step(self.optimizer)
    self.scaler.update()

    if self.scheduler is not None:
        self.scheduler.step()
```

Profile 时间线上最终会看到：

```text
data_wait
host_to_device
train_step
  ├── forward_and_loss
  ├── backward
  └── optimizer
```

`record_function` 就是 PyTorch 官方提供的自定义代码区间标签，可以在 profiler 中把这些阶段单独显示出来。([PyTorch Documentation][2])

# 十、明确不放在 Base 的内容

你的判断正确，Base 中不应该出现：

```text
sequence
subject
left/right
shared.npz
LRU sequence cache
sequence-aware sampler
文件命名规则
candidate mask
stride 数据语义
```

Base 只看到：

```text
一个 DataLoader
一个 batch
一个 batch_size
一个训练 step
```

Task 继续负责：

```text
Dataset 怎么读取
是否按 sequence 缓存
sequence key 是什么
是否使用 grouped sampler
多 stride 验证如何构造
```

最终改动范围就是：

```text
新增：
src/base/performance.py

修改：
src/base/base_config.py
src/base/base_runner.py

不修改：
src/base/data.py
任何 sequence/group 相关逻辑
Task Dataset 的数据语义
```

这是当前最小且边界清晰的方案。
