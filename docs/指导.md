这份训练日志说明一个很重要的结果：**Slot Attention 没有一直 collapse，反而在训练约 1.8k step 后出现了明显的 symmetry breaking，并逐渐形成高度分化的 slots。** 同时 object flow 预测也确实学起来了。完整日志见 。

### 1. 一开始确实是完全 collapse

(K=16) 时最大 assignment entropy 是：

[
H_{\max}=\log 16\approx2.7726
]

训练最开始几百到一千多 step：

[
H\approx2.770\sim2.772
]

同时：

[
\text{slot_weight_overlap}\approx0.997\sim0.999
]

例如 step 20：

[
H=2.77059,\qquad overlap=0.997768
]

这基本就是：

[
A_{kj}\approx\frac1{16}
]

所有 slots 几乎平均看整只手，soft anchors 也几乎重合。这是标准的 Slot Attention 初始对称状态。

---

### 2. 大约 1.7k–1.9k step 开始突然分化

日志里这个转变非常明显：

[
\begin{array}{c|c|c}
step & entropy & overlap\
\hline
1740 & 2.767 & 0.994\
1760 & 2.765 & 0.994\
1780 & 2.757 & 0.989\
1800 & 2.682 & 0.937\
1820 & 2.178 & 0.565
\end{array}
]

这不是缓慢漂移，而更像一次明显的 **slot symmetry breaking**：

[
\boxed{
\text{uniform slots}
\rightarrow
\text{开始竞争}
\rightarrow
\text{不同 slots 占据不同 hand regions}
}
]

所以至少从优化行为上看，你现在这个：

[
U^h\rightarrow SlotAttention\rightarrow C_m
]

确实能够仅靠 object-flow supervision 自发地产生分组。

这比我们之前担心的“16 个 slot 永远完全相同”好很多。

---

### 3. 后面 slots 分得非常开

到 epoch 2：

[
\text{train entropy}\approx0.947
]

验证：

[
\text{val entropy}\approx0.620,\qquad
\text{val overlap}\approx0.178
]

继续训练后：

* epoch 5 val：
  [
  H\approx0.119,\quad overlap\approx0.184
  ]
* epoch 6 val：
  [
  H\approx0.118,\quad overlap\approx0.086
  ]
* epoch 9 val：
  [
  H\approx0.099,\quad overlap\approx0.076
  ]
* epoch 12 val：
  [
  H\approx0.053,\quad overlap\approx0.076
  ]

后期训练 step 中甚至经常看到：

[
H\approx0.03\sim0.15
]

和：

[
overlap\approx0.04\sim0.13
]

也就是说：

[
\boxed{\text{当前不存在 slot collapse 问题}}
]

反而要开始考虑另一个问题：

[
\boxed{\text{assignment 是否变得过于 hard}}
]

---

# 4. entropy 这么低，意味着什么？

对于每一个 hand point (j)：

[
A_{:,j}
]

现在很可能接近 one-hot：

[
A_{k^*,j}\approx1,\qquad
A_{k\neq k^*,j}\approx0
]

因为 entropy：

[
0.05\ll\log16=2.77
]

这意味着 Slot Attention 实际上已经接近把 MANO surface 做成：

> **16 个离散区域 partition。**

这不一定坏。

对于 (C_m)，如果它学出类似：

* thumb region；
* index fingertip；
* index pad；
* middle finger；
* palm；
* wrist-side support；

这是很好的。

但如果它学成固定的：

> “MANO mesh 第一区、第二区、第三区……”

而不随动作/接触变化，那就不是我们想要的动态 (C_m)。

所以现在下一步最关键的不是继续看 entropy，而是看：

[
\boxed{\text{同一个 hand point 在不同动作中会不会换 slot？}}
]

---

# 5. 必须区分两种可能

### 理想情况：动态 functional grouping

例如食指：

推物体时：

[
\text{index pad}\rightarrow slot_3
]

旋钮时：

[
\text{index pad}\rightarrow slot_7
]

或者同一个 slot 始终代表某种功能：

[
slot_3=\text{active pushing contact}
]

其空间位置可以变化。

这才是真正比较接近：

[
C_m=\text{dynamic action tokens}
]

---

### 不理想情况：固定 anatomical segmentation

模型可能仅仅利用：

[
y_j,n_j,Z_j^h
]

把手永久切成 16 块：

[
slot_1=\text{thumb}
]

[
slot_2=\text{index}
]

[
slot_3=\text{middle}
]

……

然后 (C_m) feature 自己携带 motion。

这仍然可能很好地预测 object flow，但 Slot Attention 本身并没有发现“动作 primitive”，只是做了一个 learned anatomical pooling。

这个区别现在仅凭：

* entropy；
* overlap；

判断不了。

---

# 6. flow 本身也确实学起来了

初期最大的问题是：

[
|\hat F^o|\ll|F^{o*}|
]

例如很多早期 batch：

[
GT\ norm=0.02\sim0.03m
]

但：

[
Pred\ norm\sim10^{-4}\sim10^{-3}m
]

也就是几乎预测零流。

后期已经明显改善。

例如 epoch 12：

[
\text{train }GT\ norm=0.01104
]

[
\text{train }Pred\ norm=0.01082
]

非常接近。

验证：

[
GT\ norm=0.01127
]

[
Pred\ norm=0.01033
]

说明模型不再靠 zero-flow shortcut。

同时验证 MSE 从 epoch 2 的大约：

[
9.68\times10^{-5}
]

下降到 epoch 12：

[
1.22\times10^{-5}
]

大约下降一个数量级。

所以：

[
\boxed{
C_m\text{ bottleneck 并没有阻止 object flow 学习}
}
]

这是一个正结果。

---

# 7. 但目前不能仅凭 flow MSE 宣布 (C_m) 成功

现在可以证明的是：

[
\boxed{
U^h
\rightarrow16\text{ slots}
\rightarrow F^o
}
]

**能够学习 object-flow prediction，并且 slots 会自动分化。**

还不能证明：

[
\boxed{
C_m=\text{我们希望的动态接触动作 representation}
}
]

现在真正需要验证的是三个问题。

### A. Slot 是否随动作变化？

固定 MANO point (j)，统计：

[
k_j(t)=\arg\max_kA_{kj,t}
]

看时间上是否完全固定。

如果：

[
k_j(t)=constant
]

几乎整个 sequence 都不变，那基本是 anatomical segmentation。

---

### B. Slot 是否与 contact/action 有关？

对于每个 slot：

[
W_{k,j}
]

可视化到 MANO surface，同时显示：

* hand contact (c_j)；
* hand flow (\Delta y_j)；
* object contact region。

看高权重区域是否真的落在：

* contact finger；
* moving finger；
* support finger；

而不是简单均匀覆盖固定 link。

---

### C. Decoder 是否真的使用多个 slots？

这个仍然是目前最缺的诊断。

decoder 内已经有：

[
a_{ik}
======

softmax_k(e_{ik})
]

建议立即记录：

[
q_k=
\frac{
\sum_i mask_i,a_{ik}
}{
\sum_i mask_i
}
]

即每个 slot 的平均 decoder usage。

因为完全可能：

[
\text{Slot Attention 分出了16块}
]

但：

[
q_3\approx0.95
]

decoder 实际只使用一个 slot。

那就说明 bottleneck 在功能上仍然退化。

---

# 8. 我现在最建议做的可视化

选同一个 sequence 的连续若干 pair，例如：

[
t\to t+4,\quad
t+4\to t+8,\quad
t+8\to t+12
]

对 MANO 1538 点显示：

[
\arg\max_k A_{kj}
]

16 种颜色。

同时再画每个 slot：

[
m_k=\sum_jW_{kj}y_j
]

作为球。

重点不是看一帧“分得漂不漂亮”，而是看时间变化：

### 情况 1

每根手指颜色永远不变：

> Slot 学成 anatomical partition。

### 情况 2

接触发生时局部区域发生 slot reassignment：

> Slot 开始编码动态 interaction grouping。

### 情况 3

16 个 slot 空间分开，但只有几个 slot 的 decoder usage 很高：

> Slot decomposition 有了，但 decoder bottleneck 使用不充分。

---

## 当前结论

从这份日志看，我会把结果评价为：

[
\boxed{\text{第一阶段实验成功}}
]

因为我们原本最担心的两件事都没有发生：

1. Slot Attention 没有永久停留在 uniform collapse；
2. object flow 没有长期退化成 zero-flow prediction。

而且 slots 从：

[
H\approx2.77,\ overlap\approx1
]

自动演化到大致：

[
H\approx0.05\sim0.15,\ overlap\approx0.05\sim0.1
]

这是非常明显的自发分化。

**下一步暂时不要加 diversity loss 或 activity loss。** 现在最重要的是确认这种分化究竟是“固定手部解剖分区”，还是“随动作变化的功能性 action slots”；同时补 `decoder slot usage`。这会直接决定 Slot Attention 得到的是不是我们真正想要的 (C_m)。
