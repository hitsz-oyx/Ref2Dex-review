# 四、HandGlobalEncoder 怎么设计

第一版不要 Transformer，不要 PTv3。

直接 PointNet-style。

我建议每个 hand point 输入：

[
u_j=
[
h_j,
n_j,
c_j,
h_j-c_j,
E_f(f_j),
E_r(r_j)
]
]

维度：

[
3+3+3+3+8+8=28
]

其中：

* (h_j)：当前手势坐标
* (n_j)：当前 normal
* (c_j)：canonical anatomical coordinate
* (h_j-c_j)：相对 canonical deformation
* (E_f)：finger embedding
* (E_r)：region embedding

代码大致：

```python
class HandGlobalEncoder(nn.Module):
    def __init__(
        self,
        num_fingers: int,
        num_regions: int,
        context_dim: int = 32,
    ) -> None:
        super().__init__()

        semantic_dim = 8

        self.finger_embed = nn.Embedding(
            num_fingers,
            semantic_dim,
        )
        self.region_embed = nn.Embedding(
            num_regions,
            semantic_dim,
        )

        input_dim = 3 + 3 + 3 + 3 + semantic_dim + semantic_dim

        self.local_mlp = nn.Sequential(
            nn.Linear(input_dim, 64),
            nn.GELU(),
            nn.Linear(64, 64),
            nn.GELU(),
        )

        self.global_mlp = nn.Sequential(
            nn.Linear(128, 64),
            nn.GELU(),
            nn.Linear(64, context_dim),
        )

        self.context_norm = nn.LayerNorm(context_dim)

    def forward(
        self,
        hand_points: torch.Tensor,
        hand_normals: torch.Tensor,
        hand_cano_points: torch.Tensor,
        hand_finger_id: torch.Tensor,
        hand_region_id: torch.Tensor,
    ) -> tuple[torch.Tensor, torch.Tensor]:

        finger_feat = self.finger_embed(hand_finger_id)
        region_feat = self.region_embed(hand_region_id)

        hand_delta = hand_points - hand_cano_points

        point_input = torch.cat(
            [
                hand_points,
                hand_normals,
                hand_cano_points,
                hand_delta,
                finger_feat,
                region_feat,
            ],
            dim=-1,
        )

        local_feat = self.local_mlp(point_input)

        global_mean = local_feat.mean(dim=1)
        global_max = local_feat.max(dim=1).values

        global_feat = torch.cat(
            [global_mean, global_max],
            dim=-1,
        )

        context = self.global_mlp(global_feat)
        context = self.context_norm(context)

        return local_feat, context
```

输出：

[
L_H\in\mathbb R^{B\times1538\times64}
]

和：

[
g_H\in\mathbb R^{B\times32}
]

当前真正用于 PTv3 的是：

[
\boxed{g_H}
]

# 五、为什么先 local MLP 再 pooling

不能直接：

```python
g = hand_points.mean(dim=1)
```

因为那基本只是 hand centroid。

而我们需要：

```text
拇指当前在哪
食指当前在哪
中指当前是什么状态
手掌什么姿态
各 semantic point 如何 deformation
```

所以先：

[
l_j=\phi(u_j)
]

每个点先结合：

[
\text{当前位置}+\text{anatomical identity}
]

得到 semantic local feature。

比如：

```text
这个点是 thumb pad
当前相对 canonical 向食指方向弯曲
```

再：

[
g_H=
\psi([
Mean(l_j),
Max(l_j)
])
]

把整只手聚合。

这样：

[
g_H
]

才可以表达：

> 当前 whole-hand configuration 是 pinch-like。

# 十、Loss 怎么设计

当前：

[
L=
L_r^{QFL}
+
0.05L_c^{QFL}
]

新增 conditioned hand heatmap：

[
L_H^{cond}
==========

BCEWithLogits(
s^{hand},
y^{hand}
)
]

总 loss：

[
\boxed{
L=
L_r^{QFL}
+
0.05L_c^{QFL}
+
\lambda_HL_H^{cond}
}
]

你的 `hand_contact_target` 现在已经在 GPU supervision builder 中根据 `hand_min_dist` 和当前 `contact_radius` 生成。

所以 runner 只需要：

```python
hand_target = batch["hand_contact_target"].float()
hand_logits = preds["pred_hand_contact_logits"]

hand_contact_bce = F.binary_cross_entropy_with_logits(
    hand_logits.float(),
    hand_target,
)
```

我第一版建议：

```yaml
loss_hand_contact_weight: 0.005
```

不是 1。

因为你当前：

[
L_r\sim4\times10^{-4}
]

[
0.05L_c\sim4\times10^{-4}
]

而 hand BCE 大概率：

[
L_H\sim10^{-1}
]

若：

[
\lambda_H=1
]

hand task 会在 scalar loss 上大两个数量级。

先：

[
\lambda_H=0.005
]

大致：

[
0.005\times0.2=0.001
]

至少量级接近。

然后看 gradient norm share，而不是只看 loss share。
