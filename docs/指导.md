不建议把“反向交叉熵”作为主指标。你真正要衡量的是：

> 模型看到扰动物体后，预测 (p^{pert}) 相比“直接按扰动几何得到的伪接触关系” (\tilde y)，向 clean GT (y) 修正了多少。

定义：

[
y_{ij}
======

\max\left(1-\frac{|o_i-h_j|}{r},0\right)
]

[
\tilde y_{ij}
=============

\max\left(1-\frac{|\tilde o_i-h_j|}{r},0\right)
]

其中两者都使用：

[
r=2\text{ cm}
]

模型输入是 ((\tilde O,H))，输出：

[
p_{ij}=f(\tilde O,H)
]

---

# 最推荐的指标：Pseudo-contact Recovery Ratio

## 1. 基于 Brier error 的恢复比例

把伪接触关系相对 clean GT 的初始误差定义为：

[
E_{\text{pseudo}}
=================

\sum_{ij}M_{ij}
(\tilde y_{ij}-y_{ij})^2
]

模型预测的剩余误差：

[
E_{\text{model}}
================

\sum_{ij}M_{ij}
(p_{ij}-y_{ij})^2
]

然后：

[
\boxed{
R_{\text{Brier}}
================

1-
\frac{E_{\text{model}}}
{E_{\text{pseudo}}+\epsilon}
}
]

解释：

|     数值 | 含义             |
| -----: | -------------- |
|    (1) | 完全恢复到 clean GT |
|    (0) | 与直接使用扰动伪接触一样   |
|  (0.5) | 消除了 50% 的伪接触误差 |
|   (<0) | 模型比扰动伪接触更差     |
| 接近 (1) | 恢复效果很好         |

这是最直接的：

[
\boxed{\text{模型消除了多少比例的扰动几何误差}}
]

我建议把它作为主 recovery metric：

```text
val_perturbed/pseudo_recovery_brier
```

---

# 2. 再增加一个“沿正确方向恢复了多少”的指标

定义扰动需要修正的方向：

[
\Delta_{ij}
===========

y_{ij}-\tilde y_{ij}
]

模型实际做出的修正：

[
C_{ij}
======

p_{ij}-\tilde y_{ij}
]

定义投影恢复率：

[
\boxed{
R_{\text{proj}}
===============

\frac{
\sum M_{ij}
C_{ij}\Delta_{ij}
}{
\sum M_{ij}\Delta_{ij}^2+\epsilon
}
}
]

解释：

* (R_{\text{proj}}=0)：预测仍停留在扰动伪接触上；
* (R_{\text{proj}}=1)：平均正好移动到 clean GT；
* (0<R_{\text{proj}}<1)：向正确方向进行了部分恢复；
* (R_{\text{proj}}<0)：模型反而沿错误方向移动；
* (R_{\text{proj}}>1)：修正方向正确，但发生 overshoot。

这个指标特别符合“恢复了多少”的直觉。

例如：

[
\tilde y=0.8,\qquad y=0.2
]

模型预测：

[
p=0.5
]

那么：

[
R_{\text{proj}}
===============

\frac{(0.5-0.8)(0.2-0.8)}
{(0.2-0.8)^2}
=============

0.5
]

意思就是：

> 从伪接触 0.8 到正确值 0.2 的修正路径，模型走了 50%。

建议记录：

```text
val_perturbed/pseudo_recovery_projection
```

---

# 为什么两个指标都要

只看 projection 会有一个问题。

假设高维情况下：

[
p-\tilde y
]

一部分沿正确方向移动，一部分产生了额外噪声。投影可能很好，但最终离 clean GT 仍然不近。

因此：

* `recovery_projection`：有没有沿正确方向修正；
* `recovery_brier`：最终到底消除了多少误差。

建议二者同时报告。

---

# 要不要使用 Excess BCE

可以，但作为第二层指标。

定义：

[
E_{\text{model}}^{BCE}
======================

# BCE(y,p)-H(y)

KL(\operatorname{Bern}(y)\Vert\operatorname{Bern}(p))
]

伪接触 baseline：

[
E_{\text{pseudo}}^{BCE}
=======================

BCE(y,\tilde y)-H(y)
]

然后：

[
\boxed{
R_{\text{ExcessBCE}}
====================

1-
\frac{
E_{\text{model}}^{BCE}
}{
E_{\text{pseudo}}^{BCE}+\epsilon
}
}
]

解释仍然一样：

* 1：完全恢复；
* 0：和 pseudo baseline 一样；
* 负数：更差。

但是有一个问题：

[
\tilde y=0
]

而：

[
y>0
]

时，理论上的：

[
KL(y\Vert\tilde y)
]

会趋于无穷大。

因为你的 2 cm target 在截断后会产生大量精确的 0 和少量精确的 1，因此计算 pseudo Excess BCE 前必须平滑：

[
\tilde y_\epsilon
=================

\operatorname{clamp}
(\tilde y,\epsilon,1-\epsilon)
]

例如：

[
\epsilon=10^{-4}
]

否则 recovery ratio 会被少数从 0↔正值变化的 edge 主导。

所以我的建议是：

[
\boxed{
R_{\text{Brier}}\text{ 做主指标},
\quad
R_{\text{ExcessBCE}}\text{ 做置信度敏感的辅助指标}
}
]

---

# 不建议的“反向 BCE”

如果你说的反向是：

[
BCE(\tilde y,p)
]

这个指标只是在测：

> 模型与扰动伪接触有多接近。

它越低，反而说明模型越忠实于错误的扰动关系。

把它取负或者最大化也不行，因为：

> 远离伪接触并不等于接近 clean GT。

例如 pseudo 是 0.8，clean 是 0.2：

* 预测 0.2：正确；
* 预测 0.0：也远离 pseudo；
* 预测 1.0：同样可能远离某些 pseudo；

所以必须用 clean target 作为方向锚点，而不能只“排斥 pseudo”。

---

# 必须拆成两类伪接触错误

扰动会产生两种不同错误。

## A. 扰动制造了假接触

[
\tilde y>y+\delta
]

即：

```text
pseudo false positive
```

物体被扰动到手附近，使原本不接触的边看起来接触。

定义 mask：

[
M_{\rm fake}
============

[\tilde y-y>\delta]
]

计算：

```text
pseudo_fake_contact_recovery_brier
pseudo_fake_contact_recovery_projection
```

这反映模型能不能**删除伪接触**。

---

## B. 扰动破坏了真实接触

[
y>\tilde y+\delta
]

即：

```text
pseudo false negative
```

物体从真实接触位置被移开，原本接触的边在扰动几何中消失。

定义：

[
M_{\rm missed}
==============

[y-\tilde y>\delta]
]

计算：

```text
pseudo_missed_contact_recovery_brier
pseudo_missed_contact_recovery_projection
```

这反映模型能不能**恢复被扰动破坏的真实接触**。

我建议：

[
\delta=0.05
]

避免把极小 target 浮动也算成显著伪接触变化。

---

# 代码实现

```python
import torch


def compute_pseudo_contact_recovery(
    *,
    pred_prob: torch.Tensor,
    clean_target: torch.Tensor,
    pseudo_target: torch.Tensor,
    valid_mask: torch.Tensor,
    change_threshold: float = 0.05,
    eps: float = 1e-8,
) -> dict[str, torch.Tensor]:
    """
    pred_prob:
        Model prediction from perturbed input.

    clean_target:
        Contact target generated from clean geometry.

    pseudo_target:
        Contact target generated directly from perturbed geometry.

    All tensors have the same shape.
    """
    p = pred_prob.float()
    y = clean_target.float()
    y_pseudo = pseudo_target.float()
    valid = valid_mask.bool()

    changed = valid & ((y - y_pseudo).abs() > change_threshold)
    fake_contact = valid & ((y_pseudo - y) > change_threshold)
    missed_contact = valid & ((y - y_pseudo) > change_threshold)

    def reduce_recovery(mask: torch.Tensor) -> tuple[torch.Tensor, torch.Tensor]:
        mask_f = mask.float()

        clean_direction = y - y_pseudo
        model_correction = p - y_pseudo

        pseudo_error = (
            clean_direction.square() * mask_f
        ).sum()

        model_error = (
            (p - y).square() * mask_f
        ).sum()

        recovery_brier = 1.0 - model_error / pseudo_error.clamp_min(eps)

        recovery_projection = (
            model_correction * clean_direction * mask_f
        ).sum() / pseudo_error.clamp_min(eps)

        has_data = mask_f.sum() > 0

        recovery_brier = torch.where(
            has_data,
            recovery_brier,
            torch.zeros_like(recovery_brier),
        )

        recovery_projection = torch.where(
            has_data,
            recovery_projection,
            torch.zeros_like(recovery_projection),
        )

        return recovery_brier, recovery_projection

    all_brier, all_projection = reduce_recovery(changed)
    fake_brier, fake_projection = reduce_recovery(fake_contact)
    missed_brier, missed_projection = reduce_recovery(missed_contact)

    return {
        "pseudo_recovery_brier": all_brier,
        "pseudo_recovery_projection": all_projection,

        "pseudo_fake_contact_recovery_brier": fake_brier,
        "pseudo_fake_contact_recovery_projection": fake_projection,

        "pseudo_missed_contact_recovery_brier": missed_brier,
        "pseudo_missed_contact_recovery_projection": missed_projection,

        "pseudo_changed_edge_fraction": (
            changed.float().sum()
            / valid.float().sum().clamp_min(1.0)
        ),
    }
```

# 推荐的最终指标组合

主面板：

```text
val_perturbed/pseudo_recovery_brier
val_perturbed/pseudo_recovery_projection
```

分方向：

```text
val_perturbed/pseudo_fake_contact_recovery_brier
val_perturbed/pseudo_missed_contact_recovery_brier
```

辅助校准：

```text
val_perturbed/pseudo_recovery_excess_bce
```

同时继续保留绝对性能：

```text
val_perturbed/random_excess_bce
val_perturbed/random_nonzero_mae
val_perturbed/random_y_075_100_mae
val_perturbed/zero_pred_p95
```

最核心的结果描述可以变成：

> 扰动几何本身产生的伪接触误差为基准，新模型消除了其中 (R_{\text{Brier}}\times100%) 的误差；其中对假接触的删除率和真实接触的恢复率分别是多少。

这比“反向 BCE”更直接，也更符合你要分析的实际问题。
