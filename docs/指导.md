打算参照一下/home/oyx/test_ws/ContactOpt的做法
1.我建议在输入ptv3的特征加入一下内容：
xyz
point type one-hot: hand / object
normal
到对方点云的最近距离
nearest direction 与 normal 的投影
指向对方 centroid 的方向与 normal 的 dot
然后不要用cano了，也不要加stem,让这些点直接参与ptv3
2.loss里面加一个新的loss，把概率分bin，这样可以解决交叉熵的理想下界问题，cross和edge的loss都要用这个bin
3.其他的loss先暂时关闭，你可以在/home/oyx/test_ws/Ref2Dex/src/task/correspondence_ptv3/configs里面写不同的config的yaml，外面的config.py作为一个基础配置，可以加载yaml改变一些要做区分的配置，分别开启不同的loss，我们目前先只开带bin版的loss，其他的指标只作为观察指标，不参与梯度反传
