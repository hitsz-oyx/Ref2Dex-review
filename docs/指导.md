# 4. Contact GT 改为 0–1 cm 线性 soft target

删除旧：

```python

d_neg
gamma
```

以及 plateau + transition 形式：

```text
d <= d_pos       -> 1
d_pos < d < d_neg -> transition
d >= d_neg       -> 0
```

v2 使用唯一 contact target：

[
y(d)=\operatorname{clamp}\left(1-\frac{d}{r},0,1\right)
]

默认：

[
r=0.01\text{ m}
]

即：

```text
0 mm    -> 1.00
2.5 mm  -> 0.75
5 mm    -> 0.50
7.5 mm  -> 0.25
10 mm   -> 0.00
>10 mm  -> 0.00
```

config 只保留：

```python

```

实现 v2 专用函数，例如：

```python
def contact_target_from_distance(
    distance: torch.Tensor,
    contact_radius: float,
) -> torch.Tensor:
    if contact_radius <= 0:
        raise ValueError("contact_radius must be positive.")
    return (1.0 - distance / float(contact_radius)).clamp(0.0, 1.0)
```

object contact GT 和 cross-edge contact GT 必须调用同一个函数。

object contact target：

```text
clean object point
    ->
distance to nearest clean hand point
    ->
contact_target_from_distance
```

cross-edge target：

```text
clean object point / sampled clean hand point pair
    ->
pair Euclidean distance
    ->
contact_target_from_distance
```

GT 始终基于 clean geometry。

输入仍可使用 noisy/perturbed geometry。

不要根据 noisy input geometry 计算训练 target。

代码中统一使用 `contact_target`、`edge_contact_target` 等命名，不要把 GT 命名成 calibrated probability。

# 6. 使用 Quality Focal Loss

v2 的 object contact 和 cross-edge contact 都固定使用 Quality Focal Loss。

对于 raw logit：

[
z
]

预测：

[
p=\sigma(z)
]

连续 target：

[
y\in[0,1]
]

使用：

[
L_{\mathrm{QFL}}
================

|y-p|^\beta
\cdot
\operatorname{BCEWithLogits}(z,y)
]

默认：

```python
quality_focal_beta: float = 2.0
```

实现建议：

```python
def quality_focal_loss_map(
    logits: torch.Tensor,
    target: torch.Tensor,
    *,
    beta: float = 2.0,
) -> torch.Tensor:
    if beta < 0:
        raise ValueError("beta must be non-negative.")

    logits = logits.float()
    target = target.float()

    pred_prob = torch.sigmoid(logits)

    bce = F.binary_cross_entropy_with_logits(
        logits,
        target,
        reduction="none",
    )

    modulating_factor = torch.abs(target - pred_prob).pow(beta)

    return modulating_factor * bce
```

这是 v2 中唯一 contact training loss。

不要保留：

```python
BCE mode
bin CE mode
excess BCE training mode
focal/BCE switch
```

不要 detach：

```python
pred_prob
```

QFL modulation 必须参与完整梯度计算。

即不要写：

```python
pred_prob = torch.sigmoid(logits).detach()
```

也不要：

```python
modulating_factor = modulating_factor.detach()
```

object contact：

```python
obj_qfl_map = quality_focal_loss_map(
    pred_obj_contact_logits,
    obj_contact_target,
    beta=meta.quality_focal_beta,
)
```

然后按 object valid mask 做 masked mean。

cross-edge contact：

```python
edge_qfl_map = quality_focal_loss_map(
    pred_cross_contact_logits,
    edge_contact_target,
    beta=meta.quality_focal_beta,
)
```

继续保持原任务已经采用的 per-object normalization 语义：

[
L_i
===

\frac{\sum_k m_{ik}\ell_{ik}}
{\sum_k m_{ik}}
]

然后：

[
L
=

\frac{1}{|\mathcal V|}
\sum_{i\in\mathcal V}L_i
]

其中有效 object 必须满足：

```text
runtime object valid
AND
at least one valid supervision edge
```

不要改成全局 edge mean。

原因是否则 edge 数量不同的 object 会产生不同 loss 权重。

all-invalid 情况必须返回 graph-connected zero，例如：

```python
return loss_map.sum() * 0.0
```

并保证：

```python
loss.backward()
```

正常执行。

# 8. 必须增加 random sampling coverage diagnostics

虽然本版暂时取消分层采样，但必须显式记录随机 128 edge 的 target coverage。

Quality Focal Loss 只能重新加权已经采样进入计算图的 edge。

如果一个 object point 的 128 条 sampled edge 全部满足：

```text
distance >= 1 cm
```

则：

```text
edge_contact_target = 0
```

QFL 无法学习该 object 对应的非零 edge，因为这些 edge 根本没有被采到。

因此必须增加以下诊断指标。

## 8.1 sampled nonzero edge count

```python
sampled_nonzero_edge_count
```

定义：

```python
(edge_contact_target > 0).sum()
```

仅统计 valid supervision edges。

## 8.2 sampled nonzero edge fraction

```python
sampled_nonzero_edge_fraction
```

定义：

[
\frac{
#{y>0}
}{
#{\text{valid sampled edges}}
}
]

## 8.3 object nonzero coverage

```python
object_nonzero_edge_coverage
```

对每个 valid object point，判断：

```python
(edge_contact_target > 0).any()
```

定义：

[
\frac{
#{\text{valid objects with at least one sampled nonzero edge}}
}{
#{\text{valid objects}}
}
]

这是本版非常关键的指标。

如果该值长期很低，则说明：

```text
uniform random K=128
```

没有充分覆盖 contact-support region。

后续是否重新引入 stratified sampling，应基于这一指标和 dense visualization 决定。

不要在本次实现中偷偷增加 near-edge fallback。

不要写：

```python
if no positive:
    force sample nearest hand point
```

这会重新引入距离采样偏置。

本版 baseline 必须保持真正的 uniform random sampling。
