# 需要修的四个问题

## 1. 当前默认配置会每一步强制同步 GPU

`TaskConfig.train` 当前默认：

```python
log_every_steps = 1
```

而性能监控每到日志步就执行：

```python
torch.cuda.synchronize(self.device)
```

两者结合后，默认 `light` 模式实际上是：

```text
每一步都强制等待 GPU 完成
```

这会破坏 CUDA 异步执行，轻量模式可能明显拖慢训练。

### 应直接修改默认值

```python
class train(BaseConfig):
    log_every_steps = 100
```

具体任务可以覆盖：

```yaml
train:
  log_every_steps: 20
```

只有小样本 overfit 调试才使用：

```yaml
train:
  log_every_steps: 1
```

这是当前最需要先修的一项。

---

## 2. `step_ms` 会把验证和保存时间算进去

当前性能窗口通过：

```python
perf_counter() - self._window_start
```

计算耗时，然后一记录指标就立即 `_reset_window()`。

但训练循环后面还会执行：

```text
写日志
验证
保存 checkpoint
```

下一批训练开始前，这些时间已经进入新窗口。训练中间一旦验证耗时十分钟，下一次 `step_ms` 和 `eta_hours` 就会严重偏大。当前执行顺序可以在训练循环中看到。

### 应改成逐 step 累加

在 `BaseRunner` 每步开头：

```python
step_start = time.perf_counter()
```

位置放在等待 DataLoader 之前：

```python
while self.global_step < self.total_steps:
    step_start = time.perf_counter()

    data_wait_start = time.perf_counter()
    batch = next(loader_iterator)
    data_wait_seconds = (
        time.perf_counter() - data_wait_start
    )

    batch = self.prepare_batch(batch)
    batch_size = self.batch_size(batch)
    metrics = self.train_step(batch)

    self.global_step += 1

    performance_metrics = self.performance.observe_step(
        global_step=self.global_step,
        batch_size=batch_size,
        data_wait_seconds=data_wait_seconds,
        step_start_seconds=step_start,
    )
```

`PerformanceMonitor` 改为累加：

```python
self._window_step_seconds += step_seconds
```

不再通过连续墙上时间：

```python
perf_counter() - self._window_start
```

计算窗口耗时。

这样：

```text
step_ms = DataLoader + H2D + train_step
```

不会包含：

```text
验证
保存 checkpoint
W&B 写日志
epoch 之间的停顿
```

## 3. 恢复训练时第一个窗口会被污染

`PerformanceMonitor` 在 `_setup_train()` 中创建，之后才构造模型、优化器、日志系统，并且恢复训练还会加载 checkpoint。

但当前 `start()` 只启动 profiler，没有重置轻量统计窗口：

```python
def start(self) -> None:
    if self.profiler is None:
        return
```

因此：

* `warmup_steps=0` 时，模型初始化时间会进入第一个窗口；
* resume 后 `global_step` 已超过 warmup，第一个窗口会包含 checkpoint 加载和训练前空闲时间。

### 修改为

```python
def start(self) -> None:
    self._reset_window()

    if self.profiler is None or self._profiler_started:
        return

    self.profiler.start()
    self._profiler_started = True
```

即使是 `light` 模式，也在真正进入 `learn()` 时重新开始统计。

## 4. DDP 下 `samples_per_s` 现在只是单卡吞吐量

当前传入的是：

```python
batch_size = self.batch_size(batch)
```

这是单个 rank，也就是单个训练进程上的 batch size。

因此两卡训练时，当前：

```text
perf/samples_per_s = 单卡 samples/s
```

但名称看起来像整个训练任务的吞吐量。

### 建议传入 `world_size`

创建监控器时：

```python
self.performance = PerformanceMonitor(
    ...
    world_size=self.distributed.world_size,
)
```

`performance.py`：

```python
def __init__(
    self,
    *,
    ...
    world_size: int = 1,
) -> None:
    self.world_size = max(1, int(world_size))
```

计算：

```python
"perf/samples_per_s": (
    self._window_samples
    * self.world_size
    / self._window_step_seconds
)
```

这样输出的是全局吞吐量。

另一种做法是保持现状，但把名称改成：

```text
perf/samples_per_s_per_rank
```

对你的用途，全局吞吐量更直观。

# 推荐的 `observe_step()` 结构

核心建议改成：

```python
def observe_step(
    self,
    *,
    global_step: int,
    batch_size: int,
    data_wait_seconds: float,
    step_start_seconds: float,
) -> dict[str, float] | None:
    if self.profiler is not None:
        self.profiler.step()

    if not self.enabled:
        return None

    global_step = int(global_step)

    if global_step <= self.warmup_steps:
        if global_step == self.warmup_steps:
            if self.device.type == "cuda":
                torch.cuda.synchronize(self.device)
            self._reset_window()
        return None

    should_log = (
        global_step % self.log_every_steps == 0
    )

    # 只在窗口最后一步同步。
    if should_log and self.device.type == "cuda":
        torch.cuda.synchronize(self.device)

    step_seconds = max(
        perf_counter() - step_start_seconds,
        1e-8,
    )

    self._window_steps += 1
    self._window_samples += int(batch_size)
    self._window_data_wait_seconds += float(
        data_wait_seconds
    )
    self._window_step_seconds += step_seconds

    if not should_log:
        return None

    elapsed_seconds = max(
        self._window_step_seconds,
        1e-8,
    )
    num_steps = max(self._window_steps, 1)

    metrics = {
        "perf/step_ms": (
            1000.0 * elapsed_seconds / num_steps
        ),
        "perf/data_wait_ms": (
            1000.0
            * self._window_data_wait_seconds
            / num_steps
        ),
        "perf/data_wait_ratio": (
            self._window_data_wait_seconds
            / elapsed_seconds
        ),
        "perf/samples_per_s": (
            self._window_samples
            * self.world_size
            / elapsed_seconds
        ),
        "perf/eta_hours": (
            max(self.total_steps - global_step, 0)
            * elapsed_seconds
            / num_steps
            / 3600.0
        ),
    }

    self._reset_window()
    return metrics
```

对应的重置：

```python
def _reset_window(self) -> None:
    self._window_steps = 0
    self._window_samples = 0
    self._window_data_wait_seconds = 0.0
    self._window_step_seconds = 0.0
```

# 其他判断

`profile` 目前只在 primary rank，也就是 DDP 的 rank 0 上创建，这是合理的，避免每张卡同时生成大量 trace。

轻量和 profile 两种模式
