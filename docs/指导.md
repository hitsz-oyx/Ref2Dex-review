
[

===============

\frac{0.020945}{0.000799}

[

这和我之前担心的一样：

> `loss_contact_aux_weight=1.0` 实际效果远大于 1。

原因不是权重，而是两个任务尺度完全不同。

现在模型主要在学：

[
\text{附近点预测}
]

而不是：

[
\text{随机128边预测}

# 我认为当前最需要改的是：

## 修改 1（优先）：降低 contact loss 权重

不要：

```yaml
loss_contact_aux_weight: 1.0
```

改：

```yaml
loss_contact_aux_weight: 0.05~0.1
```

理由：

现在：

[
L_c/L_r≈20-30
]

希望：

[
\lambda L_c/L_r≈1-3
]

所以：

[
\lambda≈0.05
]

比较合理。

---

## 修改 2：contact sampler 不要全部 y>0

现在：

```
positive only
```

导致分布偏。

建议：

保持：

80% positive contact

加入：

20% hard negative：

[
y=0
]

例如：

距离：

[
d\in[1cm,1.5cm]随机采样
]

这样模型学习：

```
接触
vs
近但不接触
```

更符合实际。

---

## 修改 3：不要优化 contact QFL，改 BCE
contact auxiliary 的目标不是精确质量估计。

它只是：

告诉 backbone：

哪里可能接触。

所以：

[
L_c
===

BCE(y>0)
]

可能比：

[
QFL(y)
]

更合适。

现在强接触：

MAE：

0.57

说明模型没有学到强弱关系。
