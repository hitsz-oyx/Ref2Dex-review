# 二、Base 增加通用有效指标协议

## 2.1 需要解决的问题

当前普通指标接口只能返回一个数值。

这无法区分：

```text
metric = 0，且它是一个真实有效的零分
```

和：

```text
该 batch 没有足够的 GT，因此 metric 未定义
```

不得再通过以下方式表达未定义指标：

```text
返回 0
返回 NaN
沿用上一个 step 的值
在 Base 中对特定 metric 名称做判断
```

需要用显式的：

```text
total
count
```

表达可聚合指标。

最终值统一定义为：

```text
metric = sum(total) / sum(count)
```

当：

```text
sum(count) == 0
```

时，该 metric 未定义，不输出 metric value。

---

## 2.2 增加 MetricStat

建议在：

```text
src/base/utils.py
```

中增加，也可以建立：

```text
src/base/metrics.py
```

定义：

```python
from dataclasses import dataclass


@dataclass(frozen=True)
class MetricStat:
    """A metric represented by a reducible numerator and valid count."""

    total: float
    count: float
    expose_validity: bool = False

    @classmethod
    def from_value(
        cls,
        value: float,
        *,
        count: float = 1.0,
        valid: bool = True,
        expose_validity: bool = False,
    ) -> "MetricStat":
        if not valid or count <= 0:
            return cls(
                total=0.0,
                count=0.0,
                expose_validity=expose_validity,
            )

        count = float(count)
        return cls(
            total=float(value) * count,
            count=count,
            expose_validity=expose_validity,
        )

    @classmethod
    def invalid(
        cls,
        *,
        expose_validity: bool = False,
    ) -> "MetricStat":
        return cls(
            total=0.0,
            count=0.0,
            expose_validity=expose_validity,
        )
```

将 `MetricStat` 从：

```text
src/base/__init__.py
```

导出。

## 2.4 修改 AverageMeter / MetricAverager

普通 float 保持现有语义：

```text
total += value * batch_size
count += batch_size
```

`MetricStat` 使用自己的统计量：

```text
total += stat.total
count += stat.count
```

不得再乘整个 batch size。

建议 meter 支持：

```python
def update_total_count(
    self,
    total: float,
    count: float,
) -> None:
    self.total += float(total)
    self.count += float(count)
```

`MetricAverager` 还需要记录：

```text
哪些 key 设置了 expose_validity=True
```

最终计算时：

```python
if meter.count > 0:
    result[key] = meter.total / meter.count
```

如果：

```python
meter.count == 0
```

则不输出该 metric value。

禁止使用：

```python
meter.total / max(1, meter.count)
```

因为这会将未定义的 `0/0` 伪装成 0。

当：

```python
expose_validity=True
```

时，无论 count 是否为 0，都输出：

```text
<metric_name>_valid_count
<metric_name>_valid
```

定义：

```python
result[f"{key}_valid_count"] = float(meter.count)
result[f"{key}_valid"] = float(meter.count > 0)
```

例如：

```text
train_epoch/cross_edge_auprc=0.87
train_epoch/cross_edge_auprc_valid_count=9
train_epoch/cross_edge_auprc_valid=1
```

如果整个 epoch 无有效观测：

```text
不输出 train_epoch/cross_edge_auprc
输出 train_epoch/cross_edge_auprc_valid_count=0
输出 train_epoch/cross_edge_auprc_valid=0
```

## 2.6 DDP 聚合

DDP 下不能对各 rank 已计算好的 metric value 直接求平均。

错误示例：



```text

global_value=0.9
```



```python
if global_count > 0:
```

```python

    total=0.0,
    count=0.0,
```

```python
def _batched_binary_auprc_stat(
    self,
    scores: torch.Tensor,
    labels: torch.Tensor,
    valid_mask: torch.Tensor,
) -> MetricStat:
    total = 0.0
    count = 0

    for batch_idx in range(scores.shape[0]):
        sample_valid = valid_mask[batch_idx].reshape(-1)

        if not bool(sample_valid.any()):
            continue

        sample_scores = scores[batch_idx].reshape(-1)[sample_valid]
        sample_labels = labels[batch_idx].reshape(-1)[sample_valid].bool()

        num_positive = int(sample_labels.sum().item())

        if num_positive <= 0:
            continue

        ap = self._binary_auprc(
            sample_scores,
            sample_labels,
        )

        total += float(ap.detach().cpu())
        count += 1

    return MetricStat(
        total=total,
        count=float(count),
        expose_validity=True,
    )
```

# 四、soft 训练目标改为 excess BCE

## 4.1 数学定义

对于 soft target：

```text
y ∈ [0, 1]
```

raw BCE：

[
\operatorname{BCE}(z,y)
=======================

-y\log\sigma(z)
-(1-y)\log(1-\sigma(z))
]

该 target 能达到的理论最小 BCE，即 Bernoulli entropy floor：

[
H(y)
====

-y\log y
-(1-y)\log(1-y)
]

定义 excess BCE：

[
\operatorname{BCE}_{excess}(z,y)
================================

\operatorname{BCE}(z,y)-H(y)
]

soft 模式训练使用：

```text
excess BCE
```

而不是 raw BCE。

代码注释和文档必须明确：

```text
entropy floor 只依赖 target；
因此 excess BCE 与 raw BCE 对 model logits 的梯度完全相同；
该修改只改变损失零点和可解释性，不改变优化方向。
```

---

## 4.2 稳定计算 entropy floor

增加逐元素 helper，例如：

```python
@staticmethod
def _binary_entropy_floor_map(
    target: torch.Tensor,
) -> torch.Tensor:
    with torch.autocast(
        device_type=target.device.type,
        enabled=False,
    ):
        target = target.float().clamp(min=0.0, max=1.0)

        return -(
            torch.xlogy(target, target)
            + torch.xlogy(1.0 - target, 1.0 - target)
        )
```

要求：

```text
target=0 -> entropy=0
target=1 -> entropy=0
0<target<1 -> entropy>0
所有结果 finite
```

如果当前环境不支持 `torch.xlogy`，使用端点稳定的等价实现。

不得直接计算：

```python
-target * torch.log(target)
```

否则 `target=0` 时可能产生 NaN。

---

## 4.3 Object contact loss

soft 模式下先计算逐点 raw BCE：

```python
raw_loss_map = F.binary_cross_entropy_with_logits(

    target,
    reduction="none",
)
```

计算逐点 oracle floor：

```python

```

二者使用完全相同的：

```text

```

得到：

## 4.4 Cross-edge loss

cross-edge 必须继续使用当前 per-object normalization。

先计算逐 edge raw BCE：

```python
raw_edge_map = F.binary_cross_entropy_with_logits(
    logits,
    target,
    reduction="none",
)
```

计算逐 edge oracle floor：

```python
oracle_edge_map = self._binary_entropy_floor_map(target)
```

二者独立经过完全相同的：

```python
_reduce_loss_map_per_object(
    loss_map,
    edge_weight,
    obj_valid_mask,
)
```

即：

```python
raw_edge_bce = self._reduce_loss_map_per_object(
    raw_edge_map,
    edge_weight,
    obj_valid_mask,
)

oracle_edge_bce = self._reduce_loss_map_per_object(
    oracle_edge_map,
    edge_weight,
    obj_valid_mask,
)

edge_excess_bce = (
    raw_edge_bce
    - oracle_edge_bce.detach()
)
```

训练损失改为：

```python
edge_contact_loss = edge_excess_bce
```

必须保证：

```text
raw BCE 每个 object 内先按有效 edge 加权平均
oracle BCE 每个 object 内使用相同权重和相同 valid mask
最终对有效 object 等权平均
没有有效 edge 的 object 不参与
整个 batch 无有效 edge时返回 graph-connected zero
```

禁止用：

```text
global edge mean oracle BCE
```

去减：

```text
per-object normalized raw BCE
```

因为二者 reduction 不一致。

## 4.5 不要 clamp excess BCE

理论上 excess BCE 非负。



因为这会改变接近最优点时的梯度。

测试中使用合理的 numerical tolerance。

# 五、修正 stratified sampler 的 S4 补位

修改：

```text
src/task/correspondence_ptv3/dataset.py
```

## 5.1 当前问题

当前五层初始 quota：

```text
S0: d <= 5mm             16
S1: 5mm < d <= 15mm      32
S2: 15mm < d < 30mm      32
S3: 30mm <= d <= 60mm    32
S4: d > 60mm             16
```

当前补位顺序虽然写成：

```text
S1 -> S2 -> S3 -> S0 -> S4
```

但实现是所有层共同 round-robin。

这意味着只要 S4 还有候选，它每一轮都会获得一个额外名额。

结果是 S4 并不是真正“最后兜底”，而是与其他层一起持续补位。

需要改成分阶段补位。

---

## 5.2 新补位规则

初始 quota 采样完成后，如果不足 K=128：

### 第一阶段

仅在：

```text
S1、S2、S3
```

之间 round-robin 补位。

持续到：

```text
达到 K
```

或：

```text
S1/S2/S3 的剩余候选全部耗尽
```

### 第二阶段

如果仍不足，使用 S0 剩余候选补位。

### 第三阶段

如果仍不足，最后才使用 S4 剩余候选补位。

最终优先级严格为：

```text
{S1, S2, S3} > S0 > S4
```

其中 S1/S2/S3 内部使用 round-robin，避免单个 transition/hard-negative 区间独占补位。

---

## 5.3 推荐实现

不要继续在 while 循环中反复执行 `np.concatenate`。

改用 Python list 收集 selected index，最后一次转换为 NumPy array。

示意：

```python
selected: list[int] = []

for layer_idx, candidates in enumerate(layer_candidates):
    shuffled = rng.permutation(candidates)
    take_count = min(
        int(quotas[layer_idx]),
        int(shuffled.size),
    )

    selected.extend(
        int(value)
        for value in shuffled[:take_count]
    )

    remaining_parts.append(
        np.asarray(
            shuffled[take_count:],
            dtype=np.int64,
        )
    )
```

增加通用内部 helper：

```python
def refill_round_robin(
    layer_indices: tuple[int, ...],
) -> None:
    while len(selected) < k_logit:
        progress = False

        for layer_idx in layer_indices:
            offset = remaining_offsets[layer_idx]
            remaining = remaining_parts[layer_idx]

            if offset >= len(remaining):
                continue

            selected.append(
                int(remaining[offset])
            )
            remaining_offsets[layer_idx] += 1
            progress = True

            if len(selected) >= k_logit:
                break

        if not progress:
            break
```

然后：

```python
refill_round_robin((1, 2, 3))

if len(selected) < k_logit:
    refill_round_robin((0,))

if len(selected) < k_logit:
    refill_round_robin((4,))
```

也可以将单层阶段实现为普通循环，但语义必须一致。

---

## 5.4 示例验收

候选数量：

```text
S0=4
S1=8
S2=100
S3=100
S4=100
```

初始 quota 后：

```text
S0=4
S1=8
S2=32
S3=32
S4=16

总数=92
还缺36
```

第一阶段只从 S2/S3 补位，各补 18。

最终应为：

```text
S0=4
S1=8
S2=50
S3=50
```
