最推荐你采用下面这种结构：

```text
processed_data/

│           ├── data/
│           │   ├── s1/
│           │   ├── s2/
│           │   └── s3/
│           ├── manifest.csv
│           └── meta.json
│       └── splits/
│            ├── sequence_split_v1/
    │         │   ├── train.txt
    │         │   ├── val.txt
    │         │   ├── test.txt
    │         │   └── split.json
    │        └── object_holdout_v1/
    │         ├── train.txt
    │         ├── val.txt
    │         ├── test.txt
    │         └── split.json
├── stage4/

│           │   ├── s2/
│           │   └── s3/

```

## 不建议把数据真的复制三份

不要这样组织：

```text
stage3/
├── train/
├── val/
└── test/
```

然后把 `.npz` 或 `.pkl` 文件分别复制进去。

因为后面一旦换划分，比如：

* 按 sequence 划分；
* 按 subject 划分；
* 按 object 划分；
* 跨数据集划分；

就需要反复复制数据，容易出现重复文件、漏文件和版本混乱。

更好的方式是：

```text
数据文件只保存一份
+
train.txt / val.txt / test.txt 记录哪些样本属于哪个集合
```

## `train.txt` 里面写什么

写相对于数据根目录的路径：

```text
s1/bowl_pass_1_left.npz
s1/bowl_pass_1_right.npz
s2/cup_lift_2_left.npz
```

`val.txt`：

```text
s3/box_pass_1_left.npz
s3/box_pass_1_right.npz
```

`test.txt`：

```text
s4/mug_lift_1_left.npz
s4/mug_lift_1_right.npz
```

Dataset 加载时：

```python
from pathlib import Path

data_root = Path(cfg.data.root)
split_file = Path(cfg.data.train_split)

relative_paths = [
    line.strip()
    for line in split_file.read_text().splitlines()
    if line.strip()
]

sample_paths = [
    data_root / relative_path
    for relative_path in relative_paths
]
```

## 配置文件怎么写

例如 correspondence：

```yaml
data:
  root: processed_data/stage3/correspondence_v2/grab_initonly_ds4_hroot/data

  split_json_path: processed_data/splits/correspondence_v2/sequence_split_v1/split.json

  batch_size: 32
  val_batch_size: 32
  test_batch_size: 32
```


这样 `BaseConfig.data` 最好逐渐从：

```python
train_path = ""
val_path = None
test_path = None
```

改为更清楚的：

```python
class data(BaseConfig):
    root = ""

    train_split = None
    val_split = None
    test_split = None

    batch_size = 256
    val_batch_size = None
    test_batch_size = None
```

## `split.json` 保存什么

除了三个 `.txt`，再放一个说明文件：

```json
{
  "name": "sequence_split_v1",
  "task": "cm_v3",
  "dataset": "grab",
  "seed": 42,
  "group_by": "sequence",
  "train_ratio": 0.8,
  "val_ratio": 0.1,
  "test_ratio": 0.1,
  "num_train_sequences": 80,
  "num_val_sequences": 10,
  "num_test_sequences": 10
}
```
里面的dataset可以有多种来源，可以写成列表
