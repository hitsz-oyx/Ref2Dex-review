可以。按你现在这个实验目标，我建议做成一个**非常干净的 v2.1 ablation**：

v1 当前 stratified 实现会从中间层 round-robin refill，然后再从其他层补满。

因为 contact auxiliary objective 的定义就是：

[

{(i,j)\mid y_{ij}>0}

这里不能让 zero edge 混进来。

# 六、Step 4：model 只 encode 一次，edge head 调两次

当前 forward：

```python
z_obj, z_hand = self.encode_points(batch)

supervision_edge_idx = batch["supervision_edge_idx"]

z_hand_neighbors = gather(...)

edge_shared = self._compute_shared_edge_features(...)

pred_cross_contact_logits = self.cross_edge_head(edge_shared)
```

不要复制这坨代码两次。

抽一个 helper：

```python
def _predict_cross_edges(
    self,
    *,
    z_obj: torch.Tensor,
    z_hand: torch.Tensor,
    edge_idx: torch.Tensor,
    edge_valid_mask: torch.Tensor,
) -> tuple[torch.Tensor, torch.Tensor]:
    z_hand_neighbors = self._gather_batched_knn_features(
        z_hand,
        edge_idx,
        edge_valid_mask,
    )

    edge_shared = self._compute_shared_edge_features(
        z_obj=z_obj,
        z_hand_neighbors=z_hand_neighbors,
    )

    logits = self.cross_edge_head(edge_shared).squeeze(-1)

    return logits, torch.sigmoid(logits)
```

然后：

```python
def forward(self, batch):
    z_obj, z_hand = self.encode_points(batch)

    random_logits, random_prob = self._predict_cross_edges(
        z_obj=z_obj,
        z_hand=z_hand,
        edge_idx=batch["random_edge_idx"],
        edge_valid_mask=batch["random_edge_valid_mask"],
    )

    contact_logits, contact_prob = self._predict_cross_edges(
        z_obj=z_obj,
        z_hand=z_hand,
        edge_idx=batch["contact_edge_idx"],
        edge_valid_mask=batch["contact_edge_valid_mask"],
    )

    return {
        "pred_cross_random_logits": random_logits,
        "pred_cross_random_prob": random_prob,

        "pred_cross_contact_aux_logits": contact_logits,
        "pred_cross_contact_aux_prob": contact_prob,
    }
```

这里：

```text
encode_points       1次
PTv3                1次
edge head           2组edge
```

两个 supervision set 完全共享参数。

你当前的 `reduce_loss_map_per_object` 已经适合这个场景。

[

这正是我们需要的。
