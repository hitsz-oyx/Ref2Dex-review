请修改 contact supervision，使其支持 bin 和 soft 两种模式，并保留之前要求的 per-object normalization。

新增配置：

contact_supervision_mode: bin   # 可选：bin / soft

要求如下：

bin 模式保持当前实现：
使用 soft_contact_label 生成连续 contact probability；
转成 10 个 bin；
使用带 contact_bin_weights 的 CrossEntropyLoss；
输出概率继续通过 bin logits 解码得到。
soft 模式使用原始连续软标签：
不再调用 contact_prob_to_bins；
head 输出单个 logit；
使用 BCEWithLogitsLoss(reduction="none")；
target 直接使用 soft_contact_label 得到的 [0, 1] 连续值；
推理概率使用 sigmoid(logit)；
contact_bin_weights 在 soft 模式下不使用。
obj contact 和 cross-edge contact 都由同一个 contact_supervision_mode 控制。
cross-edge loss 在两种模式下都使用 per-object normalization：
先得到 [B, N_obj, K] 的逐 edge loss；
乘 input_obj_to_hand_logit_loss_weight 和 valid mask；
对每个 object point 的有效 edges 求加权平均；
再对所有有效 object points 求平均；
没有有效 edge 的 object point 不参与最终平均。
object contact loss：
bin 模式使用当前 masked CE；
soft 模式使用 masked BCEWithLogits；
只在 runtime_obj_valid_mask=True 的 object points 上计算。
模型 head 根据模式决定输出维度：
bin：输出维度为 num_contact_bins；
soft：输出维度为 1。
不要同时保留两套 head。

无论哪种模式，模型输出中都保留：

pred_obj_contact_prob
pred_cross_contact_prob

bin 模式由 bin logits 解码，soft 模式由 sigmoid 得到，保证评估和可视化代码可以共用。

AUPRC、rank@k、decoded BCE 和可视化都统一使用上述 probability，不改变指标定义。
默认配置继续设为：
contact_supervision_mode: bin

保证现有实验默认行为不变。soft 模式与 bin 模式的 checkpoint head 维度不同，不要求相互兼容。

请补充最基本的测试：

bin 模式输出 shape 和当前一致；
soft 模式 head 最后一维为 1；
soft target 不经过分 bin；
两种模式下 cross-edge 都是 per-object normalization。
