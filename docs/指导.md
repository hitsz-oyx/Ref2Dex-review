我认为这个改法**比以 object frame 为统一坐标更符合你当前任务**。但我建议不要只做“以手 root 为中心化”，而是直接定义明确的 **hand-root frame**：

[
\mathbf x^{hand}
================

R_{hand}^{T}
\left(
\mathbf x^{world}-t_{hand}
\right)
]

也就是**平移和旋转都去掉**。

rotation = poses[:, :3, :3]

# 我赞成换成 hand-root frame

因为你的任务本质上是：

[
\text{hand geometry}
+
\text{relative object geometry}
\rightarrow
\text{hand-object contact}
]

从语义上看，**手是 interaction agent，物体是相对手的环境对象**。

在 object frame 下：

```text
物体始终固定
手姿态 + 手整体位置变化
```

模型学的是：

> 手相对于物体在哪里。

而 hand-root frame 下：

```text
手 root 始终固定
物体相对于手运动
手只保留 articulation
```

模型学的是：

> **这个手姿态下，物体位于手的什么位置。**

我认为后者更符合你后面想做 hand-object interaction representation 的主线。

---

## 特别是你的 hand point 有固定 correspondence

你这里 1538 个 hand point 本质上是 MANO face center，拓扑固定；ARCTIC 代码也明确是每个 MANO face 一个采样点，共 1538 点。

所以：

[
h_j
]

在不同帧中本身具有稳定的 hand-semantic identity。

例如某个 (j) 始终对应：

```text
食指某个 surface patch
```

那么 hand-root frame 下：

[
h_j^{root}
]

主要变化来自：

[
\text{finger articulation}
]

而不会混入：

[
\text{whole-hand translation}
+
\text{whole-hand rotation}
]

这对 PTv3 很重要。

否则模型现在看到一个食指点：

```text
frame A: (0.1, 0.2, 0.3)
frame B: (-0.2, 0.5, 0.1)
```

差异可能只是整只手相对 object 转了。

换到 hand-root frame：

```text
frame A: (0.03, 0.08, 0.01)
frame B: (0.031, 0.079, 0.012)
```

它才更容易形成稳定的 hand representation。

# 但是我建议 root 定义为“wrist origin + MANO root rotation”

这里要严谨。

不要简单拿：

```text
MANO transl
```

当 hand root position。

我建议定义：

[
t_{hand}=J_{wrist}
]

即 MANO joint 0 的 world coordinate。

你的 ARCTIC 代码已经明确：

```text
joint 0 = wrist
```

旋转：

[
R_{hand}=R_{global_orient}
]

于是：

[
T_{world\leftarrow hand}
========================

\begin{bmatrix}
R_{root} & J_{wrist}\
0&1
\end{bmatrix}
]

然后：

[
x^{hand}
========

R_{root}^{T}
(x^{world}-J_{wrist})
]

法向量：

[
n^{hand}
========

R_{root}^{T}n^{world}
]

这个定义非常清楚：

> 原点是 wrist，坐标轴跟随 MANO root orientation。

---

## 为什么不建议只减 wrist

即：

[
x'=x-J_{wrist}
]

只消除了平移。

假设整只手转 (90^\circ)：

```text
原来食指朝 +x
旋转后食指朝 +y
```

只减 wrist 后：

```text
frame A: 食指朝 +x
frame B: 食指朝 +y
```

整个 global orientation variation 仍然存在。

而你的目的显然不仅是“把坐标值变小”，而是：

> **建立 hand-centric representation。**

所以必须做：

[
R_{root}^{T}
]

# 一个很关键的设计问题：不要直接用 `hand_cano_points` 当输入坐标

当前 Stage 2 已经保存：

```python
"hand_cano_points"
```

但它和我现在说的 hand-root coordinates 不是一回事。

### hand-root posed coordinates

[
x^{root}_{posed}
================

T_{root}^{-1}x_{posed}
]

保留：

```text
手指弯曲
关节姿态
当前 hand shape
```

只是去掉 root SE(3)。

### hand canonical coordinates

通常：

```text
rest pose / template pose
```

可能去除了 articulation。

所以你当前模型输入应该换成：

[
\boxed{\text{posed hand points in hand-root frame}}
]

而不是：

[
\boxed{\text{hand_cano_points}}
]

否则手指弯曲信息都没了，这显然不适合 contact prediction。

# 数据流我建议直接这样改

现在：

```text
world
  ↓ T_obj^-1
object frame
  ├── object points
  └── hand points
```

改成：

```text
world
  ↓ T_hand_root^-1
hand-root frame
  ├── posed hand points
  └── object points
```

即：

[
h_i^{root}
==========

R_h^T(h_i^{world}-t_h)
]

[
o_j^{root}
==========

R_h^T(o_j^{world}-t_h)
]

法向：

[
n_h^{root}=R_h^Tn_h^{world}
]

[
n_o^{root}=R_h^Tn_o^{world}
]

因为两类点做相同刚体变换：

[
|o_j^{root}-h_i^{root}|
=======================

|o_j^{world}-h_i^{world}|
]

所以你的：

```text
obj_to_hand_min_dist
contact_target
edge_contact_target
candidate_mask
```

数学上完全不变。

QFL 也不用改。

sampling 也不用改。

model 也不用改。

**这是一个非常干净的 coordinate-frame ablation。**

## 我对这个设计的意见很明确

我建议改。

而且不是：

> object center → hand center

这种简单中心点替换。

而是明确改成：

[
\boxed{
\text{object-root SE(3) frame}
\rightarrow
\text{hand-root SE(3) frame}
}

其中：

[
\boxed{
