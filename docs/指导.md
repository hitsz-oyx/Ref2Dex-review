## 0. 任务背景

当前工作分支：

```text
reconstruct
```

当前重构提交已完成第一阶段 Task 内部组件化：

```text

supervision/

```

当前已经成立的结构：

```text

        ↓

        ↓
```


# 4. 新增 composition.py

新增：

```text
src/task/correspondence_ptv3/composition.py
```

## 4.1 核心职责

`composition.py` 负责：

```text
读取 raw task config
处理 new component config
处理 legacy flat config
识别 CLI explicit override
检查新旧 selector 冲突
补全 component defaults
类型 normalization
参数 validation
返回 canonical resolved configs
```

它不负责：

```text
实例化 nn.Module
创建 Dataset
创建 DataLoader
创建 Runner
move model to device
DDP wrapping
checkpoint load
```

即：

```text
composition = resolve / normalize / interpret
factory = instantiate
```

---

## 4.2 移动 component config dataclass

将当前 `config.py` 中：

```python
EdgeSamplerConfig
ContactSupervisionConfig
CorrespondenceModelConfig
```

移动到：

```text
composition.py
```

增加：

```python
from dataclasses import dataclass
from typing import Any


@dataclass(frozen=True)
class EdgeSamplerConfig:
    name: str
    params: dict[str, Any]


@dataclass(frozen=True)
class ContactSupervisionConfig:
    name: str
    params: dict[str, Any]


@dataclass(frozen=True)
class CorrespondenceModelConfig:
    name: str
    params: dict[str, Any]


@dataclass(frozen=True)
class ResolvedCorrespondenceComponents:
    edge_sampler: EdgeSamplerConfig
    contact_supervision: ContactSupervisionConfig
    model: CorrespondenceModelConfig
```

# 5. Resolved config 必须 canonical

Resolved config 必须满足：

```text
name lowercase
float -> float
integer -> int
sequence -> tuple
default 已补全
参数已 validation
不存在 unresolved selector ambiguity
```

例如 raw YAML：

```yaml
meta:
  edge_sampler:
    name: STRATIFIED
    distance_edges: [0.005, .015, 3e-2, 0.060]
    quotas: [16, 32, 32, 32, 16]
```

resolved：

```python
EdgeSamplerConfig(
    name="stratified",
    params={
        "distance_edges": (
            0.005,
            0.015,
            0.03,
            0.06,
        ),
        "quotas": (
            16,
            32,
            32,
            32,
            16,
        ),
        ...
    },
)
```

Factory 应可以假设传入的是 valid canonical config。

组件内部 defensive validation 可以继续保留。

# 6. 新 config 与 legacy config 规则

## 6.1 Canonical config

新 recipe 使用：

```yaml
model:
  name: ptv3_concat

meta:
  contact_supervision:
    name: soft

  edge_sampler:
    name: stratified
    distance_edges: [0.005, 0.015, 0.03, 0.06]
    quotas: [16, 32, 32, 32, 16]
    logit_near_radius: 0.005
    logit_far_min_radius: 0.03
```

这是 canonical source of truth。

```text

logit_sampling_mode

logit_stratified_quotas
k_near_logit
k_far_logit
logit_near_radius
logit_far_min_radius
```

继续支持。

但兼容方向必须是：

```text

```

## 6.3 Explicit conflict

保持当前规则。

例如 YAML：

```yaml
meta:
  edge_sampler:
    name: dense
```

CLI：

```bash
--set meta.logit_sampling_mode=stratified
```

如果 legacy selector 是 explicit override：

```text
raise ValueError
```

错误应明确：

```text
Conflicting edge sampler configuration
```

同理：

```text
meta.contact_supervision.name
vs
meta.contact_supervision_mode
```

如果 legacy 值只是 Config class fallback，没有 explicit override：

```text
new component config wins
```

# 10. Runner 一次 resolve composition

Runner 生命周期中只 resolve 一次。

建议增加：

```python
@property
def components(
    self,
) -> ResolvedCorrespondenceComponents:
    components = getattr(
        self,
        "_resolved_components",
        None,
    )
    if components is None:
        components = resolve_correspondence_components(
            self.cfg,
            explicit_override_keys=self.explicit_override_keys,
        )
        self._resolved_components = components
    return components
```

或者在适合的 Runner setup 生命周期中显式：

```python
self.components = resolve_correspondence_components(...)
```

注意 BaseRunner 初始化顺序。

不要在 `BaseRunner.__init__` 尚未设置：

```text
cfg
explicit_override_keys
```

前访问。

核心验收：

```text
同一个 Runner runtime
只 resolve 一次 composition
```

# 11. ContactSupervision 不得每 step build

删除当前：

```python
def _get_contact_supervision(self):
    return build_contact_supervision(...)
```

每次调用重新构造的行为。

改为 cache。

例如：

```python
@property
def contact_supervision(self):
    supervision = getattr(
        self,
        "_contact_supervision",
        None,
    )
    if supervision is None:
        supervision = build_contact_supervision(
            self.components.contact_supervision
        )
        self._contact_supervision = supervision
    return supervision
```

然后：

```python
obj_result = self.contact_supervision.compute_object_loss(...)
edge_result = self.contact_supervision.compute_edge_loss(...)
```

一次 Runner runtime 只 build 一次。

特别保证：

```text
contact_bin_weight_path
```

不会每 step 重复读文件。

# 27. 关键设计原则

必须遵守：

> Raw Config 进入 correspondence task 后，先 resolve composition。

之后业务代码使用：

```text
ResolvedCorrespondenceComponents
```

或由其构造出的 component。

不要继续：

```python

```

不要继续：

```python

```

不要在 Dataset、Runner、Model、Visualizer 各自解释 YAML。

允许：

```python
if config.name == ...
```

仅存在于 factory/composition boundary。
