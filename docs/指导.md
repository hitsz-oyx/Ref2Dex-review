## 一、QFL 本身是对的，不改

当前实现：

```python
pred_prob = torch.sigmoid(logits)
bce = F.binary_cross_entropy_with_logits(logits, target, reduction="none")
modulating_factor = torch.abs(target - pred_prob).pow(beta)
return modulating_factor * bce
```

即

[
L=|y-\sigma(z)|^\beta\operatorname{BCE}(z,y)
]

这和 QFL 原论文 Eq. (2) 一致；论文也明确指出连续 (y\in[0,1]) 是 QFL 要处理的情形，且 (\sigma=y) 是全局最优点，文中实验里 (\beta=2) 表现最好。 

所以这里**不要让 AI 再改 loss 公式**。

新的 target 也正确：

```python
return (1.0 - distance.float() / float(contact_radius)).clamp(0.0, 1.0)
```

random128 也是严格从全部 hand index 中均匀、无放回抽 128 个，没有距离输入，因此 supervision edge sampler 本身不存在距离分层偏置。

# 六、强烈建议改：coverage metrics 现在聚合不精确

这件事情很关键，因为我们特意增加 coverage metrics，就是想判断：

> random128 是否采不到 (d<1\text{ cm}) edge。

现在 batch 内计算没错：

```python
sampled_nonzero_edge_count
sampled_nonzero_edge_fraction
object_nonzero_edge_coverage
```

问题在 `step()`：

```python
metrics = {
    key: float(value.detach().cpu())
    for ...
}
```

这样所有 metric 都变成普通 float。

Base 对普通 float 使用 batch-size weighted averaging；而 Base 已经原生支持 `MetricStat(total, count)` 的 numerator/count 聚合。

DDP 也已经正确分别 SUM total/count。

所以应该直接用：

```python
MetricStat(
    total=sampled_nonzero_edge_count,
    count=valid_edge_count,
)
```

表示：

```text
sampled_nonzero_edge_fraction
```

以及：

```python
MetricStat(
    total=num_objects_with_nonzero_edge,
    count=num_valid_obj,
)
```

表示：

```text
object_nonzero_edge_coverage
```

否则当前 epoch metric 是：

[
\operatorname{mean}*{batch}
\left(
\frac{n*{\text{nonzero}}}{n_{\text{edge}}}
\right)
]

而我们真正想看的是：

[
\frac{
\sum n_{\text{nonzero}}
}{
\sum n_{\text{edge}}
}
]

这两个只有各 batch denominator 完全相同时才严格相等。

**既然这个 metric 要决定后续是否恢复 stratified sampling，我建议把它算严格。**

`step()` 同时要保留 `MetricStat`，不能无条件 float。

# 七、建议改：当前 overfit mode 已经不再真正 fixed-sample

runner 还专门实现了：

仍然每个 epoch 改 dataset epoch。

```text

epoch 1 -> 另一套 object / edge
```

这不是真正 fixed sample overfit。

你之前已经大量依赖 overfit test 做诊断，所以我建议不用新增 `fix_overfit_seed` 开关，直接：

```python
dataset_epoch = 0 if self.cfg.train.overfit_mode else epoch
```

这样不增加新 mode，只让已有 Base `overfit_mode` 语义成立。

# 九、有一个偏置仍然存在，但我暂时不建议改

虽然 hand supervision edge 是 uniform random128，但 object point 仍然来自：

```python

```

所以目前数据分布是：

```text
先只选择距离手 <= 5 cm 的 object candidate pool
        ↓

        ↓
每个 object 对全部 1538 hand points uniform random 128
```

因此：

> **edge sampling 没有距离偏置，但 object sampling 仍有 contact-region bias。**

我认为先不要改。

因为你当前任务本来就是 hand-object interaction region，不是预测整个物体表面的 arbitrary pair field。

但 README 应该明确写一句，避免以后我们误以为整个训练是完全 uniform sampling。

**QFL、target 和 random128 主训练逻辑可以保留。**

目前最明显的问题不是训练 loss，而是 **AI 把 visualization 糊成了一个 stub，同时 v2 清理得还不够彻底**。
