## 1. 增加 stratified sampling mode

如果当前已经有：

```python
meta.logit_sampling_mode
```

则保留现有模式，并增加：

```text
balanced
dense
stratified
```

如果本地还没有该字段，则新增：

```python
logit_sampling_mode: str = "balanced"
```

默认必须继续是 `balanced`，保证原 baseline 行为不变。

新增配置：

```python
logit_stratified_distance_edges: tuple[float, ...] = (
    0.005,
    0.015,
    0.030,
    0.060,
)

logit_stratified_quotas: tuple[int, ...] = (
    16,
    32,
    32,
    32,
    16,
)
```

要求：

```python
sum(logit_stratified_quotas) == 128
len(logit_stratified_quotas) == len(logit_stratified_distance_edges) + 1
```

配置不合法时立即抛出带明确信息的 `ValueError`。

五个距离层定义为：

```text
S0: d <= 5 mm                    quota 16
S1: 5 mm < d <= 15 mm           quota 32
S2: 15 mm < d < 30 mm           quota 32
S3: 30 mm <= d <= 60 mm         quota 32
S4: d > 60 mm                   quota 16
```

30 mm 必须进入 S3，因为当前 soft label 在 `d >= d_neg=30mm` 时已经是零标签。

分层只用于采样。监督 target 仍然直接调用现有 `soft_contact_label`，soft 模式仍使用 `BCEWithLogitsLoss`。


## 3. 每个距离层的初始采样

对每个 valid object point：

1. 使用 clean GT object/hand geometry 计算该 object point 到全部 hand points 的距离。
2. 根据上述五个区间建立候选池。
3. 每层在自己的候选池内随机无放回采样：

   ```python
   min(quota, candidate_count)
   ```
4. 相同 hand point 不得重复出现。
5. `logit_weight` 对所有 valid edge 设为 `1.0`。

随机性使用现有 `stable_frame_seed(..., namespace="logit-neighbors")` 体系。

正常训练时：

```python
fix_overfit_seed = False
```

因此不同 epoch 应产生不同的 edge sample。

相同 frame、epoch、base seed 下必须完全可复现。

## 4. 候选不足时的补齐策略

初始五层采样不足 128 时，必须尽可能补满到 128，但不得重复 hand point。

先将每层未被选择的候选随机打乱，然后按以下优先级 round-robin 补齐：

```text
S1 -> S2 -> S3 -> S0 -> S4
```

即：

* 优先补充 soft transition 和 hard negative；
* 其次补充强接触；
* 最后补充 easy negative；
* 每轮从每个仍有剩余候选的层取一个，再开始下一轮；
* 直到达到 128 或所有 hand points 都已使用。

不要直接从全部剩余 hand points 做一次全局均匀抽样，否则补位很容易被 easy negative 主导。

如果 hand point 总数小于 128，则：

```text
剩余槽位 idx=-1
valid=False
weight=0
```

对于 invalid/padding object point，整行必须是：

```text
idx=-1
valid=False
weight=0
```

## 5. Dataset 分发逻辑

在 Dataset `__getitem__()` 中根据：

```python
self.logit_sampling_mode
```

选择：

```text
balanced   -> 当前 near/far sampler，行为不变
dense      -> 当前 dense sampler，行为不变
stratified -> 新的 128 分层 sampler
```

`make_dataloaders()` 必须把以下配置传入 Dataset：

```python

```

不要在模型或 runner 中写死 `K=128`。模型继续从：

```python
logit_idx.shape[-1]
```

自然处理动态 K。

现有 per-object normalization 保持不变。

## 6. 不增加 object 分层采样

本实验明确保持当前 object point sampling 不变。

不要增加：

* object positive/transition/negative quota
* object contact-aware sampling
* object loss weighting

否则无法判断结果变化来自 edge sampling 还是 object sampling。
