## Goal

使 `verify.py --changed` 只选择可由 GitHub Actions 最小依赖重建的测试，不把需要 torch 的
framework contracts 测试当作轻量 CI 门禁。

## Changes

- `src/base/` 变更自动选择 `tests/test_run_manifest.py`，不再自动选择
  `tests/test_framework_contracts.py`。
- framework contracts 测试保留，作为完整运行时（含 torch）的显式集成验证；测试说明和
  治理测试记录该边界。
- CI workflow 不复制 Conda `graspenv`，也不新增 torch；根 work_version 前移至 V1.2e。

## Protected semantics

- 未删除、跳过或弱化 framework contracts 测试本身。
- 未修改研究代码、数据、cache、checkpoint、outputs 或本机 Conda 环境。
- CI 通过只证明轻量门禁，不冒充完整研究运行时回归。

## Verification

- `conda run -n graspenv python -m pytest -q tests/test_framework_contracts.py`：`8 passed`；
  证明完整运行时中的显式测试仍可用。
- `conda run -n graspenv python -m pytest -q tests/test_run_manifest.py tests/governance`：
  `13 passed`，有 3 条既有 NumPy alias FutureWarning，无测试失败。
- `conda run -n graspenv env VERIFY_BASE=origin/oyx python tools/verify.py --changed`：
  `VERIFY PASS`；自动范围不含 framework contracts 测试。
- `git diff --cached --check`：通过。合并推送后必须查询该 commit 对应 GitHub Actions run，
  并记录最终状态。
