## Goal

为目录合同不能决定位置的情况建立先询问、既成例外即时汇报和是否提升为长期规范的明确门槛。

## Changes

- 根 AGENTS 要求在未决位置写入前请求用户决定；发现既成例外时优先汇报路径、内容/规模、
  原因、偏离、影响、Git 状态和处理选项。
- `directory-and-artifacts` 成为该规则的唯一细则所有者：既成例外报告不构成追认，并须单独
  询问用户是否将个案提升为通用规则。
- `research-change-control` 只路由未决位置到目录 Skill 和用户确认，不复制目录合同。
- 新增治理测试，确保 AGENTS 与目录 Skill 可发现该门槛。

## Protected semantics

- 未创建、移动、删除或修改任何实际数据、cache、checkpoint、outputs 或用户文件。
- 已明确符合目录表的正常路径不增加额外确认步骤。
- 未改变任何 Task 的研究语义、坐标、单位、GT、split、metric 或 checkpoint 解释。
