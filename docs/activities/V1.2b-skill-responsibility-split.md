## Goal

把目录/产物与长任务操作从既有 Skill 中拆出为独立、可发现的合同，并移除逐路径
Activity-diff audit 脚本门禁。

## Changes

- 新建 `directory-and-artifacts`，作为目录、数据、cache、资产、输出、manifest 和测试归属
  的唯一 Skill 所有者。
- 新建 `long-running-tasks`，作为长任务启动、等待、监控、停止与恢复的唯一操作所有者。
- 收敛 `research-change-control` 为修改控制，收敛 `research-experiment-workflow` 为实验设计、
  证据和科学结论；根 AGENTS 与文档索引明确四个 Skill 的边界。
- 移除 `audit_diff.py`、audit reference 和专属测试。`verify.py --changed` 保留语法、结构、
  链接、版本合同和 hermetic 测试门禁；Activity 内容、提交范围和变更理由继续人工审阅。
- 根治理 `work_version` 前移至 V1.2b；不改写 V1.2a Activity 的历史事实。
