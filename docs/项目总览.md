# Ref2Dex 项目总览

## 项目目标

Ref2Dex 研究从人手参考动作中提取交互信息，并将其用于灵巧手操作、动作推理和跨 embodiment 优化。仓库包含数据预处理、点云 correspondence、交互表示学习以及各类下游任务。

本文档是项目级入口。具体任务的事实和运行方法由各 task 自己的 `docs/项目说明.md` 维护。

## 代码层级

- `process/`：原始数据到任务缓存、manifest 和中间数据的预处理。
- `src/base/`：共享配置、Runner、数据划分、checkpoint 和训练基础设施。
- `src/task/`：按研究任务组织的模型、数据集、Runner 和工具。
- `tests/`：影响实验结论可信度的聚焦测试。
- `src/task/<Task>/research/log.md`：任务级研究日志，保存假设、改动、定量结果和决策。
- `output/`（`exp/` 训练输出 + `research/` 分析产物）、`outputs/`、`data/processed_data/`：实验产物和缓存，不作为源码提交。

### PointWorldWAM

验证 PointWorld 的预训练 3D interaction backbone 能否迁移到 MANO 驱动的 GRAB 刚体
dynamics。V0 已完成 E0-E3、3000–7000 step 收敛/预训练消融与 held-out 诊断；V0.1 又验证
xyz feature、RPE、5 mm grid 和无 DropPath 的组合修改。训练集 ADE 从 16.23 mm 降至
14.76 mm；V0.2A 改为局部 hand point flow 到 object point flow，10000-step one-step error
降至 5.12 mm 且显著依赖正确 action，但仍未通过 1–2 mm gate，因此当时未进入 variable-span
或 rollout；随后按 V1 指导单独验证 inverse MANO branch。
V1 已实现 desired object point flow 条件的双手 MANO Flow Matching；128-transition debug
长训后 FM loss 下降，但生成 hand surface error 仍劣于 identity，因此没有扩到 6652 条全量数据。
V1.1 进一步实现 10 帧 world/action 联合 chunk WAM；3000-step debug 中 clean action 已能改善
forward，但 inverse 与 forward 均未超过各自零变化基线，因此没有扩到 6868 条全量窗口。
V1.2 修正逐 horizon normalization、world noise coordinate、object skip 与 action readout；
deterministic inverse/forward 均通过 30 mm gate；6000-step 单任务 FM 中 forward 通过，inverse
在完整 128 windows 上仍劣于 identity，因此未恢复 joint 或扩量。
