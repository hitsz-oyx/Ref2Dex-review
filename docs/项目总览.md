# Ref2Dex 项目总览

## 项目目标

Ref2Dex 研究如何从人手参考动作中提取交互信息，并将其用于物体动态预测、灵巧手操作、动作表示和跨 embodiment 优化。当前工程包含共享数据处理、训练基础设施和多个相互独立的研究 Task。

本文档只维护全局事实和 Task 索引。详细架构和维护记录见 [`docs/logs/`](logs/)，机器环境和绝对路径见被 Git 忽略的 `docs/logs/machine_memory.md`（若存在），Task 的模型、数据合同、运行命令和实验状态由各自的 `src/task/<Task>/docs/` 维护。当前版本见 [`docs/current_versions.yaml`](current_versions.yaml)，修改版本和操作分类见 [`docs/modification_policy.md`](modification_policy.md)。

## 目录与数据约定

- `process/`：数据集 adapter 及 Stage 2/3/4 预处理入口。
- `src/base/`：配置、Runner、数据划分、checkpoint、分布式与训练基础设施。
- `src/task/`：按研究 Task 组织的数据集、模型、Runner、配置和研究工具。
- `tests/`：影响实现和实验可信度的聚焦测试；根级 `pytest.ini` 将默认发现范围限制在此目录。
- `data/raw_data/`、`dataset/`：机器本地原始数据与数据集资源；`dataset/<name>/data/` 只属于外部数据集自身的输入入口。
- `data/processed_data/`：派生 cache、split 和统计，不纳入版本管理。
- `src/task/<Task>/assets/`：该 Task 使用的预训练模型、body model、URDF 等外部资产，不纳入版本管理；根 `assets/` 只允许历史兼容软链接。
- `outputs/`：正式训练和评估运行；`src/task/<Task>/research/<experiment>/output/`：研究诊断产物；两者均不纳入版本管理。
- 根级 `output/` 只保留历史兼容产物，不再作为新实验入口；不再创建 `results/` 或 `result/`。

## Task 索引

### InteractionDynamics

学习 hand-object interaction 表示及未来 object effect，并包含后续 interaction field、diffusion、MANO feasibility 与跨 embodiment 优化路线。

- [任务说明](../src/task/InteractionDynamics/docs/项目说明.md)

### InteractionTransfer

验证当前 hand-object relation 通过 hand action 形成动态 interaction message，并预测 one-step object effect。

- [任务说明](../src/task/InteractionTransfer/docs/项目说明.md)

### Cm

从当前 target object、当前单手状态和未来 hand point flow 学习 `C_m`，预测目标物体短时 point flow。当前主路线是 V1.2 object-only GRAB + ARCTIC，多数据集只共享数据合同，不把 `dataset_id` 输入模型；Scene Cache V1.1.2 保留为历史对照。

- [任务入口](../src/task/Cm/docs/README.md)
- [V1.2 指导](../src/task/Cm/docs/指导/V1.2.md)

### CmResidual

研究由耦合几何 reference 训练物理反馈 tracker，并在冻结 base tracker 后研究独立的 interaction residual。
V1.0 计划已定稿；当前只授权 V1.0.1 生成并离线验证单轨迹 fixed-wrist/q6 constrained reference，尚未授权
Isaac Gym、PPO、pilot 或长训。

- [任务入口](../src/task/CmResidual/docs/README.md)
- [V1.0 指导](../src/task/CmResidual/docs/指导/V1.0.md)
- [V1.0 最终计划](../src/task/CmResidual/docs/plan/V1.0.md)

### Posetoken

学习单帧 root-frame MANO 手表面的静态姿态表示和 morphology normalization。

- [任务说明](../src/task/Posetoken/docs/项目说明.md)

### Actiontoken

学习单个 root-local hand transition 的纯局部运动表示。

- [任务说明](../src/task/Actiontoken/docs/项目说明.md)

### PointWorldWAM

研究 PointWorld backbone 在 MANO 驱动刚体 dynamics、双向 action/world 生成和可实现性约束中的迁移。

- [任务说明](../src/task/PointWorldWAM/docs/项目说明.md)

## 已确认的全局事实

- 左右手默认作为独立 sample；是否合并必须由具体 Task 的数据合同明确规定。
- 点轨迹监督依赖跨帧稳定 point correspondence，不能把独立重采样点直接相减当作 GT flow。
- train/val/test 默认按 sequence 或更高层级实体互斥，禁止随机打散同一 sequence 的 frame。
- calibration、normalization 和统计量必须由 train split 得到，不能使用 val/test 拟合。
- 详细实验产物写入被忽略的输出目录，只有可复查的摘要证据写入 Task `docs/logs/experiment_log.md`。
- 全局环境、共享目录或 Task 关系变化时更新本文档；局部实现与结论只更新对应 Task 文档。
