# Ref2Dex 项目总览

## 项目目标

Ref2Dex 研究从人手参考动作中提取交互信息，并将其用于灵巧手操作、动作推理和跨 embodiment 优化。仓库包含数据预处理、点云 correspondence、交互表示学习以及各类下游任务。

本文档是项目级入口。具体任务的事实和运行方法由各 task 自己的 `docs/项目说明.md` 维护。

## 代码层级

- `process/`：原始数据到任务缓存、manifest 和中间数据的预处理。
- `src/base/`：共享配置、Runner、数据划分、checkpoint 和训练基础设施。
- `src/task/`：按研究任务组织的模型、数据集、Runner 和工具。
- `tests/`：影响实验结论可信度的聚焦测试。
- `src/task/<Task>/research/log.md`：任务级研究日志，保存假设、改动、定量结果和决策。
- `output/`（`exp/` 训练输出 + `research/` 分析产物）、`outputs/`、`data/processed_data/`：实验产物和缓存，不作为源码提交。

### Posetoken

从单帧 root-frame 手表面预训练静态姿态表示。V1 使用固定 morphology 的 synthetic MANO；V2 输入随机 beta、重建 beta=0 的同姿态 surface，学习 morphology normalization。动态动作、root SE(3) 和物体交互留给后续独立阶段。

- 任务说明：[`src/task/Posetoken/docs/项目说明.md`](../src/task/Posetoken/docs/项目说明.md)

- V2 规模化预训练指导：[`src/task/Posetoken/docs/指导/V2.md`](../src/task/Posetoken/docs/指导/V2.md)

### Actiontoken

V2 将 ActionToken 定义为单个 root-local transition 的纯局部运动表示：直接编码解析 dense point flow，不依赖 PoseToken、trajectory 或 temporal context；V1/V1.1 保留用于历史对照。

## 文档维护规则

1. 从本文件进入目标 task 的 `docs/项目说明.md`。
2. task 文档只索引与该任务有关的设计、数据和实验文档。
3. 全局目录、共享基础设施或任务关系变化时修改本文件。
4. task 局部 schema、模型、命令或结论变化时修改对应 task 文档。
5. 有意义的实验结果同时写入对应任务 `src/task/<Task>/research/log.md`。
